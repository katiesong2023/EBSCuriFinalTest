# Task R08-09 - 교육과정 공백별 공식 내용 원문 보강

## 설명

이미 확보한 자료의 수보다 선택 기준의 요구를 설명할 수 있는 원문을 늘리는 데 집중한다. 기존 보강 목록을 활용해 후보가 없는 과학 주제, 제목뿐인 회차, 필요한 관계 설명이 없는 자료부터 공식 공개 근거를 확보한다. 사용자 우선순위 5를 담당한다. 상태: **진행중 — 2026-10-11 구현·검증 완료, 사용자 결과 확인 대기**.

2026-10-05 [보관 지표](../docs/r08-06-improvement-summary.json)의 최소 원문 통과는 판본 포함 **4,711/23,360건(약20.17%)**이다. 기본 카탈로그의 4,685/22,118과 분모가 다르며 현재 재측정 값으로 사용하지 않는다. 2026-10-10 확장 기록의 후보 없는 기준18개·규칙 미지원210개도 서로 다른 공백이다. 구현 시작 시 같은 분모와 버전으로 기준선을 다시 확인한다.

## 구현 항목

- [x] 기존 교육과정 공백·원문 보강 목록을 현재214개 기준에 맞춰 갱신한다. 후보 없음, 제목뿐, 소개문 부족, 요구 관계 설명 부족과 자동 비교 미지원을 분리해 보강 이유를 제시한다. 규칙만 없는 자료를 내용 원문 부족으로 간주하지 않는다.
- [x] 후보가 없는 과학 주제를 먼저 확인하고 제목뿐인 회차·필수 관계 설명이 없는 자료를 우선 보강한다. 사회·과학을 모두 핵심 범위로 유지하고, 여섯 과정·교과 구간별 공백과 선택한 보강 대상·선정 이유를 기록한다.
- [x] 기존 공식 상세 수집 경로로 소규모 보강을 실제 수행한다. 시작 전에 대상 회차·기준·현재 부족한 요구를 기록하고 시도·회차 일치·내용 증가·변경 없음·실패·다른 회차 도착을 각각 남긴다. 원문을 찾지 못한 시도도 결과에 포함한다.
- [x] 공식 공개 대본·학습자료가 있는지 확인하고, 확보 가능한 자료는 회차 식별과 출처를 대조한 뒤 해당 회차의 보조 근거로 연결한다. 자료 유형·출처 URL·판본/게시 또는 확인 시점·정확한 인용 위치를 보존한다. 해당 회차와의 연결이 불명확하면 근거로 확정하지 않는다.
- [x] 공개 대본·학습자료와 소개문을 구분해 검색·요구별 비교에서 사용할 수 있게 한다. 교재 일반 설명·같은 프로그램의 다른 회차·같은 제목의 다른 판본을 해당 영상의 내용 증거로 전파하지 않는다. 대본 확보를 실제 장면·재생시간 확인으로 표시하지 않는다.
- [x] 보강 후 영향받은 관계를 재비교하고 원문 변경에 따른 기존 확인의 재검사·무효화를 적용한다. 원문이 길어졌다는 이유만으로 자동 공개나 사람 확인을 생성하지 않는다.
- [x] 같은 검색·관계 판정 조건에서 원문 보강 전후를 비교한다. 고유 회차와 판본 포함 건수, 최소 원문 통과, 후보 없는 기준, 요구별 인용 확보, 자동 비교 미지원의 수치와 분모를 따로 기록한다.

## 범위 밖

## 실제 구현·검증

`source-supplements.js`, `curriculum-source-queue.js`, `source-gap-metrics.js`, `broadcast-store.js`, `curriculum-discovery.js`, `curriculum-evidence.js`, `teacher-source.js`, `teacher-evidence.js`와 교육과정 화면에 회차별 공식 보조 문서·별도 출처/인용·보강 사유·과학 공백 탐색을 연결했다. 보조 발췌는 후보 발견 근거에 쓰며 자동 요구 판정은 소개문으로 제한한다.

개발용으로 고정한7회차에 기존 공식 상세 경로를 실행했다. [실제 보강 기록](../docs/r08-09-enrichment-run.json)은 증가4·동일1·근거 부족2·실패0·다른 회차0이다. [공개 링크 점검](../docs/r08-09-public-material-search.json)에서 대본·학습자료는 확보하지 못했다. 사이트 전체에 없다고 판정하지 않는다. 방송일을 대조한 라오스 소금마을1부 [공식 보도자료1건](../docs/r08-09-supplement-run.json)을 소개문과 별도로 연결했다. 영상/장면은 미확인이다.

[계약11개](../docs/r08-09-source-contract-check.json), [실제 보조문서 연결6개](../docs/r08-09-supplement-discovery-check.json), [화면3개](../docs/r08-09-source-browser-check.json)를 통과했다. 소규모 보강으로 판본 포함 최소 소개문4,711→4,713/23,360, 후보 관계8,544→8,569/214, 고유 후보2,899→2,901이며 후보 없는 기준16개·미지원210개는 유지됐다. 소개문 최소 기준과 보조 문서1건은 별도 집계한다.

[전](../docs/r08-09-before.json)·[후](../docs/r08-09-after.json)는 자동 링크를 빈 배열로 고정한 비교 집계다. [운영 상태](../docs/r08-09-operational-state.json)는 사람 승인0·자동 공개1·기존 curi-store SHA 불변을 확인했다. 기존 농경문 자동 후보는 새 규칙으로 명시적으로 재검사했고 이전 이력을 보존했다. 원문 변경 무효화는 기존 자산26개 회귀의 격리 사례에서 확인했다. 독립33관계와 인접 판본은 보강에서 제외했다.

재현: `node server/source-supplements-check.js`, `node server/source-gap-metrics.js docs/r08-09-after.json`. 공식 상세 수집은 명시적 운영 실행이며 검사 재현 시 전수 실행하지 않는다.
