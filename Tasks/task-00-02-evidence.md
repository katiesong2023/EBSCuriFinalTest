# Task 00-02 - 공개 메타데이터 문제 증거 확보

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

일반 방송 VOD와 학교용 클립의 공개 필드 차이를 심사에서 보여줄 증거로 만든다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: 준비
- 예상 집중 작업: 약 1시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Luna** (`gpt-5.6-luna`)
- 추천 추론 수준: **low**
- 선택 이유: 정해진 비교 항목의 수집·정리에 적합하며 내부 업무를 추론할 필요가 없다.
- 상향 조건: 요구사항이 모호하거나 수정이 여러 파일·상태로 번지면 해당 문제만 Terra / medium으로 올린다.
- 사람 판단/수행 포함: 모델은 양식·대조·정리를 보조한다. 직접 검수·채점·시간 측정·녹화·발송의 수행 사실을 대신 만들지 않는다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.

### 관찰 한계와 가설

- **확인한 사실:** 위 URL의 공개 화면과 저장소의 원본 표본(`ebs_raw_docuprime_409.csv`, `ebs_official_clip_seed_68.csv`)에서 확인한 필드 차이만 기록했다. 일반 VOD 원본 표본에는 프로그램명·제목·방송일·상세 URL·식별자·이미지 URL이, Clip 원본 표본에는 학년·교과·단원차시·조회·좋아요가 있다.
- **확인하지 못한 항목:** EBS 내부 CMS의 입력 필드, 담당 부서, 월 처리량, 실제 업무시간은 확인하지 않았다. 공개 웹페이지의 보이는 필드만으로 내부 저장 구조나 업무량을 추정하지 않는다.
- **가설(검증 전):** 일반 아카이브에 2022 교육과정 기준의 학년군·교과·성취기준·연계근거를 만들고 사람이 검수하면, 교사 수업 언어 검색에 재사용할 수 있다. 이 가설의 품질·시간 효과는 이후 Gold, 검색 평가, 수작업 기준선 task에서 별도로 측정한다.
