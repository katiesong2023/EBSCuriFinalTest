# Task R07-10 - 공식 편성 안내·성취기준 해설·과정별 검색 예시

## 설명

사용자가 추가한 중학교 교육과정 한글 원문과 기존 사회·과학 PDF를 활용하여 편성 안내의 공식 근거, 기준 해설을 통한 요구·근거 비교, 초3~6·중1 참고 과정의 균형 있는 검색 예시를 보강한다. 특정 학교의 진도나 영상의 학년 적합성을 공통 사실로 확정하지 않는다. 상태: **진행중**. 아래 과정별 예시 화면의 구현/확인 항목은 당시 기록이다. 현재 화면 구성과 결과 확인은 [R07-11](task-r07-11-search-simplification.md)의 과정별 목록 제거·기본18예시·상세 필터 구성을 따른다.

## 구현 항목

- [x] 중학교 학년군·중1 참고 구성·교사의 수업 진도 선택을 공식 편성 근거와 함께 안내한다.
- [x] 선택 성취기준의 공식 해설과 단원별 적용 시 고려 사항을 원문·출처와 함께 제공하고 영상 인용·자동 비교 상태와 구분한다.
- [x] 초3~4·초5~6·중1 참고의 사회·과학 핵심 영역을 고려한 검색 예시를 실제 결과와 대조하여 제공한다.
- [x] 기존 조건 해제·검색 저장·수업 폴더·승인 및 자동 자산의 상태를 보존한다.

- 새 자동 의미 판정 규칙, 영상 전수 시청·학년 적합성 확정

## 구현 결과

- 공식 편성 안내는 추가된 중학교 한글 총론의 추출 문단209·341·342를 인용한다. 학년군별 내용 배열의 조정과 학년별·학기별 자율 편성 근거이며 특정 학교의 중1 배치를 확정하지 않는다. HWP 위치는 추출 문단 번호이고 인쇄 쪽 번호가 아니다.
- `server/hwp-source-text.js`·`curriculum-guidance-pdf.py`·`curriculum-guidance-build.js`로 공식 코드와 본문을 대조하여 `server/data/curriculum-guidance.json`을 생성했다. 214기준·73단원, 개별 해설171개·별도 해설 없음43개, 단원별 고려 사항214기준을 제공한다. PDF는 두 추출기의 문자 일치와 띄어쓰기를 대조하고 파일 SHA·발췌 위치를 보존한다.
- `curriculum-guidance.js`는 현재 공식 기준 본문·판본이 일치할 때만 읽기 전용 안내를 반환한다. 요구 계획과 선택 기준 비교 응답에 `guidance`·`placementGuidance`를 연결했다. 기존 탐색어·네 자동 규칙·승인 저장소는 변경하지 않았다.
- `public/teacher-guidance.js`가 선택 기준과 검색 카드에 공식 해설/단원별 고려 사항·출처·교사 비교 질문을 제공한다. 공식 교육과정 설명은 영상 내용 인용·자동 검사·학년 적합성 확인과 구분한다. 현재 선택 기준 비교가 있는 자료의 내보내기에도 안내를 포함한다. 기존 일반 내 자료 새로고침은 요청별 비교를 지우므로 영상 인용을 과거 상태에서 되살리지 않는다.
- 대표 예시는 사회 도시/독립운동/인권/민주주의/다문화, 과학 생태계/소리/전기/연소/태양계, 공통 기후 변화다. 확장 예시20버튼은 초3~4·초5~6·중1 참고의 사회/과학 여섯 묶음으로 구성했다. [원문 대응·검색량·상위 결과](../docs/r07-10-search-examples-review.json)를 기록했다. 과정·영역의 균형→검색 관련성→원문 확보→결과 수 순으로 검토했고 증발1건 등 핵심 주제도 유지했다. 전체 성취기준 충족·영상 적합성 판정은 아니다.

## 검증 기록

- 새 원문/표시 계약5개와 격리 브라우저5개 통과: [계약](../docs/r07-10-guidance-check.json), [화면](../docs/r07-10-guidance-browser-check.json).
- 기존 결합 검색20·선택 근거7·학년/폴더6·통합 화면14·개인 문맥8 통과. 새 검사 포함65개 통과, 페이지 오류0·유료API0·보호 저장소4개의 SHA 동일.
- 공식 안내 재생성 `--check` 일치, JS 구문·차이 공백 검사 통과. 사회 PDF 원문과 390px 모바일/데스크톱 캡처를 육안 확인했다.
- 재현: `python3 server/curriculum-guidance-pdf.py --output /private/tmp/curi-guidance-pdf-input.json` (pypdf·pypdfium2 필요), `node server/curriculum-guidance-build.js --pdf-pages /private/tmp/curi-guidance-pdf-input.json --check`, `node server/curriculum-guidance-check.js`. 화면 검사는 `node server/curriculum-guidance-browser-check.js`이며 Playwright/브라우저 경로 환경 변수를 사용한다.
- 사용자 서버는 재시작하지 않았다. 구현·에이전트 검증 완료, 사용자 결과 확인 대기로 진행중이다.
