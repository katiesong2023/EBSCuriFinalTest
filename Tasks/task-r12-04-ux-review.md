# Task R12-04 - UX 별도 검토·수정 지시

## 설명

교사가 요청 입력부터 비교·원문/영상 확인·선택·수업 폴더 재사용까지 진행하는 동선을 별도 UX 트랙에서 검토한다. 먼저 정리한 수정 지시를 남기고 R12-05가 이를 기준으로 반영한다. 상태: **진행중**. 2026-10-14 사용자 요청으로 등록했다.

## 구현 항목

- [x] 현재 제품의 데스크톱/작은 화면에서 사회·과학 개발 요청으로 입력→결과 이해→비교→원문/영상 확인→선택 이유 기록→저장/재열기 동선을 검토한다. 빈 결과·로딩·실패 복구·조건 수정·키보드 접근도 포함한다.
- [x] 실제 화면과 행동을 근거로 문제 위치·재현 조건·사용자 영향·심각도·수정 지시·기대 동작·확인 기준을 정리한다. 에이전트 UX 검토와 실제 교사 관찰을 구분한다.
- [x] 검색 결과가 부적절한 문제와 좋은 자료가 있어도 설명/비교/저장을 못 하는 문제를 분리한다. 자료 부족을 문구나 카드 디자인으로 해결했다고 보고하지 않는다.
- [x] 교사가 결과에서 내용·내 요청과의 연결·남은 확인·원문 접근을 이해할 수 있는지, 선택과 제외 이유를 남기고 다시 사용할 수 있는지 검토한다.
- [x] 수정 지시를 필수/후속/보류로 정리하고 기존 개인 기록·교육과정/원문/영상 확인의 의미를 유지하는 범위를 명시한다. 지시와 반영 여부를 추적할 식별자를 부여한다.
- [x] UX 수정 지시의 정리본과 화면 근거를 먼저 제시한다. R12-05는 이 정리본을 기준으로 반영하며 사용자 수정 의견이 있으면 먼저 지시에 반영한다. 별도 승인을 임의로 추가하지 않는다.
