# Task P0B-03 - 프로그램 필터

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R03 / 기존 구현 재사용**. 프로그램 필터는 구현되어 있으므로 새 기능으로 재구현하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

출처 기반 홈페이지의 프로그램 필터는 02-10E에서 구현됐다. R03 회귀 검증 대상으로 재사용한다. 종전 승인 검색의 선택 확장과 새 탐색 프로그램 조건을 혼동하지 않는다.

## 작업 크기와 추천 모델

- 구분: P0-b 선택 확장
- 배치: 선택
- 예상 집중 작업: 약 1시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Luna** (`gpt-5.6-luna`)
- 추천 추론 수준: **low**
- 선택 이유: 기존 검색에 정해진 조건 하나를 붙이는 좁은 기능이라 Luna가 효율적이다.
- 상향 조건: 요구사항이 모호하거나 수정이 여러 파일·상태로 번지면 해당 문제만 Terra / medium으로 올린다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.
