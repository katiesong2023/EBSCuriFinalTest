## 구현·검증 결과 — 2026-10-14

사용자가 명확한 개선까지 진행하도록 승인하여 공식4소개 복구에서 멈추지 않고 공개 자막·검색 연결·화면 인용까지 구현했다. [개선 보고서](../docs/r07-21-improvement-report.json), [공식4복구](../docs/r07-21-official-source-applied.json), [공개 자막6대조](../docs/r07-21-official-caption-audit.json), [자막5연결](../docs/r07-21-caption-attached.json), [저장 변경 검증](../docs/r07-21-store-change-check.json)을 제공한다.

원문 부족12대상 중 소개문4개 + 서로 다른5회차의 공식 공개 자막을 확보하여9개에 내용 원문을 보강했다.6미확인 중5개는 HTML의 공통/첫 회차 메타데이터와 달리 실제 플레이어 선언에서 같은 회차의 제목·프로그램·courseId/stepId/lectId·자막 참조를 대조할 수 있었다. 외부 스크립트/영상은 실행하지 않고 정적 선언만 읽었다. SMI의 SYNC 시간 순서·공개 자막 텍스트·페이지/자막 해시를 기록했다. 자막 발행일은 미확인, 회차 방송일은 identity에 별도 보존한다. 보조 원문은 소개문과 합치지 않는다. ‘신기한 자석 놀이’는 선언 대조 실패, 두 공장 회차는 상세도 제목 수준으로 남아 있다. 검색에서 찾은 보도자료/누리샘 제목 단서는 날짜·회차/판본 대조 전 연결하지 않았다.

### 실제 개선과 한계

| 같은 검색 | 전 | 후 | 확인된 개선 |
| --- | --- | --- | --- |
| 제시 피난 생활 | 0 | 1 | 독립운동가 부부 회차의 실제 소개문/인용 발견 |
| 천연벽지 제작 | 0 | 1 | 제작·시공을 명시한 소개문/인용 발견 |
| 자석 | 0 | 2 | 같은 회차 공개 자막을 근거로 두 자료 발견·기본 선택 영역의 인용 표시 |

앞2개는 복구 원문을 확인해 고정한 발견 probe, 자석은 좁은 주제 발견 probe다. 새 독립 평가나 모든 요구 충족률이 아니다. 코드에는 회차ID/질문별 검색 분기를 넣지 않았다. 수신된 긴12질문은 같은 로컬 경로에서 모두0→0으로, 관계/형태/제외를 포함한 전체 요청 처리 개선은 입증하지 못했다. 이를 원문 보강 성과로 대체하지 않는다. 자석 회차의 붙음/붙지 않음·극/밀어냄은 공개 자막에 근거한 내용 확인이며 실제 영상 장면·실험 형태/학년 적합성 승인이 아니다. 원래 가상광물 질문에 부적합한 후보의 자막도 수집됐지만 정답으로 승격하지 않는다.

### 실제 코드·검증

- `source-restoration-apply.js`: 기존 공식 상세 복구/이력 경로로4개만 변경하고 조사 이후 해시·변경 회차·보호3저장소를 대조한다. 변경 전 전체 회차 백업은 `/private/tmp/curi-r07-21-broadcast-before.sqlite`에 보존했다.
- `source-gap-audit.mjs`: 공식 TV 표면/목록 prodId를 보존한 주소도 재대조했다. 새로운 주소가 맞다는 추측으로 기존 회차를 덮어쓰지 않았다.
- `official-caption-audit.mjs`: 공식 HTML의 플레이어 식별·자막 참조와 공개 SMI를 읽기 대조한다. 발췌는 제목 어휘가 많은 구간을 고르는 보조 선택이며 관계 적합성 판정은 아니다. 인계 JSON에 원문 구절·SYNC 시간·출처/지문을 보존한다. 기존 `attachOfficialSupplement`로 실제5자막을 연결했다.
- `supplement-search.js`·`semantic-layer.js`: 회차/판본/원문 해시가 일치하는 보조 원문에 기존 문맥 검사를 적용한다. 주제 태그의 field/supplementId/offset은 실제 보조 원문에 대응한다. 소개문 태그·승인 정본을 덮어쓰지 않는다. 자석의 붙음/끌어당김/밀어냄을 기존 물리 문맥 어휘에 보강했다.
- `discovery-search.js`·`source-explanation.js`·`teacher-source.js`: 같은 회차 보조 텍스트를 발견/제외 대조에 사용하고 별도 원문 인용을 기본 선택 영역과 상세에 표시한다. 영상·관계 미확인을 유지한다. 실제 소개문 품질과 보조 원문 확보는 서로 다른 표시다.
- 별도 의미 검색 SQLite는8구절만 재임베딩/28,277구절 재사용으로 갱신했다. 자막은 기존 제목/소개문 E5 색인과 분리하며 이번 보조 검색은 검증된 원문 어휘/문맥 경로다. SQLite의 기존 시맨틱 태그 정본은 변경하지 않았다.

[복구7검사](../docs/r07-21-source-restoration-check.json), 기존 보조자료11·질의27·결합20, [실제3000/390px/저장4검사](../docs/r07-21-running-browser-check.json)가 통과했다. 회차/판본/해시 변조 자막 거절과 보조 원문 인용 slice·소개문 분리·영상 미확인을 확인했다. 모바일 기본 인용·상세·넘침/오류0을 확인했고 [화면](../docs/r07-21-magnet-mobile.png)을 육안 확인했다.

방송23,360회차 수 유지·회차행9개만 변경(4소개/5보조payload), 이력·FTS와 재생성 의미 검색 색인 갱신. 승인JSON·시맨틱SQLite·자동자산SQLite SHA 동일. 유료 호출/영상 재생0. localhost:3000에 반영했다. 구현 검증은 마쳤으며 사용자 결과 확인 전 task 상태는 진행중이다. 남은3자료는 R07-22에 미확인 항목으로 인계한다. 긴 질문 처리와 실제 A/B 효과는 R07-19에 남긴다.
