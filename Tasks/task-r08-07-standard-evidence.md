# Task R08-07 - 선택 성취기준별 확인 상태와 요구·근거 비교

## 설명

자료 자체의 확인 이력과 선택한 성취기준에 대한 확인을 구분해, 교사가 해당 기준에서 무엇이 확인됐고 무엇이 남았는지 정확히 판단하도록 한다. 사용자 개선 요청의 우선순위 1~3을 담당하는 첫 개발 단계다. 상태: **진행중 — 구현·기술 검증 완료, 사용자 결과 확인 대기**.

2026-10-10 저장 기록의 공식 기준은 214개이고 자동 관계 규칙은 4개 기준만 지원한다. 초등 3~4·중1 확장은 R09-01에서 구현했으며 사용자 결과 확인을 대기한다. 현재 사람 승인·승인 검색 투영은 0건, 부분 자동 공개는 1건이다. 이전 사람 승인 4건은 취소 이력으로 보존하며 되살리지 않는다. 10월 5일의 78개 기준 수치는 과거 기준선이다.

## 구현 항목

### 1. 선택 기준에 한정한 확인 표시

- [x] 교육과정 후보 카드의 첫 확인 줄에 선택 기준 코드와 해당 관계의 현재 상태를 함께 표시한다. 사용자 제시 예시인 **“선택 기준 6사04-01: 부분 연계 후보”**처럼 읽을 수 있게 하고, 사람 확인인지 자동 비교인지도 구분한다.
- [x] 같은 자료의 다른 성취기준 확인은 별도로 펼쳐 볼 수 있게 한다. 다른 기준·과정·교과·판본의 승인이나 자동 후보가 선택 기준의 배지·건수·필터 결과로 전파되지 않게 한다. 선택 기준이 없는 일반 검색의 자료별 이력과도 구분한다.
- [x] 기준 전환·뒤로가기·새로고침·내 자료·수업 폴더·내보내기에서 선택 기준의 범위를 일관되게 유지한다. 재확인 중·실패·원문 변경·승인 취소 상태를 과거의 유효한 확인처럼 표시하지 않는다.

### 2. 검사 가능 범위와 자료 근거의 분리

- [x] 자동 비교 지원 여부, 원문 충실도, 요구별 근거, 실제 사람 확인을 구분해 카드·상세·필터·공백 집계에서 같은 의미로 사용한다. 한 자료가 규칙 미지원이면서 소개문도 부족한 경우 두 사실을 함께 남긴다.
- [x] 다음 차이를 사용자가 식별할 수 있게 한다. 아래는 요구 의미이며 내부 상태 이름·최종 UI 문구는 구현 시 확정한다.

| 구분할 의미 | 표시·판정 경계 |
| --- | --- |
| 해당 기준의 자동 비교 미지원 | 시스템의 검사 범위다. 자료의 교육적 부적합이나 관계 설명 부재로 집계하지 않는다. |
| 소개문 부족 | 제목뿐·반복 문구 등 기존 원문 품질 분류와 연결한다. 내용 확인이 부족하다는 뜻이다. |
| 관련 개념만 확인 | 실제 확인한 개념과 아직 확인하지 못한 요구 관계를 구분한다. 미지원만으로 이 상태를 확정하지 않는다. |
| 일부 요구를 뒷받침하는 설명 확인 | 확인한 요구와 정확한 인용을 제시하고 나머지 요구를 명시한다. 전체 기준 충족으로 승격하지 않는다. |
| 표현 해석 보류 | 부정·의문·조건 등의 의미를 확정하기 어려운 이유를 표시한다. |
| 명확한 상충 | 어떤 요구 관계를 원문이 명시적으로 부정하거나 다르게 설명하는지 제시한다. 해석 보류·원문 부재와 구분한다. |

- [x] 미지원 자료를 교육적 부적합으로 자동 제외하지 않는다. 미지원과 원문 부족, 실제 비교 결과의 분모를 따로 집계하고 항목이 겹치면 중복 가능성을 밝힌다. 기존의 유효한 사람 확인·자동 검사 기록은 각 확인 범위대로 제공한다.
- [x] 기존 `CONFLICT`를 그대로 명확한 상충으로 이름만 바꾸지 않는다. 어떤 요구 관계를 명시적으로 부정하는지 입증하지 못한 기존 결과는 해석 보류로 표시한다. 부정 대상·문맥 판정 자체의 개선은 R08-08에서 이어간다.

### 3. 기준의 요구와 인용을 직접 대응

- [x] **기준의 요구 → 콘텐츠가 제공하는 내용 → 정확한 인용 → 남은 요구**를 요구별로 대응시켜 비교한다. 한 인용이 여러 요구에 사용되면 각 대응 이유를 명시하고, 여러 문장을 근거 없이 합쳐 하나의 관계를 입증하지 않는다.
- [x] 인용에는 해당 회차·출처·원문 위치와 확인 가능한 버전을 연결한다. 후보를 발견한 단어와 관계를 뒷받침하는 문장을 구분하며, 공식 기준의 원문·내용 요약·직접 인용·교사 활동 제안을 혼합하지 않는다.
- [x] 농경문 청동기–`6사04-01`은 청동기 유물·농경 문양의 근거와 고조선 소속·당시 생활 전반의 미확인을 설명 가까이에 함께 표시한다. 학생의 생활 추론은 교사가 연결할 수업 활동이며 자료만으로 수행·달성이 확인된 것이 아님을 명시한다.
- [x] 요구 분해가 미지원인 기준은 공식 문장을 유지하고 그 한계를 표시한다. 요구·근거를 만들어 채우거나 전체 자동 비교가 가능한 것처럼 표시하지 않는다.

## 구현 결과와 검증 — 2026-10-11

- `server/curriculum-evidence.js`가 선택 기준 코드·교과·과정에 맞는 관계와 다른 기준 이력을 분리한다. `curriculum-discovery.js`는 미지원·원문 부족·비교 결과의 겹치는 필터와 분모를 제공하며 판본을 필터한 뒤 묶는다.
- `public/teacher-evidence.js`·`teacher-storage.js`가 교육과정 카드·내 자료·폴더·내보내기에 같은 선택 범위를 적용한다. 다른 기준은 **다른 기준의 확인 기록**으로 접고, 재확인 중·실패·자료 소실 시 과거 비교와 관계 배지를 숨긴다. 저장된 과거 비교가 새 응답에 없으면 현재 상태로 되살리지 않는다.
- `curriculum.js`·`curriculum.html`·`admin-curriculum.html`·`curriculum.css`에 **자동 비교 범위 / 원문 충실도 / 선택 기준의 원문 비교**와 **기준의 요구 → 내용 → 인용 → 남은 요구**를 표시한다. 인용의 회차·출처·위치·버전·지문은 **인용 출처·원문 위치**에서 확인하며 후보 발견 문장은 별도로 접는다.
- 미지원 기준은 공식 문장을 그대로 남기고, 농경문 자료에는 고조선 소속·생활 전반 미확인과 교사의 생활 추론 활동 경계를 가까이 표시한다. 기존 `CONFLICT`는 요구별 입증 없이 명확한 상충으로 이름만 바꾸지 않는다. 부정 문맥 개선은 후속 R08-08에서 수행했다.
- [서버 계약 7개](../docs/r08-07-standard-evidence-check.json), [화면·저장 7개](../docs/r08-07-browser-check.json), [기존 교육과정·관리자 자동 저장 10개](../docs/r08-07-regression-curriculum.json), [학년 검색 회귀 6개](../docs/r08-07-regression-grade-search.json)가 통과했다. [PC](../docs/r08-07-evidence-desktop.png)·[390px 모바일](../docs/r08-07-evidence-mobile.png) 표시와 입력 실패 뒤 이전 카드 제거·재시도를 확인했다. 격리 기능 검사이며 실제 교사 의미 평가는 수행하지 않았다.
- 재현: `node server/standard-evidence-check.js`, `node server/standard-evidence-browser-check.js`. 브라우저 검사는 `CURI_PLAYWRIGHT_MODULE`·`CURI_BROWSER_EXECUTABLE`을 설정한 격리 서버에서 실행한다. 후속 규칙 변경에 따른 자동 자산 무효화와 최종 공개 수치는 R08-08·R09-02의 해당 시점 결과로 구분한다.

## 수동 작업

필수 외부 설정은 없다. 실제 관계의 교육적 의미와 수업 활용 판단은 사용자 선택에 따른 후속 확인이며, 전량 사람 승인을 요구하지 않는다.
