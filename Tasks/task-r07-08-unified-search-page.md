# Task R07-08 - 교사 검색 화면과 성취기준 선택 통합

## 설명

자료 찾기를 기본 화면으로 두고 교육과정 조건을 선택적으로 펼치는 한 페이지를 제공한다. 교사가 검색 방식을 먼저 선택하거나 페이지를 옮기지 않아도 검색·조건 조정·자료 확인을 이어갈 수 있게 한다. 상태: **진행중**. 2026-10-11 구현·에이전트 검증 완료, 사용자 결과 확인 대기.

## 권장 개발 모델

- **GPT-6.1 Sol · Medium** (`gpt-6.1-sol`): 정리된 범위와 기존 시안을 바탕으로 화면·검색 상태·접근성을 함께 연결한다.
- 확정된 문구 대조와 한정된 반응형 표시 수정은 GPT-6 Luna · High로 처리할 수 있다. 새 시안을 여러 개 제작하지 않는다.
- 개발 모델 추천이며 공통 사용 원칙은 [PLANS](../docs/PLANS.md#검색-화면-통합-후속-계획--2026-10-11)을 따른다.

### 검색 관련 기준 우선 표시 — 2026-10-11 추가 수정

- 사용자 요청으로 ‘검색 관련 기준’과 ‘전체 기준 보기’를 추가했다. 질문이 있으면 관련 후보 최대8개를 먼저 보여주고, 질문이 없으면 전체 기준을 표시한다. 공식 문장·코드 직접 입력은 전체 기준 탐색으로 전환한다. 교과·과정 목록 조건은 두 보기 모두에 적용한다.
- `server/curriculum-related.js`와 `GET /api/curi/curriculum/related?q=...&subject=...&grade=...`가 현재 공식 기준의 문장·탐색어/별칭과 질문의 긍정 주제를 대조한다. 기준 코드·구체 어휘·기존 주제 표현으로 순서를 정하며 관련 이유와 후보 수를 반환한다. 자동 비교 미지원·방송 후보0건인 기준도 제외하지 않는다. 관계 승인·기준 충족·영상 적합성 판단과 별개인 로컬 어휘 후보이며 의미 검색의 전수 정확도를 주장하지 않는다.
- 관련 후보0건·조회 실패는 전체 기준 탐색으로 복구할 수 있다. 질문 변경 때 이전 후보를 지우고 중단/요청 대조로 늦은 응답을 차단한다. 후보 표시는 자료 검색·선택 조건을 자동 변경하지 않는다. `standardView`는 URL/기존 검색 키에 보존하는 브라우저 전용 보기 값이다.
- 사용자 보고의 동일 결과 문제는 실행 중이던 `127.0.0.1:3000`의 이전 서버가 세 다른 기준에도20749건·동일ID를 반환한 것으로 확인했다. 사용자 요청으로 해당 서버를 종료했다. 추가로 화면에서 요청 기준과 응답 기준/검색 모드를 대조하여 구버전 응답을 정상 카드로 표시하지 않도록 했다. 에이전트는 사용자 서버를 재시작하지 않았다. 이후 현재3000서버는 기준 검색3건을 반영했지만 새 관련 기준 API는401로 최신 모듈 미반영을 확인했다. 추가 수정 확인 전 서버 재시작이 필요하다.
- 통합 화면 검사에 관련 후보·전체 보기/복원·교과/과정·미지원 포함·빈/부정/실패/늦은 질문·구버전 응답 차단을 추가했다. 최신14개 검사가 통과했으며 결과는 [통합 화면 검사](../docs/r07-08-page-check.json)에 기록한다. [관련 기준 모바일](../docs/r07-08-related-mobile.png)에서 이유·전체 보기 버튼을 확인했다.

### 검색창 수업 대상 제거 — 2026-10-11 추가 수정

- 사용자 요청으로 `discover.html`의 수업 대상 선택·안내와 `discovery-filters.js`의 연결 이벤트·선택 조건 표시를 제거했다. `discover.js`는 이전 URL/검색 저장값의 `grade`를 `all`로 정규화하여 숨은 대상 조건을 적용하지 않는다. 질문의 학년 표현 해석·공식 기준 목록의 과정 선택·내 수업 폴더의 대상 학년과 기존 개인 기록은 유지한다.
- 기존 통합 화면/개인 문맥 검사의 제거된 조작과 기대값을 현재 화면에 맞춰 갱신했다. [통합 화면14개](../docs/r07-08-target-removal-page-check.json)·[개인 문맥8개](../docs/r07-08-target-removal-context-check.json) 통과, 페이지 오류0·실제4저장소 SHA 동일·유료 API0. 데스크톱 캡처에서 검색창 대상 선택 제거와 교육과정 영역 배치를 확인했고 390px 넘침 검사도 통과했다. 사용자 실행 서버는 재시작하지 않았다.
