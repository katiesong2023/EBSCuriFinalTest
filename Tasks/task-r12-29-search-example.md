# Task R12-29 - 검색창 예시 교체

## 설명

2026-10-15 사용자 요청. 검색 결과가 충분하고 주제에 맞는 자연어 문장을 검색창 예시로 제공한다. 상태: 진행중.

## 구현 항목

- [x] 실제 검색 건수와 상위 결과를 확인해 예시를 선택한다.
- [x] 검색창과 접근성 안내의 예시를 함께 변경한다.

## 범위 밖

검색 로직·콘텐츠·필터 변경.

## 수동 작업

없음.

## 완료 조건

### 에이전트 확인

- [x] 로컬 검색 API에서 후보 문장별 건수·상위 제목 확인
- [x] 검색창 placeholder와 검색 도움말 문구 일치

### 결과 확인

- [ ] 새로고침 후 검색창에 “기후 변화를 다룬 다큐” 예시가 보이는지 확인한다.
- [ ] 필터가 없는 상태에서 예시 문장으로 검색하면 관련 자료가 표시되는지 확인한다.

## 실제 반영·검증

`public/discover.html`의 검색창 placeholder와 화면 읽기 프로그램용 도움말을 “기후 변화를 다룬 다큐”로 변경했다. 로컬 교사 검색 API에서 새 예시34건과 상위 기후변화 다큐 제목5건을 확인했다. 비교 후보인 “동물의 생태를 보여주는 다큐”11건, “민주주의를 설명하는 영상”32건. 사용자 제보의 기존 문장은 현재 로컬에서12건으로0건 재현되지 않았다. 결과 수는 데이터·필터에 따라 달라지며 화면에 고정 표기하지 않는다. 검색 기능은 변경하지 않았다.
