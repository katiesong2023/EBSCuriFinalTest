Chrome1440/390px에서404실패 배경2건·고정 정상 이미지 레이어2건 확인, 가로 넘침/브라우저 오류0. 정상 이미지 검사는 외부EBS 연결 대신 브라우저 고정SVG를 사용했다. [검사](../docs/r12-27-thumbnail-check.json), [PC](../docs/r12-27-thumbnail-1440.png), [모바일](../docs/r12-27-thumbnail-390.png). 구현·에이전트 확인 완료, 사용자 화면 확인 대기.

2026-10-15 사용자 요청으로 고정 살구/라일락 사선을 확장한다. `teacher-cards.js`는 콘텐츠ID(없으면 프로그램/제목/출처)의 해시로 네 팔레트 색 중 서로 다른2색·6조합과 사선 반분/세로 반분/굵은 사선 줄무늬/격자4패턴을 배정한다. 렌더 순서·새로고침에 따른 임의 변경을 피하고 같은ID는 같은 배경을 유지한다. 조합은 여러 콘텐츠에서 반복될 수 있다. `curi-v11.css`가 CSS만으로 표시하며 정상 이미지는 기존대로 덮는다.

추가 확인: 실제 콘텐츠 카드의1440/390px 두 화면에서 팔레트의 서로 다른 두 색·복수 패턴, 동일 콘텐츠를 새로 불러올 때 배경 유지, 정상 고정 이미지 덮기·가로 넘침0·브라우저 오류0 확인. [검사](../docs/r12-27-thumbnail-patterns-check.json), [PC](../docs/r12-27-thumbnail-patterns-1440.png), [모바일](../docs/r12-27-thumbnail-patterns-390.png). 기존 단색/고정 사선 검사는 이력이며 현재는 콘텐츠별 조합·패턴이 적용된다.
