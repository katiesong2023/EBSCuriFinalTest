# Task R07-12 - 자연어 프로그램·장르 조건 반영

## 설명

주제와 함께 입력한 프로그램명 및 장르가 실제 검색 후보/관련순과 화면의 해석 안내에 반영되도록 한다. 공개 메타데이터의 장르 표현과 실제 영상 장르 확인을 구분한다. 상태: **진행중**. 후속 방송 형태의 공식 분류/회차 근거·현재 검색 동작은 [R07-13](task-r07-13-broadcast-form-search.md)을 따른다. 아래 수치/구현은 R07-12 당시 기록이다.

## 구현 항목

- [x] 현재 목록의 프로그램명·일반 약칭을 주제와 함께 입력하면 해당 프로그램으로 좁히고 유사/선호 표현은 순위에 반영한다.
- [x] 장르 선호를 관련순에 반영하고 명시적 한정·제외를 공개 장르 표현 기준으로 처리한다.
- [x] 화면에 해석한 프로그램·장르 조건을 알려주고 미확인 범위를 설명한다.
- [x] 주제 AND/OR·선택 기준 교집합·필터/개인 저장·기존 자동 근거 상태를 유지한다.

## 범위 밖

- 영상 시청/장르 전수 확정·추정 장르를 공식 메타데이터로 저장
- 새 장르 선택 UI·유료 API·검색 데이터 재수집

## 사전 전제

- 기존 자연어 요청 해석·통합 검색·R07-11 화면

## 수동 작업

새 키·계정·외부 자료 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 실제 검색 재현·해석/후보/순위 확인
- [x] 신규 계약·기존 질의/결합 검색·화면 회귀 확인
- [x] 실제 구현 기준 문서/상태 갱신

### 결과 확인

- [ ] 자료 찾기를 새로고침하고 ‘생태계 다큐프라임’을 검색한다. 프로그램 조건이 EBS 다큐프라임으로 표시되고 해당 프로그램의 자료가 나오는지 확인한다.
- [ ] ‘생태계 다큐멘터리’를 검색한다. 장르 한정이 표시되고 다큐 표현이 있는 자료만 나오는지 확인한다.
- [ ] ‘생태계 다큐만’을 검색한다. 공개 표현 기준 장르 한정과 미확인 범위 안내가 표시되는지 확인한다.
- [ ] 프로그램/장르 요청과 선택 성취기준·상세 필터를 함께 사용해 조건 교집합과 현재 조건 해제가 유지되는지 확인한다.


## 구현 결과

- 원인: `discovery-request.js`는 프로그램 단독 입력이나 ‘~에서/같은’만 해석했고 주제와 나란히 입력한 프로그램명은 일반 내용어로 남겼다. 다큐는 선호 배열에 기록됐지만 후보/순위에는 쓰지 않았다. 변경 전 ‘생태계 다큐프라임’22건에는 다른 프로그램의 소개문에서 다큐프라임을 언급한 회차도 포함됐다.
- 현재 목록의 프로그램명과 EBS 접두사 생략·쉼표 앞 프로그램 이름을 인식한다. 주제 앞뒤·조사·프로그램명의 띄어쓰기 변형을 처리한다. 기본은 필수 프로그램 조건, 같은/같이/유사한은 관련순 선호, 제외/말고/빼고는 프로그램 필드의 제외다. 알 수 없는 이름과 부분 문자열은 내용어로 보존한다.
- `server/discovery-genre.js`는 다큐멘터리·애니메이션·드라마·강연/강의 요청을 분리한다. 다큐/다큐멘터리 기본 입력은 공개 표현 한정이고, 다른 장르 또는 명시적 유사/선호 문맥은 관련순 선호이며 ‘만/중에서/에서’는 공개 표현 한정, 제외 표현은 공개 표현 제외다. 근거는 프로그램명·제목·소개문의 표현 또는 기존 강의 자료 유형으로 한정하며 실제 영상 장르를 확정하지 않는다. 원문 필드·인용·오프셋·TEXT_CUE/RESOURCE_TYPE 목적을 응답에 제공한다.
- `discovery-search.js`에서 장르 선호를 점수에 반영하고 한정/제외·프로그램 제외를 후보 구성에 적용한다. 프로그램명에 포함된 ‘다큐’는 장르 요청으로 중복 해석하지 않는다. 내용 주제 없이 특정 프로그램 선호가 있는 요청은 일반 장르 언급만으로 다른 프로그램 전체로 확대하지 않는다.
- `teacher-discovery.js`는 장르만 요청했을 때 전체 목록 fallback으로 조건이 사라지지 않게 한다. 기존 선택 기준·질문·화면 필터 교집합과 자동 관계 규칙은 유지한다.
- `public/discover.js`는 기존 검색 해석 영역에 프로그램/장르 선호·한정·제외를 표시한다. 새 장르 선택 UI는 추가하지 않았다. 선호는 관련순에서 반영하며 날짜순을 선택하면 날짜 정렬을 유지한다. 선택 기준이 있는 관련순은 기존 요구 관계→원문 품질 우선순위를 유지한다.

## 검증 기록

- 신규 프로그램/장르 계약12개·격리 화면3개 통과: [계약/현재 카탈로그](../docs/r07-12-program-genre-check.json), [화면](../docs/r07-12-program-genre-browser-check.json).
- 기존 질의 회귀27개·결합 검색20개 통과. 기존 교사 질의10개 실행 오류0·정밀 표본8/8·조사 표본2/2 통과. [질의](../docs/r07-12-query-regression.json), [결합](../docs/r07-12-combined-regression.json), [교사 질의](../docs/r07-12-teacher-query-regression.json).
- 화면에서 프로그램 조건/장르 선호·한정·제외 안내·새로고침·선택 기준/프로그램 필터 교집합·빈 결과·390px 넘침 없음을 확인했다. 첫 화면 실행의 새로고침 대기 시간 초과는 같은 검사 재실행에서 재현되지 않았고 최종3개 모두 통과·페이지 오류0이다.
- 실제 카탈로그에서 생태계82, 생태계 다큐멘터리82(상위3건 다큐프라임으로 변화), 생태계 다큐만22, 생태계 다큐프라임21, 세계테마기행 볼리비아4를 확인했다. 세계테마기행 사막은 프로그램 조건을 정확히 인식하지만 현재 원문/의미 근거 조건의 교집합0건을 유지한다. 주제 조건을 완화해 채우지 않았다.
- 실행 중인 이전3000서버의 동일 프로젝트 cwd/Node 실행 방식을 확인하고 정상 종료 후 같은 env-file 방식으로 재시작했다. 실제3000 API에서도 프로그램21·장르 선호82·한정22를 확인했다. [실행 서버](../docs/r07-12-running-server-check.json). 실제 읽기 검색 후 보호4저장소 SHA 동일·유료API0.
- JS 구문·차이 공백 검사 통과. 사용자 결과 확인 대기로 진행중이다.
- 재현: `node server/program-genre-check.js`, `node server/program-genre-browser-check.js`(기존 Playwright/브라우저 경로 환경 변수). 현재 실행 서버는 `node --env-file-if-exists=.env server/server.js`다.


### 다큐멘터리 기본 검색 한정 — 2026-10-12 후속 수정

- 사용자 제보에 따라 ‘다큐/다큐멘터리’ 기본 입력을 선호가 아닌 공개 장르 표현 한정으로 변경한다. 별도 ‘만’ 없이도 다른 형식·장르 미확인 자료를 제외한다.
