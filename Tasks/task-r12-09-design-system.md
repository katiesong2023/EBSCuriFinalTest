# Task R12-09 - Curi 공통 스타일·인터랙션 가이드

## 설명
사용자가 지정한 GO:OD 사이트의 실제 화면과 상호작용을 분석하여 웹사이트, Chrome 확장 프로그램, Curi 로고에 공통 적용할 디자인 기준과 검토 가능한 시안을 제공한다. 참고 관찰과 Curi 제안을 구분하며 현재 검색·가져가기·폴더·개인 기록 계약을 보존한다. 상태는 가이드·시안 작성 및 에이전트 확인 후 사용자 결과 확인 대기로 진행중이다.

- [x] 색·글자·간격·컴포넌트·모션·키보드·상태 기준
- [x] 웹 검색/근거/두 단계 가져가기/내 수업 자료 지침
- [x] 확장 영상·폴더·구간·연결/저장 상태 지침
- [x] 워드마크·심볼·작은 크기·반전 사용 제안
- [x] 공통 JSON/CSS 토큰, SVG, 동작하는 정적 시안 제공
