## 실제 반영·검토

웹 `public/discover.html`·`lesson.html`의 헤더/하단을 EBS CURI로 바꾸고 홈 링크 접근성 이름도 맞췄다. `curi-v11.css`는 EBS를 보조 크기로, CURI를 기존 크기로 표시하며 줄바꿈을 방지한다. 확장 `popup.html`의 표시 로고·연결 버튼 명칭과 다운로드ZIP도 갱신했다. 기존 저장 키/동작·파비콘/아이콘·과거 비교용SVG는 변경하지 않았다.

[3안 비교 원본](../docs/design/ebs-curi-logo-options.html), [렌더링](../docs/design/ebs-curi-logo-options.png). 점 두 개는 기존 인상을 보존하지만 기능을 직접 설명하지 않는다. 폴더는 수업 자료 모으기/정리를 나타내며 기존 폴더 형태와 일관된다. 문자 사이를 폴더로 바꾸면 CURI 가독성이 낮아지므로 이름 왼쪽에 작게 두는 안을 추천한다. 일반적인 폴더 모양은 독자성이 약하므로 명칭과 함께 사용한다. 폴더 심벌은 비교안이며 현재 운영은 점 없는 문자형 EBS CURI다.
