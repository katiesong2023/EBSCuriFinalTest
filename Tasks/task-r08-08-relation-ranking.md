# Task R08-08 - 필수 관계 중심 후보 검색과 부정 문맥 판정

## 설명

선택 성취기준의 필수 대상·인과관계·조건을 실제로 설명하는 자료가 단어만 많이 일치하는 자료보다 앞에 오도록 후보 발견과 순위를 개선한다. 표현 차이로 적합한 자료를 놓치는 경우와 부정어 때문에 잘못 상충 처리하는 경우를 함께 줄인다. 사용자 우선순위 4를 담당한다. 상태: **진행중 — 2026-10-11 구현·검증 완료, 사용자 결과 확인 대기**.

## 구현 항목

- [x] 후보를 **필수 대상·관계·조건의 근거 → 원문 충실도 → 개념 일치** 순으로 비교한다. 단어 수가 많다는 이유로 필수 관계가 없는 자료가 근거 있는 자료보다 앞서지 않게 하고, 순위 이유와 남은 요구를 선택 기준에 맞게 설명한다.
- [x] 표현이 달라도 같은 대상·작용·결과·조건을 설명하는 문장을 후보 발견에 활용한다. 순위만 바꾸어 이미 누락된 후보를 놓치지 않도록 발견 단계도 확인하고, 동의 표현의 적용 범위와 한계를 기록한다.
- [x] 요구 분해·자동 비교 미지원 기준에서는 사용 가능한 원문·개념 근거를 표시하고 미지원을 불일치 점수나 부적합 판정으로 사용하지 않는다. 관계가 확인된 것처럼 가산하지도 않는다. 관계 지원 범위를 실제 구현한 기준별로 기록한다.
- [x] 부정의 대상과 범위를 구분한다. **“폭력을 사용하지 않고도”**는 폭력 사용의 부정이므로 다른 관계 전체의 상충으로 처리하지 않는다. 실제 문맥을 대조해 선거·시민 참여 등의 관계가 별도로 확인되는지 판단한다.
- [x] 같은 대상·같은 관계의 명시적 부정, 다른 행위의 부정, 반어·의문·조건·인용된 주장·전후 문장 문맥을 구분한다. 의미를 확정하지 못하면 해석 보류로 남기며, 부정 오탐을 고치기 위해 실제 상충 검사까지 제거하지 않는다.
- [x] 관련 없는 부정 표현 때문에 이미 확인한 다른 요구의 인용을 일괄 삭제하지 않는다. 확인·보류·상충은 해당 요구의 범위에서 유지하고 전체 기준의 상태와 구분한다.
- [x] 원문 일부의 관계 확인을 기준 전체 충족으로 승격하지 않는다. 인용 실존·위치·회차·버전 대조와 사람 제외/보류 우선, 변경 무효화 및 판본별 확인을 유지한다.
- [x] 같은 고정 자료에서 변경 전후 후보 발견·순위·오연계 노출·누락을 비교한다. 검색 로직 변경 효과와 후속 원문 보강 효과를 별도로 측정하며, 검색 순위 향상을 사람 승인·의미 정확도 검증 완료로 보고하지 않는다.

- [x] 단어 다수/관계 없음과 단어 소수/관계 설명 있음의 순위 비교 및 다른 표현의 후보 발견 확인
- [x] 부정 대상이 다른 실제 사례, 같은 관계의 명시적 상충, 해석 보류 사례를 각각 확인
- [x] 농경문 부분 연계·꿀벌/연소 피해 오탐·선거·자전 규칙과 미지원 기준의 경계 회귀 확인

- [x] 관련 정적 점검·기존 검색/확인/판본 회귀 및 HTML/CSS/JavaScript 규칙 확인, 실제 구현 기준 task·계획 갱신

## 실제 구현·검증

`automatic-relation-language.js`, `automatic-relation-rules.js`, `curriculum-requirements.js`, `curriculum-discovery.js`, `candidate-retrieval.js`에 관계 우선 순위와 제한된 동의 표현·부정 대상·조건/인용 문맥을 적용했다. 규칙은 `automatic-evidence-v3:source-text-v3`이며 지원 기준은 기존4개다. 전체214개 중 나머지210개는 미지원이다.

[관계 계약13개](../docs/r08-08-relation-ranking-check.json), [선택 기준 계약7개](../docs/r08-07-standard-evidence-check.json), 기존 자동41개·자산26개·관계10개·학년/관리 회귀를 통과했다. 같은 원문에서의 독립 비교는 [최종 보고](../docs/R09_02_STANDARD_EVIDENCE_RESULTS.md)에 분리해 기록했다. 의미 확정은 네 제한 규칙 안에서만 수행하며 에이전트 검사를 사람 검수로 승격하지 않았다.

재현: `node server/relation-ranking-check.js`, `node server/standard-evidence-check.js`.
