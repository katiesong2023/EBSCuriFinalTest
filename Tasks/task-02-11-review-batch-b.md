# Task 02-11 - Pilot 콘텐츠 검수 2차 25건

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R09 / 사람 판단 후속 유지**. 기존 검수 양식·기록 보존, 고정 검수량은 수집·검색 개발의 선행 조건이 아니다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

R09의 최종 사람 판단으로 이월한다. 기존 25/25/100~150건은 과거 승인 확장 계획의 목표이며 현재 수집·태깅·검색 구현을 막는 선행 조건이 아니다. 실제 수업 필요·원문 근거·검수 여력을 확인한 뒤 배치를 재산정한다. 기존 양식과 실제 판단 이력은 보존한다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 2~3 초반
- 예상 집중 작업: 약 1.5시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Luna** (`gpt-5.6-luna`)
- 추천 추론 수준: **low**
- 선택 이유: 확정된 반복 검수 기록 작업이므로 강한 모델을 매번 쓸 필요가 없다.
- 상향 조건: 요구사항이 모호하거나 수정이 여러 파일·상태로 번지면 해당 문제만 Terra / medium으로 올린다.
- 사람 판단/수행 포함: 모델은 양식·대조·정리를 보조한다. 직접 검수·채점·시간 측정·녹화·발송의 수행 사실을 대신 만들지 않는다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.
