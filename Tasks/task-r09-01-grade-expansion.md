# Task R09-01 - 초등 3~4학년·중학교 1학년 교육과정 확장

후속 변경 — 2026-10-10: 사용자 요청으로 기존 사람 승인4건을 취소했다. 현재 사람 승인/승인검색 투영0건, 자동 공개1건이며 원본과 이전 검수 이력은 보존했다. 아래의 승인4건 보존·검증 수치는 취소 전 구현 기록이다. 결과 확인에서는 사람 승인0건을 기준으로 한다. [취소 기록](../docs/r09-01-approval-revocation.json)

## 설명

2026-10-04 사용자 요청에 따라 기존 초등 5~6학년 사회·과학을 유지하면서 초등 3~4학년과 중학교 1학년 사회·과학을 추가한다. 목표 이용 범위는 초등 3~6학년·중학교 1학년이며, 교육과정 근거·교사 요청 해석·교육과정 역방향 탐색·자동/사람 연계·검색·수업 폴더를 함께 확장한다. 현재 상태는 **진행중 — 구현·에이전트 검증 완료, 사용자 결과 확인 대기**다. 2026-10-10 공식 성취기준 136개를 실제 저장소에 추가하고 검색·연계·수업 폴더 확장을 검증했다. 실제 사람의 교육과정 적합성·수업 효용 평가는 수행하지 않았다.

학년 범위는 수업 문맥과 교육과정 연계를 위한 조건이다. 일반방송 수집을 학년으로 제한하거나 학년 적합성을 자동 승인하는 기준으로 사용하지 않는다. 전체 대상 과정의 성취기준과 자료 확보 현황을 구분하고, 미확보 단원은 공백으로 표시한다.

현재 구현된 R07-01~04·R08-01~06의 검색·원문 품질·자동/사람 경계를 확장 학년에도 적용한다. 대량 사람 검토를 추가 학년 제공의 선행 조건으로 두지 않는다. 공식 기준과 후보를 탐색할 수 있는 범위, 자동 관계 규칙이 지원하는 범위, 실제 사람 승인이 있는 범위는 각각 표시한다.

공통 학년 해석은 [grade-context.js](../public/grade-context.js), 공식 데이터 적재는 [curriculum-expansion-import.js](../server/curriculum-expansion-import.js)에 구현했다. 교사 검색·교육과정에서 찾기·공백 관리·자동/사람 연계·CuriMap 검토·승인 저장·수업 폴더에 과정과 교과 문맥을 연결했다. 원본 콘텐츠의 학년과 수업용 연계 과정을 분리하며, 실제 사람 확인과 영상의 학년 적합성을 자동으로 확정하지 않는다.

현재 저장소에는 적재를 마쳤다. 다른 작업 사본에서 재현할 때 `node server/curriculum-expansion-import.js`는 사전 검사만 수행하고, `node server/curriculum-expansion-import.js --apply`는 검증한 136개를 병합한다. 반복 적재는 기존 항목을 유지한다. 공식 데이터·변조/멱등 23건, 탐색/공백 9건, 자동/사람 경계 13건, 검색/폴더 6묶음, CuriMap 모의 초안→검토→승인 저장 5묶음과 기존 회귀를 통과했다. 실제 브라우저 확인과 세부 재현 명령은 최종 결과 보고서에 기록했다. 합성 자료의 모의 사람 결정은 실제 사람 평가에 포함하지 않았다.
