# Task 02-10E - 일반방송 회차 모집단 5,000건 이상 확장

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R01·R02 / 필수 확대에 통합**. 5천 회차·과학 선택 10~20건 상한을 해제한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명
초기 구조 검증용 소량 데이터를 일반방송 중심의 반복 수집 가능한 모집단으로 확장한다. [확장 설계서](../docs/DATA_EXPANSION_5000.md)를 기준으로 프로그램·시리즈를 실제 회차로 전개하고, 사람 전수 검수나 유료 API 없이 탐색용 데이터와 근거를 확보한다. 상태는 `완료`다. 5,548개 공식 회차 ID와 9개 프로그램을 실제 수집했고 로컬 검색·모음·메모에 연결했다. 구현 근거는 [수집 실측](../docs/BROADCAST_CORPUS.md)과 `docs/broadcast-simulation.json`이다. 영상 재생·교육적 적합성 승인은 제외한다.

## 구현 항목
- [x] 다큐프라임·기행·지식채널e 등 프로그램과 회차 수집 경로·가용량을 조사한다.
- [x] 기존 검수 대기열과 분리한 탐색 저장소·반복 수집·중단 재개를 제공한다.
- [x] 공식 ID·프로그램·제목·개별 주소가 있는 고유 방송 회차 5,000건 이상을 누적하고 중복·재방송·합본·클립을 구분한다.
- [x] 소개문·개별 도착 페이지 대조·미확보 수와 공급원 편중을 별도로 보고한다.
- [x] 확장 데이터로 수업 질문·원문·모음·다운로드를 연결하고 30개 시나리오의 전후 차이를 측정한다.
- [x] 지속 증분 수집으로 5,000건 이후도 확장 가능하게 한다.

## 범위 밖
- 5,000건 전수 사람 태깅·자동 교육과정 승인·유료 LLM 일괄 처리
- 영상 다운로드·비공개 자막 확보·확인하지 않은 타임코드 생성
- 제목만 같다는 이유로 콘텐츠 병합 또는 목록을 영상으로 집계
- 모든 학년의 교육과정 매핑 기능을 동시에 구축

## 사전 전제
- 기존 원본 604행·지리 보강·원문 링크 대조 기록·02-10D 시나리오
- 기존 25건 사람 검수 완료를 수집의 선행 조건으로 두지 않는다.

## 수동 작업

없음. 새 API 키·25건 검수·태깅은 필요하지 않다.
