# Task 03-03 - CuriMap 공식근거·검수 흐름 최종 확인

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R09 / 기술·품질 검증에 통합**. 유료 모델·대량 사람 승인과 독립적으로 기술 검증한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

기능 동결한 CuriMap이 공식 목록 제약, 근거 표시, 보류·오류 처리와 검수 흐름을 지키는지 확인한다.

## 구현 항목

- [ ] 공개 텍스트 5~10건을 실행해 반환·저장된 모든 성취기준 ID가 공식 승인 목록에 존재하는지 확인한다.
- [ ] 결과·보류·오류에서 코드·본문·원문 근거·상태가 표시되는지, 임의 코드가 없는지 확인한다.
- [ ] 승인·수정·제외·검수 전 검색 제외·재시도 동작과 실행 이력이 남는지 확인한다.
- [ ] 공식 ID 유효율·근거 표시 완결률·검수 동작 성공률·실행 기록 완결률만 보고하고 의미 정확도로 해석하지 않는다.

## 범위 밖

- Gold 정확도·Hit@K·성취기준 의미 적합성 주장
- 교사 검토가 없는 수업 유용성 주장

## 사전 전제

- [Task 03-02](./task-03-02-dev-ranking.md)의 기능 동결 완료
- [Task 00-06](./task-00-06-evaluation-design.md)의 공식근거·기능검증 설계 완료

## 완료 조건

- [ ] 기능검증 실행·원자료·오류·재시도 이력이 남는다.
- [ ] 공식 목록 밖 ID 0건과 근거·상태 표시 결과를 확인한다.
- [ ] 의미 정확도 또는 교사 유용성을 측정한 것으로 기록하지 않는다.
