# Task R07-05 - 수업별 선택 이유 보존과 콘텐츠 난이도 구분

## 설명

교육과정에서 자료를 고른 이유를 내 자료·수업 폴더·내보내기까지 이어가고, 저장 당시의 활용 의도와 현재 연계 상태를 구분한다. 공식 학년군 연계와 실제 콘텐츠 난이도·선수개념·장면 확인을 독립적으로 관리한다. 사용자 우선순위 6~7을 담당한다. 상태: **진행중 — 구현·기술 검증 완료, 사용자 결과 확인 대기**.

R09-01에서 초등3~4·중1 공식 기준과 편성 근거, 선택 기준·대상 과정의 기본 전달은 이미 구현했다. 이번 task는 이를 재구현하지 않고 구체적인 수업 목적·활용 부분·남은 내용과 확인 기록을 보완한다. 중1은 공식 중학교1~3학년군과 EBS 뉴런 편성 참고이며 학교별 배치는 미확인이다.

## 구현 항목

- [x] 자료 선택 문맥으로 **성취기준·이번 수업 목표·활용할 부분·추가로 다룰 내용**을 저장·수정·재열기·내보내기까지 보존한다. 선택 기준의 공식 문장·과정과 교사의 개인 선택 이유를 구분하고 작성하지 않은 내용은 추정해 채우지 않는다.
- [x] 선택 당시의 기준·연계 상태·저장 시점과 현재 해당 관계의 상태·재확인 시점을 구분해 보여준다. 현재 조회 실패·원문 변경·승인 취소 시에도 개인 기록은 유지하며, 저장 당시 상태를 현재 유효한 확인처럼 표시하지 않는다.
- [x] 같은 자료를 여러 기준·수업에서 쓰는 목적이 서로 덮어써지지 않게 한다. 같은 폴더에서도 복수 선택 이유를 보존할 수 있고, 다른 기준에서 다시 선택했을 때 기존 이유가 사라지지 않게 한다. 기존 내 자료의 중복 방지 동작과 양립하도록 결과를 확인한다.
- [x] 폴더의 수업 대상을 바꾸어도 저장 당시 선택 기준·이유를 조용히 삭제하거나 새 학년 기준으로 바꾸지 않는다. 현재 대상 과정과의 차이를 표시하고 사용자가 활용 문맥을 갱신할 수 있게 한다.
- [x] **학년군 연계·영상 난이도·선수개념·장면/사용 구간 확인**을 별도로 기록하고 비교할 수 있게 한다. 개인 판단·확인 여부·확인 근거/시점을 남기며 미기록은 미확인으로 유지한다. 공식 학년군·중1 편성·교사의 목표 학년에서 콘텐츠 추천 학년을 자동 도출하지 않는다.
- [x] 농경문 자료의 생활 추론처럼 교사가 추가할 수업 활동과 원문이 직접 제공하는 내용을 구분한다. 개인의 사용 판단·메모·장면 확인이 공용 교육과정 사람 승인으로 바뀌지 않게 한다.
- [x] 기존 학년 미지정 폴더·메모·내 자료를 손실 없이 열고 저장할 수 있게 한다. 비동기 관계 갱신이나 내보내기 중에도 개인 입력을 덮어쓰지 않고 저장 실패를 알린다. 기존 동일 브라우저 저장 범위를 유지한다.

## 구현 결과와 검증 — 2026-10-11

- `public/lesson-context.js`에 자료별 `selectionContexts`를 추가했다. 기존 내 자료·폴더 저장 키와 자료 ID 중복 방지는 유지하며 같은 자료의 다른 기준은 새 이유로 병합한다. 한 자료에서 최대 20개 이유를 보존한다.
- `public/curriculum.js`·`teacher-cards.js`·`discover.js`에서 기준·공식 문장·과정을 내 자료에 전달하고, `lesson.js`의 **수업 선택 이유**에서 기준·목표·활용 부분·추가 내용, 난이도·선수개념·장면의 개인 확인·근거·시점을 입력한다. **사용·제외 이유 남기기 · 선택 사항**은 같은 브라우저에만 보존하며 공용 승인이나 서버 평가에 반영하지 않는다.
- 선택 당시 표시 캡처시점과 실제 관계 재확인 시점을 구분한다. 당시 확인시점이 없으면 미기록으로 남긴다. 활용 기준을 바꿔도 원래 기준 코드·공식 문장은 당시 기록에서 볼 수 있다. 복수 과정과 학년 확인 필요 문맥, 현재 목록에서 사라진 저장 기준도 보존한다.
- 단일 이유의 카드 상단은 해당 기준을, 복수 이유의 상단은 자료 전체 현재 기록을 표시한다. 각 이유에서는 그 기준의 현재 상태를 따로 확인한다. 폴더 학년 변경과 관계 조회 실패는 개인 문맥을 지우지 않는다.
- `teacher-storage.js`는 현재 원문/관계를 다시 읽으며 과거 비교를 현재 상태로 재사용하지 않는다. 폴더의 비동기 갱신·내보내기 중 편집을 보존하고, 내 자료 내보내기는 클릭 당시 모음을 출력하면서 대기 중 추가·삭제를 현재 모음에 보존한다.
- 신규 [문맥·브라우저 12개 검사](../docs/r07-05-browser-check.json), [리뷰 회귀 3개](../docs/r07-05-review-check.json), 기존 [수업 폴더 12개](../docs/r07-05-regression-folder-browser-check.json), [학년/검색 6개](../docs/r07-05-grade-search-regression.json)와 선택 기준 화면 7개가 통과했다. [PC 화면](../docs/r07-05-lesson-desktop.png)·[모바일 화면](../docs/r07-05-lesson-mobile.png)을 확인했다. 실제 교사 판단·영상 난이도 평가·공용 승인 생성은 수행하지 않았다.
- 재현: `node server/lesson-context-browser-check.js`, `node server/lesson-context-review-check.js`. 브라우저 검사는 `CURI_PLAYWRIGHT_MODULE`·`CURI_BROWSER_EXECUTABLE`을 설정한 격리 서버에서 실행한다. 기존 검사 재실행 시 `CURI_REPORT_PATH`/`CURI_REPORT_PREFIX`로 새 출력 경로를 지정해 과거 보고서를 보존한다.

## 수동 작업

필수 외부 설정은 없다. 실제 수업 목표·활용할 부분·추가 활동과 난이도·선수개념·장면에 대한 개인 판단은 사용자가 직접 작성한다. 실제 사용·제외·보류 이유 입력은 선택 사항이다.
