# Task 03-01 - DEV에서 서비스 호출 모델·비용 비교

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R10 / 프로덕션 추론으로 재정의**. 로컬 시맨틱 레이어 이후 모델 역할·예산·인용 검증을 비교한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

R10로 통합한다. 로컬 시맨틱 레이어와 검색 결과를 바탕으로 프로덕션에서 요청을 해석하고 출처에 근거한 추천 이유를 만드는 모델의 역할·비용을 검증한다. 이번 세션에서는 유료 API를 호출하지 않는다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 3 초반
- 예상 집중 작업: 약 1.5시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Terra** (`gpt-5.6-terra`)
- 추천 추론 수준: **medium**
- 선택 이유: 코드 연결보다 공정한 작은 비교·비용 계산이 중심이며 Sol 전체 실행은 불필요하다.
- 상향 조건: 원인을 좁혀도 해결되지 않는 제약·상태·데이터 무결성 문제는 해당 부분만 Sol / medium으로 검토한다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.
