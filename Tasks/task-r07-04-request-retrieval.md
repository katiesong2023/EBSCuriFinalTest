# Task R07-04 - 교사 요청 해석과 후보 발견 개선

## 설명

교사 요청의 핵심 주제와 관계/방법·제외·선호·장면/시간을 구분해 긴 자연어 요청의 후보 누락을 줄인다. 2026-10-05 사용자 요청으로 다섯 task를 작성해 순서대로 구현·검증한다. 사용자 결과 확인은 별도로 남기며 연속 진행 요청에 따라 각 에이전트 검증 후 다음 task를 진행한다. 상태: 진행중 / 구현·검증 완료, 사용자 결과 확인 대기

## 구현 항목

- [x] 다양한 문화가 함께 사는 모습·대표를 뽑다 등 근거 있는 표현 확장을 추가하고 일반 요청 문구가 필수 검색어로 남지 않게 한다.
- [x] 제목·소개문 전체로 후보를 발견하며 알 수 없는 주제·고유명·AND/OR·제외·프로그램 제약을 보존한다.
- [x] 검색 관련 이유에 요청별 일치 주제·관계/방법의 대응 문장·미확인 조건을 구분해 제공한다. 단어 일치를 관계 충족으로 표시하지 않는다.
- [x] 고정 진단 요청과 새로운 변형 요청으로 빈 결과·조건 유실·알려진 오탐을 비교하고 전후 결과를 기록한다.

## 범위 밖

- 유료 API·범용 의미 이해 주장·근거 없는 후보 채움

## 사전 전제

- R07-03·기존 R04/R05/R09 질의 기준선

## 실제 구현

- `discovery-query-language.js`는 여러 문화의 공존→다문화, 대표를 뽑다→선거/투표를 요청 해석에서만 확장한다. 원문 태그를 새로 부여하지 않는다. `discovery-intent.js`·`discovery-request.js`는 찾고 있어요/사례/움직임을 필수 내용어에서 분리하고 관계/방법·시간·장면을 별도로 보존한다.
- 같은 고정 카탈로그·진단8개에서 빈 결과4→2, 다문화0→15·기관 움직임0→48. 고조선 유물 발굴과 산성비/산성화는 여전히0이며 무관한 후보로 채우지 않았다. 기관 후보는 움직임 장면 충족이 아니다.
- 변형 요청/알 수 없는 고유명/제외/AND·OR/시간 등 신규6개, 기존 질의27·교사 정밀도10·고정 요청8개 회귀 통과. [전](../docs/r07-04-request-before.json), [후/계약](../docs/r07-04-request-check.json), [회귀](../docs/r07-04-quality-regression.json). 이는 개발 요청의 기능 검사이며 의미 정확도 측정이 아니다.
