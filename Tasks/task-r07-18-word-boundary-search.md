# Task R07-18 - 검색어의 부분 문자열 오탐 방지

## 구현·검증 기록

`search-term-matching.js`의 Unicode 단어 경계·조사/활용·확인된 복합어를 `discovery-query-language.js`에서 공유한다. 일반 검색/지리 보조 어휘/OR/제외/관련순/검색 이유와 인용에 적용했다. 등록 개념의 소개문 문맥 심사는 R07-17 경로를 유지한다. 불완전연소/연소반응은 유지하고 최연소/연소득/연소자는 차단한다. 제목에 최연소가 있어도 소개문에 실제 연소가 있으면 유지한다.

전체23,360건 × 504어휘 = 11,773,440비교를 수행했다. 부분 문자열 후보 중 11,575자료·어휘 조합은 새 경계에서 보류되었다. 이 수는 의미 오류의 확정 건수가 아니다. 모르는 복합어는 임의로 분해하지 않아 누락될 수 있으며, 확인 후 명시 사전에 추가한다. 감사는 `docs/r07-18-word-boundary-audit.json`에 전량 기록했다. 실제 연소 검색은4→2건, 최연소만 포함한2건 제외.

새 계약27·기존 검색21·시맨틱19·교육과정 결합20·프로그램/장르12·브라우저4검사 통과. 실행 서버/API 확인은 `docs/r07-18-running-server-check.json`, 화면은 `docs/r07-18-browser-check.json`. 원본4저장소 SHA 보존·유료 API0. 상태는 사용자 결과 확인 대기.
