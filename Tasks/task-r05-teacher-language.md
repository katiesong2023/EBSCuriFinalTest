# Task R05 - 교사 자연어 문맥·선호 해석 보강

## 설명

사용자가 제공한 교사형 수업 요청을 개발용 고정 fixture로 재현하고, 주제 검색어와 요청 문맥을 분리해 후보·제약·근거 상태를 보여준다. 프로그램 선호·필수 조건, 붙여 쓴 선택 표현의 국소 OR, 폭력 장면·자연 촬영 미확인, 관계 미확인 표시, 동음이의어 제한 가드를 포함한다. 기존 8개와 추가 조사 2개의 질의는 수정에 사용한 개발·회귀 자료이며 독립 최종 평가나 교육적 정답률 자료가 아니다. 제품 코드와 에이전트 검증은 통합 완료했지만 사람 결과 확인 전이므로 task는 완료로 표시하지 않는다.

## 구현 항목

- [x] 요청 문맥을 주제 검색어와 분리하고 수업 도입·활동 전 등의 문맥, 세부 요청, 미지원 조건을 별도 상태로 보존한다.
- [x] `같은` 프로그램은 선호로, `에서` 또는 단독 프로그램명은 필수 프로그램으로 해석해 결과 필터·점수에 반영한다.
- [x] `고조선이나 삼국시대`처럼 붙여 쓴 선택 표현을 국소 OR로 보존하고, 전체 질의의 다른 조건은 AND로 유지한다.
- [x] 폭력·수술 장면 제외와 실제 자연 촬영 조건을 검색 충족으로 단정하지 않고 경고·미확인 상태로 표시한다.
- [x] 60개 편집 검색 개념과 동음이의어 제한 가드(예: 도시의 심장·화석 씨)를 유지한다.
- [x] 요청한 기관·발굴·형성 등 관계를 후보와 별도로 `RELATION_NOT_VERIFIED` 상태로 표시한다.
- [x] 프로그램·문맥·세부 요청을 포함한 교사 질의 fixture 전후 결과를 기록한다.
