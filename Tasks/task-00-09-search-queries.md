# Task 00-09 - 알려진 항목·조건 검색 시나리오 확정

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R03·R09 / 검색 검증에 통합**. 사회·과학 균형 질의, 문장 해석·근거·빈 결과를 함께 평가한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

교육과정 전문가의 관련도 채점 없이, EBS 공식 인벤토리로 확인 가능한 검색 기능검증 시나리오 8~12개를 확정한다.

- 상태: 예정

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: 준비
- 예상 집중 작업: 약 1시간
- 개발 보조 모델: **GPT-5.6 Terra** (`gpt-5.6-terra`)
- 추천 추론 수준: **low**
- 선택 이유: 공개 인벤토리의 식별자·필터 조건을 누락 없이 구조화하는 작업이다.

## 구현 항목

- [ ] `p0_manjumwang_course_inventory_16.csv`와 `p0_manjumwang_basic_lecture_inventory_391.csv`에서 공식 기본 강좌 8개를 기준으로 8~12개 시나리오를 만든다.
- [ ] 각 시나리오에 질의 또는 필터 입력, 기대 강좌/강의 식별자, 학년·교과·학기 조건, 공식 인벤토리 근거 행을 기록한다.
- [ ] 기대 식별자 반환, 조건 위반 0건, EBS 원문 링크 표시만 판정하고 수업 유용성·의미 관련도·순위 품질 점수는 만들지 않는다.
- [ ] 기능검증 자료가 개발·회귀 확인에 사용될 수 있음을 기록하고 독립 성능 수치로 표현하지 않는다.

## 범위 밖

- 사람의 0/1/2 수업 유용성 채점
- Precision@K·후속 표본·Negative 관련도 지표
- 교육과정 의미 적합성 판단

## 사전 전제

- R02 근거 태그 및 R03 사회·과학 12개씩의 로컬 질의·기준선
- R04의 고정 가상 자료 조건 처리 회귀
- 실제 교육적 적합성 평가는 R09에서 구분한다. 유료 API·대량 사람 승인 완료는 기능 검증 선행 조건이 아니다.

## 수동 작업

공식 인벤토리의 강좌명·식별자·교과·학년·학기만 확인한다. 콘텐츠의 교육적 유용성이나 성취기준 적합성은 판단하지 않는다.

## 완료 조건

### 에이전트 확인

- [ ] 시나리오 8~12개와 공식 인벤토리 근거가 준비된다.
- [ ] 기대 강좌/강의 식별자가 공식 인벤토리에 존재하고 시나리오 간 중복·조건 충돌이 없는지 점검한다.
- [ ] 코드 변경이 없으면 HTML/CSS/JavaScript 규칙은 적용 대상이 아니다.
- [ ] 의미 관련도·교사 유용성·독립 검색 성능을 AI 또는 비전문 제작자가 채점한 것으로 기록하지 않는다.

### 결과 확인

- [ ] 모든 시나리오에 질의/필터·기대 식별자·공식 근거·조건이 있는지 확인한다.
- [ ] 시나리오가 알려진 항목·조건 검색 기능검증이며, 일반 검색 품질의 독립 성능 수치가 아님을 확인한다.
