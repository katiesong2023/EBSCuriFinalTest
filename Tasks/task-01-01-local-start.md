# Task 01-01 - 로컬 실행 기반 준비

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

입문자가 자신의 컴퓨터에서 화면·서버를 시작하고 종료할 수 있게 준비한다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 1
- 예상 집중 작업: 약 1시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Terra** (`gpt-5.6-terra`)
- 추천 추론 수준: **low**
- 선택 이유: 실행 환경·설정 문제를 다뤄야 하므로 단순 문서 모델보다 일반 구현 모델이 효율적이다.
- 상향 조건: 원인을 좁혀도 해결되지 않는 제약·상태·데이터 무결성 문제는 해당 부분만 Sol / medium으로 검토한다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.

## 산출물 (2026-09-17)

- `package.json`: 의존성 설치 없이 `npm start`로 실행하고, `npm run dev`로 파일 변경 감시 실행을 제공한다.
- `server/server.js`: `public/`의 정적 파일만 `127.0.0.1` 로컬 주소에 제공하는 Node.js 서버다.
- `public/index.html`: 서버와 화면 연결 여부를 확인하는 최소 시작 페이지다.
- `.env.example`과 `.gitignore`: 포트 설정 예시를 제공하고 실제 `.env` 파일을 Git 추적에서 제외한다.
- `README.md`: 시작·종료, 비밀값 분리, 변경 확인·특정 파일 되돌리기 방법을 안내한다.

## 수동 작업

기본 포트 `3000`을 사용할 때는 추가 입력이 필요 없다. 다른 포트가 필요할 때만 프로젝트 최상위 폴더에서 `cp .env.example .env`를 실행한 뒤 `.env`의 `PORT` 값만 변경한다. 실제 API 키가 필요한 이후 task에서도 값은 `.env`에만 입력하며, 이 문서나 화면·로그·Git에 넣지 않는다.
