# Task R07-06 - 통합 자료 검색의 조건과 역할 정리

## 설명

교사의 기본 진입점은 자료 찾기로 유지하고, 교육과정 조건을 선택적으로 추가하는 통합 범위를 정리한다. 질문·주제 검색과 공식 성취기준 탐색을 하나의 자료 선택 흐름으로 연결하되, 기존 근거 비교와 수업 문맥 기능을 재구현하지 않는다. 상태: **진행중**. 2026-10-11 실제 코드 대조·계약 정리·정적 점검 완료, 사용자 문서 결과 확인 대기. 후속 순서는 R07-07 → R07-08 → R07-09 → R09-03이다.

## 권장 개발 모델

- **GPT-6.1 Sol · Medium** (`gpt-6.1-sol`): 기존 검색 두 경로의 의미와 후속 단계의 경계를 정리한다.
- 문구·문서 링크 대조만 하는 좁은 작업에는 GPT-6 Luna · High를 사용할 수 있다. 기존 교사·심사 관점 검토와 시안을 처음부터 반복하지 않는다.
- 모델은 개발 도구 추천이며 서비스 실행 시 사용할 LLM 선정은 아니다. 공식 안내와 공통 사용 원칙은 [PLANS의 통합 계획](../docs/PLANS.md#검색-화면-통합-후속-계획--2026-10-11)을 따른다.

### 2. 세 검색 경우와 조건 해제

`Q`는 기존 교사 검색의 자연어 조건을 통과한 **페이지 분할 전 판본별 후보**, `S`는 선택 공식 기준의 **페이지 분할 전 판본별 후보**다. 기준 후보는 승인 자산만이 아니라 기존 원문·공식 보조문서의 탐색 근거로 발견한 자료를 포함한다. 실제 회차 ID를 기준으로 대조하며 같은 제목이라는 이유로 교집합을 만들지 않는다.

| 입력 | 후보 범위 | 해제 결과 |
| --- | --- | --- |
| 검색어만 | Q에 현재 화면 필터 적용 | 질문 해제 시 전체 보유 자료에 남은 필터 적용 |
| 성취기준만 | S에 현재 화면 필터 적용. 자동 비교 미지원 기준도 후보 탐색 제공 | 기준 해제 시 전체 보유 자료에 남은 필터 적용 |
| 검색어 + 성취기준 | Q ∩ S에 현재 화면 필터 적용. 기준 원문을 질문 뒤에 붙이는 방식으로 대체하지 않음 | 기준만 해제하면 Q, 질문만 해제하면 S. 나머지 조건 유지 |
| 두 입력 없음 | 기존 교사 전체 목록에 현재 화면 필터 적용 | 전체 조건 초기화 시 기존 기본값으로 복귀 |

- 질문의 기존 AND/OR·주제/관계·장소·제외·필수 프로그램·선호를 유지한다. 프로그램 선호는 가산이고 필수 조건은 좁힘이다. 학년이나 수업 방법만 있는 문장은 기존 해석대로 주제 제한 없이 문맥·미확인 안내를 제공한다.
- 기존 엔진이 관계·장면·난이도를 판정하지 못하면 해석된 조건과 미확인 범위를 안내한다. 미지원 요청을 충족했다고 표현하거나 결합 결과를 늘리려고 질문·기준을 자동 해제하지 않는다.
- 잘못된 기준 코드·허용하지 않은 필터·날짜·페이지는 입력 오류다. 자동 비교 규칙 미지원은 유효한 기준이며 입력 오류가 아니다. 후보 0건, 조건 교집합 0건, 조회 실패를 구분한다.
- 기준 선택·해제·변경과 질문/필터 변경은 페이지 1로 돌아간다. 기준 패널 접기/펼치기는 조건·페이지에 영향을 주지 않는다. 조건 해제는 명시적 사용자 조작으로만 수행한다.
- 단일 기준 선택을 기본으로 한다. 복수 기준 검색은 이번 범위 밖이고, 저장 자료의 복수 선택 이유는 기존 기능으로 유지한다.

### 3. 단일 목록·필터·정렬·집계

| 조건 | 유지할 의미 |
| --- | --- |
| 유형 `kind` | 방송 회차·교과 클립·강의·프로그램/회차 목록. 기존 `all`은 개별 자료이며 `collection`은 명시적 선택. 기준 후보에는 현재 목록형 자료가 없으므로 목록 유형과 기준 결합은 0건일 수 있음 |
| 주제 `conceptGroup/concept`, 이전 `topic`, 장소 `place` | 원문 개념과 기존 주제 경계·제외 처리 유지. 미분류는 태그 없음이며 내용 부적합이 아님. 주제 묶음 변경 시 세부 개념 해제는 기존 명시적 동작 |
| 프로그램 `program`, 기간 `year/from/to` | 프로그램 일치와 유효 방송일 적용. 연도와 날짜 범위는 서로 대체, 미확인 날짜는 따로 선택. 수집일로 방송일 대체하지 않음 |
| 교과 탐색 `subject` | 사회/과학/공통/미분류 원문 태그 탐색. 선택 기준의 공식 교과와 별개 |
| 원문 `description` | 기존 5분류 `none/repeated/production/short/detailed`와 `present/title` 호환. 공식 보조문서 발췌를 소개문 품질로 승격하지 않음 |
| 확인 `curriculum` | 기준이 없으면 기존 수업 과정/교과 문맥의 현재 유효 관계. 기준이 있으면 **선택한 기준**의 사람 승인 또는 공개 자동 검사 자산만 적용. 검색 중 계산한 부분 설명을 저장된 자동 검사 통과로 대체하지 않음 |
| 개별 페이지 확인 `access` | 기존 출처·ID·제목 대조 상태. 재생 가능·학년 적합성·교육과정 승인을 뜻하지 않음 |

- 모든 판본에 질문·기준·필터·현재 관계를 적용한 뒤 전체 정렬→판본 묶음→총건수→페이지를 계산한다. 기존 9건 페이지 단위를 유지하고 현재 페이지의 9건끼리 교차·재필터하지 않는다. 필터 통과하지 못한 판본을 대안으로 되살리지 않는다.
- 관련순: 질문만이면 기존 제목/소개문·직접 개념·명시적 선호 점수와 품질 동점을 유지한다. 기준이 있으면 선택 기준의 유효한 제한 관계 설명을 우선하고, 같은 관계 수준에서는 기존 원문 품질·개념 근거 순서를 유지한다. 결합 시 같은 관계/품질 수준에서 질문 관련도를 반영한다. 규칙 미지원은 불일치나 음수 벌점으로 쓰지 않는다. 안정적인 제목/ID 동점을 유지하며 가중치의 구체 구현은 R07-07에서 검증한다.
- 최신순·오래된순은 필터를 통과한 전체 판본의 유효 방송일 순서이며 날짜 미확인은 마지막이다. 같은 제목 판본도 해당 정렬과 근거를 유지한다. 선택 관계의 인용이나 승인 배지를 다른 대표 판본으로 전파하지 않는다.
- 총건수는 현재 조건을 통과한 판본 **묶음 수**, 페이지도 같은 목록이다. 각 필터 옵션 수는 질문·기준·다른 조건을 유지하고 해당 필터만 바꾼 묶음 수다. 주제 묶음/연도처럼 기존 연동 조건을 바꾸는 경우 그 동작을 함께 반영한다. 옵션 수는 서로 겹칠 수 있어 합산하지 않는다.
- 빈 결과는 `total=0/pages=0/page=1`에 해당하며 화면은 이동 불가 상태를 표시한다. 범위를 넘는 유효 페이지는 마지막 페이지로 보정한다. 빈 목록·오류를 이전 기준 결과로 채우지 않는다.

### 4. 교과·학년·공식 기준·수업 목표

- 일반 `subject`는 탐색 태그 조건, 공식 기준의 교과는 선택 기준 자체의 출처 정보다. 기준 선택용 교과/과정 필터는 **기준 선택 목록**을 찾는 조건이며 결과의 탐색 태그를 덮어쓰지 않는다. 예를 들어 과학 기준과 사회 탐색 태그를 함께 선택하면 두 조건을 유지하고 0건도 허용한다.
- `grade`는 교사의 수업 대상 문맥(초등3~6·중1 또는 미지정)이다. 기준 원문의 `gradeBand`와 적용 참고 `courseId/placement`는 따로 보존한다. 기준을 선택해도 대상 학년을 자동 변경하지 않는다.
- 대상 초등3학년 + 초등5~6 기준처럼 과정이 다르면 차이를 안내하되 선택 기준 후보와 그 관계를 임의로 제거하지 않는다. 기준의 현재 관계는 해당 기준 과정으로 검증하고, 대상 학년은 영상의 추천 학년이나 적합성 판정으로 사용하지 않는다. 질문에서 추출한 학년과 명시적 대상이 충돌하면 기존 확인 필요 안내를 유지한다.
- 공식 214개 기준은 실제 저장 목록을 사용한다. 공식 코드·교과·학년군·전체 문장·교육과정 판본·출처 문서/쪽·원문 대조 범위를 표시한다. 공식 기준 원문 대조 승인과 **방송–기준 관계 승인**은 별개다.
- 중1은 공식 중학교 **1~3학년군** 원문과 **EBS 뉴런 중1 편성 참고**를 함께 표시한다. 개별 학교의 중1 편성·영상 난이도는 미확인이다. `9사(지리)…`·`9사(일사)…` 코드를 괄호 포함 원형과 URL 인코딩으로 보존한다.
- 교사의 `lessonGoal`은 이번 수업에서 하려는 개인 목표다. 공식 기준을 편집하거나 기준 전체 충족으로 표시하지 않는다. `usePart/additionalContent`·개인 난이도·선수개념·장면 기록도 공용 승인·공식 출처와 분리한다.

### 5. 근거와 역할

- 교사는 개별 자료의 내용 안내·질문 관련 이유·선택 기준 요구→소개문에서 확인한 내용→정확한 인용→남은 요구·출처·현재 확인 수준을 본다. 다른 기준의 사람/자동 이력은 별도 정보이며 선택 기준 배지·필터·인용으로 사용하지 않는다.
- `UNSUPPORTED/TITLE_ONLY/DESCRIPTION_LOW/CONCEPT_ONLY/PARTIAL_SUPPORTED/INTERPRETATION_HELD/EXPLICIT_CONFLICT`를 유지한다. 미지원·원문 부족 등은 중복될 수 있다. 명시적 상충은 요구 대상에 대한 입증이 있는 경우이며, 미지원·미확인으로 부적합을 단정하지 않는다.
- 제목/소개문 탐색 인용, 요구별 관계 인용, 별도 공식 보조문서의 `DISCOVERY_ONLY` 발췌를 구분한다. 인용의 회차 ID·판본·출처 URL·필드/오프셋·내용 지문·버전·확인일을 유지한다. 소개문 비교를 영상 전체 시청·학생 수행·기준 전체 달성으로 표현하지 않는다.
- 자동 요구 비교, 자산 저장 검사, 공개 자동 후보, 실제 사람 승인은 서로 다른 상태다. 현재 운영 사람 승인 0·자동 공개 1은 이전 보고 기준이며 이번 검색 계약으로 새 승인·자산·판단을 만들지 않는다.
- 관리자는 확보 기준/회차·공백·원문 보강·규칙 지원·검사/공개/승인 집계와 오류·변경 처리·선택적 사람 결정을 관리한다. 전체 운영 집계는 관리자 작업공간에 두고 교사 기본 흐름에서 제거하는 연결은 R07-09다. 이번 단계는 기존 공개 응답 필드의 삭제나 권한 변경을 구현하지 않는다.
- 관리자 교육과정 주소·세션 인증·Origin/Host 검사·쓰기 권한을 보존한다. 교사 검색에서 자동 검사/저장·사람 결정 API를 우회 호출하지 않는다.

### 6. 이전 주소·검색 복원·개인 저장 호환

| 기존 입력/저장 | 통합 후 보존 범위 |
| --- | --- |
| `/?q=…&grade=…` 및 일반 필터 | 질문·대상 학년·필터·정렬·페이지 의미 유지. URL이 있으면 URL 우선, 없으면 저장된 검색 조건 복원. 이전 `topic` 호환, `view/browse` 무시 유지 |
| `/curriculum.html?standard=…&subject=…&grade=…&state=…&page=…` | R07-08에서 통합 자료 찾기로 조건 보존 이동. `standard`는 선택 기준, **이 주소의** `subject/grade`는 기준 선택 목록 교과/과정으로 변환하고 일반 탐색 태그/수업 대상으로 바꾸지 않음. `state`는 선택 관계 상태 필터, `RELATION_MISSING`은 기존처럼 `CONCEPT_ONLY`. 같은 조건의 `page`를 유지하되 결과 범위 초과 시 보정 |
| 이전 기준 주소에 선택 기준 없음 | 기준 선택 목록의 교과/과정은 보존하고 통합 전체 목록 표시. 이전 화면의 빈 자료 목록을 새 통합 기본값으로 고정하지 않음 |
| 이전 주소의 기준과 교과/과정 불일치 | 오류와 수정할 조건 안내. 기준/조건을 삭제하거나 다른 기준으로 치환하지 않음. 새 통합 화면의 개인 대상 학년 차이 안내와 구분 |
| `/admin-curriculum.html` 및 관리자 복귀 주소 | 이전 주소 그대로 관리자 경로 유지, 교사 화면으로 일괄 이동하지 않음 |
| `curi.teacher.search.v1` | 기존 문자열 필드와 이전 검색 읽기 유지, 선택 기준 등 추가 조건을 R07-08에서 복원 연결. 이전 저장에는 기준 미선택 기본값, 읽기 실패 시 안내. 새 필드의 실제 이름은 해당 구현에서 기록 |
| `curi.discovery.shelf.v1` | 같은 회차 ID·내 자료 최대100개·기존 `selectionContexts` 최대20개와 저장 당시 스냅샷/개인 입력 유지. 검색 기준 해제/변경으로 저장된 선택 이유를 소급 수정하지 않음 |
| `curi.teacher.folders.v1`·`curi.teacher.lesson.v1` | 기존 폴더·대상 학년·자료 역할·메모·복수 수업 이유와 이전 준비안 읽기용 원본 유지. 키 삭제·일괄 변환·서버 동기화 없음 |
| 재열기·내보내기 | 현재 원문/관계 재조회와 저장 당시 문맥을 구분. 승인 취소·원문 변경·조회/저장/내보내기 실패 시 개인 입력 유지, 오래된 배지는 현재 확인으로 표시하지 않음. 같은 브라우저·같은 origin 저장의 한계 유지 |

새로고침·뒤로 가기·빠른 기준 전환·재시도는 현재 조건을 복원하고 늦은 응답을 버린다. 선택 패널의 접힘 상태는 기준 해제와 별개다. 기존 기준 API를 즉시 폐기하거나 관리자 호환을 깨는 변경은 후속 구현 범위에 포함하지 않는다.

### 7. 후속 확인용 대표 입력

아래는 개발/통합 회귀 사례다. 실제 저장소의 공식 코드를 대조했으며 결과 ID·건수·교육적 정답을 미리 보증하지 않는다. 질문 검색의 기존 결과를 고정 대조하고, 기준 후보 전체와 결합 교집합·해제 결과를 비교한다. R09-02 독립33관계·판단·해시는 수정하지 않으며 이 사례를 독립 품질 점수로 합산하지 않는다.

| ID | 교과·경우 | 입력 | 기대 동작 |
| --- | --- | --- | --- |
| S-Q | 사회·질문만 | 대상 초등5학년, `선거에서 시민이 대표를 뽑는 자료를 찾아줘` | 기존 자연어 해석/검색과 같은 범위. 대표 선정·태도 달성은 설명 확인 범위를 넘어 단정하지 않음 |
| S-S | 사회·기준만 | `6사04-01`, 질문 없음 | 유적·유물 생활 추론 후보와 선택 기준 근거. 농경문 청동기의 기존 자동 공개가 나오면 그 회차·기준에만 표시, 고조선 소속/학생 수행은 미확인 |
| S-QS | 사회·결합 | `농경문 청동기` + `6사04-01` | 판본 ID로 Q ∩ S. 질문만 해제하면 S-S 후보, 기준만 해제하면 같은 질문의 일반 후보. 프로그램/기간 등 남은 조건 유지 |
| S-U34 | 사회·초등3~4 미지원 | 대상 초등3학년, `주변 장소` + `4사01-01` | 기준은 3~4학년군, 후보가 있으면 미지원 안내와 원문 탐색 근거. 기준 선택으로 대상 학년·교과 태그 자동 생성 없음 |
| S-UM1 | 사회·중1 미지원 | 대상 중학교1학년, `사막` + `9사(지리)01-01` | 공식 1~3학년군/뉴런 참고/학교 미확인 표시. 괄호 코드 복원, 자연·인문환경 추론 요구 전체 충족은 미확인 |
| C-Q | 과학·질문만 | 대상 초등6학년, `지구 자전과 낮과 밤을 설명하는 자료` | 기존 질의 범위·조건/관계 미확인 안내 유지. 자전/공전·우주 배경 오탐 경계 재사용 |
| C-S | 과학·기준만 | `6과12-02`, 질문 없음 | 제한된 자전·낮밤 원인 요구 비교, 대응 인용/남은 요구. 단어 일치만으로 원인 설명 확인 배지 생성 없음 |
| C-QS | 과학·결합 | `지구 자전` + `6과12-02` | Q ∩ S, 질문 해제 시 C-S, 기준 해제 시 일반 검색. 방송일순/필터 수/페이지도 같은 교집합 전체에서 계산 |
| C-U34 | 과학·초등3~4 미지원 | 대상 초등4학년, `물체를 밀거나 당기는 현상` + `4과01-01` | 공식3~4학년군, 미지원과 후보 없음 구분. 관찰 수행/난이도는 미확인 |
| C-UM1 | 과학·중1 미지원 | 대상 중학교1학년, `마찰력` + `9과05-02` | 공식1~3학년군/뉴런 참고 유지. 힘의 크기·방향 설명은 직접 근거가 없으면 미확인 |

공통 경계는 위 입력을 재사용한다: S-S의 대상만 초등3학년으로 바꿔 기준 보존/차이 안내, C-S에 사회 탐색 태그를 추가해 독립 조건 유지, S-QS/C-QS에 원문·프로그램·기간·확인 필터와 방송일 정렬을 적용해 전체 묶음/건수/페이지 대조. 잘못된 코드·역전 날짜는 오류, 미지원 필터는 유효 탐색, 빠른 기준 전환/조회 실패는 이전 결과 미노출, 자료 담기 후 기준 변경은 저장 이유 보존을 확인한다. 현재 사람 승인0 상황에서 선택 기준 승인 필터가 0건이어도 정상이며 배지 전파 경계는 기존 격리 fixture를 재사용한다.
