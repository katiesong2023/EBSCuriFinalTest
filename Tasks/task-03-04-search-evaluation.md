# Task 03-04 - 알려진 항목·조건 검색 최종 확인

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R03·R09 / 검색 검증에 통합**. 사회·과학 균형 질의, 문장 해석·근거·빈 결과를 함께 평가한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

EBS 공식 인벤토리로 확인한 알려진 항목·학년·교과 조건 검색이 동결 버전에서 동작하는지 확인한다.

## 구현 항목

- [ ] 사전 등록한 8~12개 시나리오의 기대 강좌/강의 식별자가 결과에 포함되는지 확인한다.
- [ ] 명시한 학년·교과 조건 위반 결과, 무결과·오류, EBS 원문 링크 표시 여부를 기록한다.
- [ ] 알려진 항목 반환율·조건 위반 반환 건수·원문 링크 표시율·오류 건수만 계산한다.
- [ ] 결과를 개발·회귀 기능검증으로 보고, 일반 검색 관련도·교사 수업 유용성·Precision@K로 해석하지 않는다.

## 범위 밖

- 비전문 제작자의 0/1/2 관련도 채점
- Precision@K·후속 표본·교사 유용성 주장

## 사전 전제

- R02 근거 태그 및 R03 사회·과학 12개씩의 로컬 질의·기준선
- R04의 고정 가상 자료 조건 처리 회귀
- 실제 교육적 적합성 평가는 R09에서 구분한다. 유료 API·대량 사람 승인 완료는 기능 검증 선행 조건이 아니다.

## 완료 조건

- [ ] 모든 시나리오의 입력·기대 식별자·실제 반환·조건·원문 링크 상태가 남는다.
- [ ] 기능검증 수치가 일반 검색 성능 수치가 아님을 보고서에 명시한다.
