# Task R07-11 - 검색 화면·정보 구조 간소화

## 설명

사용자가 승인한 검색 화면 정리안을 적용한다. 과정별 예시의 중복을 제거하고 검색창·주제 예시, 선택적 교육과정 조건, 결과·필터 순으로 화면을 간소화한다. 상태: **진행중**.

## 구현 항목

- [x] 기본18개 예시를 유지하고 과정별 예시를 제거하며 검색 후 예시를 접는다.
- [x] 문장 검색 안내와 검색어 지우기를 검색창에 통합한다.
- [x] 자료 유형·정렬을 우선 표시하고 나머지 결과 조건은 상세 필터로 묶는다.
- [x] 중학교 편성·해설은 기준 선택 후 제공하고 관리자 안내는 하단에 통합한다.
- [x] 기존 검색 조건·주소/저장 복원·기준/근거·내 자료 동작을 보존한다.

## 범위 밖

- 검색 엔진·자동 판정 규칙·공식 기준/원문 변경
- 내 수업 폴더·관리자 화면 재설계

## 사전 전제

- R07-08~10 통합 검색·공식 안내·기본18개 예시

## 수동 작업

새 키·계정·추가 자료 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 관련 코드 수정·HTML/CSS/JS 기준 확인
- [x] 예시 접기/열기·조건 보존·상세 필터/복원·모바일 표시 확인
- [x] 실제 구현에 맞춰 task·구조·상태 문서 갱신

### 결과 확인

- [ ] 자료 찾기를 새로고침해 기본 예시18개와 접힌 교육과정·상세 필터를 확인한다. 과정별 예시와 결과 위 관리자 안내가 없는지 확인한다.
- [ ] 예시 또는 직접 입력으로 검색한다. 예시가 접히고 다시 열 수 있는지 확인한다.
- [ ] 교육과정 기준과 상세 조건을 선택한 뒤 검색창의 ‘지우기’를 누른다. 검색어만 지워지고 선택 기준·다른 조건이 유지되는지 확인한다.
- [ ] 상세 필터에서 주제·프로그램·기간·소개문·확인 상태를 조정하고 현재 조건의 개별 해제·새로고침 복원을 확인한다.
- [ ] 중1 기준을 선택해 공식 학년군·EBS 참고·공식 해설/편성 근거가 표시되는지 확인한다.
- [ ] 좁은 화면에서도 검색창·필터·결과를 이용할 수 있는지 확인한다.


## 구현 결과

- `public/discover.html`에서 중복 과정별20예시·문장 예시 버튼·별도 검색어 해제 영역을 제거했다. 기본 사회7·과학8·공통3의18예시는 `search-examples`에 보존했다. 문장 검색 예시는 검색창 도움말, 검색어 해제는 검색창의 ‘지우기’에 통합했다.
- `discover.js`는 초기 질문/기준이 없을 때 예시를 펼치고 질문 또는 기준이 바뀌면 접는다. 사용자가 다시 펼친 예시는 같은 질문/기준의 정렬·페이지 변경에서도 유지된다. 지우기는 검색어만 변경하고 선택 기준/필터를 보존하며 검색창으로 초점을 이동한다.
- 자료 유형과 정렬은 우선 노출한다. 주제 묶음/개념·프로그램·기간·교과/소개문·확인 상태·선택 관계 상태·개념/장소 탐색을 단일 ‘상세 필터’로 묶었다. 현재 조건과 개별 해제는 밖에 유지하고 적용한 조건이 없으면 빈 조건/해제 영역을 숨긴다. 활성 상세 조건의 주소/저장 복원에서는 해당 패널을 펼친다.
- 선택 전 반복 중학교 안내와 비활성 성취기준 해제 버튼을 숨기고 기존 선택 기준의 공식 안내를 유지했다. 관리자 안내는 하단 관리자 작업공간·교육과정 관리 링크로 통합했다.
- `discover.css`는 예시 상세/검색창 지우기/조건 영역을 조정했다. `curriculum-picker.js`는 선택이 없을 때 해제 버튼을 숨긴다. 기존 필터 ID·검색 파라미터·저장 키·공식214기준·자동 규칙/승인 데이터는 유지한다.
- 과정·영역의 균형→관련성→원문→결과 수의 예시 선정 순서와 과정별 대응은 내부 검토 기록으로 보존하며 과정별 목록을 화면에 반복하지 않는다.
