## 설명

자동 추출된 사회 교육과정을 공식 원문과 비교해 사용할 기준 목록을 확정한다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: 준비
- 예상 집중 작업: 약 2시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Terra** (`gpt-5.6-terra`)
- 추천 추론 수준: **medium**
- 선택 이유: 표·본문 대조와 문맥 판단이 필요하다. 모델은 대조를 보조하고 최종 사람 QA를 대신하지 않는다.
- 상향 조건: 원인을 좁혀도 해결되지 않는 제약·상태·데이터 무결성 문제는 해당 부분만 Sol / medium으로 검토한다.
- 사람 판단/수행 포함: 모델은 양식·대조·정리를 보조한다. 직접 검수·채점·시간 측정·녹화·발송의 수행 사실을 대신 만들지 않는다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.
