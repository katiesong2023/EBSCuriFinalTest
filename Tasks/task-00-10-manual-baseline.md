# Task 00-10 - 운영 기록 기준선 정의

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R09 / 기술·품질 검증에 통합**. 유료 모델·대량 사람 승인과 독립적으로 기술 검증한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

교육과정 의미 판단 시간을 비교하지 않고, CuriMap·검수·검색의 실행 시간·성공·오류·재시도를 재현 가능하게 기록할 기준선을 정의한다.

- 상태: 예정

## 구현 항목

- [ ] CuriMap 실행, 검수 동작, 알려진 항목 검색의 공통 기록 필드(실행 ID·시각·입력 ID·코드/데이터 버전·결과 상태·지연·오류·재시도)를 정한다.
- [ ] 측정 시작·종료를 화면 동작 또는 API 요청 기준으로 정하고, 로그인·최초 설치·사람의 교육과정 의미 판단 시간은 제외한다고 기록한다.
- [ ] 실행 성공률·오류/재시도 건수·지연 시간은 기술적 운영 수치이며 교사·EBS 업무시간 절감으로 일반화하지 않는다고 명시한다.

## 범위 밖

- 수작업 성취기준 라벨과 CuriMap의 시간 절감 비교
- 교육과정 전문가가 아닌 제작자의 의미 판단 시간 측정
- 실제 EBS 업무시간 주장

## 사전 전제

- R01~R03 실제 실행 보고와 측정 가능한 로컬 검색
- R09에서 시간·오류·프로그램 편중·내용 근거를 분리 집계한다. 유료 모델 사용 기록은 실제 R10 실행 시에만 추가한다.

## 완료 조건

- [ ] 공통 운영 기록 양식과 시작·종료 기준이 준비된다.
- [ ] 기능·운영 수치와 교육적·업무적 효과 주장이 구분된다.
- [ ] AI가 실제 실행·시간 측정을 수행한 것으로 기록하지 않는다.
