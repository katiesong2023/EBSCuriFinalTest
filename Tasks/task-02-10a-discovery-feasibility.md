# Task 02-10A - 개념·장소 기반 콘텐츠 탐색 자료 타당성 확인

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R09 / 사람 판단 후속 유지**. 기존 검수 양식·기록 보존, 고정 검수량은 수집·검색 개발의 선행 조건이 아니다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

2026-09-30 정본: 기술 자료 확보·반복 수집·검색 연결은 [02-10E](./task-02-10e-broadcast-corpus.md)와 [수집 실측](../docs/BROADCAST_CORPUS.md)으로 갱신됐다. 김제는 제목뿐이던 단계에서 공식 회차 소개문·회차 ID 대조까지 확보했다. 아래 20건·2시간은 초기 조사 이력이며 현재 수집 상한이 아니다. 이 task의 현업 적합성·장면 확인 Gate는 `진행중`으로 유지하고 마지막 사람 판단 단계로 미룬다. 아래 과거 미확인 설명을 현재 구현 미완료로 해석하지 않는다.

‘동고서저 관련 클립’ 요청에서 개념·지형·지명을 거쳐 실제 EBS 자료를 찾을 수 있는지 유료 서비스 API 없이 확인한다. 콘텐츠 직접 태깅과 25건 검수에 앞서 자료 확보 가능성과 근거를 점검하는 첫 작업이다.

- 상태: `진행중` — 02-10B에서 출처 검색 색인과 지리 메타데이터를 일부 확보했다. 아래 원래 자료 확보 Gate는 아직 통과하지 않았다.
- 2026-09-28 진행 근거: [0.2 자료 범위·출처·부족 사항](../docs/CURI_LOCAL_0.2.md). 서쪽 평야 자료는 제목 단계이며 일반방송 개별 재생·장면 근거, 반복 공급 적격률·건당 조사 시간은 미확인이다. 사용자 요청으로 사람 판단을 미루고, 근거 수준을 표시하는 로컬 탐색 구현을 별도 완료했다.
- 기준: [수정 설계서](../planning/concept-place-discovery/PLAN.md). 구현 방침은 검토용 초안이며 이 task는 자료 타당성 확인만 다룬다.

## 구현 항목

- [ ] 공식 교육·지리 자료에서 개념과 지형·지명의 관계 및 출처를 확인한다.
- [ ] 기존 데이터와 EBS 공개 자료에서 실제 회차·클립 후보를 찾고 고유 ID·제목·자료 단위·출처·짧은 내용 근거·확인일을 기록한다.
- [ ] 장소 언급과 지형 주제 설명을 구분하고, 같은 지명의 무관한 콘텐츠를 대조 후보로 기록한다.
- [ ] 고유 후보 20건 또는 실제 조사 시간 2시간 중 먼저 도달한 시점까지 조사하고 확보·부족·제외 사유를 보고한다. 이는 수집 목표가 아닌 초기 조사 상한이다.
- [ ] 근거 있는 자료 3건·지형 사례 2종·식별 가능한 실제 클립 1건의 확보 여부를 보고한다. 회차만 있으면 클립 확보로 집계하지 않는다.
- [ ] 고정 검색 확인 시나리오와 최대 5건의 간단한 근거 대조 자료를 준비한다. 성취기준 직접 태깅·자유서술을 사용자 필수 작업으로 만들지 않는다.
- [ ] 서비스 생성 API 호출 0회, 실제 조사 범위, 프로그램 다양성, 접근·학년 적합성 미확인 항목을 기록한다.
- [ ] [현업 실용화 평가](../planning/concept-place-discovery/READINESS.md)에 따라 후보 공급원별 실제 적격률·확보 필드·건당 조사 시간·반복 확보 가능성을 기록한다. 조사 상한에서 판단할 수 없으면 미확인으로 남기고, 소수 자료 확보를 현업 서비스 가능으로 보고하지 않는다.
- [ ] 자료가 충분하면 최소 검색 경로 구현을, 부족하면 추가 소싱 또는 시나리오 조정을 제안한다.

## 범위 밖

- 서비스 코드 변경과 유료 LLM 호출
- 기존 25건의 일괄 승인 또는 기존 검증 자산 수정
- 확인하지 않은 지명 관계·영상 제목·자막·타임코드 생성
- 회차를 임의의 클립으로 표시
- 교육과정 전문 정확도 평가, 전 학년 확장

## 사전 전제

- 기존 Working Set과 원문 출처, 사회 공식 기준, 02-10 검수 준비 자료를 사용한다.
- 02-10의 25건 사람 검수 완료를 선행 조건으로 두지 않는다.
