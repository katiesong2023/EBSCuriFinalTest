# Task R03 - 자연어 수업 요청 해석과 근거 검색

## 설명

키워드 일치 중심 탐색을 주제·대상·장소·수업 의도·제약으로 나눠 해석하는 로컬 탐색으로 개선한다. 지원하지 않는 조건을 조용히 버리거나 충족했다고 표시하지 않는다.

## 구현 항목

- [x] 자연어 문장에서 핵심 주제와 문맥·제약 분리
- [x] 시맨틱 레이어의 원문 근거 태그·동의어로 방송 후보 검색
- [x] 복수 주제·부정·미지원 시간/자막/학년 조건을 명시
- [x] 사회·과학 같은 수의 시나리오로 전후 비교
- [x] 조정에 사용하지 않은 추가 표현·무관 결과·빈 결과 검증
- [x] 홈페이지에 해석·근거·미지원 조건 표시

## 범위 밖

- 범용 한국어 이해 완성 주장, 유료 모델, 교육적 정답률 평가

## 사전 전제

- 기존 탐색 화면·R02의 원문 근거 태그

## 수동 작업

추가 계정·키 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 10건 이상 유료 API 없는 로컬·브라우저 테스트
- [x] 원문 링크·자료 모음·승인 저장소 회귀 확인
- [x] 검색 후보 존재와 의미 적합성을 구분한 전후 보고

### 결과 확인

- [ ] 사회·과학 수업 요청으로 검색하고 자료 목록을 먼저 본 뒤 설명을 펼치는 흐름이 원하는 방식인지 확인한다.

## 실제 산출물과 확인 경계

[이번 작업 보고](../docs/REDESIGN_RESULTS.md)에 실제 수집량·검사·재현 명령을 기록한다. 구현·에이전트 확인은 완료했지만 사용자 결과 확인 전 상태는 진행중이다. 사람 적합성 승인·재생·장면 검증은 수행하지 않았다.
