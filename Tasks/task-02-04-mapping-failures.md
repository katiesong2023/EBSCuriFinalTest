# Task 02-04 - 연계 입력·실패·재시도 처리

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

잘못된 입력과 API 실패가 가짜 성공이나 불필요한 비용으로 이어지지 않게 한다.

- 상태: `완료` — 2026-09-22 사용자 확인과 `docs/PLANS.md`의 완료 기록 기준. 아래 미체크 분기는 실제 발생하지 않았거나 개별 확인 기록이 없는 항목으로 유지한다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 2
- 예상 집중 작업: 약 1.5시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Sol** (`gpt-5.6-sol`)
- 추천 추론 수준: **medium**
- 선택 이유: 실패 분기·중복 비용·입력 제약은 정상 흐름만 만드는 것보다 판단이 필요하다.
- 상향 조건: 처음부터 xhigh·max로 시작하지 않는다. 해결하지 못한 원인이 명확하고 더 깊은 분석이 필요한 부분에만 high로 올린다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.

## 실제 산출물

- `public/curimap.html`, `public/curimap.js`, `public/curimap.css`: 빈 텍스트·20자 미만 설명·지원하지 않는 URL 안내, 공개 원문 확인 체크박스, 실행 중 입력 잠금, 최근 24시간 실행 횟수·남은 횟수·다음 실행 가능 시각, 실패한 호출의 사용량 표시를 추가했다. 입력 변경 후 도착한 후보 응답과 실행 시작 전의 오래된 이력 응답을 무시한다.
- `server/curimap-mapping.js`: 활성 저장 콘텐츠에 대해 공개 텍스트 20~1200자와 HTTPS EBS 출처를 확인한다. 사용자 정보·별도 포트가 들어간 URL은 거절한다. 저장된 소개문·출처와 다른 입력은 `publicTextConfirmed: true`가 있어야 처리한다. URL 자동 수집은 하지 않는다.
- 실행 정책: 콘텐츠별 최근 24시간 최대 3회(최초 실행 포함), 자동 재시도 없음. 입력 오류는 실행 횟수를 쓰지 않는다. 실행 예약 후의 키체인 실패·후보 없음·API 실패·성공은 모두 횟수에 포함되며, 입력을 수정해도 콘텐츠별 한도는 유지된다. 이전 실행 이력도 24시간 한도에 포함된다.
- 같은 입력·콘텐츠 조건·공식 목록의 최근 성공 결과는 API 재호출·초안 중복 저장 없이 재사용한다. 호출 전에 `server/data/curi-store.json`의 `mappingRuns`에 실행을 예약하며, 재시작 뒤에도 한도를 유지한다. 중단된 `RUNNING` 이력은 조회 시 `MAPPING_INTERRUPTED` 실패로 안내한다.
- 실행 이력에 동일 입력의 `attemptNumber`·`retryCount`, 실제 요청 시도 여부, 공식 후보 ID, 사용량, 지연, 실패 코드를 남긴다. 응답 형식 오류·후보 밖 기준도 API가 반환한 사용량을 보존하며, 사용량 미수신을 비용 0으로 표시하지 않는다.
- `server/server.js`: 입력 오류 400·본문 초과 413·동시 요청 409·사용/재시도 제한 429·타임아웃 504를 구분하고 실패 결과·재시도 정보를 응답에 포함한다. 동일 서버의 연계·증분 가져오기 쓰기 요청은 한 번에 하나만 허용한다.
- `public/review.js`: 실행 중인 이력을 `RUNNING`으로 표시하고 검수 선택을 비활성화한다.
- API 키는 기존 키체인에서 Authorization 헤더에만 사용한다. 고정 API 주소, 리디렉션 거부, 도구 없음, 비신뢰 원문 지시 무시, 응답 필드·타입·공식 후보 검증을 유지·보강했다. API 오류 원문·예외 상세는 화면이나 연계 로그로 전달하지 않고, 화면의 원문·AI 결과는 텍스트로 렌더링한다.
- `server/curimap-failures-check.js`, `package.json`: `npm run data:mapping:failures:check`로 실제 API·키체인·저장소 변경 없이 입력·실패·재시도·동시 요청·중단 복구·화면 응답 순서와 HTTP 상태를 모의 검증한다.
- 현재 중복 쓰기 보호 범위는 한 로컬 서버 프로세스다. 별도 CLI 적재나 다른 서버 프로세스와 동시에 같은 저장 파일을 수정하는 운영은 다루지 않는다.
