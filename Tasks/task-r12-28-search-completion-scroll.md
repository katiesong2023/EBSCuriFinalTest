# Task R12-28 - 검색 버튼 높이·완료 후 결과 이동

## 설명

사용자 요청2026-10-15. 검색란의 지우기/자료 찾기 버튼 높이를 맞추고 검색 완료 후 결과 영역으로 이동한다. 상태: 진행중.

## 구현 항목

- [x] 지우기·자료 찾기 버튼의 높이를 같게 표시한다.
- [x] 결과 렌더/로딩 종료 후 최신 요청의 결과 영역으로 이동한다.
- [x] 대기/완료/요청 교체·오류·PC/모바일을 확인한다.

## 범위 밖

- 검색 관련성/원본/개인 저장 변경

## 수동 작업

없음.

## 완료 조건

### 에이전트 확인

- [x] 버튼 공통44px·완료 이벤트 연결
- [x] 실제 브라우저 표시/이동 시점 확인

### 결과 확인

- [ ] 새로고침 후 지우기/자료 찾기 높이가 같고 검색 중에는 현재 위치를 유지하다 완료 후 결과로 이동하는지 확인한다.

## 실제 반영·검증

`curi-v11.css`가 두 버튼의44px 높이·줄간격/세로 정렬을 공통 적용한다. `discover.js`는 최신 요청의 렌더/오류 처리와 로딩 표시 해제 후 `curi-search-complete`를 보낸다. `curi-v11.js`는 제출 즉시 스크롤하던 처리를 제거하고 완료 이벤트에서만 결과 헤더로 이동한다. 프레임을 기다리는 중 새 검색이 시작되면 이전 완료의 스크롤도 실행하지 않는다. 기존 모션 줄이기 설정을 유지한다.

실제Chrome1440/390: 두 버튼44px/상단좌표 동일·대기 중 높이 유지·스크롤0, 결과5건 표시/aria-busy=false 뒤 이동 확인. 연속 요청에서는 이전 취소/완료가 이동을 유발하지 않고 최신7건 완료만 이동했다.503오류 표시를 마친 뒤 이동도 확인했다. PC일반/모바일모션줄이기·가로 넘침/브라우저 오류0. [검사](../docs/r12-28-search-completion-check.json). 구현·에이전트 확인 완료, 사용자 확인 대기.
