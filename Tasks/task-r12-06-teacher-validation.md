# Task R12-06 - 교사 자료 선택·반복 사용 검증

## 설명

새 요청에서 자료 선택에 도움이 됐는지와 실제 교사의 반복 사용을 확인한다. 기술 검사·에이전트 대리 판단·교사의 선택·수업 사용을 다른 결과로 보고한다. 상태: **예정**. 2026-10-14 사용자 요청으로 등록했다.

## 구현 항목

- [ ] R12-01의 미노출 평가12개로 상위5 적합성·부분 적합/원문 부족/부적합·알려진 정답 상위20 발견·조건 위반·지연을 기준선과 비교한다. 입력·자료·검색·UX 버전 및 판단자 역할을 기록한다.
- [ ] 사회·과학 지도 교사 최소3명·각4개 실제 요청으로 총12회 사용을 목표로 모집/참여 방식을 준비한다. 교사 연락·초대는 사용자 명시 지시가 있을 때 진행하며 참여가 없으면 대리 평가와 남은 검증을 보고한다.
- [ ] 10분 내 요청에 맞는 자료를 한 건 이상 선택하고, 이유/활용 목적을 설명하며 공식 원문 또는 실제 영상의 내용 확인 후 저장/재열기를 완료했는지 기록한다. 단순 저장과 제목만 본 선택은 성공에서 구분한다.
- [ ] 기준선과 개선판을 대응 가능한 다른 요청으로 비교하고 버전 순서를 교사별 교차 배정하여 학습 효과를 줄인다. 사전 평가 요청을 노출한 교사는 해당 요청의 독립 판단자로 집계하지 않는다.
- [ ] 탐색 시작부터 선택 완료까지 시간·쿼리 재작성·무관 후보·포기/제외 이유·원문/영상 접근·내용 확인·저장 실패를 기록한다. 실패는10분으로 계산하고 성공자만의 시간은 보조 지표로 보고한다.
- [ ] 교사2명 이상의 후속 실제 수업 요청 재사용을 1주 이내 목표로 확인한다. 실제 수업 사용 여부·활용 부분·추가 확인·다음 사용 의향과 실제 재방문을 구분한다.
- [ ] R12 계획의 제품 판단 목표를 비교하고 과목/구간별 성공·실패·미확인 분모와 남은 원인군을 공개한다. 목표 미달이면 우선순위/다음 배치를 수정하고 이미 노출된 평가를 재사용해 독립 개선으로 주장하지 않는다.
