# Task R01 - 방송 공급원 다양화와 2만 회차 확대

## 현재 후속 실행 — 2026-10-14

추가 원천 수집의 우선순위/배치는 [R12-02](task-r12-02-source-coverage.md)로 통합한다. 기존 대량 수집 경로·과거 완료 체크를 재사용하고 실제 요청 공백에 맞춰 신규 프로그램/시즌/회차와 같은 원인의 수집 누락을 함께 개선한다. 누적 회차 수만으로 수업 준비 성공을 완료 처리하지 않는다.

## 설명

사용자가 선택한 50개 프로그램·20,000개 고유 회차를 1차 목표로 공식 공개 메타데이터를 수집한다. 과학은 생태·기후·인체·우주 다큐를 우선하고, 사회·생활·문화·어린이 방송까지 넓힌다.

## 구현 항목

- [x] 공식 방영·종영 프로그램 인벤토리와 출처·확인일 확보
- [x] 프로그램별 실제 회차 ID·제목·공개 소개문·원문 주소 누적
- [x] 중복·실패·중단 재개·프로그램 별칭·시즌 수 집계
- [x] 50개 프로그램·20,000회차 목표 달성 여부와 실제 수집 한계 보고
- [x] 홈페이지 검색 반영 및 승인 자산 불변 확인
