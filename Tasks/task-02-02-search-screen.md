# Task 02-02 - 교사 검색 화면 먼저 만들기

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

교사 자연어 검색과 결과 카드의 화면을 먼저 확인한다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 2
- 예상 집중 작업: 약 1시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Luna** (`gpt-5.6-luna`)
- 추천 추론 수준: **low**
- 선택 이유: 표시 항목이 기획에 정해져 있어 저비용 모델로 빠르게 화면을 확인할 수 있다.
- 상향 조건: 요구사항이 모호하거나 수정이 여러 파일·상태로 번지면 해당 문제만 Terra / medium으로 올린다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.

- [x] `public/index.html`, `public/index.css`, `public/index.js`에 수업 질의·필터·정렬·결과 카드·상태 예시 화면을 준비했다.
- [x] 관련 파일·자료의 정적 점검 또는 구조 기준 확인이 끝났다.
- [x] HTML 시맨틱 구조, CSS 변수·반응형 규칙, 화면 전용 JavaScript 규칙을 확인했다.
- [x] 실제 수행 결과에 맞춰 이 task의 산출물·수동 작업·결과 확인을 갱신했다.
- [x] 사람 수행·검토가 필요한 브라우저 결과를 AI가 완료한 것으로 기록하지 않았다.
- [x] `node --check public/index.js`와 `git diff --check`를 통과했다.

### 결과 확인 (구현 후 구체화)

- [x] 터미널에서 `npm start`를 실행하고 브라우저에서 `http://127.0.0.1:3000/`을 연다.
- [x] 상단에 `검색 화면 예시`, `최소 연관도 기준 적용`, `실제 API 미연결` 안내와 교사 검색·CuriMap·사람 검수 이동 메뉴가 보이는지 확인한다.
- [x] 수업 언어 질의 입력값과 `초등 5~6학년군`, `사회`, `관련도순` 조건이 보이고, `검색 화면 예시 보기`를 눌렀을 때 실제 검색 요청 없이 화면 예시 갱신 안내가 나오는지 확인한다.
- [x] 결과 영역에 최소 연관도 기준을 통과한 전체 결과 수와 `10개씩 표시` 문구가 보이고, 카드에 제목·프로그램·방송일·학년군·교과·성취기준·추천근거·활용 유형·`EBS 원문 링크`가 표시되는지 확인한다.
- [x] 카드의 `접근조건 미확인` 배지가 다른 정보와 구분되어 보이는지 확인한다.
- [x] 정렬을 `최신 방송순`과 `오래된 방송순`으로 바꿨을 때 결과 카드 순서와 정렬 배지가 바뀌고, `관련도순`으로 되돌릴 수 있는지 확인한다.
- [x] `다음` 또는 `2` 페이지를 눌렀을 때 10개 단위 페이지 이동 영역이 바뀌고, 결과가 2건 표시되는지 확인한다.
- [x] `빈 결과`를 눌렀을 때 결과 없음 안내와 페이지 이동 영역이 사라지는지, `로딩`을 눌렀을 때 로딩 안내가 보이는지 확인한다. 이후 `예시 결과`로 되돌린다.
- [x] 브라우저 폭을 좁혔을 때 검색 조건과 결과 카드가 세로로 배치되고 텍스트·버튼·페이지 이동이 잘리지 않는지 확인한다.
- [x] 확인 후 터미널에서 `Ctrl+C`를 눌러 서버를 종료하고, 보인 문제나 확인 결과를 응답으로 남긴다.
