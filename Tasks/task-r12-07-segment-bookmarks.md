# Task R12-07 - Curi 연동 수업용 구간 북마크 확장 프로그램

## 설명

교사가 EBS 영상을 보면서 사용할 시작·끝 시간을 지정하고, 구간 이름·메모와 함께 Curi의 내 자료·수업 폴더에 저장하여 다시 재생할 수 있게 한다. 영상 파일을 복제하는 대신 원본 회차와 시간 구간을 연결하는 개인 북마크를 제공한다. 2026-10-14 사용자 요청으로 작성했다. 상태: **진행중**. 2026-10-14 사용자 진행 요청으로 실제 플레이어 조사와 제작을 시작했다.

**현재 화면 — 2026-10-14 사용자 후속 요청:** 별도 수업용 구간 페이지를 제거하고 `lesson.html`의 내 수업 폴더에서 구간 목록/재생/편집을 제공한다. 확장 프로그램 저장 성공은 ‘내 수업 페이지에 저장되었습니다’로 안내한다. 아래 독립 페이지 제작/검증은 초기 구현 기록이며 현재는 통합 화면을 사용한다.

## 구현 항목

### 첫 지원 범위와 플레이어 확인

- [x] 첫 버전은 데스크톱 Chrome용 확장 프로그램과 로컬 Curi의 연동을 대상으로 한다. EBS 일반방송 플레이어 한 종류부터 실제 지원 사이트·회차 범위를 확인하고 명시한다. 초등·중학 등 다른 플레이어의 지원을 확인 없이 주장하지 않는다.
- [x] 실제 EBS 회차에서 현재 재생 시간·전체 길이 읽기, 지정 시간 이동, 구간 끝 일시정지가 가능한지 먼저 확인한다. 가능한 기능과 불가능한 기능·로그인/재생 조건을 각각 기록한다.
- [x] 회차 식별과 재생 시간 제어가 가능한 대상에서 구간 저장→Curi 연결→구간 재열기의 전체 동선을 최소 한 종류의 플레이어로 구현한다. 호환 조사나 수동 시간 메모만으로 제작 완료를 표시하지 않는다.

### 시청 중 구간 지정

- [ ] EBS 페이지에서 현재 영상의 시간으로 ‘시작 지정’·‘끝 지정’을 할 수 있게 한다. 광고·예고편·다른 회차의 시간을 본편 구간으로 저장하지 않는다. 현재 영상 식별이 불명확하면 저장을 보류한다.
- [ ] 시작·끝 시간은 직접 입력하거나 수정할 수 있다. 시간 단위를 명확하게 표시하고 시작 0초를 허용한다. 음수·잘못된 형식·끝≤시작·확인된 영상 길이 초과는 이유와 함께 거절한다.
- [ ] 구간 이름과 선택적 메모를 함께 기록하며 한 영상에 여러 구간을 저장할 수 있다. 기존 ‘장면·사용 구간’ 개인 메모와 선택 이유는 보존한다.
- [ ] 재생 시간 읽기 실패나 미지원 페이지에서는 자동 지정이 가능한 것처럼 표시하지 않는다. 수동 기록 여부와 실제 재생 제어 지원 여부를 구분한다.

### Curi 개인 자료와 연결

- [ ] Curi에서 연 영상의 원본 ID·회차·판본과 확장 프로그램의 현재 영상을 대조한다. 제목만 같은 다른 회차에 구간을 붙이지 않는다. EBS에서 직접 연 영상은 현재 Curi 목록의 동일 회차를 확인한 뒤 연결하고, 찾지 못하면 연결 미완료로 안내한다.
- [ ] 저장 전에 연결할 Curi 자료·수업 폴더·구간을 확인할 수 있게 한다. 사용자의 ‘Curi에 저장’ 동작으로만 개인 자료에 반영한다. 같은 자료를 여러 폴더에서 사용할 때 폴더별 구간·메모를 독립적으로 편집할 수 있다.
- [ ] 북마크에 연결 자료/판본, 공식 회차 주소, 시작·끝 시간, 구간 이름·메모, 기록/수정 시점과 지원·확인 상태를 보존한다. 재열기·수정·삭제가 가능하고 기존 내 자료·폴더·개인 판단 기록을 유지한다.
- [ ] 중복 클릭·연결 실패·저장 실패·Curi 미접속을 성공으로 표시하지 않는다. 저장 확인 전 입력을 유지하고 재시도에서 중복 구간을 만들지 않는다. 여러 창의 편집 충돌은 기존 개인 기록을 덮어쓰지 않게 처리한다.
- [ ] 연결은 사용자가 지정한 Curi 주소와 지원 EBS 페이지에 한정한다. 다른 웹페이지가 임의 구간이나 폴더 변경을 보내지 못하며 개인 기록을 공용 교육과정 제안·사람 승인·자동 연계 자산으로 전송하지 않는다.

### 저장 구간 재사용

- [ ] 내 자료와 수업 폴더의 영상 아래에 구간 이름·시작~끝·길이와 ‘저장 구간 보기’를 표시한다. 원본 전체 영상을 여는 기능도 유지한다.
- [ ] ‘저장 구간 보기’로 정확한 EBS 회차를 열고, 플레이어 준비 후 저장한 시작 시점으로 이동하여 지정 구간을 재생한다. 브라우저 정책상 재생에 클릭이 필요하면 명확한 재생 동작을 안내한다.
- [ ] 지원 플레이어에서는 구간 끝에 일시정지하고 같은 구간을 다시 재생할 수 있다. 다른 회차로 이동하거나 구간 재생을 해제하면 이전 구간의 제어가 새 영상에 남지 않게 한다.
- [ ] 확장 프로그램 미설치·연결 끊김·플레이어 변경·재생 제한 시 원본 링크와 저장 시간을 제공하고 구간 자동 재생의 미지원/실패를 명확히 표시한다.
- [ ] 기존 자료/폴더 내보내기에 구간 이름·시간·공식 회차 주소·메모를 포함한다. 일반 링크만 받는 환경에서도 지정 시간이 보이게 하며 확장 프로그램 없는 환경의 자동 시점 재생을 보장하지 않는다.

## 수동 작업

- Chrome에서 [설치 ZIP](../public/downloads/curi-segments-extension.zip)을 압축 해제한 후 `chrome://extensions`의 개발자 모드에서 ‘압축해제된 확장 프로그램을 로드합니다’로 폴더를 선택한다. 로컬 확장 설치와 실제 사용자 프로필 재생 검증은 아직 수행하지 않았다.
- 현재 설치는 완료되어 있다. 내 수업 화면 통합 수정본0.2.0을 적용하려면 기존 확장 카드의 ↻를 누르고 Curi의 `lesson.html`과 EBS 페이지를 새로고침한다. 위 설치 미완료 문장은 초기 제작 당시 기록이다.
- 확장 팝업에 실제 Curi 주소를 입력한다. 기본은 `http://localhost:3000`이며 다른 포트·`127.0.0.1`은 개인 저장이 별개다. Curi 연결을 누르고 EBS/Curi 페이지를 새로고침한다.
- 해당 주소의 Curi 내 자료 또는 수업 폴더에 지식채널e 회차를 담아 둔다. EBS 로그인/본편 재생 권한이 필요한 경우 해당 사이트에서 사용자가 준비한다. 우회하지 않는다.

## Chrome 설치 시도 — 2026-10-14

사용자가 Chrome 설치를 명시적으로 승인했다. 확장 관리 `chrome://extensions`를 열려고 했으나 브라우저 도구의 URL 보안 정책이 HTTP/HTTPS 외 프로토콜을 차단했다. 같은 결과를 다른 브라우저 표면·명령으로 우회하지 말라는 도구 지시에 따라 설치하지 않았다. 설치 승인은 유효하며 권한을 다시 묻는 상황은 아니다. 사용자가 Chrome에서 직접 개발자 모드의 폴더 로드를 수행하면 Curi 연결과 실제 재생 확인을 이어간다. 설치 대상은 저장소의 `extensions/curi-segments/`이며 ZIP 재다운로드/압축 해제 없이 해당 폴더를 선택할 수 있다. 상태는 진행중·실제 확장 설치 미완료다.

## 사용자 설치 후 연결 확인 — 2026-10-14

사용자가 직접 설치 후 확인을 요청했다. Chrome 도구 모음의 ‘Curi 구간 지정’과 실제 팝업에서 설치를 확인했다. 기존 설치 차단 기록은 당시 시도 결과이며 현재는 설치되어 있다. 설정 주소는 `http://localhost:3000`이다. 실제 지식채널e 두 회차에서 시작·끝 시간을 읽고 개인 자료와 동일 회차를 연결해 명시 저장했다. 사용자가 지정한 ‘자전 속도’ 47.995~83.230초는 이름/시간을 유지했다. 두 번째 ‘다윈 · 구간 재생 확인’ 25.000~45.549초도 저장했다. 실제 시점 이동/끝 정지 측정은 이어서 기록한다.

첫 회차는 시작47.995초 정확 이동, 끝83.244초 정지 안내(+0.014초)를 확인했으나 후속 관찰에서 재개되어 정지 유지 검증은 미완료다. 끝 정지 직후 감시를 해제하던 코드를 수정해 제어 해제/명시 재재생 전까지 끝 정지를 유지한다. 재개 회귀 포함26검사 통과·설치 폴더/ZIP 갱신. 관리 화면에 도구로 접근할 수 없어 사용자의 확장 카드 새로고침 후 두 회차를 재검증한다. 상태는 진행중이며 정지 안내만으로 재생 검증 완료를 표시하지 않는다.

## 수정본 실제 재검증 — 2026-10-14

사용자가 확장 카드의 새로고침을 완료했고 Curi 페이지도 새로고침했다. 기존 구간을 수정하지 않고 두 회차를 한 탭씩 재열기했다. ‘다윈’은 시작25.000초, 끝45.602082초(+0.053082초), ‘자전 속도’는 시작47.995초, 끝83.241414초(+0.011414초)였다. 재생 종료 후 paused=true를 확인했고, EBS 재생 버튼으로 재개를 시도한 뒤에도 각각45.603095/83.241756초에서 paused=true를 유지했다. 자동 재생 제한 시 직접 재생하는 경로를 사용했다. [실측](../docs/r12-07-live-playback.json)·[실제 정지 화면](../docs/r12-07-playback-stop.png).

설치·회차별 시간 읽기·명시 저장·정확한 시작 이동·끝 정지 유지의 기술 확인은 완료했다. 이전 설치/정지 보류는 당시 기록이며 현재는 해결됐다. 사용자 결과 확인·실제 내보내기 파일 대조 등 남은 확인은 보존하고 task 상태는 진행중으로 유지한다. 기존 교사 검색 경고 회귀 실패는 이 재생 검증과 별개다.

## 내 수업 화면 통합·저장 안내 — 2026-10-14
