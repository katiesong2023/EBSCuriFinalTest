# Task R12-08 — 확장 연결 복구·영상 등록

## 설명
사용자 요청으로 확장 프로그램의 Curi 불러오기 실패를 복구하고, 개인 수업 또는 CuriBase에 없는 지원 영상을 기존·새 수업 폴더에 담아 이후 검색할 수 있게 한다. 상태: 진행중.

## 구현 항목
- [x] 오래 열린 탭·여러 탭·Curi 탭 없음에서도 연결을 복구하며 실패 원인을 안내한다.
- [x] 지원 영상에서 기존 폴더 선택·새 폴더 생성으로 영상과 구간을 저장한다.
- [x] CuriBase에 영상 메타데이터를 보존하고 다음 검색·자료 재조회에 반영한다.
- [x] 회차 중복·반복 저장·입력 보존·다른 창 변경·저장 실패를 보호한다.
- [x] 기존 개인 자료·폴더·승인과 검색 근거 확인 수준을 보존한다.

## 실제 구현 — 2026-10-14

확장 0.3.0에서 ‘Curi 연결·자료 불러오기’는 응답하는 최신 내 수업 탭을 선택하며 없으면 자동으로 연결 탭을 연다. 영상 준비 실패와 Curi 연결 실패를 구분한다. 개인 자료가 없어도 전체 수업 폴더를 가져온다.

‘내 수업에 영상 추가’의 수업 폴더에서 기존 폴더 또는 ‘새 수업 폴더 만들기’를 선택한다. ‘영상만 추가’는 구간 없이 담고, 구간 이름·시작·끝을 입력한 뒤 ‘영상·아래 구간 저장’을 누르면 함께 담는다. 기존 개인 영상은 아래 ‘이미 담긴 자료의 구간 저장 위치’에서 기존 구간 저장을 이어갈 수 있다. 지식채널e 외 현재 사용자 다큐프라임의 같은 EBS 본편 구조를 확인해 지원했다. 새 권한은 다큐프라임 공개 회차 호스트이며 기존 로컬 호스트는 유지한다.

`extension-library.js`, `teacher-resource-store.js`와 `/api/curibase/teacher-resources`를 추가했다. 신규 영상은 별도 교사 등록 SQLite에 저장해 다음 일반·교사 검색/자료 재조회에 반영한다. 기존 회차는 원본 ID를 재사용하고 등록으로 공식 원본/교육과정 승인을 덮어쓰지 않는다. 저장 오류·개인 자료/구간 경쟁·부분 성공을 구분한다.

### 수동 작업
Chrome 확장 관리 화면에서 Curi 카드의 ↻를 한 번 누른다. 기존 EBS 회차도 새로고침해 새 플레이어 연결을 적용한다. 도구 보안 정책상 확장 관리 화면은 사용자가 직접 조작한다. 서버는 에이전트가 기존 실행 명령을 확인해 수정본으로 재시작했다.

### 검증
구간 회귀31개(두 EBS 호스트·오래 열린 탭 복구/새 연결 탭 포함), 내 수업 메시지7개, 영상 등록 저장14개, 격리 HTTP8개·팝업 동선5개를 통과했다. 보고서는 `docs/r12-07-segment-check.json`, `r12-07-lesson-integration-check.json`, `r12-08-library-check.json`, `r12-08-library-http-check.json`. 가상 신규 회차는 임시 DB에만 저장한다. 사용자가 확장 새로고침을 완료했다. 실제 팝업 조작은 Chrome의 동시 조작이 감지되어 검증을 잠시 보류하고 사용자에게 약1분 조작 중지를 요청했다. 내 수업 현재 화면 실행 오류는0이며 기존 전체6자료/3폴더를 확인했다.

### 사용자 결과 확인

- [ ] 내 수업에 없는 영상도 기존 폴더 또는 새 폴더에 담긴다.

## 실제 Chrome 확인 — 2026-10-15

사용자 검증 진행 응답 후 설치된0.3.0 팝업을 확인했다. 이전 EBS 탭은 확장 연결이 없어 Curi 폴더 조회만 성공했고, 선택된 EBS 탭 새로고침 후 ‘바다에 숲을 일구다’의 본편 길이35:17.077와 수업 폴더3개·기존 생태계 자료 연결을 읽었다. 생태계 폴더에서 ‘영상만 추가’를 눌러 실제 ‘내 수업 페이지와 CuriBase에 저장되었습니다’ 안내를 확인했다. 생태계2자료·전체6자료·3폴더가 유지되어 중복이 생기지 않았다. 신규 미보유 영상/새 폴더/영상·구간 함께 저장은 격리 검사 결과이며 이번 실제 확인과 구분한다. [실제 저장 화면](../docs/r12-08-live-save.png). 구현/에이전트 검증 완료, 사용자 결과 확인 전 상태는 진행중이다.

## 저장 무반응 제보 수정 — 2026-10-15

사용자 팝업은 애니키즈 회차와 EBS 비밀번호 변경 팝업이 열린 상태에서 지원 영상 인식 실패로 저장 버튼이 비활성화되어 있었다. 애니키즈 `/vodCommon/show`의 같은 EBS 본편 회차 선언/소스/시간과 제목·프로그램 DOM을 확인해 지원에 추가했다. 확장0.3.1은 ‘저장할 영상’ 선택과 선택한 탭 ID로 시간 읽기/등록을 수행하여 별도 창 선택에 의존하지 않는다. 빈 입력의 저장 보류도 명시 안내하며, 저장 안내는 상단 고정·각 저장 버튼 아래에 표시한다. 기존 지식채널e/다큐프라임과 승인 경로는 유지한다. 사용자 새로고침 후 실제 애니키즈 폴더 저장을 재검증한다.

### 실제 새 영상 등록·안내 보존 보완

0.3.1 새로고침 후 미등록 애니키즈 회차60771803의 정확한 제목/프로그램/563.451초를 읽고 사용자가 입력했던 ‘조선시대’ 새 폴더에 영상만 추가했다. 실제 내 수업에 조선시대1자료·전체7자료·4폴더와 저장 완료 안내가 표시되고 CuriBase에 TEACHER-cfcf95576e7a73119bea8ce4가 저장되었다. 후속 조회 지연과 EBS 별도 창으로 팝업이 닫히는 상황을 확인해0.3.2에서 저장 완료 결과를 Curi/확장 저장소에 보존하고 팝업 재열기/페이지 새로고침에 표시한다. 등록/목록 응답 대기 시간을 실제 API 대기 범위와 맞췄다. 사용자 재확인 전 진행중.

## 전체 폴더·자료·구간 동선 수정 — 2026-10-15

사용자 후속 요청으로 파일을 수업 폴더로 해석하고0.4.0의 세 단계 동선을 구성했다. ‘새 폴더 생성’은 영상 준비와 무관하게 독립 생성하고 곧바로 선택한다. ‘선택한 폴더에 자료 담기’는 영상/프로그램 메타데이터를 CuriBase와 폴더에 저장한다. ‘구간 클립 저장’은 자료가 폴더에 없으면 함께 등록하며, 자동 시간 읽기 불가 시에도 직접 입력을 허용한다. 선택한 폴더를 Curi에서 여는 버튼과 실시간 폴더 조회를 제공한다. 구간 클립은 원본 링크와 시간 구간이며 영상 파일 추출은 이 작업의 구현이 아니다.

공개 `*.ebs.co.kr` 페이지를 대상으로 제목/소개/원본 링크를 수집한다. source-reader.js가 공개 메타데이터를 별도로 읽고 player.js는 접근 가능한 단일 HTML5/기존 공통 본편의 시간을 읽고 재생을 제어한다. 로그인/비밀번호/개인정보 페이지는 수집하지 않는다. iframe/복수 플레이어처럼 자동 시간을 읽을 수 없는 경우에는 직접 입력 안내를 제공한다. 프로그램 목록 자체를 회차 영상으로 표시하지 않고 프로그램 유형을 유지한다. 교사가 등록한 프로그램도 교사 전체 검색에 포함한다.

Curi 연결 프로토콜4의 WORKSPACE/CREATE_FOLDER는 전체 자료 재대조를 기다리지 않는다. 등록은 방송 SQLite의 선택 회차와 기존 원본 변경분만 조회하고 전체 의미 검색 준비와 분리했다. 생성·등록 결과를 확인한 뒤 내 수업 목록/안내를 갱신하고 폴더/구간 충돌과 재시도 중복 보호를 유지한다. 실행 확인 및 실제 Chrome 결과는 후속 기록한다. 상태는 진행중이다.
