# Task R08-01 - 근거 기반 연계 후보와 자동 검사

## 설명

2026-10-04 사용자 요청에 따라 준비 기간의 기본 흐름을 공식 자료 확보 → 연계 후보 생성 → 자동 근거 검사 → 확인 수준과 함께 검색 제공 → 오류·변경 관리로 전환한다. 사람의 교육과정 관계 검토는 선택적인 후속 운영으로 유지한다. 기존 [R08](task-r08-admin-workspace.md)의 완료 기록은 보존하며, 이 task는 2026-10-05 사용자 완료 처리·후속 진행 요청을 반영해 **완료**다. R08-02의 저장·검색 구현 결과와 후속 관리자/사람 확인 상태는 해당 task 및 PLANS에서 관리한다.

이 task는 근거 없는 후보 보충을 제거하고 검사 가능한 관계 근거를 만든다. 영구 저장·검색은 R08-02, 관리자 작업공간은 R08-03, 관계별 사람 판단은 R08-04에서 이어간다. 구현된 API·CLI·상태와 제한된 규칙 범위는 아래 실제 구현에 기록한다.

## 실제 구현 — 2026-10-05

상태는 **완료**다. 구현·에이전트 검사 후 2026-10-05 사용자가 완료 처리와 R08-02 진행을 요청했다. 사용자 직접 명령 실행 여부나 실제 교육과정 검토를 추가 실적으로 기록하지 않는다. 기존 승인 JSON·방송 SQLite·시맨틱 SQLite를 변경하지 않았다.

### 파일과 진입점

- `server/candidate-retrieval.js`: 일반방송의 고정 코드 보충과 한 단어 보조 보충을 제거했다. 두 개 이상 실제 겹치는 용어가 있는 공식 후보만 순위화한다. 원문 부족이면 후보를 만들지 않는다. 명시적으로 빈 소개문을 보냈을 때 저장된 이전 소개문으로 되돌리지 않는다.
- `server/source-text-quality.js`: 후보 조회와 자동 검사에서 제목 반복·제목 외 내용 부족·편성/시청 안내를 함께 판정한다. 인접 분류(환경/생태·사회/경제)는 특정 공식 교과로 자동 확정하지 않고 조회 교과 지정을 안내한다. 교과 선택은 사람의 관계 승인이 아니다.
- `server/automatic-relation-rules.js`: 아래 두 공식 기준의 제한된 서술 패턴과 부정·상충·의문·조건 표현을 검사한다. 규칙 버전은 `automatic-evidence-v1`이다.
- `server/automatic-evidence.js`: 자료·판본·원문 스냅샷, 공식 요구·출처·버전, 인용·UTF-16 위치, 연결/미확인 부분과 13개 개별 검사 결과를 만든다. 전달된 과거 통과·confidence·유사도는 통과 근거로 사용하지 않는다. 임베딩 모델은 호출하지 않는다.
- `server/automatic-evidence-service.js`: 저장된 CURI 콘텐츠 또는 방송 원본 ID를 읽는다. 방송을 검수 저장소에 먼저 가져올 필요가 없다. 같은 원본의 관리자 저장 내용이 있으면 그것을 우선하며, 모호한 원본 ID는 거절한다. 요청으로 임의 원문이나 과거 검사 결과를 주입할 수 없다.
- `server/server.js`: `POST /api/curimap/evidence`를 연결했다. 기존 관리자 세션과 Origin/Host 보호를 적용하고 `no-store`로 응답한다. 기존 유료 AI 초안·사람 검토·승인 Gate는 별도로 보존한다.
- `server/automatic-evidence-cli.js`: `npm run data:evidence -- --content CURI-ID` 또는 `--resource BCAST-ID`로 같은 읽기 전용 검사를 수행한다. 선택적으로 `--subject 사회|과학`, `--grade "5~6학년군"`을 지정한다. API와 CLI 모두 실행 이력·승인·자동 자산을 저장하지 않는다.

API 입력 예:

```json
{"resourceId":"BCAST-4280dd3cf2aaac6c3584","subject":"과학","gradeBand":"5~6학년군"}
```

API를 사용하려면 새 코드로 서버를 재시작하고 기존 관리자 로그인을 사용한다. 기존 화면에 자동 검사 버튼은 추가하지 않았다.

### 지원 범위와 확인 수준

| 교과·공식 기준 | 현재 검사하는 설명 | 자동 확인하지 않는 부분 |
| --- | --- | --- |
| 사회 `6사08-01` | 시민/유권자/국민이 투표로 대표를 선출한다는 설명, 선거/투표로 주권을 행사한다는 설명 | 실제 참여 태도·학생의 이해·수업 적합성 |
| 과학 `6과12-02` | 지구가 자전한다는 설명, 지구 자전 때문에 낮과 밤이 생긴다는 인과 설명 | 실제 관찰·영상 장면·학생의 설명 수행 |

현재 공식 성취기준 78개에서 용어 후보를 조회하되, 관계 설명 검사는 위 두 기준의 정확한 2022 개정 원문에만 적용한다. 각 기준의 지원 설명 두 항목을 모두 찾으면 `SUPPORTED`, 한 항목만 찾으면 `PARTIAL`이다. 둘 다 **전체 성취기준 충족 범위는 `PARTIAL`**이며 남은 학습 요구를 같이 반환한다. 단어 언급·의문·추측은 `HELD`, 부정·상충은 `CONFLICT`, 다른 기준이나 변경된 공식 문구는 `UNSUPPORTED`다.

실행의 `CHECKED`는 관계 검사 결과가 있다는 뜻이며 통과율·의미 정확도가 아니다. 후보 0건·원문 부족·미지원 교과/학년은 실행 `HELD`, 저장소 읽기 등 처리 오류는 HTTP 500의 `FAILED`로 구분한다. 관계별 구조 검사는 `PASS`·`FAIL`·`HELD`로 반환한다. 구조 `PASS`와 의미 `SUPPORTED/PARTIAL`을 동시에 만족할 때만 `publicationEligible`이 참이다. 이 필드는 후속 제공 가능 판정이며 **현재 검색 공개·저장 실행을 뜻하지 않는다**.

`currentValidity`는 이번 원문·공식 기준·규칙 버전과의 일치 여부이며 이전 근거를 다시 검사하면 변경 시 `STALE`로 반환한다. 영구 이력과 검색 무효화는 R08-02의 별도 경로에서 담당한다. 사람 결정은 이 경로에서 조회·판정하지 않는 `NOT_EVALUATED`, 검색 준비는 `NOT_REQUESTED`로 반환한다. 기존 실제 사람 승인 4개를 미검토 상태로 변경한 것이 아니다.

출처 검사는 저장된 원본 식별과 공식 EBS URL 형식, 알려진 방송 링크 불일치, 저장 원문 안의 정확한 인용을 검사한다. 이번 실행은 외부 EBS 원문을 새로 가져와 대조하지 않았다. 도착 페이지·재생·자막·장면·학년 적합성은 미확인이다. 짧은 원문, 지원하지 않는 표현·문장 구조, 일부 부정 표현은 보수적으로 보류될 수 있다. 규칙을 통과한 건수를 교육과정 의미 정확도·교사 효용으로 발표하지 않는다.
