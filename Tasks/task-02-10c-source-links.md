# Task 02-10C - 콘텐츠와 EBS 도착 페이지 일치

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명
원문 보기에서 해당 콘텐츠와 무관한 기본 영상·목록이 열리는 문제를 고친다. 화면 디자인 변경은 범위가 아니다.

사용자 추가 요청에 따라 심사위원·초등교사 관점의 [사용성 크리틱 1회](../docs/USABILITY_CRITIQUE_01.md)를 수행하고, 링크 유형 안내·개별 페이지 필터·모음과 메모의 이동 주소 일치를 함께 반영한다.

## 구현 항목
- [x] 공개 페이지에서 개별 클립·회차의 실제 이동 식별자를 확보한다.
- [x] 확보한 링크는 새 페이지의 선택된 콘텐츠 제목과 대조한다. 개별 콘텐츠 142건·소개/목록 5건 일치 확인.
- [x] 탐색·검증 자산 검색·검수 화면에서 일관된 링크를 제공한다.
- [x] 미확인 주소를 정확한 개별 원문처럼 표시하지 않는다. 제목 검색 안내와 개별 페이지 조건을 제공한다.
- [x] 기존 승인 기록을 변경하지 않고 링크 대조 결과와 회귀 검증을 남긴다.
- [x] 다운로드 메모의 수집 목록·근거 페이지 오연결을 제거하고, 예전에 모은 자료도 최신 링크로 내보낸다. 2026-09-29 후속 수정: 읽기 전용 자료 ID 조회로 현재 링크를 반영하고 구 목록을 개별 근거 링크로 출력하지 않는다. 기존 원본 이력은 보존한다.

## 범위 밖
- 화면 디자인 개편, 영상 다운로드·임시 서명 URL 저장, 사람 승인 대행
