# Task R07-07 - 검색어와 성취기준의 결합 검색

## 설명

검색어만, 성취기준만, 두 조건의 결합을 동일한 검색 결과 계약으로 제공한다. 화면을 합쳐도 후보 범위·필터·정렬·집계·페이지가 서로 다른 검색처럼 동작하지 않도록 한다. 상태: **진행중**. 2026-10-11 API 구현·에이전트 계약/HTTP/회귀 검증 후 사용자 결과 확인 대기.

## 권장 개발 모델

- **GPT-6.1 Sol · High** (`gpt-6.1-sol`): 후보 범위·자연어 조건·기준 관계·순위·페이지의 상호작용이 핵심이므로 이 단계에 높은 추론을 배정한다.
- 문서 정리와 명확한 단일 실패 수정은 Medium으로 낮출 수 있다. 검색 전체를 다시 설계하거나 새 모델 비교를 수행하지 않는다.
- 개발 모델이며 서비스 추론 모델과 별개다. 공통 사용 원칙은 [PLANS](../docs/PLANS.md#검색-화면-통합-후속-계획--2026-10-11)을 따른다.

## 구현 항목

- [x] R07-06에서 정리한 세 검색 경우를 실제 자료로 제공하고, 검색어가 비어 있어도 선택한 기준의 후보를 찾을 수 있게 한다. 조건이 없는 경우에는 기존 전체 목록 동작을 유지한다.
- [x] 결합 검색에서 질문의 주제·관계·제외 조건과 선택 기준의 후보 범위를 함께 반영한다. 잘못된 기준이나 지원하지 않는 조건을 조용히 무시하지 않는다.
- [x] 기준 자동 비교가 미지원이어도 관련 후보 탐색을 제공한다. 제목뿐·소개문 부족·개념 일치·부분 근거·해석 보류·상충을 적절히 구분하고, 미지원을 부적합으로 판정하지 않는다.
- [x] 선택 기준에 대한 설명 근거를 관련순에 반영하면서 기존 원문 품질·개념 근거·부정 문맥 처리를 재사용한다. 검색어만 있을 때는 기존 일반 검색의 의미를 유지한다.
- [x] 기존 필터·방송일 정렬·판본 묶음·결과 건수·페이지를 검색 결과 전체에 일관되게 적용한다. 현재 페이지 밖의 자료가 누락되거나 조건과 집계가 어긋나지 않게 한다.
- [x] 공식 기준의 교과·학년군과 일반 자료의 태그·교사 수업 대상을 구분한다. 기준 선택으로 사용자 대상 학년을 자동 변경하거나 추천 학년을 생성하지 않는다.
- [x] 선택한 기준의 근거만 해당 기준의 확인으로 제공하고, 다른 기준의 승인·자동 검사 이력이 혼합되지 않게 한다. 기존 원문·인용·현재 관계의 유효성 확인을 유지한다.
- [x] 결합 검색의 빈 결과·조회 실패·기준 변경을 구분하고, 결과를 넓히려면 어떤 조건을 해제해야 하는지 알 수 있게 한다.

## 실제 구현과 API 계약

- `server/teacher-discovery.js`에서 일반 검색의 전체 판본별 자연어 후보를 재사용하고, 선택 기준이 있으면 새 `server/teacher-combined-search.js`로 연결한다. 질문만·기준만·질문+기준·입력 없음은 각각 `searchMode=QUERY/STANDARD/COMBINED/ALL`이다.
- 기존 `GET /api/curi/discover?workspace=teacher`에 `standard`(공식 코드 한 개), `state`(선택 관계 상태)를 추가했다. 검색어 `q`가 빈 경우에도 기준 후보를 제공한다. 기존 유형/주제/교과 태그/프로그램/기간/원문/확인/페이지 확인/정렬 조건을 그대로 받는다.
- `curriculum-discovery.js`의 전체 기준 색인과 `curriculum-evidence.js`의 선택 관계·상태·요구별 인용 함수를 재사용한다. 질문 조건을 통과한 판본과 기준 후보를 **회차 ID로 교차**하고, 필터→전체 정렬→판본 묶음→총건수→9건 페이지 순으로 계산한다. 현재 페이지끼리 교차하거나 같은 제목에 근거를 전파하지 않는다.
- `teacher-filters.js`의 공통 필터/옵션 집계에 선택 기준 관계 대조를 연결했다. 탐색 교과 태그와 공식 교과는 독립 조건이다. 기준이 있으면 사람/자동 확인 필터는 해당 기준의 현재 유효 관계만 사용한다. 관계 상태 옵션 건수도 해당 상태만 바꾼 전체 묶음 수다.
- 기준 관련순은 제한된 관계 설명→원문 품질→질문 관련도→기준 개념 표현→안정적인 제목/ID 순서다. 질문만이면 기존 순위를 유지한다. 방송일순은 전체 판본의 유효 날짜부터이며 미확인은 마지막이다. 미지원에 불일치 벌점을 주지 않는다.
- 공식 기준·출처는 응답 `standard`와 자료 `selectedStandard`, 선택 요구/인용/남은 요구는 `curriculumComparison`, 기준 관련 이유는 `curriculumRelevanceReason`이다. 일반 질문 이유/원문 품질/내용 안내를 따로 유지하고 다른 기준 이력은 `otherStandardLinks`로 분리한다. 계산한 부분 설명을 저장된 자동 공개나 사람 승인으로 표시하지 않는다.
- `grade/gradeContext`는 교사 대상 문맥을 유지한다. 과정이 다른 기준을 선택해도 후보·관계를 유지하며 `contextWarning`과 해석 경고에 차이를 알린다. 자료 `teachingContext`의 `targetGrade/targetNeedsClarification`은 개인 대상, `courses/standardId/officialGradeBand`는 기준 문맥이다. 학년 적합성은 `UNCONFIRMED`다. 중1 공식1~3학년군·뉴런 참고·학교별 편성 미확인을 보존한다.
- 빈 결과는 `emptyReason=STANDARD_NO_CANDIDATES/COMBINED_NO_MATCH/FILTERED_OUT`으로 기준 후보 없음/교집합 없음/필터 후 빈 결과를 구분하고 어떤 조건을 개별 해제할 수 있는지 안내한다. 빈 목록은 total0/pages0/page1, 유효한 초과 페이지는 마지막으로 보정한다. API는 상태 없는 조회이므로 기준 변경 시 페이지1로 초기화하는 화면 연결은 R07-08이다.
- 잘못된 기준·필터·페이지·기준 없는 상태 필터·미허용 조건·중복 URL 조건은 HTTP400이다. 기준 조건을 일반 검색에 잘못 전달해 무시하지 않도록 `workspace=teacher`를 요구한다. 자료 조회 실패는 기존 HTTP503을 유지한다. 미지원 기준의 유효한 조회는 HTTP200이며 부적합 판정이 아니다.
- 기존 `/api/curi/curriculum`·일반 `/api/curi/discover`·관리자 인증/쓰기 경계를 유지했다. 기존 교사 화면·URL/localStorage 복원·내 자료/폴더 키·현재 승인/취소 이력은 변경하지 않았다. 통합 화면은 R07-08, 수업 문맥/근거 표시 연결은 R07-09다.

## 검증 결과 — 2026-10-11

- 신규 `server/teacher-combined-search-check.js`: 기능 fixture와 실제 대표10입력을 포함한 20개 계약 묶음. 전체 페이지 교집합·필터별 건수·판본별 인용·다른 기준/판본 승인 분리·자동 공개 분리·미지원/상충/보류·학년 차이·원문 변경·보조문서 범위를 확인한다. [검사 기록](../docs/r07-07-combined-search-check.json).
- 신규 `server/teacher-combined-http-check.js`: 격리 로컬 서버 5묶음. 실제 세 검색 경우·학년 차이·중1 코드·400 입력 오류·기존 API·미인증 관리자 쓰기401을 확인하고 검사 서버를 종료했다. 루프백 바인딩은 sandbox 밖 실행 승인을 받아 수행했다. 기존 사용자 서버는 재시작하지 않았다. [HTTP 기록](../docs/r07-07-http-check.json).

- 구문·UTF-8·상대 문서 링크·diff 정적 점검을 마쳤다. 원본 JSON/방송/시맨틱/자동자산4개 SHA를 전후 대조하고 독립 R09-02 표본/판단 변경을 하지 않았다. 실제 교사 평가·영상 시청·브라우저 통합 화면 검증은 수행하지 않았으며 유료 API 호출0이다.

## 재현 명령

저장소 루트에서 Node24로 실행한다. 새 검사만 다시 실행하려면 아래 두 명령을 사용한다.

```sh
node server/teacher-combined-search-check.js
node server/teacher-combined-http-check.js
```

HTTP 검사는 별도의 빈 로컬 포트를 선택하고 테스트 종료 시 해당 서버를 종료한다. 포트 바인딩이 제한된 환경에서는 실행 권한이 필요하다. 이번 단계의 검색 화면은 기존 형태이며 기준 선택 UI가 아직 연결되지 않았다.
