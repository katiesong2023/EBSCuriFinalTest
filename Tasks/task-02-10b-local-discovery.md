# Task 02-10B - Curi 로컬 탐색 버전업

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명
사람 판단을 뒤로 미루고 로컬에서 사용할 수 있는 출처 기반 콘텐츠 탐색을 구현한다. 사용자의 2026-09-28 요청에 따라 에이전트가 실행·시뮬레이션까지 수행한다. 교육과정 승인이나 영상 시청 결과를 대신 생성하지 않는다.

상태: **완료(에이전트 실행 확인 범위)**. 현업 적합성·자료 재생 확인·실제 제출 패키징은 별도다. [사용법·시연·검증 기록](../docs/CURI_LOCAL_0.2.md).

## 구현 항목
- [x] 보유 원본 카탈로그를 검색에 활용하고 콘텐츠 단위와 근거 수준을 구분한다.
- [x] 동고서저 질문에서 개념·지명·자료 출처를 따라 탐색할 수 있다.
- [x] 자료를 모으고 출처가 포함된 수업 준비 메모로 내보낼 수 있다.
- [x] 유료 API 호출을 기본 차단한다.
- [x] 로컬 시뮬레이션·회귀·브라우저 확인 결과와 실행 안내를 제공한다.

## 범위 밖
- 사람 승인 대행, 전 교과 추천 정확도 보증, 영상 재생·저작권·학년 적합성 판정, 외부 배포

## 사전 전제
- 기존 원본 카탈로그, Working Set, 개념·장소 탐색 수정 설계

## 수동 작업
이번 로컬 사용에 필요한 별도 키 입력이나 검수는 없다.

## 완료 조건
### 에이전트 확인
- [x] 실제 데이터와 격리 시나리오로 검색·저장·API 차단을 검증한다. `npm run simulate`: 11개 시나리오 통과.
- [x] 기존 승인 자산을 변경하지 않고 기존 검증을 통과한다. 저장소 SHA-256 불변, 기존 검증 스크립트 7개 통과.
- [x] 데스크톱·모바일에서 탐색 흐름을 실행한다. Chromium 9개 시나리오 통과, 1440×1080·390×844 화면 확인.

### 결과 확인
- [ ] 사용자 체감 품질·학년 적합성은 후속 현업 평가로 확인한다.
