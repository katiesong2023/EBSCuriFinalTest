# Task R12-25 - 키워드 누락 점검·추출

## 설명

전체 대표·판본 콘텐츠에서 표시/검색 공통 내용 키워드가 없는 항목을 확인하고 실제 원문 근거가 있는 키워드를 추출한다. 사용자 직접 요청2026-10-15. 상태: 진행중.

## 구현 항목

- [x] 전체 콘텐츠의 키워드 유무·누락 사유를 집계한다.
- [x] 소개문/검증 원문에 실제 있는 내용어를 추출하고 은유·제작 안내·부정 표현을 보류한다.
- [x] 추출 근거와 미확보 목록을 보존하고 실제 검색 응답에서 확인한다.

## 범위 밖

- 원문 없는 내용·학년·교육과정 연계 추정
- 유료API·개인 자료/승인 변경

## 수동 작업

없음.

## 완료 조건

### 에이전트 확인

- [x] 전체 전후 집계·추출 원문/인용 검증
- [x] 관련 검색/키워드 계약 확인
- [x] 문서·구조 기준 반영

### 결과 확인

- [ ] 키워드 보충 콘텐츠와 추출 불가 목록을 확인한다.

## 실제 반영

`keyword-vocabulary.js`의 소재/조리명/명시 주제 명사구를 `content-keywords.js`에서 원문 대조한다. 제작 안내 보류는 `source-editorial.js`에서 검색과 공유한다. 소개문이 없을 때 회차/판본/지문이 맞는 공식 보조 원문만 사용하며 파생 키워드 SQLite와 검색 응답에 연결했다. `missing-keywords-audit.js`가 전체23,403개 원문 지문·인용30,201개·보호 저장소 불변을 검사했다.

기존 누락14,597개 중6,787개에11,522개 키워드 보충, 전체 키워드 보유15,591개·미확보7,812개. 부정된 도시/영국2키워드를 보류했다. 보충/미확보 전체 목록과 근거 JSONL·실제API8·화면2확인은 [보고서](../docs/R12_MISSING_KEYWORDS.md)를 따른다. 키워드는 원문 언급이며 의미/영상/학년/교육과정 적합성 승인이 아니다. 한 글자/복합어/영문/짧은 소개 등은 추출 기준의 한계로 남을 수 있다.

최종 keywords-verified 새200/기존170 실행 오류0·새0건 전환0·전체 건수 유지, 기존170의2문장 순위만 변경. 원본/승인/임베딩4저장소와 런타임JS 불변, 파생 키워드SQLite 재생성은 별도 기록. 신규8/공통25/은유15/근거8계약·전체 원문 인용/SQLite·기존 소개문 계약7·실제API8/화면2 확인. 오래된 semantic-check의 요청어 단언 불일치는 키워드를 꺼도 재현되어 별도 한계로 보고했다. 구현·에이전트 확인 완료, 사용자 결과 확인 대기.
