# Task R12-31 - 가져가기 교육과정 다중 선택 흐름

## 설명

2026-10-15 사용자 요청. 교육과정 보기 선택을 필터 위에 배치하고 전체 기준에서 필터를 제공한다. 여러 기준을 선택한 뒤 명시적으로 2단계로 이동한다. 상태: 진행중.

## 구현 항목

- [x] 요청한 개인 연결 설명 문구 삭제
- [x] 관련 후보 보기·전체 기준 보기를 위에 배치하고 전체 기준에서만 필터 표시
- [x] 체크 시 현재 단계 유지·선택 개수에 따라 선택 안 함/선택 완료 전환
- [x] 다음 단계·이전 단계·보기 전환에서 다중 선택 보존

## 범위 밖

검색 관련성·원문·서버 승인·개인 저장 형식 변경.

## 실제 반영·검증

`public/curriculum-selection.js`의 개인 연결 설명을 제거하고 “이 자료 관련 후보 보기 / 전체 기준 보기”를 필터 위에 배치했다. 전체 기준에서 교과·과정·기준 찾기를 표시한다. 관련 후보에서는 숨긴 필터의 값을 적용하지 않으며 전체 기준으로 돌아오면 입력값을 유지한다. 같은 공통 선택기를 사용하는 자료별 교육과정 팝업에도 적용된다. 자료 없이 여는 폴더 기준 선택은 전체 기준과 필터를 유지한다.

`public/teacher-folder-picker.js`는 체크 즉시 이동을 제거했다. 선택0개면 “선택 안 함”, 1개 이상이면 “선택 완료”를 표시하고 버튼을 누르면 선택값을 보존한 채2단계로 이동한다. 이전으로 돌아가 추가·해제할 수 있다. `public/curriculum-selection.css`는 보기 선택 배치와 필터 숨김을 담당한다.

`node server/teacher-bring-browser-check.js`의 격리 브라우저 검증9건 통과. 보기 배치/설명 제거/필터 표시, 체크 후1단계 유지, 버튼 전환, 다중 선택과 보기/검색/이전 단계 전환 보존, 해제, 기존 폴더·메모·선택 이유 보존, 미선택 저장, 취소·중복 방지·저장 실패 후 재시도 확인.390/1440px 화면 확인, 모바일 가로 넘침·브라우저 오류0. 개인 저장은 테스트 전용 브라우저 저장소에서만 수행했다.
