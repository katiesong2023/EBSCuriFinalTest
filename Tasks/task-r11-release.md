# Task R11 - 시연·운영·제출 준비

## 현재 후속 실행 — 2026-10-14

발표·운영 판단은 [R12-06](task-r12-06-teacher-validation.md)의 실제 요청·자료 선택·남은 공백/재사용 결과에 연결한다. 기술 시연은 준비할 수 있지만 교사 효용/수업 활용 미측정을 제품 검증 완료로 발표하지 않는다. 승인 취소 이후 현재 사람 승인0·별도 자동 공개1이며 아래 기존4건 보존 문장은 과거 이력 보존을 뜻한다. 현재 지원 범위와 예시의 검증 수준을 구분한다.

## 설명

기존 04-02~04-06의 배포·리허설·영상·보고서·ZIP 작업을 현재 사회·과학 탐색 제품 기준으로 진행한다. 로컬 기술 확인과 외부 공개·실제 제출의 완료를 구분한다.

## 구현 항목

- [ ] R09의 원문·작은 화면·오류 복구 검증을 반영하고 시연 질문을 초등 3~4·초등 5~6·중1의 사회·과학으로 구성
- [ ] 목표 학년과 실제 검증된 지원 범위·성취기준 확보·중1 편성 근거·자료 공백·사람 미확인을 구분해 제출물에 표시하고 기존 검증 수치를 추가 학년 실적으로 재사용하지 않음
- [ ] 로컬 버전과 선택적인 R10 모델 연결 버전의 기능·비용·한계를 명시
- [ ] 교사의 주제 결정·자료 비교·수업 준비 저장 흐름과 관리자의 자료·품질 관리 흐름을 분리해 시연
- [ ] 발표의 중심을 “공식 교육과정 후보와 원문 근거를 연결하고, 자동 검사 결과를 보존·재사용하는 Agent”로 맞춘다. 주제 자료·교육과정 연계 후보·자동 근거 검사 통과·실제 사람 검토를 구분하고, 전체 자료가 사람이 검증한 자산이라는 설명을 사용하지 않는다.
- [ ] 자동 연계 생성·검사·검색 제공과 오류/변경 예외 처리, 선택적 관계별 사람 결정·자산 저장을 구현된 범위에서 시연한다. 기존 승인 4개는 별도 보존 실적으로 표시한다.
- [ ] 공식 코드·인용·원문 부족 보류·변경 무효화·오탐 회귀의 기술 측정과 의미 정확도·교사 효용 평가를 분리한다. 사람 평가·독립 정답자료가 없으면 미측정으로 명시하고 대량 사람 승인을 제출 준비의 필수 조건으로 두지 않는다.
- [ ] 외부 공개 전 관리 화면·관리 API 권한과 직접 접근 동작을 확인하고 미완료 접근 통제를 배포 완료로 보고하지 않음
- [ ] 기존 04-02 배포 보호, 04-03 리허설, 04-04 실제 녹화, 04-05 보고서, 04-06 제출 패키지 기준 갱신·실행
- [ ] 접수 여부·일정·외부 공개·제출은 실제 확인과 사용자 지시에 따라 기록
