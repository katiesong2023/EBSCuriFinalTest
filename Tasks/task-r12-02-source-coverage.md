# Task R12-02 - 요청 공백별 원천 자료 수집·수집 누락 개선

## 설명

개발 요청의 공통 공백을 해결하기 위해 기존 자료의 수집 누락과 신규 공식 회차·보조 원문을 함께 보강한다. 개별 복구 건수보다 요청별 판단 가능한 자료 확보를 성과로 삼는다. 상태: **진행중**. 2026-10-14 사용자 요청으로 등록했다.

## 구현 항목

- [ ] R12-01에서 우선순위를 정한 사회·과학 원인군에 대해 프로그램/시즌/공식 상세 경로별 대상 전체 목록과 현재 확보·누락·식별 미확인·텍스트 부족을 집계한다.
- [ ] 기존 4복구 가능·2상세 부족·6식별 미확인 사례를 시작 표본으로 사용하여 공통 누락 원인을 확인한다. 실제 수업 요청과 무관한 복구는 유지보수 실적으로 분리한다.
- [ ] 1차 조사량을 공식 상세/보조자료 합계 최대200회차·과목당 최대100회차로 정한다. 프로그램군당10회차를 먼저 대조하고 추가 설명 확보와 요청 공백 해결 가능성이 있는 군의 나머지 대상을 수집한다. 전체 집단이 작으면 전량 조사한다.
- [ ] 기존에 없는 적절한 회차가 공식 목록에 있으면 신규 프로그램/시즌/회차를 추가 수집한다. 소개문·공개 대본·학습자료·공식 자막은 자기 회차/판본 식별과 출처를 갖춘 경우에 연결한다.
- [ ] 수집 누락이 재현되면 같은 경로의 대상군 전체에 적용 가능한 수집 개선과 재실행·중단 재개를 수행한다. 개별 ID에만 설명을 붙이는 수정으로 공통 원인 해결을 완료 처리하지 않는다.
- [ ] 수집 전후 원문 지문·출처·확인 시각·추가/변경/동일/실패·품질별 분모를 보존하고 변경 자료의 검색 색인·현재 근거 상태를 갱신한다. 기존 사람 결정과 개인 자료를 보존한다.
- [ ] 개발 요청별 독립 원문 판단으로 선택 후보 확보/요구 충족 근거 증가/공백 유지와 무관 자료 증가를 구분한다. 수집량 확대에도 효과가 없는 군은 중단 이유와 대체 경로를 기록한다.
- [ ] 200회차 이후 확대는 다음100회차에서 해결할 요청 공백·확보 가능성·운영 비용을 제시해 실행 범위를 갱신한다. 공개 무료 원천 수집은 사용자 허용 범위에서 진행하며 유료 전사/API는 실행하지 않는다.
