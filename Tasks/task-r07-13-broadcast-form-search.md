# Task R07-13 - 화면 추가 없이 방송 형태 검색 반영

## 설명

방송 형태 분류를 화면에 추가하지 않고 자연어 요청의 결과 한정/선호/제외에 활용한다. 기존 공식 프로그램 분류와 회차 원문의 전달 방식 근거를 이용하고 형태의 단순 언급과 실제 형식 설명을 구분한다. 상태: **진행중**.

## 구현 항목

- [x] 프로그램/회차 식별자가 맞는 기존 공식 프로그램 분류를 검색 근거에 연결한다.
- [x] 다큐·강의/강연·대담/인터뷰·실험/시연·드라마·애니메이션·뉴스/보도 요청을 주제와 구분해 검색에 적용한다.
- [x] 단순 형태 언급·부정·다른 프로그램/시즌 분류 상속을 방지하고 형태 조합과 명시적 유사/제외를 처리한다.
- [x] 새 형태 필터/목록/카드 배지 없이 기존 검색·선택 기준·저장·자료 유형을 유지한다.

## 범위 밖

- 영상 전수 시청·형태 전수 확정·추측 태그를 원본/승인 자산에 저장
- 새 형태 선택 UI·외부 수집·유료 추론

## 사전 전제

- R07-12 자연어 프로그램·장르 검색과 기존 EBS 프로그램 목록 스냅샷

## 수동 작업

추가 키·계정·외부 자료 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 공식 분류 식별자 대조·형태 요청/후보·오탐 방지 계약 확인
- [x] 기존 질의/프로그램/기준/화면 회귀·실제 결과 확인
- [x] task·구조·출처/상태를 실제 구현 기준으로 갱신

### 결과 확인

- [ ] 자료 찾기를 새로고침하고 새 방송 형태 필터/목록/카드 배지가 추가되지 않았는지 확인한다.
- [ ] ‘생태계 다큐멘터리’와 ‘생태계 애니메이션’을 검색하고 해당 형태 근거가 있는 결과로 좁혀지는지 확인한다.
- [ ] ‘인터뷰’, ‘실험’, ‘강의’, ‘뉴스’를 입력해 결과가 나타나는지 확인한다. 주제를 함께 입력한 조합에 근거가 없으면 빈 결과를 유지하는지 확인한다.
- [ ] ‘다큐 인터뷰’처럼 복수 형태를 입력하면 두 근거가 있는 자료만, ‘인터뷰 또는 실험’은 둘 중 하나의 근거가 있는 자료가 나오는지 확인한다.
- [ ] 프로그램명·성취기준·상세 필터를 함께 적용해 기존 조건이 유지되는지 확인한다.


## 구현 결과

- 기존 `server/data/broadcast-programs.json`은 EBS 공식 프로그램 목록의 2026-09-30 스냅샷808개다. `category`·프로그램명·course/step·출처/쪽·확인 시점이 있지만 기존 검색에서는 형태에 활용하지 않았다. 새 수집은 하지 않았다.
- `server/program-form-source.js`는 프로그램명(EBS 접두사/공백 정규화)과 회차 URL의 courseId/stepId가 모두 일치하는 분류만 연결한다. 다른 프로그램/과정/시즌·충돌 분류에는 연결하지 않는다. 문화·예술/사회·시사 등 주제 분류를 형태로 추정하지 않고 다큐멘터리·애니메이션·지식특강의 명시 분류만 대응한다.
- `discovery-catalog.js`는 프로그램 목록 파일을 읽기/캐시 서명에 포함하고 자료·판본에 `programClassification`을 파생 연결한다. 현재2,866개 자료에 연결된다. 원본 JSON/방송 DB는 수정하지 않는다. 직접 `buildCatalog`를 사용하는 과거 고정 검사에는 기본 빈 목록으로 기존 결과를 보존한다.
- `discovery-genre.js`는 다큐·애니메이션·드라마/극화·강연/강의·대담/인터뷰/토론·실험/시연·뉴스/보도의7형태를 처리한다. 기본 입력은 형태 한정, 명시적 유사/위주/선호는 관련순, 제외는 형태 근거 제외다. ‘실험 장비’, ‘인터뷰의 기술’ 등 형태를 주제로 삼은 표현은 내용어로 보존한다.
- 형태 근거는 프로그램의 명시 표현, 제목의 형태 표시, 소개문의 형식 선언/전달 방식 문장, 기존 강의 자료 유형, 식별자가 맞는 공식 분류다. 형식의 단순 언급/제작·비평 주제·부정은 근거로 삼지 않는다. 강의 자료에서 다큐라는 단어를 언급해도 다큐 형식으로 분류하지 않는다. 명시적 주 형식이 있으면 상충하는 공식 프로그램 분류로 대체하지 않는다. 인터뷰·실험은 다큐 등과 함께 성립할 수 있다.
- 복수 필수 형태는 AND로 비교하고 ‘형태A 또는 형태B’는 OR로 비교한다. 기존 질문/선택 기준 교집합·자동 관계 상태·필터/개인 저장은 유지한다. `public/discover.js`는 기존 검색 해석 문구만 ‘형식 조건/선호/제외’로 조정하고 OR/AND를 표시한다. 새 선택 UI·기본 형태 목록·자료별 배지는 추가하지 않았다.

## 검증 기록

- 신규 형태/공식 근거 계약10개와 기존 프로그램/장르 계약12개, 격리 화면4개 통과. [형태](../docs/r07-13-broadcast-form-check.json), [프로그램/형태 회귀](../docs/r07-12-program-genre-check.json), [화면](../docs/r07-13-program-genre-browser-check.json).
- 기존 질의27개·결합 검색20개·교사 질의10실행/정밀8/조사2 통과. [질의](../docs/r07-13-query-regression.json), [결합](../docs/r07-13-combined-regression.json), [교사 질의](../docs/r07-13-teacher-query-regression.json). 기존 기본 UI18예시·유형5버튼 유지·형태 필터/배지 없음, 선택 기준/형태 조합·390px 넘침 없음 확인.
- 실제 카탈로그와 재시작한3000서버에서 생태계 다큐66·애니메이션2, 인터뷰14·실험25·강의153·뉴스7을 확인했다. 기존22건보다 다큐가 늘어난 이유는 제목/프로그램명에 단어가 없어도 공식 분류가 맞는 자료를 포함했기 때문이다. 전체 생태계 후보82개를 모두 다큐로 승격하지 않았다. [실제 서버](../docs/r07-13-running-server-check.json).
- 인체 강의·인권 인터뷰·전기 실험·우주 뉴스는 현재 주제×형태의 근거 교집합0건이다. 조건을 버리거나 다른 방송으로 채우지 않는다. 형태별 결과는 실제 영상의 모든 장면 확인·교육적 적합성 전수 판정이 아니다.
- 페이지 오류0·유료API0, 실제4저장소와 공식 프로그램 목록의 SHA 동일. JS 구문·차이 공백 검사 통과. 서버를 기존 실행 방식으로 재시작했고 사용자 결과 확인 대기로 진행중이다.
- 재현: `node server/broadcast-form-check.js`, `node server/program-genre-check.js`, `node server/program-genre-browser-check.js`(기존 Playwright 환경 변수). R07-13 화면 검사는 기존 스크립트의 보고서 접두사를 바꿔 과거 기록을 보존했다.
