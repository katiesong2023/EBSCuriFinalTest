# Task 03-05 - 운영 기록·지연·오류 확인

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R09 / 기술·품질 검증에 통합**. 유료 모델·대량 사람 승인과 독립적으로 기술 검증한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

CuriMap·검수·검색의 실행 기록을 집계해 기술적 운영 상태를 확인한다.

## 구현 항목

- [ ] 실행 ID·시각·입력 ID·코드/데이터 버전·결과 상태·지연·오류·재시도 기록을 집계한다.
- [ ] 성공률·지연 분포·오류와 재시도 건수·가능한 호출 비용을 실제 원자료로 제시한다.
- [ ] 수치가 기술적 운영 지표이며 교육과정 의미 정확도·교사 업무시간·EBS 업무 절감 효과가 아님을 명시한다.

## 범위 밖

- 수작업 성취기준 라벨 대비 시간 절감률
- 실제 EBS 업무량·교사 업무시간 일반화

## 사전 전제

- R01~R03 실제 실행 보고와 측정 가능한 로컬 검색
- R09에서 시간·오류·프로그램 편중·내용 근거를 분리 집계한다. 유료 모델 사용 기록은 실제 R10 실행 시에만 추가한다.

## 완료 조건

- [ ] 원자료와 집계 기준이 남는다.
- [ ] 미측정 교육적·업무적 효과를 주장하지 않는다.
