# Task R07-01 - 대표 후보 제거와 단일 검색 목록·정렬·필터

## 설명

대표 후보 최대 4건과 전체 자료의 탭 구분을 없애고, 교사가 하나의 검색 결과에서 원문 근거를 확인하며 직접 자료를 고르게 한다. 정렬은 순서, 필터는 조건에 따른 범위, 카드 태그는 소재 안내로 구분한다. 2026-10-05 사용자 요청에 따라 task 작성·구현·에이전트 검증을 마쳤으며 상태는 **진행중 / 사용자 결과 확인 대기**다. 기존 R07 완료와 R08 사람/자동 연계 기록은 보존한다.

## 구현 항목

- [x] 대표 후보 선정·탭을 제거하고 빈 검색부터 단일 목록·총건수·페이지를 제공한다. 이전 대표 탭 주소/브라우저 검색 상태도 단일 목록으로 열고 검색·필터·정렬·페이지를 복귀/새로고침/수업 폴더 왕복에서 유지한다.
- [x] 관련순을 기본으로 제목·소개문의 주제/조건 근거와 명시한 프로그램 선호를 사용한다. 자료 유형·링크 확인·프로그램 다양성을 교육적 관련성 가점으로 사용하지 않는다. 카드에 검색어와 연결되는 짧은 원문 기반 이유를 표시한다.
- [x] 방송일 최신순·오래된순을 검색 결과 전체에 적용한 뒤 페이지를 나눈다. 유효하지 않거나 없는 날짜는 양방향 모두 마지막에 표시하고, 방송일이 EBS 공개 목록 표기이며 최초 방송일과 다를 수 있음을 안내한다.
- [x] 기존 원문 언급 개념을 상위 주제 묶음과 세부 개념으로 선택할 수 있게 한다. 분류되지 않은 자료도 제목·소개문 검색을 유지하며 미분류 선택을 제공한다. 추론 후보를 직접 확인된 태그로 사용하지 않는다.
- [x] 자료 유형·실제 프로그램명 선택/검색·방송 연도 또는 시작/종료일·날짜 미확인 필터를 제공한다. 프로그램·회차 목록은 개별 영상과 구분한다. 교과 탐색·소개문 상태는 보유 원문 태그/텍스트 범위에서 제공하며 공식 교육과정 연계와 구분한다.
- [x] 기존 사람 확인/자동 근거 검사·개별 페이지 확인 필터를 유지한다. 필터별 결과 건수·현재 선택 조건·조건별 해제·전체 해제를 제공하며 빈 결과에서도 해제할 수 있게 한다. 개수는 페이지 일부가 아닌 현재 조건 전체의 판본 묶음 기준으로 센다.
- [x] 카드 앞면에는 직접 원문에 있는 핵심 개념 최대 3개·자료 유형·소개문 상태와 프로그램/방송일을 표시한다. 교육과정 관계·상세 원문 근거는 펼쳐 볼 수 있게 하고 자동 검사/사람 확인·부분 연계의 차이를 유지한다.
- [x] 다른 판본 묶음·원문 근거·자료 모음·수업 폴더를 보존한다. 필터·정렬에 맞는 판본을 먼저 보여주고 관계를 다른 판본에 전파하지 않는다. 기존 사막 비유·우주 극 배경 등의 오탐 방지 조건을 단일 목록에 맞게 적용하되 OR 검색의 다른 유효 주제와 어휘 밖 자유 검색을 잃지 않는다.

## 실제 구현

- `public/discover.html`·`discover.js`에서 대표 탭·대표 카드·4건 선정 동선을 제거했다. 빈 검색도 전체 개별 자료 목록을 보여주고, 검색 결과 하나에 총건수·정렬·9건 페이지를 제공한다. `teacher-curation.js`의 대표 선정과 다양성 가산은 제거했으며 과거 `topic` 주소의 필터 해석과 판본 묶음/오탐 경계만 남겼다.
- `server/discovery-search.js`의 관련 점수에서 유형·링크 확인·소개문 보유 가점을 제거했다. 제목/소개문 요청 표현·직접 개념 언급·보존 지형 근거·명시적인 프로그램 선호로 정렬한다. `teacher-discovery.js`는 사막 비유/우주 극 배경 등의 경계를 해당 주제의 단일 목록에 적용한다. OR의 다른 유효 주제와 어휘 밖 자유 검색은 유지한다.
- `server/teacher-filters.js`는 60개 원문 개념을 8개 탐색 묶음으로 제공하고 **주제 묶음/핵심 개념·유형·프로그램·연도/기간·교과·소개문·확인 상태**를 처리한다. 미분류·날짜 미확인도 선택할 수 있다. 교과는 직접 언급 태그의 사회/과학/공통 분류이며 공식 교육과정 판정이 아니다.
- `public/discovery-filters.js`는 프로그램명 검색과 선택, 시작일/종료일의 **기간 적용**, **교과 탐색·소개문·확인 상태**, 선택 조건별 해제와 **필터 전체 해제**를 제공한다. 전체 해제는 검색어를 유지한다. 검색어만 바꿀 때도 필터를 유지하고, 검색 예시/전체 목록은 새 검색으로 초기화한다.
- 관련순·방송일 최신순/오래된순은 전체 일치 자료에 적용한 뒤 페이지를 나눈다. 날짜 미확인은 양방향 모두 마지막, 동점은 제목/ID 순이다. 방송일을 수집일로 대체하지 않는다. 연도 선택과 날짜 범위는 서로 대체하며 시작/종료일을 포함한다.
- 기본 카탈로그에서 숨겨졌던 같은 제목의 방송 회차를 읽기 전용 `searchVariants`로 보존하고 교사 경로에서 원본 ID별로 확장했다. **필터 → 전체 정렬 → 판본 묶음 → 페이지** 순서이므로 최근 판본이 과거 판본의 날짜 때문에 빠지지 않는다. 조건에 맞는 판본만 묶으며 다른 판본의 승인·자동 관계를 복사하지 않는다. 원본·승인·자동 DB 스키마 변경은 없다.
- 필터 건수는 다른 조건을 유지하고 해당 필터만 변경했을 때의 전체 판본 묶음 수다. 주제/교과는 겹칠 수 있으며 상위 주제 묶음 변경 시 세부 개념은 해제한다. 빈 결과에서도 선택된 조건과 대체 옵션을 유지한다.
- `teacher-cards.js` 앞면에 직접 원문 개념 최대3개·유형·소개문 상태·프로그램/방송일·짧은 검색 관련 이유를 표시한다. 원문과 교육과정 근거는 펼침 영역에서 확인하며 자동 부분 연계와 사람 확인을 구분한다. 기존 모음/수업 폴더·내보내기는 유지한다.
- URL·`curi.teacher.search.v1`에 정렬·필터·페이지를 함께 저장한다. 과거 `view`·`browse`는 무시하고 단일 목록으로 복구하며 기존 `topic`·검색/페이지 조건을 보존한다. 폴더/자료 모음 저장 키는 바꾸지 않았다. [구조](../docs/ARCHITECTURE.md)·[검색 상태/ERD](../docs/ERD.md)·후속 R09 확인 동선도 갱신했다.

## API와 검증

기존 `GET/HEAD /api/curi/discover?workspace=teacher`에 아래 조건을 적용한다. 기존 `q`, `kind`, `program`, `place`, `page`, `access`, `curriculum`, 이전 `topic`은 유지한다.

| 조건 | 값/범위 |
| --- | --- |
| `sort` | `relevance`(기본), `newest`, `oldest` |
| `conceptGroup` / `concept` | 8개 묶음 ID / 등록 개념 ID, `unclassified`(묶음 미선택 시) |
| `subject` | `all`, `사회`, `과학`, `공통`, `unclassified` |
| `description` | `all`, `present`, `title`(없음·제목 반복) |
| `year` | 빈 값, 네 자리 연도, `unknown` |
| `from` / `to` | 유효한 `YYYY-MM-DD`, 양쪽 경계 포함. `year`와 동시 지정하지 않음 |
| `filters` 응답 | 종류별 `value`, `label`, 전체 조건에서의 `count`. 페이지 일부의 건수가 아님 |
