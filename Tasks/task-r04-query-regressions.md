# Task R04 - 자연어 검색 조건 회귀 보강

## 설명

R03 자연어 탐색에서 발견된 세 가지 조건 처리 결함을 고정 fixture로 재현하고 수정 전후 회귀 기준을 남긴다. `설악산 또는 김제`는 두 장소 중 하나를 찾고, `해안 지형 제외하고 우주`는 제외 범위를 보존하면서 우주를 찾으며, `김제 5분 이내`는 김제 후보를 유지하고 시간 조건 미지원 안내를 표시해야 한다. 수집 완료 22,753건 스냅샷과 승인 저장소는 유지하고 유료 API는 호출하지 않는다. 제품 코드와 에이전트 검증은 통합 완료했으며 사용자 결과 확인 전이므로 task는 완료로 표시하지 않는다.

## 구현 항목

- [x] 미등록 고유명사 질의에서도 `또는`의 OR 범위를 보존하여 설악산·김제 후보를 반환한다.
- [x] 부정 구를 전체 표현으로 분리하여 `해안 지형`이 제외 조건으로 유지되고, 우주 긍정 조건이 지리 조건에 의해 재유입되지 않는다.
- [x] 미지원 시간 조건을 경고와 별도로 처리하여 `김제 5분 이내`에서 `5분`·`이내`가 내용 검색어로 남지 않게 한다.
- [x] 기존 정상 단일 주제, 알려진 개념 OR/AND, 단일어 제외, 빈 결과, 근거 구절·오프셋 계약을 유지한다.
- [x] 고정 fixture의 수정 전후 결과를 비교하고, 자연어 해석·검색·근거·모음 통합 회귀를 같은 기준으로 기록한다.
- [x] 수집 작업·승인 저장소·유료 API 호출을 변경하지 않는다.
