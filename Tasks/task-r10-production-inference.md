# Task R10 - 로컬 근거 묶음 기반 프로덕션 추론

## 현재 후속 실행 — 2026-10-14

[R12-03](task-r12-03-failure-improvement.md)에서 원문/검색/UX 개선 후 남은 요청 해석·재정렬 실패의 선택적 비교로 연결한다. 모델 호출과 계약 준비가 실제 요청 기준선·원천 수집·UX의 필수 선행이 되지 않는다. 도입 효과는 R12-06의 같은 조건/분모로 비교하며 유료 실행은 기존 명시 범위/예산 승인 전까지 금지한다.

## 설명

향후 모델의 첫 역할은 로컬 시맨틱 레이어와 교사용 큐레이션 기준선을 바탕으로 프로덕션에서 요청을 해석하고 근거 있는 주제 방향·추천 이유·수업 활용 제안을 작성하는 것이다. R07의 교사 흐름과 R09 검증 이후 개선 필요를 비교하는 후속 task이며, 이번 세션의 유료 API 금지는 유지한다.

## 구현 항목

- [ ] R02의 제한된 근거 묶음 계약을 모델 입력·출력 인용 검증 계약으로 연결
- [ ] 주제·조건 해석과 근거 내 설명 생성의 개선을 로컬 기준선과 같은 질문으로 비교
- [ ] 초등 3~4·초등 5~6·중1의 사회·과학별 로컬 기준선과 비교하고 학교급·학년·선행 개념·수업 목적을 구분해 반영
- [ ] 주제 선택·대표 후보 비교·발문/활동 제안에서 원문 사실과 모델 제안을 구분하고 R07의 목록 우선·설명 펼치기 경험 유지
- [ ] 출처 지시문 무시·근거 없는 장면/학년/교육과정 주장 차단·빈 결과 처리를 검증
- [ ] 공식 성취기준의 학년군, 중1 편성 근거, 영상의 학년 적합성을 구분하고 모델이 미확인 학년 배치나 다른 학년의 승인을 만들어내지 않도록 검증
- [ ] R08-01~04의 후보·구조화된 인용·자동 검사·현재 유효성·실제 사람 결정 경계를 유지한다. 모델 출력과 confidence가 자동 검사 실패·보류를 덮어쓰거나 사람 승인을 만들지 않도록 한다.
- [ ] 실제 도입 시점의 모델·가격·호출/토큰 예산·재시도·캐시·오류 시 로컬 대체를 확정
- [ ] 유료 실행에 대한 사용자 선택과 예산이 확보된 뒤 제한 실험하고 실제 비용 기록

## 범위 밖

- 현 세션의 유료 호출, 모델이 전체 방송 원본을 매번 읽기, 자동 결과의 사람 승인 승격

## 사전 전제

- [R02](task-r02-semantic-layer.md), [R03](task-r03-natural-discovery.md)의 재현 가능한 로컬 입력·결과
- [R07](task-r07-teacher-workspace.md)의 교사용 추천·수업 준비 기준선. 화면 개편을 유료 API 도입에 의존시키지 않는다.
- [R09](task-r09-quality-gates.md)의 비교 질문·근거 검증 기준. 100~150건 사람 승인 완료를 모델 실험의 일괄 선행 조건으로 삼지 않는다.
- 추가 학년 비교는 [R09-01](task-r09-01-grade-expansion.md)의 데이터·기능과 R09의 학년별 기준선을 사용한다. 이 task에서 추가 학년 교육과정 확보·승인 체계를 대신 구현하지 않는다.
- [R08-01](task-r08-01-automatic-evidence.md)~[R08-04](task-r08-04-human-review.md)의 자동 근거 검사·별도 자산·선택적 사람 결정 계약. R09의 사람 의미·효용 평가는 미실행이면 한계로 남기고 기술 비교 기준과 구분한다.
