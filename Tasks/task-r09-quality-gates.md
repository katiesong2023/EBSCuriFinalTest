# Task R09 - 사회·과학 검색 품질과 원문 표본 검증

## 현재 후속 실행 — 2026-10-14

기존 기술 검사·원문 표본·사용자 확인 기록은 보존한다. 새 요청 품질/실제 교사 선택·반복 사용의 실행 책임은 [R12-01](task-r12-01-request-baseline.md)·[R12-06](task-r12-06-teacher-validation.md)으로 통합한다. 아래 사람 평가 선택 조건은 기술 기능 제공/시연의 과거 경계다. 새 제품 효용 검증은 실제 참여/판단을 수행해야 완료할 수 있으며 미참여를 에이전트 대리 판단으로 대체하지 않는다.

## 설명

대량 확보량과 원문 근거 태그의 존재만으로 수업 적합성을 판단하지 않는다. R01~R03의 기능 검증 후, 실제 교사 요청과 원문 대조를 통해 남은 자료·해석·순위 문제를 분리한다.

2026-10-04 사용자 요청으로 평가 대상에 **초등 3~4학년과 중학교 1학년 사회·과학**을 추가하고 기존 초등 5~6학년을 유지한다. 추가 학년의 데이터·기능 구현은 [R09-01](task-r09-01-grade-expansion.md)에서 수행하고, 이 task에서는 확장 후 품질을 확인한다. 아래 기존 완료 항목과 과거 실측은 기존 범위의 기록이며 새 학년의 검증 완료를 뜻하지 않는다.

같은 날 자동 연계 품질 관리 방향을 추가했다. [R08-01](task-r08-01-automatic-evidence.md)~[R08-04](task-r08-04-human-review.md) 이후 자동 검사 기술 결과와 실제 사람의 의미·효용 평가를 분리한다. 준비 기간의 필수 확인은 기술·원문·상태 경계이며, 대량 관계 승인과 사람 평가는 운영 여력이 있을 때 수행한다. 미실행 평가는 미확인으로 보고하고 기능 제공·시연의 선행 조건으로 삼지 않는다. 사용자의 구현 결과 확인과 실제 교육과정 관계 검토·교사 효용 평가는 서로 다른 절차다.
