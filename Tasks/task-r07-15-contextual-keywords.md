# Task R07-15 - 소개문 맥락에 따른 내용 태그

## 설명

내용 태그를 실제 소개문과 대조하고 비유적 제목·인명·주변 소재의 오분류를 줄인다. 소개문에서 확인한 교육과정 탐색 어휘를 우선 표시하며 불확실한 의미는 보류한다. 상태: **진행중**.

## 구현 항목

- [x] 실제 태그의 오류 사례와 소개문 근거를 검사한다.
- [x] 제목만으로 만든 태그와 비유·부정·동명이의 표현의 표시를 제한한다.
- [x] 소개문에 근거한 교육과정 탐색 어휘와 원문 소재를 표시하고 근거 문장을 제공한다.
- [x] 검색·승인·원문·저장 경로를 보존하고 변경 범위를 검증한다.

## 범위 밖

- 유료 모델 호출·영상 분석·교육과정 적합성 자동 승인
- 기존 검색용 시맨틱 색인의 전수 재구축

## 사전 전제

- R07-14 표시용 키워드와 공개 소개문

## 수동 작업

추가 키·외부 자료 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 실제 오류 사례·문맥 계약 확인
- [x] 관련 화면/저장 회귀·정적 점검
- [x] 문서·실행 서버 반영

### 결과 확인

- [ ] `http://127.0.0.1:3000/`에서 ‘빅오션’을 검색한다. ‘심장으로 듣는 아이돌’ 카드의 태그에서 심장이 제외되고 음악·공연·장애인이 보이는지 확인한다.
- [ ] ‘억만장자’를 검색한다. ‘역사의 빛’ 카드에서 빛이 제외되고 독립운동이 보이는지 확인한다.
- [ ] ‘사찰음식’을 검색하고 태그에 마우스를 올려 소개문 근거 문장이 표시되는지 확인한다. 카드의 공개 소개문도 확인한다.
- [ ] 태그가 많은 자료의 추가 키워드를 펼치고 모바일 화면과 내 자료 저장을 확인한다.

## 구현 결과

- 실제 비유 사례: 바다의 우유→우유 제외/굴 유지, 심장으로 듣는 아이돌→심장 제외/음악·공연·장애인, 역사의 빛→빛 제외/독립운동, 심장이 뛴다 화성→심장 제외, 일본의 심장 기후→심장·기후 제외, 머구리의 바다→전쟁 제외/바다·어업 등 실제 소재 유지.
- `content-keywords.js`는 임의 제목 단어와 coreTags 단순 합치기를 중단한다. 기존 개념 별칭/공식 단원 탐색 어휘/선별 소재를 소개문에서 확인한 뒤 대표 어휘와 본문에서 확인된 제목 주제를 우선한다. 기본8개+펼침을 유지한다.
- `keyword-context.js`는 문장 내 비유·부정·인명, 심장/빛/구름/화석/자석/세포/전쟁/기후/수분/지구/힘/별/달/발굴/시장/소화의 분야 단서, 긴 소개문에서 한 번만 등장하는 주변 소재를 검사한다. 원본 위치/인용과 `evidence.context` 문장을 반환한다. 카드 툴팁에 문장을 표시한다. 소개문이 없거나 제목 복사는 보류한다.
- 전체23,360자료의 표시 태그는2,672자료/4,071어휘다. 기존6,320자료보다 감소하며 제목만의 단어·근거 부족·불확실한 의미를 제외한 결과다. 단순 태그 수 확대보다 오분류 감소를 우선했다. 전체 검사는 인용 위치/소개문 필드의 계약 검사이며 모든 자료의 의미에 대한 사람 검수는 아니다.
- 신규 문맥 계약7개(실제 오류6자료 포함)와 최종 브라우저4개·390px 육안 확인 통과. 오류0·원본4저장소SHA동일·유료API0. 서버 재시작 후 빅오션/억만장자/사찰음식 실제 응답 확인. `docs/r07-15-contextual-keywords-check.json`, `docs/r07-15-content-keywords-browser-check.json`, `docs/r07-15-running-server-check.json`에 기록했다.
- 규칙 기반 검사로 전체 문맥 이해를 보증하지 않는다. 소개문에 표현되지 않은 교육과정 개념을 추정하지 않으며, 태그는 성취기준 충족·영상의 학년 적합성을 뜻하지 않는다. 검색용 시맨틱 색인/coreTags/개념 필터·미리보기 안내·승인·개인 저장은 유지하므로 검색 선정과 표시 태그는 다를 수 있다.
