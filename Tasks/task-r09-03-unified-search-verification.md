# Task R09-03 - 통합 검색의 회귀와 수업 준비 흐름 확인

## 설명

통합 화면이 검색 조건·근거·저장된 수업 문맥을 손실 없이 연결하는지 확인한다. 기존 검사와 기준선을 재사용하고, 통합으로 새로 생긴 경계와 실패만 추가로 점검한다. 기능 검증을 실제 교사 효용이나 교육과정 의미 정확도 평가로 표현하지 않는다. 상태: **진행중**.

## 권장 개발 모델

- **GPT-6 Luna · High** (`gpt-6-luna`): 확정된 계약과 기존 검사 수단으로 결과를 대조하고 보고를 정리하는 단계에 사용한다.
- 조건·순위·저장 문맥이 함께 얽힌 실패는 GPT-6.1 Sol · Medium으로 넘기고, 해결되지 않은 범위만 High로 높인다. 통과한 검사를 이유 없이 반복하거나 Astra·Ultra로 전체 검토를 다시 하지 않는다.
- 개발 검증 모델 추천이다. 사용량·비용 절감 비율은 실측 없이 주장하지 않는다. 공통 사용 원칙은 [PLANS](../docs/PLANS.md#검색-화면-통합-후속-계획--2026-10-11)을 따른다.

## 검증 결과 — 2026-10-11

- 기존 검사 산출물을 재사용했다. `docs/r07-07-combined-search-check.json` 계약 20건과 실제 대표 입력 10건, `docs/r07-07-http-check.json` 격리 HTTP 5건, `docs/r07-08-page-check.json` 통합 화면 14건, `docs/r07-09-context-check.json` 근거·저장 문맥 8건이 모두 통과했고 기록된 브라우저 오류는 0건이다. 폴더 회귀 12건·리뷰 회귀 3건과 R07-08 기존 화면 회귀 10건도 각 연결 산출물에서 통과했다. 이미 완료된 검사를 반복 실행하지 않았다.
- 대표 입력은 R07-06 사회·과학 기준표 그대로다. 실제 검색 묶음 수는 사회 질문만 15·기준만 10·결합 1, 과학 질문만 0·기준만 3·결합 2, 중1 과학 `마찰력`+`9과05-02` 결합 2였다. 사회·과학 3~4학년 미지원 결합은 각각 0건이며, 중1 사회 기준은 후보 없음으로, 과학 기준 자동 비교 미지원은 미지원 상태로 구분됐다. 기존 과학 긴 질문의 0건도 유지됐다. 이 수치는 교육적 정답률이나 전체 자료 재현율이 아니다.
- 통합 화면 기록은 기준 선택/해제 뒤 질문·대상 학년·정렬 필터 유지, 새로고침·뒤로 가기·기존 `/curriculum.html` 이동, 중복/충돌 주소 오류, 빠른 기준 변경의 늦은 응답 차단, 빈 결과·조회 실패 재시도, 키보드 선택과 390px 넘침 없음 확인을 포함한다. 검색→내 자료의 복수 기준·수업 이유 저장→조건 변경/재열기→폴더 왕복→Markdown 내보내기와 관계 재조회·저장·내보내기 실패 때 개인 입력 보존은 별도 격리 브라우저 기록에서 통과했다.
- R09-02 고정 33관계의 결과·판단은 수정하거나 검색 규칙 조정에 재사용하지 않았다. 기존 독립 평가 무결성 기록은 표본 원문 변경 0, 평가 후 제품 조정 없음, 교사 응답 0건을 기록한다. 해당 결과의 남은 후보 누락 1건과 표본 한계는 그대로다. 독립 표본의 수치와 기능 회귀 수치를 합치지 않는다.
- 네 보호 저장소(`curi-store.json`, 방송 카탈로그, 시맨틱 레이어, 자동 자산)의 SHA-256은 R07-07~09 검사 전후 동일했다. 인증 없는 관리자 작업공간/자동 자산 쓰기는 401, 교사 화면에서 운영 집계 미노출·관리자 경로 유지가 확인됐다. 브라우저 회귀는 격리된 합성 저장 공간을 썼으므로 실제 사용자의 브라우저 저장 자료를 열거나 직접 대조하지 않았다. 실제 저장 데이터는 테스트 환경에서 건드리지 않았으며, 개인 자료의 실물 백업·복원 확인은 사용자 화면 결과 확인 범위로 남긴다.
- 전체 기술 범위의 회귀는 통과했다. 제출·시연에서는 검색 후보의 한계와 자동 비교 미지원/미확인을 표시할 수 있다. 실제 교사 효용, 영상 시청·학년 적합성, 교육과정 의미의 전수 정확도는 검증하지 않았다. 유료 API 호출은 0건이다.
