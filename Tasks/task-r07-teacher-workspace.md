# Task R07 - 교사용 자료 추천과 수업 준비 흐름

## 설명

교사가 개발·검수 단계를 이해하지 않아도 수업 주제를 정하고, 근거가 있는 자료를 비교·선택하여 수업 준비안으로 가져가게 한다. 사용자 확정 사항은 교사용 화면과 관리자 화면의 분리다. 로컬 근거 기반 주제 방향·대표 후보와 브라우저 수업 준비안을 구현했다. 상태는 **진행중 — 구현·에이전트 검사 완료, 사용자 결과 확인 대기**다.

## 구현 항목

- [x] 교사 주 메뉴를 자료 찾기·내 수업 준비 중심으로 구성하고 관리 도구와 분리
- [x] 모호한 수업 요청에는 자료 근거가 있는 주제 방향을 소수 제안하고 필요한 맥락만 질문
- [x] 탐색 결과를 대표 후보·전체 자료 탭으로 통합하고 대표 자료 최대 4개를 선정 이유·차이·확인 한계와 함께 제시
- [x] 자료 목록을 먼저 보여주고 자세한 근거·설명은 펼쳐 확인하도록 구성
- [x] 프로그램·관점 다양성을 고려하고 같은 내용의 더빙·수어·재방송 판본은 대체 자료로 묶음
- [x] 담은 자료를 도입·탐구·정리 등 수업 역할에 배치하고 교사가 교체·순서·메모를 조정
- [x] 원문 내용과 발문·활동 제안을 구분하며 학년·재생시간·장면 미확인을 사실로 채우지 않음
- [x] 승인된 교육과정 연계는 자료의 필터·확인 표시로 제공하고 승인 전 탐색 후보와 구분
- [x] 검색·모음·수업 준비안 사이에 선택한 주제·자료를 유지
- [x] 빈 결과에서 자료 부족·미확인 조건을 설명하고 가능한 다음 행동 제공

## 실행 순서

1. 교사·관리자 역할과 진입 동선을 정리한다. 교사에게 자료 찾기와 수업 준비를 연결하고, 기존 승인 자산 검색은 교육과정 연계 확인 필터로 통합하는 안을 우선 검토한다. 관리자 진입과 자료 미선택 처리는 R08의 첫 범위와 맞춘다.
2. 로컬 근거로 주제 방향과 대표 후보를 제공한다. “우주 관련 수업을 하고 싶어 주제를 선정해줘” 같은 요청에서 주제 선택을 돕고, 관련 없는 날씨 자료를 추천하지 않는지 확인한다. 후보가 부족하면 3~5개를 억지로 채우지 않는다.
3. 선택한 자료를 수업 준비안으로 연결한다. 자료 배치·교체·순서·메모와 저장 후 재열기를 확인한다. 발문·활동은 제안으로 표시하고 원문에 있는 내용과 구분한다.

유료 모델 없이 가능한 기준선을 구현했다. 추가 추론은 R10에서 같은 요청으로 비교한다. 위 예문은 개발용이며 R09의 독립 확인에는 새로운 표현을 사용한다.

## 범위 밖

- 교사에게 연계 초안 생성·CuriBase 저장·색인 준비를 필수 절차로 요구
- 근거 없는 수업 적합성 판정·확인되지 않은 장면 시간 생성
- 이번 세션 유료 API 호출; 프로덕션 모델은 R10 별도

## 사전 전제

- R01~R03의 수집·원문 근거·검색 계약과 R06 교사 UX 크리틱 1회
- [R09](task-r09-quality-gates.md)의 현재 원문 감사·미확인 상태를 활용한다. 대량 사람 검수 완료를 화면 구현의 선행 조건으로 삼지 않는다.
- 관리자 동선은 [R08](task-r08-admin-workspace.md)로 분리하고 기존 승인 이력은 보존한다. 역할 경계를 함께 정하되 R08 전체 완료를 기다리는 순환 의존은 두지 않는다.

## 완료 조건

### 에이전트 확인

- [x] 주제 미정 → 주제 선택 → 대표 자료 비교 → 수업 준비안 저장까지 연결
- [x] 실제 자료 근거·추천 이유·미확인 조건을 확인하고 무관한 상위 결과 방지
- [x] 교사 경로에서 관리 기능·내부 구현 용어를 알아야 하는 막힘이 없음
- [x] 기능 검사와 실제 교사 평가를 분리하여 기록
- [x] 같은 고정 자료에서 기존 검색·AND/OR·제외·근거·모음과 새 수업 준비 저장·재열기 동작 확인

### 결과 확인

- [ ] 대표 후보·전체 자료 카드 제목 아래의 `방송일`로 자료의 시점을 비교하고, 다른 판본을 펼쳤을 때 판본별 날짜를 확인한다. 날짜가 없는 자료의 `미확인` 표시와 내 자료·수업 준비안·내려받기 파일의 방송일이 이해되는지 확인한다.

- [x] `탐색 결과`의 `대표 후보`와 `전체 자료` 탭을 바꿔가며 중복 카드를 연달아 읽지 않고 비교할 수 있는지 확인한다. 전체 자료의 다음 페이지로 이동한 뒤 탭을 왕복하고, 새로고침·수업 준비 화면 왕복 후에도 선택한 탭·페이지·자료 모음이 유지되는지 확인한다.

- [x] 자료 카드의 대표 키워드와 `공개 소개문 핵심`만 읽고 콘텐츠 내용을 빠르게 파악할 수 있는지 확인한다. `추천 이유와 원문 근거`를 펼쳐 검색 주제와의 연결 이유를 읽고, 필요하면 `공개 소개문 전체`를 추가로 펼친다.
- [x] 수정된 `수업 주제의 출발점`에서 각 방향의 설명·질문만 읽고 방향 간 차이와 살펴볼 내용을 이해할 수 있는지 확인한다. `연결된 자료 예시`의 원문 표현은 방향 설명과 구분해 확인한다.
- [x] [자료 찾기](http://127.0.0.1:3317/)에서 “우주 관련 수업을 하고 싶어 주제를 선정해줘”를 입력하고, 주제 방향과 대표 후보의 선정 이유·차이가 자료 선택에 도움이 되는지 확인한다.
- [x] 주제 방향을 선택하고 대표 카드의 `추천 이유와 원문 근거`를 펼쳐 설명을 확인한다. `교육과정 연계 확인`을 켰을 때 우주 승인 자료가 없다는 안내와 조건 해제 후 후보 복귀가 이해되는지 확인한다.
- [x] 자료 2~3개를 `모으기`로 담고 `내 자료 → 내 수업 준비로 가져가기`로 이동한다. `수업에 넣기` 후 도입·탐구·정리 역할, 같은 역할 안의 순서, 발문·활동·메모를 조정한다.
- [x] 다른 자료를 추가로 담아 `다른 자료로 교체`를 사용한다. 역할과 기존 메모가 유지되는 방식이 실제 준비 방식에 맞는지 확인한다.
- [x] 수업 이름·주제를 적고 `준비안 저장` 후 새로고침한다. 다시 연 준비안과 `준비안 내려받기` 파일에 배치·교체·메모·출처가 유지되는지 확인한다.
- [x] `자료 더 찾기`로 돌아왔을 때 검색어·선택한 주제와 자료 모음이 유지되는지 확인한다. 문제가 있으면 화면 주소·누른 버튼·표시 메시지를 알려준다.

## 수동 작업

추가 API 키·계정 설정은 없다. 개인 준비안은 같은 브라우저의 같은 주소(호스트·포트)에 저장되며, 다른 기기로 자동 동기화되지 않는다.

## 구현 결과 — 2026-10-01

- `/`의 주 메뉴는 **자료 찾기·내 수업 준비**, 준비안은 `/lesson.html`이다. 기존 `/index.html`의 승인 검색 API·화면은 직접 접근용으로 보존하고 교사 주 메뉴에서는 뺐다. 승인 연계는 기본 탐색의 `교육과정 연계 확인` 필터와 자료별 성취기준·검수 근거 표시로 통합했다. CuriMap·검수 상세를 교사의 선행 단계로 요구하지 않는다.
- R08 경계: 기존 `/curimap.html`, `/review.html`, `/ingestion.html`과 관리 API는 보존했다. 관리 진입 목록·자료 미선택 안내·권한 통제는 R08에서 구현한다. 이번 메뉴 분리는 인증 구현이 아니다.
- `teacher-discovery.js`는 기존 검색 조건을 통과한 전체 후보에 승인 조건·주제 방향·판본 묶음을 적용한 뒤 페이지와 대표 후보를 만든다. `teacher-approvals.js`는 기존 검수 Gate와 현재 원문 지문을 통과한 승인만 읽는다. 승인 기록이나 검색 투영을 쓰지 않는다.
- `teacher-curation.js`는 주제 미정일 때 근거가 있는 사회 2·과학 2 방향, 주제 입력 시 최대 3방향, 대표 후보 최대 4개를 제공한다. 우주·민주주의·생태계에는 편집한 방향을, 그 밖에는 원문에 함께 나온 개념을 사용한다. 실제 근거가 없으면 방향·후보를 채우지 않는다. 주제 선정 요청 문법은 기존 승인 검색과 `topic-request.js`에서 공유한다.
- 대표 후보는 원문 주제 표현·소개문 충실도·프로그램·관점 차이를 고려한다. 우주는 비유·극 배경 오탐을 줄이기 위해 천문 표현과 설명 문맥을 추가 요구한다. 예시 요청은 원래 151자료에서 판본을 묶은 143그룹으로 탐색되며 대표 4개를 제시한다. 이 숫자는 관련성 정답률이 아니다.
- 판본은 같은 프로그램·제목에서 명시적 더빙·수어·재방송 등의 표기만 제거해 묶는다. 모든 유사 영상의 동일성을 판정하지 않으며 편집·재생시간 차이는 미확인이다. 다른 판본의 링크·담기를 펼쳐 비교할 수 있다.
- `teacher-cards.js`는 대표·전체 목록의 카드, `teacher-storage.js`는 공용 자료 모음·준비안·검색 상태·안전한 링크·내보내기, `lesson.js`는 배치·교체·순서·편집을 맡는다. 스타일은 기존 화면에 `teacher-workspace.css`를 추가했다.
- 기존 모음 키 `curi.discovery.shelf.v1`을 유지하고 `curi.teacher.lesson.v1`에 준비안 하나, `curi.teacher.search.v1`에 검색 상태를 저장한다. 각 모음·준비안은 최대 100자료다. 수업에서 빼도 모음은 유지하며 교체는 역할·메모를 보존한다. 발문·활동은 교사가 고치는 일반 제안으로 원문과 구분한다.
- 저장 실패는 성공으로 표시하지 않는다. 다운로드 시 최신 링크·승인 상태를 조회하고, 실패하면 오래된 주소로 내보내지 않고 재시도하게 한다. 준비안의 소개문은 저장 시점 사본임을 표시한다.

## 사용자 피드백 반영 — 방향 소개문 수정

- 각 방향의 첫 자료에서 자른 구절이 방향 전체의 소개로 표시되어, 수업에서 무엇을 살펴볼지 설명하지 못한다는 피드백을 반영했다.
- 주제 미정·우주·민주주의·생태계의 13방향에 탐색 초점을 설명하는 소개문과 생각해 볼 질문을 추가했다. 그 밖의 함께 등장하는 개념 방향은 현재 검색 주제와 추가 개념을 명시하고 원문에서 연결을 확인하도록 안내한다.
- `teacher-curation.js`의 `description`·`question`은 편집한 수업 구상 제안이다. 기존 근거 구절은 자료 제목과 함께 `연결된 자료 예시`에 접어 두며, 자료가 소개문의 모든 내용을 담고 있다고 단정하지 않는다. 방향별 후보 선정·필터는 유지했다.

## 사용자 피드백 반영 — 탐색 결과 탭 통합 (2026-10-02)

- 별도 대표 후보 영역을 없애고 `탐색 결과` 안의 **대표 후보 / 전체 자료** 탭으로 통합했다. 유형·프로그램·교육과정 연계·개별 페이지 필터는 탭 위의 공통 영역에 두었다. 각 탭에 현재 조건의 자료 수를 표시하고, 대표 후보는 “검색 결과 중 먼저 살펴볼 자료”로 설명한다.
- 주제 검색·방향 선택은 대표 후보부터, 전체 목록 요청은 전체 자료부터 열린다. 대표 후보가 없으면 전체 자료로 전환하고 대표 탭을 비활성화한다. 오류나 로딩 중에는 이전 두 패널을 숨긴다.
- 탭 전환은 추가 검색 없이 같은 응답의 표시만 바꾼다. 전체 자료의 페이지·펼친 근거를 유지하며 모음은 공유한다. `view`를 URL과 기존 검색 저장 키에 추가하여 새로고침·뒤로가기·수업 준비 왕복에서도 탭·검색 조건·페이지를 복원한다. 검색 조건을 변경하면 전체 페이지는 1로 돌아간다.
- 키보드 방향키·Home·End로 탭을 선택할 수 있다. 탭과 패널의 접근성 관계 및 선택 상태를 표시하고, 비활성 패널의 카드는 화면·키보드 탐색에서 제외한다.

## 사용자 피드백 반영 — 방송일 표시 (2026-10-02)

- 자료 카드 제목 아래에 방송일을 `YYYY. MM. DD.`로 표시했다. 대표 후보·전체 자료·다른 판본·내 자료·수업 준비안에서 같은 형식을 사용하고 모음 메모·수업 준비안 다운로드에도 포함한다.
- 기존 방송 SQLite의 `broadcast_date`를 사용한다. 일반방송 원본 ID 22,753건 중 22,492건에 날짜가 있으며, 카드의 날짜는 선택된 회차의 EBS 공개 목록 표기다. 최초 방송일로 단정하지 않으며 판본마다 자기 날짜를 표시한다. 날짜 미보유·잘못된 형식은 `미확인`, 프로그램·회차 묶음은 `회차별 확인`이다. 자료 기록일·수집일로 대체하지 않는다.
- `teacher-storage.js`의 공통 날짜 표시 함수는 시간대에 따른 날짜 변동을 방지한다. `discovery-catalog.js`에서 기존 지리 자료와 동일 회차를 연결할 때 방송일도 전달하고, 자료 갱신 API는 방송일을 포함해 이전 모음·준비안도 내려받을 때 갱신한다. 수집·승인 원본은 변경하지 않았다.
- [방송일 브라우저 확인](../docs/r07-broadcast-date-check.json) 4경로 통과: 대표·전체·판본별 실제 날짜, 미보유·잘못된 날짜·묶음 처리, 모음·준비안 저장 및 이전 자료의 다운로드 갱신, 모바일·탭 전환. 페이지 오류·외부 요청·서버 쓰기 0건. 기존 R07 고정 자료 계약 8개도 통과했으며 승인·방송 저장소 SHA가 유지됐다.
