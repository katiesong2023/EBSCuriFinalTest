# Task R08-06 - 관계별 자동 근거 확대와 검색 재사용

## 설명

원문 보강과 역방향 후보 발견을 관계별 자동 검사·별도 자산 저장·교사 검색에 연결한다. 2026-10-05 사용자 요청으로 다섯 task를 작성해 순서대로 구현·검증한다. 사용자 결과 확인은 별도로 남긴다. 상태: 진행중 / 구현·검증 완료, 사용자 결과 확인 대기

## 구현 항목

- [x] 공식 성취기준의 대상·관계·조건·학습 행동을 비교할 수 있게 하고 사회·과학의 지원 가능한 명시적 설명 규칙을 제한적으로 확대한다.
- [x] 생태계 언급만 있는 꿀벌 자료를 연소 생성물 피해 관계로 내보내지 않는 등 관계 오탐·부정/의문/조건·원문 부족을 보류한다. 연결/미확인 부분과 인용 실존/버전을 함께 보존한다.
- [x] 역방향 후보에서 자동 검사·별도 자산 저장·검색 재사용을 이어 처리한다. 사람 승인과 구분하고 원문/기준/규칙 변경·사람 제외 우선 정책을 유지한다.
- [x] 실제 보강 원문으로 제한된 재검사를 실행하고 통과/부분/보류·검색 노출을 기록한다. 후보 수·빈 결과·내용 원문 비율·설명 근거·관계 오노출을 검증하되 의미 정확도 정답률로 발표하지 않는다.

## 범위 밖

- 전수 사람 확인·근거 없는 자동 통과·유료 추론·새 학년 데이터

## 사전 전제

- R08-05·R08-01~04 기존 별도 자동 자산·선택적 사람 확인

## 실제 구현

- `curriculum-requirements.js`와 `automatic-relation-rules.js`는 공식 기준의 대상·관계·조건·학습 행동을 보존하고 기존 선거·자전 규칙에 농경문 청동기와 연소 생성물 피해 규칙을 추가했다. 규칙은 요구 관계를 모두 뒷받침하는 실제 원문 인용을 요구하며 학생 수행·영상 장면·학년 적합성은 미확인으로 남긴다.
- `automatic-evidence-service.js`·`automatic-evidence.js`·CLI/HTTP는 선택한 공식 기준 ID 하나를 서버에서 교과·학년과 대조해 검사한다. 기준을 바꾼 요청, 인용 변조, 원문/공식 기준/규칙 버전 차이는 거절한다.
- `admin-curriculum.html`의 관계별 후보에서 자동 검사·별도 SQLite 저장·검색 준비를 실행하고 결과를 다시 읽는다. 동일 입력은 재사용하며 원문 변경은 해당 관계의 공개 투영만 무효화한다. 사람 제외/보류가 있으면 자동 결과보다 우선한다.
- 보강 원문6건 재검사 결과 농경문 청동기–`6사04-01`만 부분 연계 자동 후보로 공개했다. 시민·선거2건은 일부 설명만 확인되어 공개0, 냉동인간·꿀벌·벌레잡이 식물은 원문 부족 또는 지원 관계 없음으로 보류했다. 공개 자동 후보는 `humanVerified:false`이고 기존 사람 승인4건은 그대로다. [실행 기록](../docs/r08-06-real-runs.json), [전후 지표](../docs/r08-06-improvement-summary.json).
- 관계/변조/오탐/무효화 계약10개, 자동 자산26개, 교육과정 HTTP/화면10개, 교사 필터16개·화면10개, 사람 결정18개, 시맨틱19개와 기존 검색·수집 회귀를 통과했다. [관계 검사](../docs/r08-06-relation-check.json), [화면/API](../docs/r08-06-browser-check.json). 유료 API 호출은0이다.

## 수동 작업

추가 입력·키·계정 설정 없음. 관리 화면에서 기준별 후보의 **자동 근거 검사·저장**을 실행하거나 `node server/automatic-assets-cli.js --resource=방송ID --standard=성취기준ID`를 사용한다. 이 동작은 사람 승인 기록을 만들지 않는다.
