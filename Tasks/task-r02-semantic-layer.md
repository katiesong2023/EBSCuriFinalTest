# Task R02 - 근거를 보존하는 사회·과학 시맨틱 레이어

## 설명

공개 방송 메타데이터에 사회·과학 개념과 표현을 연결하여 로컬 검색과 향후 프로덕션 모델 추론에 재사용한다. 원문에서 확인되는 태그와 추론 후보 태그를 구분한다.

## 구현 항목

- [x] 개념 ID·동의 표현·영역을 관리하고 사회·과학을 동등하게 지원
- [x] 자료별 태그에 근거 필드·원문 구절·출처·내용 지문·규칙 버전 기록
- [x] 원문 언급 태그와 추론 후보 관계를 분리하고 자동 승인 금지
- [x] 변경된 원문·규칙의 태그 무효화와 재생성
- [x] 로컬 시뮬레이션 결과와 추론용 제한된 근거 묶음 제공
- [x] 현재 저장 구조 ERD 작성

## 범위 밖

- 유료 모델 호출, 학년·교육과정 적합성 자동 확정, 근거 없는 소개문·타임코드 생성

## 사전 전제

- R01의 실제 수집 회차. 수집 목표 전체 완료 전에도 확보 자료로 검증 가능

## 수동 작업

추가 계정·키 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 태그 근거가 실제 원문과 일치
- [x] 추론 후보와 교육과정 승인이 분리됨
- [x] 증분·재현성·유료 호출 0회 확인

### 결과 확인

- [ ] 검색 결과의 추천 이유와 원문 근거를 펼쳐 직접 언급·추론 후보·미확인 조건이 구분되는지 확인한다.

## 실제 산출물과 확인 경계

[이번 작업 보고](../docs/REDESIGN_RESULTS.md)에 실제 수집량·검사·재현 명령을 기록한다. 구현·에이전트 확인은 완료했지만 사용자 결과 확인 전 상태는 진행중이다. 사람 적합성 승인·재생·장면 검증은 수행하지 않았다.
