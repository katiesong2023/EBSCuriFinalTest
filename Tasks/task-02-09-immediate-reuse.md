# Task 02-09 - 승인 저장 후 검색 즉시 반영

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R00~R03 기반 / 완료 이력·기반 보존**. 기존 승인·증분·화면·출처 자산을 재사용하며 새 탐색의 완료로 확대 해석하지 않는다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

- 상태: `진행중` — 기존 기능의 통합 검증 완료, 신규 DEMO 1건의 실제 생성·사람 검수·저장·검색 확인 대기.

## 실제 산출물과 반영 기준

- `public/review.js`, `public/review-search-index.js`: 기존 `CuriBase에 저장` 동작이 저장 완료 후 검색 준비를 자동 실행한다. `CuriBase 저장 완료`와 `검색 준비 완료`는 별도 상태다. 준비 실패는 `검색 준비·재시도`로 복구한다.
- `server/search-index.js`, `server/data-quality.js`: 관계 전체의 준비가 끝나야 검색 자료를 게시한다. 검수 수정·제외로 무효화된 자산과 이전 검색 자료는 제거한다. 승인·수정 후 다시 저장하고 준비해야 새 결과가 검색된다.
- `server/natural-search.js`, `public/index.js`: 검색 요청마다 최신 검증 자산을 읽는다. 같은 질의의 벡터를 재사용해도 결과 목록은 새로 계산한다. 기존 최소 연관도 기본값 `0.82`와 정렬 기준을 그대로 사용한다.
- 여기서 즉시 반영은 **검색 준비 완료 후 다음 검색 요청부터 노출**된다는 뜻이다. 이미 열려 있는 검색 화면의 카드를 자동 갱신하지는 않으므로 같은 질의로 `검색`을 다시 누른다. 서버 재시작이나 전체 재색인은 필요하지 않다.
- API로 직접 CuriBase에 저장할 때는 기존 계약대로 검색 준비 API를 별도로 호출해야 한다. 이번 실제 DEMO 확인은 자동 준비가 연결된 검수 화면을 사용한다.
- 확인 시작 시 실제 저장소는 콘텐츠 144건, 검증 관계 1건, 검색 준비 관계 1건이다. 기존 `동고서저 지형, 산맥`은 이미 검색되므로 신규 저장 시연 완료 증거로 대신하지 않는다.
- 신규 DEMO 후보는 `반도와 섬` (`ECLIP-049`, `CURI-07ce0b99-2341-5a9e-8c18-36c6f0fca3f7`)이다. 확인 시점에 연계 이력·검증 자산이 없었다. 이 문서에서 시연 대상으로만 지정하며 별도 평가 분할이나 의미 정답을 생성하지 않는다. 실제 원문·공식 근거 검토 후 부적합하면 다른 미검수 콘텐츠를 선택한다.

## 수동 작업

- DEMO 후보의 EBS 공개 원문에서 해당 콘텐츠의 소개 또는 단원·차시 텍스트와 출처를 직접 확인한다. `반도와 섬`은 저장된 소개문이 없으므로 실제 원문에서 확인한 텍스트 20~1200자를 준비한다. AI가 소개문이나 확인 사실을 만들어 대신 입력하지 않는다.
- 공개 원문과 공식 성취기준, AI 연계근거를 대조해 사람이 승인·수정·제외를 판단한다. 수정 시 공식 목록의 성취기준·수정 근거·수업 활용·사유를 직접 정한다. 시연을 위해 부적합한 관계를 승인하지 않는다.
- 추가 계정·키 설정은 필요하지 않다. 신규 AI 연계에는 기존 키체인 설정과 실제 API 호출이 사용되며, 검색 준비·검색은 설치된 로컬 모델을 사용한다.

### 수행한 검증

- `node server/verified-save-check.js`, `node server/search-index-check.js`, `node server/natural-search-check.js` 모두 통과했다. 저장 후 자동 준비의 화면 연결, 저장·준비 실패 구분, 재시도, 오래된 요청 차단, 변경 자산 제거, 질의 캐시와 HTTP 캐시 처리도 포함한다. 화면 확인은 DOM 모의 실행이며 실제 브라우저 시각 확인과 구분한다.
- 추가 일회성 Node 검증에서 기존 `verified-save-check.js`의 fixture·모듈 로더로 임시 JSON 저장소를 만들고 실제 검수·저장·색인·검색 서비스를 연속 호출했다. 미검수 0건 → 승인 후 저장 전 0건 → 저장 후 준비 전 0건 → 두 번째 관계 준비 실패 0건 → 재시도 후 콘텐츠 1건·관계 2건 → 수정 직후 0건 → 수정 저장 후 준비 전 0건 → 재준비 후 콘텐츠 1건·수정 관계 1건·버전 2 → 제외 직후 및 새 검색 인스턴스 0건을 확인했다.
- 실패 뒤에도 CuriBase 저장은 유지됐으며 첫 관계의 임베딩 1건을 재사용해 복구했다. 반복 저장·준비는 파일을 변경하지 않았다. 같은 질의 벡터 계산은 전체 과정에서 1회였고, 수정 결과에는 새 검수 근거가 표시됐다. 이전 검수 ID의 준비·제외 뒤 저장은 거절됐다. 벡터와 사람 검수 입력은 모의 값이므로 실제 의미 관련도나 사람 판단의 증거가 아니다. 임시 파일은 검증 종료 후 삭제했다.
- 실제 로컬 모델로 기존 자산에 `초등 5학년 사회 동고서저 지형과 산맥`을 질의해 `동고서저 지형, 산맥` 1건, 점수 `0.9221644106588491`, 기준 `0.82`, 외부 API 호출 0회를 확인했다. 실제 저장 파일의 전후 바이트가 동일했다. 신규 DEMO의 검색 통과 여부는 아직 확인하지 않았다.
- 실제 저장소에 검수·연계·색인 기록을 추가하지 않았고 실제 CuriMap API·키체인을 호출하지 않았다. 이번 검증은 기능 일관성 확인이며 검색 품질 평가 또는 전문가 검토를 의미하지 않는다.
