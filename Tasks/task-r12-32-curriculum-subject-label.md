## 실제 반영·검증

`public/grade-context.js`의 공통 표시 함수 `standardLabel`로 `[과학]4과06-01`, `[사회]6사01-01` 형식을 제공한다. 선언된 과목을 사용하고 과목 정보가 없는 기존 기록은 공식 코드의 과/사로 구분한다. 이미 과목 접두사가 있으면 중복 추가하지 않는다.

교육과정 선택 목록·선택 태그·해제 버튼 접근성 이름, 자료/폴더의 기준 박스, 기존 선택 이유와 기록, 내보내기, 검색의 기준 표시, 관리/연계 화면의 기준 표시에 적용했다. 공식 기준 코드와 원문, 체크박스/삭제 속성값, 저장 데이터는 변경하지 않는다. 관련 화면이 이미 사용하는 `GradeContext`를 재사용하고 구형 index/curimap 화면에는 이 공통 파일을 로드한다.

표시 함수6사례·JavaScript19파일 구문 점검 통과. `node server/teacher-bring-browser-check.js`의 격리 브라우저11검증 통과: 공식214개 기준의 과목 접두사와 원래 체크박스 값, 선택 태그, 자료/폴더 공통 표시와 내보내기, 다중 선택·단계 이동·기존 메모 보존·저장 실패 재시도 확인.390/1440px 표시·모바일 가로 넘침0·브라우저 오류0. 관리/구형 화면은 표시 코드 정적 점검 범위이며 실제 관리 저장/승인은 실행하지 않았다.
