# Task R07-17 - 전체 자료 문맥 감사·검색 색인 반영

## 설명

전체 자료와 판본의 태그 후보를 소개문 문맥에 대조하고, 채택/제외/보류 근거를 자료별로 기록한다. 화면에만 적용했던 문맥 판단을 검색 개념 색인과 필터에 함께 반영한다. 상태: **진행중**.

## 구현 항목

- [x] 사용자 추가 선택에 따라 전수 모델 분석의 대상/분량/단가/가정별 비용을 산정한다.

- [x] 전체 데이터와 판본의 개념·내용 태그 후보 및 원문 공백을 전수 감사한다.
- [x] 비유·인명·부정·주변 소재의 채택/제외 이유를 자료별로 기록한다.
- [x] 소개문 문맥 검사 결과를 기존 검색·개념 필터·저장 색인에 반영한다.
- [x] 자료별 감사 산출물과 개념/교과/프로그램별 집계를 제공한다.
- [x] 실제 잘못된 검색 결과 제외와 정당한 개념 검색·승인·저장 경로를 확인한다.

## 범위 밖

- 근거 없는 교육과정 적합성 확정·영상 전수 시청
- 사전 비용 합의 없는 유료 API 호출

## 사전 전제

- R07-15 문맥 표시 태그와 R07-16 공식 소개문 보강

## 수동 작업

현재 규칙 감사/검색 반영에는 추가 입력이 없다. 모델 분석은 비용 산정만 했으며 유료 실행은 요청하지 않는다.

## 완료 조건

### 에이전트 확인

- [x] 전체 자료 수/태그 후보 수·근거/보류 감사
- [x] 검색 색인 재생성·검색/화면 회귀
- [x] 원본/승인 보호·문서/서버 반영

### 결과 확인

- [ ] [전체 감사 화면](../docs/r07-17-context-review.html)을 열고 제목·소개문·태그를 검색한다. 자료별 채택·보류·기존 태그 제외 이유와 원문을 확인한다.
- [ ] `http://127.0.0.1:3000/`을 새로고침하고 ‘심장’과 ‘우유’를 검색한다. ‘심장으로 듣는 아이돌’·‘바다의 우유’가 해당 내용 검색에 섞이지 않는지 확인한다.
- [ ] ‘빅오션’을 검색한다. 제목 직접 탐색은 가능하며 심장 태그가 붙지 않는지 확인한다. 상세 필터의 심장 개념도 같은 결과인지 확인한다.
- [ ] [모델 비용 산정](../docs/r07-17-model-cost-estimate.json)의 대상과 가정을 확인한다. 유료 모델 실행은 아직 하지 않았다.

## 구현 결과

- 전체23,360자료/판본을 모든60개 등록 개념에1,401,600회 대조했다. 제목/소개문의 별칭 후보와 선별 내용 어휘 모두 검사했으며23560행의 자료별 원문·채택·보류·제외 이유를 NDJSON로 남겼다. 등록 개념 후보1,800판정·소개문 별칭1,609/제목1,235언급·추가 내용 어휘 후보7,357판정을 기록했다. 후보 판정 수와 모든 자료 의미 검수의 수는 다르다.
- 문맥에 사용할 소개문6,235자료, 보류17,125자료다. 소개 없음·제목 복사·편성 안내·내용 근거 부족을 포함한다. 기존 태그947개 제외·새 태그7개 채택, 확정 원문 언급848태그/727자료, 내용 어휘3,904개/2,310자료다. 원문 언급은 개념 설명이나 교육과정 적합성 승인이 아니다. 분야 문맥·전체 소개 흐름을 고려해 비유/인명/부정/해녀의 물질/허구 배경/도입 일화를 검사했다. 양자점의 빛 방출·호흡/심장 교육 등의 정당한 문맥도 보존했다.
- 화면만의 keyword-context 규칙을 semantic-layer 검색/필터에도 연결했다. aliasRegex를 semantic-pattern 공통 모듈로 분리하고 제목만으로 개념을 확정하지 않는다. 소개문 전체의 관련 분야 단서·완결 문장 경계를 사용하며 등록/표시 태그는 같은 판단을 따른다. 내용 어휘도 런타임 색인/SQLite에 포함하고 검증 어휘 일치에 가점을 준다. 우유·기후·힘 등 문맥 구분이 필요한 일반어도 원문 근거를 요구한다. 직접 제목/프로그램 탐색은 유지한다.
- 전체 검색에서 찾은 대표어 ‘소화’의 일반어 우회와 지리/개념 중복 경로의 문맥 우회를 수정했다. 원문 없는 과학 개념의 결과는0일 수 있으며 제목을 근거로 자동 보충하지 않는다.
- SQLite 자료22,118→23,360으로 전체 판본을 포함해 재생성했다. context_reviews23560행, source_keywords3904행, SOURCE_MENTION848/INFERRED_CANDIDATE51행을 저장했다. 원본/승인/자동자산3저장소 SHA는 유지했다. 규칙 파일 SHA+원문 지문으로 buildId를 생성하고 FK/무결성/전체 행/인용 대조 후 원자 교체했다. 이전 색인은 `/tmp/curi-r07-17/semantic-layer-before.sqlite`에 보관했다.
- 전체 행/보류/SQLite/4,752인용(등록/표시 중복 포함)을 대조했다. 등록60개념+우유의 실제61검색 결과841항목(개념 간 중복 포함) 전체를 확인했다. 신규 화면6·기존 질의27/시맨틱19/결합20 통과, 오류0·유료API0. 변경 계약에 맞춰 제목 인용 가정을 소개문 인용으로 갱신하고 실제 소개문이 있는 캐시/추론 fixture를 사용했다. 원문 문맥 추가에 따라 추론 컨텍스트의 긴 문장을 제한해 기존24,000문자 상한을 지켰다. 서버 재시작 후 심장1/우유3/빛9/빅오션2 및 심장 필터1건을 확인했다.
- `docs/r07-17-context-review.html`은 독립된 전체 감사 화면으로 검색/상태/50행 페이지·소개문/태그/근거·출처를 제공한다. 제품 UI에는 별도 화면/필터를 추가하지 않는다. 전체 NDJSON·집계·검색·DB반영·브라우저·실제 응답은 `docs/r07-17-*`에 기록했다.

## 모델 전수 분석 비용 산정

공식 API 단가를 확인하고 실제 자료 분량을 측정했다. 소개문이 비어 있지 않은10,284자료의 제목/소개는771,115문자다. 이 중 사용 가능한 소개는6,235자료다. 소개가 없는13,076자료는 내용을 창작시키는 모델 호출의 대상이 아니다. 전수 규칙 감사와 모델의 전수 의미 판정은 별개이며 현재 meaningReview는 RULE_SCREENED_NOT_MODEL_VERIFIED다.

| 방식 | 소개가 있는10,284건의 추정 API 비용(USD) |
| --- | --- |
| GPT-6 Luna Batch 단독 | 약 $2~4 |
| GPT-6.1 Sol Batch 단독 | 약 $45~105 |
| Luna 전수 후 모호한10~20%를 Sol로 재검토 | 약 $6~25 |

같은100건을 두 모델로 비교하는 예비 검토는 약$0.5~1.5로 추정한다. 실제 교육 문맥 판단 정확도와 청구 토큰을 측정한 뒤 모델/최대예산을 정하는 방안을 추천한다. 현재는 비용 산정만 했으며 모델을 호출하지 않았다.

가정: 문자당0.8~2토큰·요청별 프롬프트/어휘/스키마1,200~2,200토큰·결과200~500토큰·Sol 추론300~800토큰·재시도10%를 포함했다. 이는 토큰 실측/청구액 보증이 아니며 추론/재시도가 늘면 증가한다. 캐시 할인은 반영하지 않았다. 영상/이미지·원문 재수집·개발 채팅 사용량·세금·214성취기준 적합성 판정은 제외한다.

[Sol 단가](https://developers.openai.com/api/docs/models/gpt-6.1-sol), [Luna 단가](https://developers.openai.com/api/docs/models/gpt-6-luna), [Batch 50% 할인](https://developers.openai.com/api/docs/guides/batch), [추론 토큰 과금](https://developers.openai.com/api/docs/guides/reasoning)을 근거로 계산했다. 계산식/범위는 `context-model-cost.js`와 `docs/r07-17-model-cost-estimate.json`에 기록했다.
