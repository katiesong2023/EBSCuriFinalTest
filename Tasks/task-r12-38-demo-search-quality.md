#### 원인과 반영

- 편집 개념의 주변 단어를 명시 개념과 혼동: 인권을 단순 평등·계층 이동으로 대체하지 않고, 태양계 행성과 외계 행성·사람 몸과 다른 동물의 몸을 명시 조건에 따라 대조한다. 명시 OR의 다른 분기는 보존한다.

- 중심 주제보다 배경 언급이 앞서는 순위: 제목·도입·본문의 주제 밀도·국소 공출현을 비교한다. 긴 소개문의 뒤쪽 설명은 일괄 삭제하지 않고 낮게 정렬한다. 동일 소개문이 다른 제목에 연결된 경우 자기 제목의 본문 근거를 확인한다.

#### 검증·재현과 실행 한계

- 최종19개 양성/음성·보존 계약, 기존10·공통25·비유15·질의21·원문 전달8을 합쳐98개 검사 통과. 최종 고정판과 현재 코드에서도 확인했다.
- 6저장소·고정 입력 지문 동일, 성공한 전후 실행 중 변경0·오류0·유료API0. 위치를 가진 근거 인용3,474개 대조 일치. 기본80건을 전후 각각 실행했으며 기존 일치 후보 보존 확인용 페이지 요청을 추가했다. 지연 값에는 그 확인 비용이 포함되어 성능 평가로 사용하지 않는다.
- 같은 저장소의 병행 수정은 보존했다. 정확도 수정10개 모듈만 전후 차이로 두고, 중간 저장 실행기와 새 검사 파일2개는 검증 하네스 변경으로 분리했다. 서버JS 고정 사본을 로드해 공통 코드가 실험 중 변하는 것을 막았다. 운영 서버는 이 고정 로더를 사용하지 않는다.
- 중간 precision-release는 서버4파일 변경을 감지해 확정 비교에서 제외했고, 병렬 precision-matched-after 첫 시도는 네이티브 런타임 종료로 폐기했다. 중간 저장을 추가한 단독 실행과 보존 보완 후 precision-final 성공 결과만 결론에 사용했다.
- 고정판 이후 현재 코드의80개 해석도 대조했다. 비어 있는 conditionClauses 메타데이터 필드 외 해석 차이0이며 현재 계약 검사98개도 통과했다. 실제 HTTP·화면·영상 재생/교사 효용은 이번에 검증하지 않았다.
