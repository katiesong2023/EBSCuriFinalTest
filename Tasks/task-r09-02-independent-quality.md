# Task R09-02 - 오연계·누락·원문 부족·미지원 분리 평가

## 설명

선택 성취기준 중심 개선이 잘못된 연계 노출과 적합한 자료 누락을 줄였는지 독립적인 실제 자료 표본으로 비교한다. 원문 부족과 검사 미지원을 별도 집계하고 교사의 선택적인 사용·제외 이유를 수집할 수 있게 한다. 기존 R09 평가를 이어받는 후속 범위이며 전수 사람 승인을 요구하지 않는다. 상태: **진행중 — 2026-10-11 구현·기술 평가 완료, 사용자 결과 확인 대기**.

## 구현 항목

### 변경 전 평가 준비

- [x] R08-07~09·R07-05 개발에 앞서 평가 기준·분모·관찰할 상위 결과 수와 소량의 실제 자료×성취기준 표본을 고정한다. 사회·과학과 초등3~4·5~6·중1의 여섯 구간, 규칙 지원/미지원·충분한/부족한 원문을 포함하고 각 구간의 실제 표본 수와 선택 이유를 기록한다.
- [x] 개발용과 독립 비교용 자료를 분리하고 같은 회차의 판본·유사 문장·같은 요청의 표현 변형이 양쪽에 섞이지 않게 한다. 독립 표본의 정답·개별 결과를 규칙 조정이나 보강 대상 선정에 쓰지 않는다. 결과를 보고 수정에 사용한 자료는 개발용으로 전환하고 최종 비교에는 새 표본을 사용한다.
- [x] 변경 전후 비교에 필요한 카탈로그·원문·공식 기준·규칙·검색 설정 버전과 판단 기준을 보존한다. 검색 변경 효과는 같은 원문에서, 원문 보강 효과는 같은 검색 조건에서 비교한다.

### 개선 효과와 한계 분리

- [x] 다음 네 항목을 별도로 측정한다. 각 집계에 자료×기준 관계 수·분모·확인 주체·미확인 범위를 명시하고 중복 가능한 항목을 합쳐 단일 정확도로 발표하지 않는다.

| 지표 | 판단·집계 기준 |
| --- | --- |
| 잘못된 연계 노출 | 다른 기준의 확인 전파, 인용 없는 요구 충족, 부분 근거의 전체 충족 표시 등 실제 표시·판정 오류를 건수와 노출 분모로 기록한다. |
| 적합한 자료 누락 | 결과 밖에서 별도로 찾은 실제 후보도 대조해 표본 내 관련 자료 집합을 만든다. 후보 발견 실패와 후보는 있으나 상위 결과에서 밀린 경우를 구분하고, 확인된 관련 자료 대비 누락을 기록한다. |
| 원문 부족 | 해당 요구를 대조할 소개문·공식 보조 자료의 양/내용이 부족한 관계를 집계한다. 전체 영상에 내용이 없다고 단정하지 않는다. |
| 검사 미지원 | 기준별 자동 비교의 미지원 수와 해당 표본 관계 수를 따로 기록한다. 교육적 부적합·검색 누락으로 자동 계산하지 않는다. |

- [x] 요구별 인용·부정 대상·부분 연계 경계와 여섯 구간별 전후 변화를 함께 확인한다. 평가 집합 밖의 전체 자료에 대한 재현율·교육적 정확도는 주장하지 않는다. 원문만으로 판단이 어려운 표본은 미확인으로 보존한다.
- [x] 교사가 원하는 자료에 대해서만 사용·제외·보류 이유와 해당 기준·수업 목적·확인한 원문 또는 장면을 남길 수 있게 한다. 응답은 생략 가능하고 자료 저장·재사용을 막지 않으며, 개인 의견과 관리자의 관계 승인·제외 결정을 구분한다.
- [x] 교사의 실제 입력과 에이전트의 원문 판단, 격리된 기능 시험을 구분한다. 실제 교사 응답이 없으면 미수행으로 보고하고 가상의 응답·사람 평가 수치를 만들지 않는다. 기술 평가와 선택적 교사 평가는 각각 완료·미확인 범위를 남긴다.
- [x] 전후 수치·남은 오류 사례·보강/규칙 미지원 공백·표본 한계를 기존 R09 결과와 연결한다. 개선 전 과거78개와 현재214개, 고유 회차와 판본 포함 수치를 같은 분모처럼 비교하지 않는다.

## 범위 밖

- 자동 결과나 에이전트 판단의 사람 확인 승격, 평가 결과를 맞추기 위한 표본 교체·누락 은폐, 유료 추론

## 구현 결과와 검증 — 2026-10-11

- `server/independent-quality-capture.js`·`independent-quality-freeze.js`로 변경 전 코드·공식 기준 214개·판본 포함 자료 23,360건·전체 기준 검색 결과를 압축 보존했다. 기존 개발 ID 513개·같은 판본·근접 원문을 제외한 여섯 구간 33관계와 판단을 잠갔다. 보강 담당에게는 원본 ID 대신 제외 해시만 제공했다.
- `server/independent-quality-check.js`로 변경 전·R08-08 직후 같은 원문·최종 같은 원문·최종 보강 원문을 비교했다. 최종 두 조건은 같은 제품 코드 스냅샷을 사용했다. 원본 DB는 쓰지 않았고, 고정 코드·보강 입력을 재생한 요약과 개별 결과는 정확히 일치했다. 기준선·중간 결과를 덮어쓰지 않는다.
- 독립 노출 표본에서 잘못된 연계 확인은 0/13→0/12, 미지원의 관계 설명 부족 표시는 8/10→0/9였다. 확인된 관련 자료 3관계 중 후보 누락 1·상위 9개 노출 2는 그대로다. 최소 원문 부족 16/33, 미지원 24/33도 변하지 않았다. 관련 자료를 확인하지 못한 구간의 누락률을 계산하지 않았다.
- 같은 표본에 자동 요구 충족·확인 배지·명시적 부정 노출 사례가 없어 해당 개선을 독립 표본으로 일반화하지 않는다. 요구별 인용·부정 대상·농경문 경계는 별도 개발 회귀로 확인했으며 실제 평가 점수에 합치지 않았다. 남은 후보 누락은 보고서에 기록했고 평가 후 제품 규칙을 조정하지 않았다.
- `public/lesson-context.js`의 **사용·제외 이유 남기기 · 선택 사항**은 해당 브라우저의 개인 기록이며 입력을 생략해도 저장할 수 있다. 공용 승인·검색 순위·서버 수집과 분리했고 수업 문맥 기능 12건·리뷰 회귀 3건으로 확인했다. 실제 교사 응답은 0건·미수행이다.
- 기존 승인 보존 검사 6종 122건을 현재 운영 사람 승인 0건·취소 이력 보존에 맞춰 검증했다. 기능용 합성 승인은 유지하며 실행 전후 배열·개수를 정확히 비교한다. 자동 자산은 최종 운영 재검사 후 공개 1건이며, 독립 평가는 변경 전 관계 이력을 고정한 별도 조건이다.
- [최종 결과와 한계](../docs/R09_02_STANDARD_EVIDENCE_RESULTS.md), [재현 규칙](../docs/r09-02-independent-protocol.md), [단계별 기계 판독 결과](../docs/r09-02-comparison.json), [최종 무결성](../docs/r09-02-final-integrity.json)에 실제 산출물·분모를 연결했다. 전체 자료의 재현율·교육적 정확도·교사 만족도를 주장하지 않는다.

## 수동 작업

필수 외부 설정은 없다. 실제 교사의 사용·제외·보류 이유와 확인한 원문·장면은 참여하는 교사가 직접 작성한다. 입력은 선택 사항이며 미응답은 평가 미수행으로 남긴다.
