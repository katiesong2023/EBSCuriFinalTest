# R12-15 — 구간 카드와 수업 영상 리스트

## 설명
저장한 구간을 카드로 보고 수업 폴더 오른쪽 리스트에 넣고 빼며 활용 순서를 구성한다. 폴더별 순서와 구간 합계 시간을 저장·표시한다. 상태 진행중.

## 구현 항목
- [x] 자료의 구간을 카드 박스로 표시한다.
- [x] 폴더별 수업 영상 리스트에 구간 추가·제거·순서 변경을 제공한다.
- [x] 드래그와 버튼 조작을 제공하고 목록 아래 총 구간 길이를 합산한다.
- [x] 새로고침·폴더 전환 후 순서를 유지하며 원본 구간·개인 자료를 보존한다.
- [x] 구간 편집·삭제·저장 실패·모바일 표시를 확인한다.

## 범위 밖
- 영상 파일 추출·합치기, 자동 연속 재생, 기기 간 동기화.

## 사전 전제
- 기존 내 수업 자료와 구간 저장·확장 재생 경로.

## 수동 작업
없음.

### 결과 확인
- [ ] 내 수업 자료를 새로고침하고 폴더를 열어 자료별 수업용 구간이 카드로 표시되는지 확인한다.
- [ ] 오른쪽 수업 영상 리스트에 드래그 또는 ‘리스트에 추가’로 담고, 위/아래 버튼이나 드래그로 순서를 바꾼다.
- [ ] ‘빼기’ 뒤에도 원래 구간 카드가 유지되고, 아래 총 영상 길이가 바뀌는지 확인한다.
- [ ] 새로고침·폴더 전환 후 폴더별 리스트와 순서가 유지되는지 확인한다.
- [ ] 확장이 연결된 환경에서 리스트의 ‘구간 보기’로 원하는 구간이 열리는지 확인한다.

## 실제 반영·에이전트 확인

- public/segment-ui.js: 자료의 구간을 이름·시작/끝·길이·메모·보기·추가 버튼을 가진 드래그 카드로 표시한다.
- public/lesson-playlist.js·lesson-playlist.css: 폴더 오른쪽 리스트·드래그/위아래 정렬·빼기·중복 방지·합계·실패 안내. 1180px 이하에서는 자료 아래에 배치한다.
- public/lesson.html·lesson.js: 폴더 보기에서만 리스트를 연결하고 기존 폴더 저장 충돌 검사로 순서 변경을 저장한다. 기존 개인 편집 미저장 시 먼저 저장하도록 안내한다.
- folders[].videoPlaylist에 구간 ID 순서만 저장한다. 원본 구간·다른 폴더·메모를 복제/삭제하지 않는다. 구간 변경을 실시간 반영하며 삭제된 구간/폴더에서 빠진 자료는 사용할 수 없음으로 표시하고 합계에서 제외한다. 해당 항목은 교사가 리스트에서 빼도록 남긴다.
- 시간 합계는 각 구간의 (끝−시작)을 밀리초 정수로 합산하고 분:초로 표시한다. 겹친 시간도 리스트에 담긴 각 구간의 재생시간으로 각각 합산한다.
