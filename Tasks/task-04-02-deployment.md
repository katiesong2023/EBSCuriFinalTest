# Task 04-02 - 심사용 배포와 쓰기·비용 보호

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R11 / 실제 배포·제출 후속 유지**. 제출·녹화·효용 측정은 수행 여부를 별도 기록한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

심사자가 접근할 수 있고 외부 요청이 검증 자산·API 비용을 임의로 바꾸지 못하는 제출 환경을 준비한다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 4
- 예상 집중 작업: 약 2시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Sol** (`gpt-5.6-sol`)
- 추천 추론 수준: **medium**
- 선택 이유: 환경·권한·무결성·비용 제약을 함께 확인해야 하므로 제출 직전 집중 검토 가치가 높다.
- 상향 조건: 처음부터 xhigh·max로 시작하지 않는다. 해결하지 못한 원인이 명확하고 더 깊은 분석이 필요한 부분에만 high로 올린다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.

- [ ] 확정한 배포 방식에 화면·서버·저장소를 연결하고 심사자의 접속 방법과 재시작 후 데이터 유지 범위를 안내한다.
