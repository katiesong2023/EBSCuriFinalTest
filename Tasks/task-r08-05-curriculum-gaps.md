# Task R08-05 - 교육과정 역방향 탐색과 원문 공백 보강

## 설명

성취기준에서 방송 후보를 찾고 원문/관계 공백을 구분해 관리자가 필요한 상세 원문부터 확보할 수 있게 한다. 2026-10-05 사용자 요청으로 다섯 task를 작성해 순서대로 구현·검증한다. 사용자 결과 확인은 별도로 남기며 연속 진행 요청에 따라 각 에이전트 검증 후 다음 task를 진행한다. 상태: 진행중 / 구현·검증 완료, 사용자 결과 확인 대기

## 구현 항목

- [x] 기존 공식 성취기준을 선택해 개념/대상·관계·조건·학습 행동과 방송 후보·근거 문장을 비교하는 경로를 제공한다.
- [x] 기준별 후보 없음·제목 후보만 있음·소개문 부족·관계 설명 부족·제한 규칙 지원 여부를 실제 현재 원문 기준으로 집계한다.
- [x] 교육과정 공백·빈약한 빈출 주제·사회/과학 균형을 근거로 상세 원문 보강 우선 목록과 재실행 가능한 수집 경로를 제공한다.
- [x] 우선 목록에서 사회·과학의 소규모 공식 상세 페이지 보강을 실제 수행하고 시도/일치/변경/실패를 기록한다. 회차 수와 원문 충실도 증가를 구분한다.

## 범위 밖

- 추가 학년 구현·전수 수집·범용 관계 자동 승인·로그인/재생 수집

## 사전 전제

- R07-04·현재 확보한 공식 성취기준·R08 관리자 권한

## 실제 구현

- `curriculum.html`·`curriculum.js/css`: 현재 공식78기준의 선택→대상/관계/조건/학습 행동→방송 후보/원문 비교→내 자료 담기. 후보 수는 전체 판본 묶음 기준이며 페이지·근거 상태·교과를 제공한다. 미지원 분해는 공식 원문을 유지하고 미지원임을 표시한다.
- `admin-curriculum.html`: 관리자 인증 후 기준별 공백·보강 우선200회차·원문 출처·기존 관리 상세로 이동한다. `/api/curi/curriculum`은 공개 원문 기반 읽기 API이며 자동 저장은 하지 않는다.
- `curriculum-requirements.js`·`curriculum-discovery.js`는 공식 중심어·정확한 경계/동음이의어·원문 품질을 적용하고 제목뿐/소개문부족/관계부족/일부설명을 구분한다. 기준별 중복 집계는 별도 안내한다. 이 단계의78기준 중 후보 없음7, 제목 후보뿐5, 최소 원문 없음6, 지원 관계 없음78이었다. [보강 전 집계와 대상](../docs/r08-05-gaps-before.json).
- 사회3·과학3회차 명시 수집: 소개문 변경2(선거37→168자, 조선 민사소송11→45자), 기존과 같음2, 회차 대조 불일치2. 일치한4회차의 페이지 표기 시간을 저장했고 다른 회차의 원문을 복사하지 않았다. [실행 기록](../docs/r08-05-source-enrichment.json). 소개문이 실제로 없는 페이지를 조회해도 내용 원문이 늘지 않는 한계가 있다.
- 계약7개·HTTP/브라우저7개 통과. 기준/상태/페이지·인용 위치·자전거/화석 인명 오탐·관리 인증/복귀·내 자료·모바일을 확인했다. [계약](../docs/r08-05-gap-check.json), [화면](../docs/r08-05-browser-check.json), [모바일](../docs/r08-05-curriculum-mobile.png).

## 수동 작업
