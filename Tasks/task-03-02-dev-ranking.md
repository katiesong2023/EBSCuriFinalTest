# Task 03-02 - DEV 검색 품질 조정과 기능 동결

> 현재 정본: [PLANS](../docs/PLANS.md) · 대응: **R03·R09 / 검색 검증에 통합**. 사회·과학 균형 질의, 문장 해석·근거·빈 결과를 함께 평가한다. 과거 구현·사람 확인 기록은 보존한다.

## 설명

R03의 로컬 자연어 검색·시맨틱 근거 순위를 DEV 질의로 조정하고 R09의 별도 확인 질문 전에 규칙을 고정한다. 유료 모델 선택은 검색 개선의 선행 조건이 아니다.

## 작업 크기와 추천 모델

- 구분: P0 필수
- 배치: Week 3 초반
- 예상 집중 작업: 약 1시간. 개인 입문자 계획용 추정이며 설치·보류·재작업 시간은 별도이다.
- 개발 보조 모델: **GPT-5.6 Terra** (`gpt-5.6-terra`)
- 추천 추론 수준: **medium**
- 선택 이유: 작은 DEV 개선과 설정 고정에는 Terra가 충분하며 최종 Test를 반복 볼 필요가 없다.
- 상향 조건: 원인을 좁혀도 해결되지 않는 제약·상태·데이터 무결성 문제는 해당 부분만 Sol / medium으로 검토한다.
- 모델 배치는 과업 성격에 따른 추천이며 이 서비스에서 측정한 모델 성능 결과가 아니다. [공식 모델 역할·추론 수준 안내](https://learn.chatgpt.com/docs/models)
- 개발 모델과 서비스 API 모델·비용의 차이는 [task 사용 안내](./00_README.md)를 참고한다.
