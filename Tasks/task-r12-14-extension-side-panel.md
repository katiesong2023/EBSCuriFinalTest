# Task R12-14 - Chrome 세로 사이드 패널

## 설명
사용자 요청으로 확장 아이콘 아래의 팝업을 브라우저 옆 세로 패널로 전환한다. 영상 페이지와 나란히 열어 둔 상태에서 기존 폴더·영상 전체·구간 가져가기를 사용한다. 좌우 배치는 Chrome 사용자 설정을 따르며 디자인안 선택과는 별개다.

## 구현 항목
- [x] 아이콘으로 열리는 Chrome 사이드 패널과 가변 폭 세로 배치
- [x] 기존 저장·연결·영상별 초안·저장 결과 보존
- [x] 패널 유지 중 선택 영상의 이동/닫힘에 대한 재확인 안내
- [x] 설치 ZIP·설명·스타일가이드의 확장 표시 방식 갱신
- [x] 0.6.1: 현재 영상의 프로그램명/회차명 표시·사이트 제목/유형/길이 제거·새로고침 아이콘화

## 범위 밖
- 새 디자인안의 제품 적용·DB/개인 자료 변경
- Chrome 전체 좌우 설정 강제 변경·영상 사이트에 임의 UI 삽입

## 사전 전제
- R12-07/08/10의 프로토콜4·기존 확장0.5.0

## 수동 작업
1. ZIP 설치 사용자는 Curi의 `/downloads/curi-segments-extension.zip`을 다시 받아 기존 설치 폴더에 덮어 푼다. 저장소 확장 폴더를 직접 로드한 경우 이 단계는 생략한다.
2. `chrome://extensions`의 Curi 카드 ↻로 확장을 새로고침한다. 새 권한 `sidePanel`을 포함하는 0.6.3이다. 기존 EBS/Curi 탭도 새로고침한다.
3. Curi 아이콘을 눌러 세로 패널을 연다. 왼쪽에 나타나면 Chrome 설정 → 모양의 사이드 패널 위치를 오른쪽으로 바꾼다. 확장은 Chrome 설정을 강제 변경하지 않는다.
