# Task R07-16 - 방송 내용 안내문 전체 점검·보강

## 설명

전체 방송 자료의 내용 안내를 원문과 대조하고 문장 잘림·내용과 무관한 표기·소개 누락과 오기입 의심을 점검한다. 근거가 있는 내용은 읽기 쉽게 표시하고 확인할 수 없는 내용은 보류한다. 상태: **진행중**.

## 구현 항목

- [x] 전체 안내문과 소개문 상태·문장 잘림·표기 오류를 점검하고 기록한다.
- [x] 자막 등 메타 표기와 HTML을 정리하고 문장을 온전히 표시한다.
- [x] 주제/내용 문장을 우선하며 실제 자막 소재와 수치·인명·부정을 보존한다.
- [x] 누락·잘림·오기입 의심은 근거 없이 채우지 않고 확인 필요로 표시한다.
- [x] 원문 인용·검색·태그·저장·모바일 경로를 검증한다.

## 범위 밖

- 유료 모델·전수 영상 시청·소개문 없는 영상 내용 창작
- 썸네일 삽입·기존 승인 관계 재판정

## 사전 전제

- 저장된 공식 소개문과 현재 방송 내용 안내

## 수동 작업

추가 API 키나 계정 입력은 필요하지 않다.

## 완료 조건

### 에이전트 확인

- [x] 전체 자료 감사·근거 인용 계약
- [x] 관련 회귀·화면·정적 검사
- [x] 문서·실행 서버 반영

### 결과 확인

- [ ] `http://127.0.0.1:3000/`을 새로고침하고 ‘대방어’를 검색한다. 안내 앞의 자막 표기가 사라지고 조업·그물·가두리 등 내용이 온전한 문장으로 보이는지 확인한다.
- [ ] ‘생명의 첫 문장’을 검색한다. AI/DNA·바이러스 사례·가능성과 위험을 설명하는 공식 소개가 보이는지 확인한다.
- [ ] 문장 잘림 안내가 있는 카드의 공개 소개문 전체를 연다. 안내에서 제외된 끝부분이 원문에는 보존되는지 확인한다.
- [ ] 모바일에서 안내가 잘리지 않고 내 자료 저장이 유지되는지 확인한다.

## 구현 결과

- 전체23,360자료를 검사했다. 원문 자막 시작 표기3,086, HTML 포함1,682, 안내의 불필요한 시작 표기324→0. 최종 안내 변경6,845자료, 원문 근거 표시4,791자료, 내용 근거 미확보18,569자료다. 마지막 수치는 원문 없음·제목 반복·짧거나 잘린 설명·편성 안내를 포함하며 소개문이 전혀 없는 개수와 다르다.
- `broadcast-guide-text.js`에서 메타 표기·HTML·공백/엔티티를 정리하고 소수점·인용 뒤 조사·?!를 보존한다. 실제 ‘자막을 통해’ 등의 소재는 유지한다. `<br>`를 임의 문장 경계로 쓰지 않으며 근거 인용/start/end는 원본에 대응한다.
- `source-explanation.js`에서 온전한 최대3문장을 고른다. 도입보다 주제·제작/활동/원리·사례/결론을 우선하고 키워드 반복 점수는 제한한다. 160자 잘라내기 없이 문장을 보존한다. 짧은 설명도 표시하되 상세 연계 품질 판정은 바꾸지 않는다.
- 말줄임/미완성 연결어/깨진 문자 문장은 보류하고 contentPreview.issues/reviewNote로 알린다. 원문은 그대로 보존한다. 복구 전 의심2,022자료에서 공식4소개 복구 후2,018자료가 남는다. 의도적 홍보 말줄임도 포함하므로 전부 실제 잘림으로 확정하지 않는다.
- 공식 상세4회차를 제목/회차 ID/최종 URL로 대조해 목록 소개를45→163,41→390,38→329,34→392자로 복구했다. 대상은 ‘AI가 쓴 생명의 첫 문장’, ‘취미는 사랑’, ‘그게, 뭐였을까’, ‘[AI를 닮은 시대] 3부 해줘! 게임’이다. source_enrichments에 이전/현재 원문·해시·출처·실제 확인 시각을 보존했다. 방송DB의4회차 변경 외 승인JSON/시맨틱DB/자동자산DB의 SHA는 유지했다.
- 신규 감사/계약6·기존 미리보기4·브라우저4 통과. 원문 위치·HTML 안전·실제 자막 소재·수치/부정·긴 문장·부족 안내·원문/저장/390px을 확인했다. 낡은160자 상한 검사는 문장 보존 계약으로 갱신했고 이전부터 실패했던 도입문 선택 검사도 통과했다. 기존 원문 복구 검사9항목은 통과했으나 마지막 과거 승인JSON SHA 고정값은 요청 전부터 달라 실패했다. 기대 SHA/원본은 바꾸지 않고 r07-16-historical-regression-note.json에 기록했다.
- `docs/r07-16-broadcast-guides-before.json`/`r07-16-broadcast-guides-audit.json`에 전후 집계·사례·재확인 목록, `r07-16-official-source-preview.json`/`r07-16-official-source-applied.json`에 공식 대조/복구, `r07-16-preview-check.json`/`r07-16-guides-browser-check.json`/`r07-16-running-server-check.json`에 실행 결과를 기록했다. 서버 재시작/실제2검색 확인·오류0·유료API0.
- 전수 검사는 텍스트 형식·근거 인용 검사다. 모든 영상 시청이나 소개문의 사실/인명/수치 오류를 전수 검증하지 않았으며 원문 없는 내용은 창작하지 않았다. 전수 의미 검수·더 많은 공식 상세 소개 복구는 남은 과제다.
