# Task R07-02 - 원문 품질 판정·검색·표시 통일

## 설명

원문 품질을 같은 기준으로 판정하고 교사 검색·배지·내용 안내·후보/자동 검사에 적용한다. 2026-10-05 사용자 요청으로 다섯 task를 작성해 순서대로 구현·검증한다. 사용자 결과 확인은 별도로 남기며 연속 진행 요청에 따라 각 에이전트 검증 후 다음 task를 진행한다. 상태: 진행중 / 구현·계약 검증 완료, 사용자 결과 확인 대기

## 구현 항목

- [x] 소개문 없음·제목 반복·편성/제작 안내 중심·짧은 내용 설명·구체적 내용 설명의 다섯 구분과 최소 연계 조건을 통일한다. 풍부함과 의미 정확도를 구분한다.
- [x] 검색 필터·건수·카드 배지·내용 안내에 동일한 품질 판정을 사용하고 기존 소개문 조건 주소를 호환한다.
- [x] 관련성 우선 순위 안에서 원문 품질을 반영하고 같은 제목 판본의 내용 있는 원문을 먼저 제공한다. 방송일 정렬과 판본별 인용/승인은 유지한다.
- [x] 현재 전체/개별 판본 기준을 구분해 기존 집계와 새 품질 분포를 측정하고 원문 부족 보류 및 기존 검색을 검증한다.

## 범위 밖

- 새 원문 수집·관계 규칙 확대·원본 수정

## 사전 전제

- 기존 R07-01·R08-01, 저장된 공개 원문

## 실제 구현

- `source-text-quality.js`의 다섯 분류·최소 조건을 후보/자동 검사·카드·필터·내용 안내에 공유한다. 기존 `present`는 최소 조건 통과, `title`은 없음/반복의 호환 조건이다. 규칙 버전에 품질 버전을 포함해 과거 자동 결과를 재검사한다.
- 관련성 동점은 품질 순이며 같은 제목 판본은 관련순에서 품질이 높은 회차를 표시한다. 날짜순은 그대로 유지하고 소개문을 복사하지 않는다.
- 기존 집계 재현: 기본22,118건 중 보유8,292·이전 최소통과5,104. 최종 `source-text-v3`로 원문 보강 전 상태를 재구성하면 기본 최소통과4,682·상세836, 판본 포함23,360건은 최소통과4,708·상세848이다. 공식 원문4건 보강 뒤 기본4,685·상세839, 판본 포함4,711·상세851이다. 분모·규칙 버전이 다른 집계를 합치지 않는다.
- `시청` 기관·소재 제작 설명을 편성 안내로 오인하지 않는 경계를 포함해 `source-quality-check.js` 17개·필터16개·자동 자산26개 통과. [최초 기준](../docs/r07-02-quality-baseline.json), [최종 검사](../docs/r08-06-quality-current.json). 화면 통합 검사는 설명 task와 함께 수행했다.
