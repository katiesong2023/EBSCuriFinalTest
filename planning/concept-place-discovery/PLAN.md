# Curi 사회·과학 자연어 탐색 개발 계획

2026-10-01 통합. 사용자 선택과 실제 로컬 구현을 반영한다. 기존 v1.4는 역사적 기록이며 현재 실행 순서는 [PLANS](../../docs/PLANS.md)를 따른다.

# MVP 목표 (MVP Goal)

2026-09-30 수정. 사회·과학을 함께 지원하는 일반방송 탐색 서비스를 만든다. 교사의 자연어 요청을 주제·수업 의도·제외어·조건으로 나누고, 공식 회차의 제목·공개 소개문과 연결하여 실제 근거가 있는 후보를 제시한다. 과학 우선 소재는 생태·기후·인체·우주다.

사용자가 선택한 1차 수집 목표는 50개 프로그램·20,000개 실제 회차다. 프로그램/시즌 인벤토리의 표시 회차 수와 실제 적재 ID 수는 다르다. 충분한 모집단과 근거 텍스트를 먼저 확보하고, 모델은 이후 프로덕션에서 이 로컬 결과를 바탕으로 추론한다.

기존 저장 콘텐츠 144개·검색 투영의 고유 콘텐츠 4개는 승인 경로의 별도 지표다. 현재 홈페이지 탐색 규모와 혼동하지 않는다. 최신 관측량은 [작업 결과](../../docs/REDESIGN_RESULTS.md), 현재 작업 순서는 [PLANS](../../docs/PLANS.md)를 따른다. 2026-09-28의 20건/2시간 조사는 초기 타당성 실험 이력이며 현재 수집 상한이 아니다.

실제 교사 효용·장면·학년 적합성은 후속 사람 판단이다. 후보를 많이 반환하는 것으로 정답률이나 현업 준비 완료를 주장하지 않는다.

# 핵심 사용자 가치 (Core User Value)

교사가 교육과정 태그를 직접 작성하거나 25건을 먼저 승인하지 않아도 방송 자료를 탐색하고 출처를 확인하여 수업 준비 모음에 담을 수 있다. 사회 사례와 과학 현상을 같은 흐름에서 찾되 모든 질문을 지리·장소 확장으로 강제하지 않는다.

기본 경험은 자연어 요청 → 해석한 주제·추가 검색어·미확인 조건 → 자료 목록을 먼저 보고 접힌 설명에서 추천 이유·원문 근거 → 프로그램/유형/장소 필터 → 모음·준비 메모다. 지원하지 못하는 길이·자막·학년·무료 조건은 충족한 것처럼 표시하지 않는다. 클립·일반방송 회차·목록은 다른 자료 단위다.

자동 태깅은 원문 표현과 근거를 채우는 작업이다. 교육적 의미 관계·장면·성취기준 승인은 별도다. 사람은 최종적으로 필요한 자료의 적합성을 판단하며, 미확인을 허용한다.

2026-10-01 사용자 확정: 교사용 화면과 관리자 화면을 분리한다. 교사는 자료 찾기·내 수업 준비를 중심으로 사용하고, 관리자는 수집·출처·태그·교육과정 연계·검수·공개 상태를 관리한다. CuriMap·CuriBase·검색 준비를 교사의 필수 단계로 노출하지 않는다. 승인 여부는 자료의 필터·확인 표시로 제공한다.

후속 제안(R07): 모호한 요청의 주제 방향을 좁히고, 대표 후보 3~5개를 선정 이유와 함께 비교한 뒤 수업 준비안에 배치한다. 현재 자료 모음·메모 다운로드를 수업 배치·발문 편집까지 구현한 것으로 표현하지 않는다. 관리자 진입 목록·접근권한은 R08 후속 범위다.

# 시스템 아키텍처 개요

현재 구현: 공식 방송 인벤토리 → 공개 회차/목록 수집 → 방송 SQLite → 기존 CSV/JSON과 통합한 탐색 카탈로그 → 원문 기반 시맨틱 태그 → 자연어 요청 해석·로컬 순위 → 근거/확인 수준을 포함한 화면과 모음.

60개 편집 개념 어휘의 동의 표현, 직접 원문 언급, 상위 개념 추론 후보를 분리한다. 기존 동고서저·화산·해안의 3개 출처 기반 장소 관계는 유지한다. 지명 공기만으로 지형 설명을 확정하지 않고, 복수 주제의 직접 근거와 추가 조건을 검사한다.

현재 검색은 카탈로그 및 태그를 메모리에 캐시한다. 원본 파일 변경 시 새 카탈로그로 재생성한다. 시맨틱 SQLite는 같은 규칙으로 만든 감사·재현용 스냅샷이다. 새 탐색은 그래프 DB·새 임베딩 모델에 의존하지 않는다.

별도 승인 경로: 기존 콘텐츠 → 공식 기준 후보 → 초안/검수 → verifiedAssets → 승인 자산 검색. 신규 방송 태그를 승인 자산으로 자동 이동시키지 않는다. 실제 저장 구조는 [ERD](../../docs/ERD.md)를 따른다.

후속 R10는 로컬 검색이 만든 최대 6자료·24,000자 근거 묶음을 프로덕션 모델 추론에 사용한다. 현재 묶음을 반환하는 기능만 구현했으며 모델 호출은 하지 않는다.

# 데이터 모델과 주요 엔티티

실제 테이블·키·관계는 [ERD](../../docs/ERD.md)에 정리했다. 기존 제안의 독립 Evidence/Relation/DiscoveryReview 테이블을 모두 구현했다고 표현하지 않는다.

| broadcast-programs.json | programs, courseId, 출처·확인일·표시 회차 수 | 공식 프로그램/시즌 인벤토리 |
| broadcast-catalog.sqlite | episodes, pages, link_checks, episode_text | 고유 회차·수집 체크포인트·도착 대조·FTS 저장 |
| semantic-layer.sqlite | builds, concepts, resources, tags | 버전·내용 지문·직접 언급·추론 후보의 재현 스냅샷 |
| discovery-geography.json | concepts, places, resources | 기존 출처 기반 지리 연결 |

SOURCE_MENTION은 제목 또는 소개문 필드의 위치·구절·출처로 확인되는 표현이다. INFERRED_CANDIDATE는 편집한 상위 개념 후보로 기본 검색의 직접 일치 근거에 포함하지 않는다. 공식 성취기준과 이 편집 어휘는 별개다.

각 자료의 내용 지문과 규칙 버전을 보존한다. 제목 반복 소개문은 충분한 설명으로 세지 않는다. 원문이 바뀌면 메모리 태그를 갱신하고 디스크 스냅샷은 빌드 명령으로 재생성한다. 별도 승인 이력을 수정하지 않는다. 구간·재생시간·자막·좌표는 확보하지 못했으면 만들지 않는다.

# 주요 API · 외부 연동

| 경로 | 현재 동작 |
| --- | --- |
| GET /api/curi/discover | 자연어 해석·근거 태그·기존 지리 연결·조건·페이지를 포함한 로컬 탐색 |
| GET /api/curi/discover/resources | 모음 내보내기 전에 자료의 현재 이동 링크·상태 조회 |
| GET /api/curi/discover/context | 향후 모델 입력용 제한된 근거 묶음. 모델 호출 없음 |
| GET /api/runtime | 유료 API 활성화 상태 확인 |
| 기존 승인 자산 검색·검수 API | 기존 승인 계약 유지. 탐색 후보를 승인 결과로 혼합하지 않음 |

외부 수집은 EBS 공식 공개 프로그램·회차 HTML/목록의 텍스트 메타데이터만 읽는다. 로그인·영상 파일·비공개 자막을 수집하지 않는다. 요청 간격·상한·체크포인트·접근 오류를 기록한다.

유료 API는 서버 기본 차단되어 있으며 이번 수집·검색·태깅·검증에서 호출하지 않는다. 사용자 요청으로 로컬 HTTP 서버와 브라우저 테스트는 허용했다. 초기 '모든 API 없이' 표현을 유료 API 금지와 로컬 함수/서버 검증으로 구체화했다.

향후 모델의 역할은 근거 묶음에 기반한 요청 해석·추천 이유 추론이다. R10에서 당시 모델·가격·토큰·호출 예산과 결과 인용 검증을 확정한다. 과거 최대 5회 제안은 이번 세션의 유료 실행 허가가 아니다. 원문 데이터는 지시문이 아니며, 추론 후보를 사실·승인으로 승격하지 않는다.

# 기술 스택과 인프라

기존 HTML/CSS/JavaScript·Node.js를 유지한다. 방송 원본과 시맨틱 스냅샷은 Node 내장 SQLite로 저장하고, 기존 JSON·CSV 자산과 조합한다. 프로그램별 공개 HTML 해석과 검증에는 설치된 Playwright를 사용하며 제품 런타임에서 브라우저 자동화를 호출하지 않는다.

로컬 탐색은 규칙 기반 질의 해석과 원문 표현 태그를 사용한다. 기존 승인 자산의 검색·모델 파일과 새 탐색 경로는 별개다. 새 프레임워크·벡터 서비스·그래프 DB·유료 외부 서비스를 추가하지 않았다.

배포·운영 보호·자동 갱신 스케줄은 후속 task에서 결정한다. 현재 수집은 명시적인 명령으로 실행하며, 스냅샷의 반복 생성과 변경 감지는 구현하되 무인 운영 완료를 주장하지 않는다.

# 비기능 요구

출처와 재현성: 자료 단위·회차 ID·출처·확인일·원문 내용 지문·규칙 버전을 기록한다. 원문 언급과 추론 후보·교육과정 승인을 구분한다. 프로그램별 실제 확보 수, 소개문 부족, 수집 실패를 숨기지 않는다.

비용: 수집·로컬 탐색·태깅·검증의 서비스 유료 API 호출은 0회로 유지한다. 외부 요청을 차단한 함수 검증과 로컬 HTTP/브라우저 검증을 별도로 기록한다. 이를 개발 도구 자체의 토큰 비용 0으로 표현하지 않는다.

성능: 현재 규모의 검색 지연을 측정하고, 원문 변경 시 캐시를 갱신한다. 입력 길이·페이지·유형·프로그램 조건을 검증하고 근거 묶음은 6자료·직렬화 24,000자로 제한한다. 글자 수는 모델 토큰 수와 다르다.

무결성: 같은 EBS 강좌/회차 ID는 중복 적재하지 않는다. 제목·URL이 바뀐 링크 대조는 무효화한다. 원문이 없는 소개문을 생성하지 않는다. 별도 승인 저장소의 변경 여부를 해시로 검사한다.

접근성·오류: 작은 화면·키보드·오류 복구·자료 모음·메모 다운로드를 브라우저에서 확인한다. DOM에 원문/질문을 삽입할 때 HTML을 이스케이프한다. 미지원 조건과 빈 결과를 표시한다.

# 포함 범위

현재 우선순위는 [R00~R11 작업 순서](../../docs/PLANS.md)다. 이번 요청에 R00 계획 수정, R01 실제 대량 수집, R02 시맨틱 태깅 구현, R03 자연어 검색·테스트까지 포함한다.

1. 808개 공식 프로그램/시즌 인벤토리를 기반으로 다양한 방송 회차를 실제 적재한다. 1차 목표는 50개 프로그램·20,000회차다.
2. 생태·기후·인체·우주부터 과학 원문과 개념을 보강하고 사회와 같은 수의 검색 시나리오로 확인한다.
3. 근거 필드·원문 구절·출처·지문·버전을 갖춘 원문 태그를 만들고 상위 개념 후보를 분리한다.
4. 자연어 문장에서 복수 주제·동의 표현·제외어·수업 의도·조건을 해석하고 미확인 조건을 화면에 알린다.
5. 10건 이상의 유료 API 없는 기능 검증과 브라우저·균형 시나리오를 실행하고 전후·공백을 기록한다.
6. 실제 구조 ERD, 기존 52개 task 대응표, 계획과 상태를 동기화한다.

수집 전체 목표 달성은 학년 적합성·원문 재생·검색 정답률을 보증하지 않는다. 기존 25/25/100~150건 사람 검수는 R09에서 필요와 여력에 맞춰 재산정하며 로컬 개발의 선행 장벽으로 삼지 않는다. 과학을 선택 P0B 업무로 제한하던 조건은 해제한다.

## 후속 실행 범위 — 2026-10-01

교사·관리자 분리 요청을 R07·R08 task에 반영했다. 다음은 R07의 교사 동선 정리, 로컬 주제·대표 후보 추천, 수업 준비안 연결 순서다. R08는 관리자 진입·자료 목록·품질 관리·접근 통제를 맡고, 역할 경계는 R07와 함께 정한다. 화면과 추천 기능은 아직 미구현이다.

R09에서 고정 자료·새 표현으로 통합 검증한 뒤 필요 시 R10 모델 추론을 로컬 기준선과 비교한다. R11는 교사와 관리자 흐름을 분리해 시연하고 외부 공개 전 권한을 확인한다. 유료 API 금지와 기존 사람 승인 상태는 유지한다. 상세 실행 순서와 상태는 [PLANS](../../docs/PLANS.md)를 따른다.

# 제외 범위

이번 세션에서는 유료 서비스 모델을 호출하지 않는다. 실제 외부 배포·접수·녹화·교사 효용 평가와 교육과정/학년/장면 승인은 수행 완료로 기록하지 않는다. 영상 파일·비공개 자막·로그인 후 자료를 수집하지 않는다.

독립 Evidence/Relation/사람 태그 검토 이력 테이블, 자동 갱신 운영, 범용 자연어 모델·임베딩 도입은 현재 구현과 구분한 후속 제안이다. 문장형 입력을 지원한다고 모든 부정·관계·조건을 정확히 이해한다고 주장하지 않는다.

기존 v1.4 원본 패키지는 당시 설계 기록으로 보존한다. 현재 변경 방향은 이 계획과 PLANS를 따르며 과거 목표를 달성 실적으로 바꾸지 않는다.

# 검증 지표

| 구분 | 측정 | 해석 |
| --- | --- | --- |
| 공급 | 실제 회차 ID·프로그램명·프로그램/시즌 courseId·제목 그룹·소개문·실패 | 인벤토리 표시 수와 실제 확보량 분리 |
| 태그 | 직접 언급 수·태그 있는 자료·추론 후보·근거 위치·출처·지문 | 태그 없음은 근거 부족/어휘 공백이며 억지 생성 금지 |
| 자연어 | 사회 12·과학 12 문장/핵심어/도착 확인 조건 검색 | 후보 존재율이며 교육적 정답률 아님 |
| 기능 | 고정 원문 계약 검사, 기존 로컬·브라우저·30개 시나리오 | 학습/튜닝에 사용한 예문과 신규 질문 분리 |
| 비용·무결성 | 유료 API 호출·네트워크 시도·승인 파일 해시 | 직접 함수 검증과 로컬 HTTP 허용 검증 구분 |
| 후속 사람 확인 | 실제 질문의 상위 결과 원문·관계·장면·학년 적합성 | 미실행은 미확인, 자동 평가 결과로 대체하지 않음 |

자연어 해석 전에 고정한 사회/과학 24개 질의의 기준선을 보존한다. 수집 규모와 엔진이 함께 바뀌므로 전체 전후 차이를 모델 이해 능력 하나의 효과로 해석하지 않는다. 고정 원문 계약 검사는 그와 별도로 수행한다.

길이·자막·학년·무료 조건을 확인할 데이터가 없으면 경고한다. 알려지지 않은 주제·고유명은 삭제하지 않는다. 직접 원문 근거가 없으면 추론 후보만으로 AND 조건을 충족시키지 않는다. 빈 결과도 정당한 결과로 기록한다.

원문·규칙·프로그램 대표화가 바뀌면 같은 질문으로 회귀 확인한다. 최종 교육적 평가를 하지 않은 상태의 기능 통과를 제품 정답률로 보고하지 않는다. 관측 결과는 [작업 보고](../../docs/REDESIGN_RESULTS.md)와 JSON 보고서에 남긴다.

현재 R09는 진행중이다. 원문 표본 21개는 사람 평가와 별도이며 엄격 대조·정규화 대조를 분리한다. 사용자 예시 10개는 수정에 사용해 개발 회귀로 전환했다. 검수 후보 4개는 준비만 했고 승인 저장소는 불변이다.
