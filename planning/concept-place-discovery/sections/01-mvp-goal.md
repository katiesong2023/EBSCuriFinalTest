# MVP 목표 (MVP Goal)

2026-09-30 수정. 사회·과학을 함께 지원하는 일반방송 탐색 서비스를 만든다. 교사의 자연어 요청을 주제·수업 의도·제외어·조건으로 나누고, 공식 회차의 제목·공개 소개문과 연결하여 실제 근거가 있는 후보를 제시한다. 과학 우선 소재는 생태·기후·인체·우주다.

사용자가 선택한 1차 수집 목표는 50개 프로그램·20,000개 실제 회차다. 프로그램/시즌 인벤토리의 표시 회차 수와 실제 적재 ID 수는 다르다. 충분한 모집단과 근거 텍스트를 먼저 확보하고, 모델은 이후 프로덕션에서 이 로컬 결과를 바탕으로 추론한다.

기존 저장 콘텐츠 144개·검색 투영의 고유 콘텐츠 4개는 승인 경로의 별도 지표다. 현재 홈페이지 탐색 규모와 혼동하지 않는다. 최신 관측량은 [작업 결과](../../../docs/REDESIGN_RESULTS.md), 현재 작업 순서는 [PLANS](../../../docs/PLANS.md)를 따른다. 2026-09-28의 20건/2시간 조사는 초기 타당성 실험 이력이며 현재 수집 상한이 아니다.

실제 교사 효용·장면·학년 적합성은 후속 사람 판단이다. 후보를 많이 반환하는 것으로 정답률이나 현업 준비 완료를 주장하지 않는다.
