# Curi 현업 실용화 가능성 평가

> 2026-09-30: 아래 내용은 9월 28일 준비도 평가 이력이다. 탐색 카탈로그는 이후 확대됐으며 최신 수량·검증은 [작업 결과](../../docs/REDESIGN_RESULTS.md), 현재 후속 기준은 [R09](../../Tasks/task-r09-quality-gates.md)를 따른다. 원문 재생·교육적 적합성·현업 효용 미확인은 유지한다.

- 기준일: 2026-09-28
- 근거: 로컬 저장소와 현재 코드·task 상태의 읽기 전용 점검. 이번 평가에서 실제 링크 재생, 교사 사용 실험, 외부 카탈로그 접근 시험은 수행하지 않았다.
- 결론: 현재 범위와 정보셋으로 일반 교사가 반복적으로 사용하는 범용 수업 영상 추천 서비스를 즉시 제공하기는 어렵다. 구현 흐름을 보여주는 로컬 시제품과 제한 주제의 자료 정리 실험 수준이다.
- 관련 설계: [개념·장소 기반 수정 설계서](./PLAN.md).

| 동고서저 한 경로 탐색 | 수정 설계 단계 | 실제 장소·지형 근거와 서로 다른 영상 확보가 선행 |
| 초등 5·6학년 사회 수업의 반복 추천 | 현재 제공 곤란 | 다양한 수업 요청에 쓸 영상·대안·원문 접근·적합성 근거 부족 |
| 사회·과학 전반 현업 서비스 | 현재 제공 곤란 | 주제 커버리지, 운영·검수 확장, 외부 접속 안정성 모두 미검증 |

자료 3건·클립 1건은 기술 경로의 구현 진입 기준일 뿐 현업 출시 기준이 아니다. 승인 25건, 검증 자산 100~150건, 레코드 1,000건도 그 숫자만으로 실용화를 입증하지 않는다.

현재 원본 데이터의 프로그램 편중을 유지한 채 후보 수만 늘리면 미충족 수업 요청은 계속 남는다. 반대로 범위를 한 단원으로 명확히 제한하면 작은 데이터도 자료 모음으로는 유용할 수 있다. 이를 범용 추천 서비스라고 설명해서는 안 된다.

## 3. 콘텐츠 규모는 수업 요청 충족률에서 역산한다

먼저 실제 사용자가 반복해서 찾는 수업 요청 목록을 정하고, 각 요청에서 최소한의 대안 영상과 내용 근거가 있는지 확인한다. 영상의 수보다 '의도에 맞는 자료가 나오고 바로 사용할 수 있는 요청의 비율'이 중요하다.

규모 추정을 위해 필요한 수치는 다음과 같다.

- 목표 수업 요청 수와 요청당 필요한 적합 자료 수
- 원본 후보 중 회차 식별·원문·주제 근거·접근 조건을 통과하는 비율
- 같은 자료가 여러 요청에 실제로 재사용되는 정도
- 후보 1건 처리 시간, 확인 대기율, 재확인·갱신 시간

예시 계산: 요청 30개에 각각 적합 자료 3건이 필요하고 재사용이 없다고 가정하면 적합 자료 90건이 필요하다. 후보 적격률을 가정상 25%로 두면 원본 후보 360건을 조사해야 한다. 실제 적격률이 10%면 900건이다. 이는 계획 계산 예시이며 현재 적격률 측정값이나 최소 콘텐츠 수 기준이 아니다. 재사용·중복·주제 편중을 반영하면 필요한 고유 자료 수는 달라진다.

144건은 목표 서비스에 비해 적고 편중돼 있다. 하지만 해결 목표를 임의의 1,000건으로 정하기보다, 대표 요청의 부족 칸과 공급원의 적격률을 측정해 규모를 결정해야 한다.

## 4. 가장 큰 사업·운영 리스크는 데이터 공급과 유지 비용이다

| 리스크 | 먼저 확인할 질문 | 불충족 시 방향 |
| --- | --- | --- |
| 지속적인 콘텐츠 공급 | 개별 회차 ID·내용 소개·URL을 반복 확보할 경로가 있는가? | 운영 가능한 자료 제공·연계 경로 확보를 선행 |
| 실제 내용 근거 | 소개문에 장소·지형 주제가 드러나는가? | 근거가 있는 출처로 범위 축소, 자막 전사 비용부터 늘리지 않음 |
| 찾은 뒤 사용까지 | 사용자가 해당 영상을 식별하고 접근할 수 있는가? | 링크·접근 품질 우선 보강, 목록 페이지를 직접 재생 링크로 표시하지 않음 |
| 인력 확장 | 자료를 늘릴 때 매번 긴 시청·태깅이 필요한가? | 자동 검사와 예외 검토를 분리하고 서비스 범위·운영 인력 재산정 |
| 교육적 신뢰 | 출처 내용 일치와 수업 적합성을 누가 확인하는가? | 검증 수준을 명시하고 전문 정확도 보장 문구 유보 |
| 배포 운영 | 여러 사용자의 검색·쓰기·비용·장애를 통제할 수 있는가? | 현재 로컬 실험 범위를 넘어서는 배포 검증 필요 |

공식 데이터 연계·기관 협력·공개 카탈로그 증분 수집은 가능한 검토 경로다. 이용 가능한 API·권한·수집 허용 범위·제공 필드를 확보했다고 가정하지 않는다. 서비스 운영의 핵심 공급원을 직접 확인해야 한다.

API 토큰 비용뿐 아니라 적합 자료 1건 확보에 드는 조사·정리·사람 확인·갱신 시간까지 계산해야 한다. 확인 1건이 1분이어도 1,000건은 단순 확인만 약 16.7시간이다. 5건 표본 확인으로 나머지 995건을 사람 승인했다고 기록해서는 안 된다.

## 5. 권장 추진 경로

### A. 지금 할 일: 데이터 공급 타당성 확인

02-10A의 동고서저 조사를 ‘좋은 예시 몇 개 찾기’에서 끝내지 않는다. 후보가 나온 출처, 확보 가능한 필드, 자료 단위, 적격률, 건당 조사 시간을 함께 기록한다. 반복 확보 가능성은 확인/미확인/불가로 표시한다. 지명 연결이 가능해도 후보 공급이 지속되지 않으면 대량 개발에 들어가지 않는다.

조사 상한 안에 실자료 3건을 확보하면 한 경로의 시제품 구현만 허용하는 근거가 된다. 해당 결과로 현업 사용 가능이나 모집단 확장 가능을 선언하지 않는다.

### B. 제한 현업 실험: 국내 지형 탐색으로 범위 제한

사용자가 동의한 경우 첫 제공 범위를 ‘국내 지형 수업 자료 탐색’처럼 명시한다. 서로 다른 교사가 제공하거나 확인한 대표 요청 20~30개로 자료 범위와 사용성을 평가한다. 숫자는 실험 설계 제안이며 이미 확보한 사용자·질의 수가 아니다.

수집에 사용한 질의와 평가용 새 표현·새 요청을 구분한다. 맞는 후보뿐 아니라 무관한 지명 일치, 자료 없는 요청, 회차만 있는 요청도 넣는다. 가능하면 기존 EBS 검색으로 자료를 찾는 시간과 비교한다. 시간 절감은 측정 전 주장하지 않는다.

### C. 확대 여부 판단

제한 범위에서 반복 사용 가능성이 확인되고 자료 공급·유지 비용을 감당할 수 있을 때 다른 지리 단원으로 확대한다. 사회·과학 전체는 그다음이다.
공급 경로가 확보되지 않으면 제품을 ‘보유 콘텐츠를 정리하는 내부 도구’ 또는 ‘한정된 주제의 자료 모음’으로 좁힌다. 이 경우에도 현재 검수 부담이 줄어드는지 실제 확인해야 한다.

## 7. 재설계 결론

서비스의 문제 정의와 목표 경험은 유지할 가치가 있다. 현재 구현은 재사용 가능한 기술 기반이지만 현업 효용을 입증하는 데이터 자산은 아직 충분하지 않다.
가장 먼저 검증할 것은 추천 모델이 아니라 ‘교사가 찾는 주제의 실제 콘텐츠와 내용 근거를 반복 확보할 수 있는가’다. 그 답이 부정적이면 프롬프트·UI·유료 API를 개선해도 현업 사용성이 크게 늘기 어렵다.
따라서 다음 투자 판단은 데이터 접근·적격률·커버리지 조사 결과로 내린다. 전면 재개발보다 데이터 공급 전략과 제한 제공 범위 확정이 우선이다.
