🔔 확장 프로그램 업데이트가 있습니다.

업데이트 방법
  1. 최신 확장 프로그램 다운로드 후 ZIP 파일의 압축을 풉니다.
  2. 기존 설치 폴더의 파일을 새 파일로 덮어씁니다.
  3. Chrome 주소창에 chrome://extensions를 입력하고 Curi 확장 프로그램의 새로고침(↻)을 누릅니다.
  4. 열려 있는 Curi·EBS 페이지를 새로고침하고 확장 패널을 다시 엽니다. 최신 버전이면 이 안내가 사라집니다.

기존 확장 프로그램을 삭제하지 않고 업데이트하세요.

🔔 EBS 본편 확인이 필요합니다

EBS 로그인
로그인 후 이어가기 방법
  1. ‘EBS 로그인’으로 연 홈페이지에서 로그인합니다.
  2. ‘영상으로 돌아가기’를 누릅니다. 원래 탭이 있으면 그 탭을 열고, 닫혔다면 다시 엽니다. 본편 확인 전에는 로그인 상태를 반영하도록 영상을 새로고침합니다.
  3. EBS 본편을 재생하면 자동으로 확인하고 구간 만들기를 이어갑니다. 폴더와 입력 내용은 유지됩니다.
