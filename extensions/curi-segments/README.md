# EBS CURI 수업용 구간 북마크 1.2.18

Chrome 데스크톱 개발자 모드에서 사용하는 로컬 확장 프로그램입니다. 스토어에 공개하지 않습니다.

## 설치

1. Curi 서버를 실행합니다. 기본 주소는 `http://localhost:3000`입니다.
2. Curi 서버의 `/downloads/curi-segments-extension.zip`을 내려받아 압축을 풉니다.
3. `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다 → 압축을 푼 폴더를 선택합니다.
4. 확장 아이콘을 고정합니다. 열린 사이드 패널의 상단의 ‘EBS CURI 연결’을 눌러 실제 Curi 주소를 입력하고 ‘연결·폴더 불러오기’를 누릅니다. `localhost`와 `127.0.0.1`, 포트가 다른 주소의 개인 자료는 별개입니다.
5. Curi에서 지식채널e 회차를 내 자료 또는 수업 폴더에 담은 뒤 원본 영상을 엽니다. EBS에서 직접 연 같은 회차도 저장한 개인 자료와 연결할 수 있습니다.
6. 영상 재생 후 확장 프로그램에서 시작·끝 지정, 이름·메모·저장 위치 확인, ‘폴더명에 저장’을 누릅니다. 다른 구간은 구간 이름 오른쪽의 새로고침 아이콘을 사용합니다.
7. Curi의 내 수업 페이지에서 구간 클립 카드 또는 수업 영상 리스트의 ‘구간 보기’를 누릅니다. 지원 본편 준비 후 시작 시간으로 이동하며 구간 끝에 일시정지합니다. 자동 재생이 막히면 EBS 재생 버튼을 누릅니다.

## 지원과 확인 범위

- 첫 어댑터: `https://jisike.ebs.co.kr/jisike/vodReplayView`의 `#mediaplayerWrap` HTML5 플레이어. 회차 주소·공개 회차 선언·현재 본편 품질 소스·본편 접근 상태를 대조합니다.
- 광고, 다른 회차 연속재생, 미리보기, 판본 불일치, 다른 EBS 사이트/플레이어는 자동 지정·제어를 보류합니다. 품질 변경으로 소스가 바뀌면 팝업을 다시 열어 새로 지정하세요.
- 로컬 Curi만 지원합니다. Chrome 접근 범위는 지식채널e와 localhost/127.0.0.1에 한정되며 연동은 팝업에 설정한 정확한 Curi 주소의 내 수업 페이지에서만 허용합니다.
- 기록은 Curi 주소의 `curi.teacher.segments.v1`에 저장합니다. 확장 프로그램에는 선택한 Curi 주소와 회차별 미저장 입력을 보존합니다. 원본 영상 주소 외 서명된 미디어 URL·쿠키·계정 정보는 저장하지 않습니다.
- 구간 정지는 브라우저의 미디어 이벤트를 사용하므로 프레임 단위 편집이 아닙니다. 백그라운드 탭·버퍼링·플레이어 변경에서는 지연 또는 실패 안내가 있을 수 있습니다.
- 영상 다운로드·클립 파일 생성·접근 제한 우회·교육과정 승인·다른 기기 동기화는 제공하지 않습니다.

2026-10-14 실제 Chrome 설치와 지식채널e 두 회차의 확장 저장·정확한 시작 이동·끝 정지 유지·재개 방지를 확인했습니다. 실측 끝 시각 차이는 약0.011초/0.053초였으며 다른 환경에서 같은 정밀도를 보장하는 수치는 아닙니다. 구간 끝에서는 ‘구간 다시 재생’으로 재사용하고, 원본 전체를 보려면 ‘구간 제어 해제’를 누르세요. 코드 갱신 시 확장 카드를 새로고침하고 EBS/Curi 페이지도 새로고침하세요. 기능 테스트와 실제 EBS 재생 검증은 task에 각각 기록합니다.

0.2 버전부터 별도 구간 페이지는 제공하지 않습니다. 구간 저장 완료 안내는 ‘내 수업 페이지에 저장되었습니다’이며 내 수업 페이지에서 기존 내 자료/폴더 구간을 함께 확인·편집할 수 있습니다.

## 1.2.19 — 새 버전 안내

1.2.25부터 로그인 안내는 ‘EBS 로그인’과 ‘영상으로 돌아가기’ 두 버튼입니다. 로그인 후 영상으로 돌아가기를 누르면 같은 회차의 기존 탭으로 복귀하거나 닫힌 영상을 다시 엽니다. 본편 확인 전에는 로그인 상태 반영을 위해 영상을 새로고침하고, 본편을 재생하면 자동으로 확인해 기존 폴더와 초안을 이어갑니다. 이미 확인된 본편은 복귀 시 새로고침하지 않습니다. 별도의 다시 확인 버튼은 제거했습니다.

1.2.21부터 본편을 확인하지 못하면 로그인·본편 재생 확인 안내와 ‘로그인 후 다시 확인’ 버튼이 표시됩니다. ‘EBS 영상 열기’에서 로그인하고 본편을 재생한 뒤 다시 확인을 누르면 같은 회차의 폴더/구간 이름/시간/메모를 이어갑니다. 로그인 중 패널을 닫아도 초안을 복원하며, 다른 회차를 대신 선택하거나 자동으로 저장하지 않습니다.

연결된 Curi 서버의 최신 배포 버전이 설치 버전보다 높으면 패널 상단에 업데이트 안내와 방법 토글이 표시됩니다. 최신 ZIP의 파일로 기존 설치 폴더를 덮어쓴 뒤 `chrome://extensions`의 Curi 카드에서 새로고침을 누르세요. Curi·EBS 페이지를 새로고침하고 패널을 다시 열면 최신 버전에서 안내가 사라집니다. 확장을 삭제할 필요는 없습니다. 이 안내 기능 자체는 1.2.19부터 제공되므로 이전 설치는 먼저 수동으로 갱신해야 합니다.

## 0.3.0 — 지식채널e·다큐프라임 연결 복구·수업 영상 등록

이전에 열려 있던 탭이 응답하지 않으면 다른 내 수업 탭에 연결하며, 연결 가능한 탭이 없으면 같은 Curi 주소에 새 탭을 자동으로 연다. 서버가 실행 중이어야 하며 `localhost`와 `127.0.0.1`은 서로 다른 개인 저장 공간이다.

지원 본편에서 **Curi 연결·자료 불러오기**를 누르면 전체 수업 폴더를 불러온다. 영상이 내 자료나 CuriBase에 없어도 **수업 폴더**를 고르거나 **새 수업 폴더 만들기**와 이름을 입력하여 **영상만 추가**를 누른다. 구간 이름·시작·끝을 입력한 뒤 **영상·아래 구간 저장**을 누르면 구간도 함께 저장한다. 기존 자료의 구간만 편집할 때는 아래 **이미 담긴 자료의 구간 저장 위치**를 사용한다.

CuriBase에는 제목·회차 주소·페이지 공개 소개문·길이를 교사 등록 자료로 보관한다. 이후 자료 찾기에서 제목/소개문으로 검색한다. 기존 회차는 동일 ID를 재사용하며 교육과정 승인을 만들지 않는다. 영상 파일·서명된 재생 주소·로그인 정보는 저장하지 않는다.

수정본 서버를 다시 시작하고 확장 카드의 ↻를 한 번 누른다. 이미 열린 EBS 회차도 새로고침해야 새 영상 정보 읽기가 적용된다. 수업 폴더/구간은 기존 주소에 보존된다.

## 0.3.1 — 애니키즈·저장 무반응 수정

애니키즈 회차(`/vodCommon/show`)도 지원한다. ‘저장할 영상’에서 사용할 회차 탭을 명시 선택하므로 EBS 로그인/비밀번호 변경 팝업이 떠 있어도 다른 창을 회차로 읽지 않는다. 저장 안내는 상단과 각 저장 버튼 아래에서 확인한다. 빈 구간 이름/시간은 저장 보류 사유를 표시한다. 확장 카드 ↻ 후 이미 열린 EBS 회차는 새로고침한다. 애니키즈 호스트 접근이 이번 업데이트에 추가되었다.

## 0.3.2 — 저장 완료 안내 유지

팝업이 닫혀도 마지막 저장 결과를 보존한다. 같은 회차 팝업을 다시 열면 저장 시각과 마지막 저장 결과가 표시되고, Curi 페이지도 저장 안내를 유지한다. 실제 등록 성공 여부를 확인한 뒤 안내를 저장한다. 등록 직후 전체 목록 조회가 늦어도 저장 성공과 조회 지연을 구분한다.

## 0.4.0 — 폴더 → 자료 → 구간의 세 단계

1. `수업 폴더 선택·생성`에서 기존 폴더를 선택하거나 이름 입력 후 `새 폴더 생성`을 누른다. 영상이 열려 있지 않아도 생성할 수 있다.
2. `저장할 EBS 페이지`를 고르고 `선택한 폴더에 자료 담기`를 누른다. 공개 프로그램과 회차 제목·소개·링크를 가져오며 없는 자료를 CuriBase 검색 풀에 추가한다.
3. 회차에서 구간 이름·시작·끝을 입력하거나 현재 시간을 지정한 뒤 `구간 클립 저장`을 누른다. 아직 담지 않은 영상도 함께 담는다. 영상 파일이 아니라 원본 링크와 시간 구간을 저장한다.

`선택한 폴더를 Curi에서 열기`로 저장 위치를 바로 확인한다. 폴더 목록은 팝업에서 주기적으로 갱신하고, 내 수업의 다른 창에도 같은 주소의 저장 변경을 전달한다. 새 버전 연결은 프로토콜4로 확인한다.

확장 접근 범위가 공개 EBS 도메인 전체(`*.ebs.co.kr`)로 확대된다. 로그인·비밀번호·개인정보 페이지는 수집 대상에서 제외한다. 자동 시간 읽기/끝 정지는 접근 가능한 HTML5 플레이어에서 제공하며 외부 iframe 등은 직접 입력으로 구간을 저장한다. 프로그램 목록에서는 실제 회차를 열어 구간을 저장한다.


## 0.5.0 — 웹·확장·로고 공통 디자인

웹과 같은 중립색 바탕·녹색·입력 경계·포커스·44px 조작 영역·연결점 로고를 사용한다. 폭은 바깥 여백을 포함해 360px이다. 현재 영상 → 가져갈 수업 폴더 → 영상 전체 가져가기 / 영상과 구간 가져가기 순서로 표시한다. Curi 연결 버튼은 접지 않고 제공한다. 저장 대기는 해당 버튼에 ‘가져오는 중’으로 표시하고, 저장 결과와 실패 사유는 상단 및 실행한 버튼 아래에 표시한다.

기존 자료·폴더·구간·영상별 초안·최근 확인된 저장 결과와 프로토콜4는 유지한다. `chrome://extensions`의 Curi 카드 ↻로 갱신한다. ZIP 설치 사용자는 새 ZIP을 기존 설치 폴더에 압축 해제한 뒤 ↻를 누른다. 기존 EBS/Curi 탭도 새로고침한다. 툴바와 설치 목록에는 새 심볼이 표시된다. Chrome 스토어 공개는 하지 않는다.


## 0.6.0 — 영상 옆 세로 사이드 패널

Chrome 116 이상에서 확장 아이콘을 누르면 브라우저 옆에 세로 패널이 열린다. 영상 페이지를 클릭해도 패널은 유지되며 패널 내용은 별도로 세로 스크롤한다. 팝업 대신 같은 저장 화면을 사용하므로 영상별 초안·폴더 설정·저장 결과와 프로토콜4는 그대로 유지한다. 파일명 `popup.html`은 호환을 위해 유지하며 실제 진입점은 `side_panel.default_path`다.

오른쪽 패널을 원하면 Chrome 설정 → 모양 → 사이드 패널 위치에서 오른쪽을 선택한다. 위치와 폭은 Chrome/사용자가 관리하며 확장에서 강제하지 않는다. ‘저장할 EBS 페이지’가 명시적인 저장 대상이다. 다른 탭으로 이동해도 선택한 대상을 자동으로 바꾸지 않는다. ‘열린 영상 목록 새로고침’으로 새 탭을 불러와 선택한다. 선택한 페이지가 이동하거나 닫히면 저장·시간 읽기를 잠그고 재확인을 안내하며 입력은 보존한다.

업데이트: ZIP 사용자는 새 ZIP을 **기존 설치 폴더**에 덮어 풀고 `chrome://extensions`의 Curi 카드 ↻를 누른다. 저장소 폴더를 직접 로드했다면 카드 ↻만 누른다. 이후 열린 EBS/Curi 페이지를 새로고침하고 Curi 아이콘을 누른다. `sidePanel` 권한이 추가되며 기존 사이트 접근 범위는 같다. 이 변경은 디자인안3/4를 운영 화면에 적용하는 작업과 별개다.


## 0.6.1 — 현재 영상 표시 단순화

현재 영상은 페이지에서 확인한 프로그램명·회차명만 표시한다. 선택된 항목의 브라우저 탭 제목(예: 애니키즈)도 이 이름으로 바꾸며 유형·길이는 현재 영상 영역에서 생략한다. 구간 지정에 필요한 길이/시간 안내는 구간 입력 영역에 유지한다. 새로고침은 현재 영상 제목 오른쪽의 ↻ 아이콘이며 툴팁/접근성 이름은 ‘영상 목록 새로고침’이다.


## 0.6.2 — 폴더 생성 입력 통합

새 폴더 이름 입력란 오른쪽 안에 ‘생성’ 버튼을 배치한다. Enter로도 같은 폴더 생성이 실행되며 저장 중 잠금·빈 이름 안내·생성 후 자동 선택은 유지한다. ‘선택한 폴더를 Curi에서 열기’ 버튼은 제거했다.


## 0.6.3 — 가져가기 범위 통합

## 1.1.0 — 카드에서 구간 클립 만들기

- 내 수업 자료의 수업 준비 안 ‘구간 클립 목록’에서 ‘구간 클립 만들기’를 누르면 EBS 새 탭과 Curi 사이드 패널을 연다. 열린 영상은 구간 지정 모드와 해당 수업 폴더를 선택한다. 시작·끝·이름을 지정해 저장하면 원래 카드 아래에 클립 카드가 표시된다.
- 미설치·구버전·다른 Curi 주소에 연결된 경우 웹에서 다운로드/설치/연결 안내를 제공한다. ZIP 압축을 푼 설치 폴더를 새 파일로 갱신하고 Chrome 확장 관리에서 새로고침한 뒤 Curi·EBS 탭도 새로고침한다. 패널 설정의 Curi 주소는 현재 내 수업 페이지의 주소와 같아야 한다.
- 자동 패널 열기는 버튼의 실제 클릭을 확장 콘텐츠 스크립트에서 즉시 전달한다. [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)의 사용자 동작 조건에 따라 새 탭 생성 전에 글로벌 패널을 연다.
- 이번 변경의 패널 실행/폴더 문맥 전달은 모의 확장 API로 검증했다. 실제 설치된 Chrome에서 EBS 페이지와 함께 열리는 동작은 최종 확인이 필요하다. 클립은 원본 영상의 구간 기록이며 기존 저장 형식을 유지한다.

## 1.1.1 — 현재 영상의 수업 폴더 자동 선택

- 패널을 열거나 영상을 바꾸면 현재 회차가 담긴 폴더를 찾아 선택한다. 다른 영상에서 마지막으로 쓴 폴더는 우선하지 않는다. 여러 폴더에 담겼으면 Curi의 구간 만들기에서 지정한 폴더, 해당 영상의 저장 초안 폴더, 현재 Curi 폴더, 첫 일치 폴더 순으로 선택한다.
- 폴더 미지정·새 영상은 기존 폴더 선택/가져오기 과정을 유지한다. 영상 목록에서 제외하지 않는다. 수업 폴더의 공개 영상 주소만 비교하고 구간 입력 초안은 보존한다.
- 확장 파일을 갱신하고 확장 관리에서 새로고침한 뒤 Curi 페이지도 새로고침한다. 폴더 주소 목록은 갱신된 웹 화면에서 전달한다.

## 1.2.0 — 새 폴더 카드·삭제 확인

- 폴더 목록의 ‘+ 새폴더 만들기’ 폴더를 누르면 ‘새 폴더 이름’ 입력과 생성 버튼이 나타난다. 생성 성공 시 입력을 비우고 접으며 새 폴더를 선택한다. 생성 실패 시 입력을 유지한다. 폴더가 없어도 새 폴더 카드는 사용할 수 있다.
- 각 폴더 위의 작은 휴지통을 누르면 웹과 같은 ‘수업 폴더 삭제’ 확인창이 열린다. ‘폴더에 저장된 자료들도 함께 삭제됩니다. 삭제하시겠습니까?’에 ‘예’를 눌러야 삭제한다. ‘아니오’/Escape는 삭제하지 않는다.
- 삭제는 Curi의 기존 폴더 삭제 함수를 사용해 해당 폴더와 구간 기록을 함께 정리한다. 다른 폴더와 폴더 미지정 자료는 보존한다. 다른 창에서 변경되었으면 중단하며 저장 오류 시 먼저 변경한 구간도 복구한다.
- 확장과 Curi 페이지를 모두 갱신해야 새 생성/삭제 연결을 사용할 수 있다.

1.2.1: 초기 ‘Curi 연결됨 · 폴더를 선택하거나 새 폴더를 생성하세요.’ 안내 제거·빈 상태 영역 숨김. 상단 연결 표시와 오류/진행 안내는 유지한다.

## 1.2.2 — 시간 지정 재연결·정수 초 기록

- EBS 영상이 선택되어 있으면 Curi 연결 지연/첫 메타데이터 조회 실패 때문에 시작·끝 지정 버튼이 계속 비활성 상태로 남지 않는다. 지정 클릭 시 영상 정보를 다시 읽는다. Curi에 연결되지 않은 동안에는 구간 초안만 편집할 수 있고 저장은 차단한다.
- 확장 갱신 전 열린 EBS 탭에 읽기 연결이 없으면 `scripting` 권한으로 기존 허용 EBS 탭의 읽기 스크립트만 다시 연결한다. 탭을 새로고침하거나 영상 재생 위치를 바꾸지 않는다. [Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)를 사용하며 기존 EBS 호스트 권한 범위는 유지한다.
- 시작은 내림, 끝은 올림하여 정수 초로 입력/미리보기/초안/구간 기록에 반영한다. 예: 시작12.8초→0:12, 끝12.1초→0:13. 직접 입력도 같은 규칙을 적용한다. 영상의 마지막 소수 초는 올림 표시하되 실제 끝에서 정지한다.
- 회차 조회 중 영상이 바뀌거나 시간이 잘못되면 기존 입력을 덮어쓰지 않고 입력칸 옆에 이유를 표시한다. 광고/미리보기와 본편 확인은 기존처럼 구분한다.
- 사용자 회차60445128은 미로그인 실제 접속에서 메타데이터 읽기와5분 맛보기 상태를 확인했다. 로그인/구독 본편의 실제 버튼 지정은 새 버전 갱신 후 확인이 필요하다. 확장 관리에서 갱신하고 패널을 다시 연다.

저장 성공 후 다음 저장은 새 구간 클립 카드로 추가됩니다. 실패한 요청의 재시도는 같은 ID를 유지합니다. 같은 영상/폴더에서 여러 구간 및 전체 영상 클립을 저장할 수 있습니다.
