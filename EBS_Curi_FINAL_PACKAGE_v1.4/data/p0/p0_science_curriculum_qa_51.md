## 사용 상태

자동 대조는 원문 텍스트·구조의 일치 여부를 보조한 결과이며 사람의 최종 승인을 대신하지 않는다. 사용자가 2026-09-17에 51건 전체의 사람 승인을 지시했으며, `p0_science_curriculum_qa_51.csv`의 51개 레코드는 모두 다음 상태로 기록했다.

- `human_review_status`: `HUMAN_APPROVED`
- `usability_status`: `USABLE_HUMAN_APPROVED`

따라서 51건은 과학 Gold 정답, CuriMap의 공식 후보, 서비스 사용 가능 기준에 사용할 수 있다. 이후 수정이 필요한 항목은 `HUMAN_EDITED`로 바꾸고 재대조·재승인 전에는 사용 불가로 전환한다. 제외할 항목은 `REJECTED`와 사유를 남기고 사용하지 않는다.

## 정적 점검 방법

원본 CSV를 UTF-8(BOM 허용)으로 읽어 51개 행·16개 열, 성취기준 ID 고유성, 필수 필드, 코드 형식, 학년군·교과·버전의 단일 값을 점검했다. PDF 원문 32~45쪽에서 각 행의 ID와 공백 정규화한 본문을 대조했으며 51건 모두 일치했다. PDF 페이지를 PNG로 렌더링해 처음·중간·마지막 대조 쪽의 성취기준 상자와 코드·문구 배치를 추가로 확인했다.
