## 구성

- 사회 계열: 24건 (`사회` 18 + `사회/경제` 6)
- 과학: 32건
- 사회·과학 합계: 56건
- 그 밖의 교과 후보: 88건

이번 산출물은 현재 확인 가능한 144건이다. task 목표 200~250건보다 56~106건 부족하다. 부족 원인은 (1) 후보 풀 228건 다큐프라임 중 공개 소개문을 확인한 건이 12건뿐이고, (2) 3건은 EBS 원문 출처 확인이 보류됐으며, (3) 나머지는 제목만 있어 소개문을 추정할 수 없기 때문이다. 목표를 채우려면 다음 회차에 EBS 공개 소개문 56건 이상을 추가 확보하거나 Working Set 목표를 실제 적격 건수에 맞춰 144건으로 조정해야 한다.

## CuriBase 확보 경로와 검수 회차

Working Set 144건은 모두 `INCLUDED_PENDING_HUMAN_REVIEW` 상태이며 사람 승인·수정 자산으로 아직 저장하지 않는다. CuriBase 초기 100~150건은 아래 순서로 사람 검수 후 확정한다.

1. 1차 회차: 공식 클립과 PD로그에서 25건을 골라 승인·수정·제외한다.
2. 2차 회차: 서로 다른 출처와 교과가 포함되도록 25건을 추가 검수한다.
3. 확장 회차: 1·2차 결과와 다큐프라임 공개 소개문 12건을 포함해 추가 50~94건을 검수한다.

각 회차의 최종 승인 수가 100~150건이 되도록 사람이 선택하며, 이 문서와 CSV에는 사람 검수 완료로 표시하지 않는다.

## 품질 게이트와 정합성 메모

- Candidate `content_id`와 `record_id`는 입력 후보 풀에서 유지했다.
- 공식 클립은 synopsis가 없어도 공식 교과·단원/차시 메타데이터가 있으므로 편입했으며 Silver 후보로만 취급한다.
- PD로그와 다큐프라임은 공개 텍스트가 있어도 교육과정 Gold 정답으로 간주하지 않는다.
- 기존 감사 보고서의 `매핑 입력 후보 160건` 표기는 산술상 불일치한다. 후보 풀 실제 구성은 공식 클립 40 + PD로그 92 = **132건**이며, 이번 Working Set 144건은 여기에 공개 소개문 확인 다큐프라임 12건을 더한 값이다.
- Raw 원본을 덮어쓰지 않았고, 보강 소개문은 Candidate/Working Set 계층에만 기록했다.

## 출처 확인 목록

보강 CSV의 `description_source_url`이 각 항목의 직접 출처다. 확인한 출처 유형은 EBS 보도자료, EBS 프로그램/VOD 페이지, EBS 공식 YouTube, EBS 매거진 PDF다. 외부 재가공 문서만 확인된 항목은 Working Set에 편입하지 않았다.
