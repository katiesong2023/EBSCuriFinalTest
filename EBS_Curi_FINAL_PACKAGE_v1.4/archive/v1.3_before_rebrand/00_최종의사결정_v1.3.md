# 최종 의사결정 v1.3

## 핵심

v1.3에서 기능은 늘리지 않는다.

강화하는 것은:
- 현업 증거의 정직한 표현
- 공개 Metadata 기반 문제증명
- P0 데이터 준비도
- Gold/Test 평가 엄밀성

## 현업 Baseline을 확보하지 못할 때

확인하지 못한 내용:
- 특정 부서가 월 몇 건을 처리하는지
- 현재 콘텐츠 1건당 태깅 시간이 몇 분인지

위 내용은 사실처럼 쓰지 않는다.

대신 관찰 가능한 사실을 사용한다.

- 일반 방송/VOD는 프로그램·제목·방송일·ID 중심 Metadata
- 공식 교과연계 Clip에는 학년·교과·단원/차시 Metadata 존재
- 일반 Archive까지 교육과정 탐색을 확장하려면 Curriculum Mapping Layer가 필요

따라서 문제는:

> **기존 학교용 교육 Metadata 구조를 일반 EBS Archive까지 확장할 때 필요한 Mapping 구축을 AI가 초안화한다.**

로 정의한다.

## 유사 검색/태깅 Agent와의 차별

CURA는:
- 공식 국가교육과정 Candidate
- N:M Curriculum Mapping
- Human Review
- Verified Metadata DB
- Version 가능한 교육 Metadata Asset

을 구축한다.

Search는 결과 활용 사례다.
