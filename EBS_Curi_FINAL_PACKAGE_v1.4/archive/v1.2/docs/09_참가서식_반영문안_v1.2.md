# 참가서식 반영 문안 v1.2

## 과제명
**2022 개정 교육과정 기반 EBS 콘텐츠 메타데이터 자동 매핑·학교용 검색 Agent**

또는 브랜드 포함:
**EBS CURA – 2022 개정 교육과정 기반 콘텐츠 메타데이터 자동 매핑·검색 Agent**

## 과제 개요
EBS CURA는 EBS 방송·VOD 콘텐츠의 교육과정 메타데이터 구축 업무를 자동화하는 AI 에이전트입니다. 공개 콘텐츠의 제목·소개 등 텍스트 메타데이터를 분석해 2022 개정 교육과정의 학교급·교과·핵심개념·성취기준 후보를 생성하고, 담당자가 검수·승인할 수 있도록 합니다. 검수된 결과는 교사가 실제 수업언어로 EBS 콘텐츠를 검색·추천받는 데 즉시 재사용됩니다. 영상 원본을 반복 분석하거나 검색 때마다 고성능 LLM을 호출하지 않고, 검수된 Mapping과 Vector Search를 재사용해 운영비를 통제하며 향후 교육과정 개정 시 변경 영향 콘텐츠만 증분 재매핑하도록 설계합니다.

## 기대효과 추천 문안

1. **교육 메타데이터 구축 업무시간 단축**  
   콘텐츠를 직접 확인하고 교육과정을 찾아 학교급·교과·성취기준을 입력하는 반복업무를 AI 초안+사람 검수 방식으로 전환합니다.

2. **기존 EBS 방송 아카이브의 교육적 재활용 확대**  
   교과전용이 아닌 다큐·교양·직업·시사 콘텐츠도 교육과정 기준으로 재분류하여 학교 수업 활용 가능성과 기존 자산의 활용가치를 높입니다.

3. **교사의 콘텐츠 탐색시간 단축 및 EBS 플랫폼 이용 활성화**  
   프로그램명을 몰라도 학년·교과·수업주제로 관련 콘텐츠를 찾게 하여 기존에 발견되지 않던 EBS 콘텐츠의 노출과 상세/VOD 페이지 유입을 확대할 수 있습니다.

4. **유료·구독 콘텐츠의 발견 및 사업적 전환 기회 확대**  
   교육과정 기반 추천으로 유료·구독 콘텐츠의 발견 가능성을 높이고, 실제 서비스화 이후 콘텐츠 클릭률·구독페이지 이동률·구독/구매 전환율을 통해 사업효과를 검증할 수 있습니다.

5. **교육과정 개정 및 유지·운영비를 고려한 구조**  
   검수된 Mapping을 반복 재사용하고, 교육과정 개정 시 전체 콘텐츠를 재처리하지 않고 변경된 성취기준과 영향 콘텐츠만 증분 재매핑하여 유지보수 비용을 통제합니다.

6. **개선 효과의 정량 검증**  
   교육과정 Mapping 정확도, 검색 유용성, 수작업 대비 AI 분석·검수 시간 절감률과 콘텐츠 1건당 AI API 비용을 측정해 실제 업무효율과 경제성을 검증합니다.

## 주의
- 구독자 증가를 확정 효과로 기재하지 않음
- `전환 기회 확대` 또는 `향후 측정 가능`으로 표현
- 유료 콘텐츠를 추천 Ranking에서 우선하지 않음
