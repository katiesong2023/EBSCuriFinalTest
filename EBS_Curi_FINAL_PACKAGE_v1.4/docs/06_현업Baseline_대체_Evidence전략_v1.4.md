# 현업 Baseline 대체 Evidence 전략 v1.3

실제 담당자 인터뷰·월 처리량을 확보하지 못할 경우 내부 프로세스를 추정하지 않는다.

## Evidence A — 가능하면 확보
- CMS/등록 Field
- 담당업무
- 수작업 시간

## Evidence B — 반드시 확보
- 일반 VOD 공개 Metadata
- 교과연계 Clip 공개 Metadata
- 두 구조의 차이

## Evidence C — Controlled Benchmark
같은 교육과정 연계 Task 10~20건을:
- 수작업
- Curi 보조

로 비교.

보고:
- 평균
- 중앙값
- 범위
- 절감률

이를 ‘현재 EBS 실제 업무시간 절감’이라고 부르지 않고:
**동일 교육과정 연계 Task 기준 Prototype 보조효과**
라고 표현한다.

## 심사 답변 예

> 특정 부서의 월 처리량까지 확인한 것은 아닙니다. 대신 공개 Metadata를 비교하면 일반 방송 VOD는 프로그램·제목·방송일 중심이고, 학교용 교과연계 Clip에는 학년·교과·단원 정보가 별도로 존재합니다. Curi는 이 교육 Metadata 구조를 일반 Archive까지 확장할 때 필요한 Mapping을 자동화하는 Prototype이며, 동일 교육과정 연계 Task의 수작업 대비 효과는 별도 Benchmark로 측정합니다.
