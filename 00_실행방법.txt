EBS CURI — 다운로드 후 실행 방법

1. 준비물
- Node.js 24.18.0 이상과 npm
- 데스크톱 Chrome
- 인터넷: npm 설치와 EBS 영상 이용에 필요합니다.
- 기본 로컬 검색에는 API 키가 필요하지 않습니다.

2. ZIP 압축 풀기
GitHub 저장소에서 Code → Download ZIP을 누릅니다.
받은 ZIP을 한 번만 완전히 압축 해제합니다.
이 안내 파일과 package.json이 보이는 폴더가 실행할 프로젝트 폴더입니다.
ZIP 미리보기 안에서 실행하거나 public의 HTML을 더블클릭하지 마세요.

3. macOS에서 터미널 열기
① 터미널 앱을 엽니다.
② cd 다음에 공백을 한 칸 입력합니다.
③ 압축을 푼 프로젝트 폴더를 터미널로 끌어놓고 Enter를 누릅니다.
④ 아래 명령을 한 줄씩 입력하고 각 명령이 끝날 때까지 기다립니다.

node --version
npm --version
npm ci
npm start

4. Windows에서 터미널 열기
① 압축을 푼 프로젝트 폴더를 탐색기에서 엽니다.
② 탐색기의 주소 표시줄에 cmd를 입력하고 Enter를 누릅니다.
③ 열린 명령 프롬프트에서 아래 명령을 한 줄씩 입력합니다.

node --version
npm --version
npm ci
npm start

PowerShell에서 npm.ps1 실행이 차단되었다면 npm ci 대신 npm.cmd ci,
npm start 대신 npm.cmd start를 사용하면 됩니다.

5. 화면 열기
서버 실행 메시지가 표시되면 Chrome 주소창에 아래 주소를 입력합니다.

http://localhost:3000

서버를 실행한 터미널 창은 열어 두세요.
첫 검색은 자료 색인을 준비하므로 수십 초 걸릴 수 있습니다.
최초 대기는 최대 2분이며, 완료 전 검색 버튼을 반복해서 누르지 마세요.

6. 데이터 압축은 직접 풀지 않습니다
처음 npm start를 실행하면 포함된 압축 DB 4개를 검사하고 자동 복원합니다.
server/data/submission-seed 안의 .gz 파일을 직접 풀거나 옮길 필요가 없습니다.
이미 복원된 DB는 다시 시작할 때 덮어쓰지 않습니다.
개인 폴더·메모·구간은 브라우저에 저장되므로 같은 프로필/접속 주소를 사용하세요.

7. Chrome 확장 설치 — 영상 구간 기능을 쓸 때
① Chrome 주소창에 chrome://extensions 를 입력합니다.
② 개발자 모드를 켭니다.
③ 압축해제된 확장 프로그램을 로드합니다를 누릅니다.
④ 프로젝트 폴더의 extensions → curi-segments 폴더를 선택합니다.
   manifest.json이 바로 들어 있는 폴더여야 합니다.
⑤ 확장 아이콘을 도구 모음에 고정합니다.
⑥ http://localhost:3000/lesson.html 탭을 열어 둡니다.
⑦ 확장 아이콘을 누르고 EBS CURI 연결 주소를 http://localhost:3000 으로 맞춥니다.
⑧ EBS 원본 영상을 열고, 필요한 경우 로그인하여 본편을 직접 재생합니다.
영상별 이용 권한과 플레이어에 따라 구간 제어가 제한될 수 있습니다.
확장을 갱신했다면 확장 카드와 Curi/EBS 탭을 새로고침하세요.

8. 종료와 다음 실행
종료: 서버를 실행한 터미널에서 Ctrl+C를 누릅니다.
다음 실행: 같은 프로젝트 폴더에서 npm start만 실행하면 됩니다.
npm ci는 최초 설치 또는 의존성 변경 후에 실행하면 됩니다.

9. 실행이 안 될 때
- node 또는 npm 명령을 찾지 못함: Node.js 설치 후 터미널을 다시 엽니다.
- Node 버전이 낮음: 24.18.0 이상으로 설치합니다.
- package.json을 찾지 못함: 압축을 푼 프로젝트 폴더로 이동했는지 확인합니다.
- EADDRINUSE / 3000번 포트 사용 중: 이미 켜 둔 Curi 서버의 터미널에서 Ctrl+C로 종료하고 다시 시작합니다.
- 브라우저에서 연결할 수 없음: npm start가 실행 중인지와 주소를 확인합니다.
- 데이터 파일 손상 안내: GitHub에서 ZIP을 다시 받아 새 폴더에 풉니다. 기존 개인 DB를 임의 삭제하지 않습니다.
- 확장 연결 실패: 서버와 내 수업 탭을 열고 확장/Curi/EBS를 새로고침합니다.

세부 설치·확인 절차는 docs/INSTALL_AND_TEST_GUIDE.md에 있습니다.
GitHub에 올리는 것만으로 웹 서비스가 실행되는 구조는 아니며, 위 절차로 내 PC에서 실행합니다.
