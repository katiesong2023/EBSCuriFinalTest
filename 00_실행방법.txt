EBS CURI 실행 방법
==================================================

Windows 10/11 PC에서 프로그램 설치 없이 바로 실행할 수 있습니다.
(Node.js 설치, 명령어 입력, API 키 모두 필요 없습니다.)


■ 준비물
--------------------------------------------------
· Windows 10 또는 11 (64비트) PC
· Chrome 브라우저
· 저장 공간 3GB 이상


■ 1단계. 압축 풀기
--------------------------------------------------
1. 내려받은 ZIP 파일을 마우스 오른쪽 버튼으로 클릭합니다.
2. [모두 압축 풀기]를 선택합니다.
3. 압축이 풀린 폴더를 엽니다.

※ ZIP 파일을 연 상태(미리보기)에서 바로 실행하지 마세요.
※ 오류가 나면 폴더를 C:\Curi 처럼 짧은 위치로 옮겨 보세요.


■ 2단계. 실행하기
--------------------------------------------------
1. 폴더에서 CURI_START.cmd 파일을 찾아 실행합니다.
   (파일 확장자가 안 보이면 CURI_START로 표시됩니다.)

2. 검은 창이 열리고 준비가 시작됩니다.
   처음 한 번은 몇 분 걸릴 수 있습니다. 기다려 주세요.

3. 파란 경고창(Windows의 PC 보호)이 뜨면
   [추가 정보] → [실행]을 누릅니다.


■ 3단계. 화면 열기
--------------------------------------------------
1. 검은 창에 아래 안내가 나오면 Chrome을 엽니다.
   "Chrome에서 http://localhost:3000 을 여세요"

2. Chrome 주소창에 아래 주소를 입력합니다.

   http://localhost:3000

3. 검색창에 수업 주제를 입력해 봅니다.
   예) 광합성, 임진왜란, 탄소 중립

※ 첫 검색은 30초 정도 걸립니다. 버튼을 여러 번 누르지 마세요.
※ 검은 창은 사용하는 동안 닫지 마세요.


■ 종료하고 다시 쓰기
--------------------------------------------------
· 종료: 검은 창을 닫습니다.
· 다시 쓰기: CURI_START.cmd 파일을 다시 실행합니다.
  저장한 폴더·메모는 그대로 남아 있습니다.


■ (선택) 영상 구간 기능 쓰기 — Chrome 확장 설치
--------------------------------------------------
영상의 원하는 구간만 골라 보는 기능을 쓸 때만 필요합니다.

1. Chrome 주소창에 chrome://extensions 를 입력합니다.
2. 오른쪽 위 [개발자 모드]를 켭니다.
3. [압축해제된 확장 프로그램을 로드합니다]를 누릅니다.
4. 압축을 푼 폴더에서 extensions → curi-segments 폴더를 선택합니다.
5. 퍼즐 모양 아이콘을 눌러 Curi 확장을 고정합니다.
6. Curi 확장 아이콘을 누르고 연결 주소를 http://localhost:3000 으로 맞춥니다.

※ EBS 영상은 인터넷 연결과, 필요한 경우 EBS 로그인이 있어야 재생됩니다.


■ 잘 안 될 때
--------------------------------------------------
[검은 창이 바로 닫히거나 오류가 나요]
→ 검은 창에 나온 오류 문구를 캡처해서 담당자에게 보내 주세요.

[실행 라이브러리가 없다고 나와요]
→ 폴더에서 runtime → windows-x64 → vc_redist.x64.exe 파일을 찾아 실행해 설치합니다.
→ 설치 후 CURI_START.cmd 파일을 다시 실행합니다.

[3000번 포트가 사용 중이라고 나와요]
→ 이미 열려 있는 검은 창을 모두 닫고 다시 실행합니다.

[파일이 손상되었다고 나와요]
→ ZIP을 다시 내려받아 새 폴더에 압축을 풉니다.

[Chrome에서 페이지가 열리지 않아요]
→ 검은 창이 열려 있는지 확인합니다.
→ 주소가 http://localhost:3000 인지 확인합니다.

[회사 보안 프로그램이 실행을 막아요]
→ 보안 담당자에게 실행 허용을 요청합니다.


■ 알아두세요
--------------------------------------------------
· 검색은 내 PC 안에서만 처리되며, 외부 유료 AI를 사용하지 않습니다.
· 폴더·메모·구간은 지금 쓰는 Chrome에만 저장됩니다.
  다른 PC나 다른 브라우저에서는 보이지 않습니다.
· 데이터 압축 파일(.gz, .part)은 직접 풀지 마세요. 실행하면 자동으로 풀립니다.


■ Mac 또는 ARM 기반 Windows PC인 경우
--------------------------------------------------
CURI_START.cmd는 일반 Windows PC 전용입니다. 이 경우에는 아래처럼 실행합니다.

1. https://nodejs.org 에서 Node.js 24 버전을 설치합니다.
2. 압축을 푼 폴더를 마우스 오른쪽 버튼으로 클릭합니다.
   · Mac: [서비스] → [폴더에서 새로운 터미널]
   · Windows: [터미널에서 열기]
3. 열린 창에 아래 두 줄을 한 줄씩 입력하고 Enter를 누릅니다.

   npm ci
   npm start

4. Chrome에서 http://localhost:3000 을 엽니다.

자세한 설명은 docs/INSTALL_AND_TEST_GUIDE.md 파일을 참고하세요.
