# 전체 콘텐츠의 은유 표현 검색 제외 — 2026-10-15

전체 콘텐츠/판본의 제목·소개문에 공통 은유·비교 검사를 적용했다. 검출하거나 보류한 표현은 일반 단어·개념 태그·지리 후보·관련순·검색 이유·로컬 문장 유사도의 검색 근거로 사용하지 않는다. 원문을 삭제하지 않으며 같은 자료에 별도로 있는 실제 내용 설명은 유지한다. 사용자 결과 확인 전 R12-03은 진행중이다.

## 범위와 구현

- `server/source-literal.js`: 원문과 같은 길이의 검색용 문자열과 제외 범위/사유를 만든다. 신체·자연·사물의 관용 은유, 경제적 먹이사슬, 바다의 우유, 살아 있는 화석, 경쟁의 전쟁, 명시적 비유/상징·비교 표지를 검사한다. 비교의 대상 전체를 은유로 확정하지 않고 차용한 어휘를 문자 그대로의 근거로 보류한다.
- 제목의 단어가 소개문에서 비유로만 쓰였으면 제목 일치도 보류한다. 별도 실제 설명이 있으면 그 설명을 근거로 검색한다. 예: 제목 ‘모래시계’/소개 ‘시간은 모래시계처럼 흐른다’는 모래시계 검색에 쓰지 않지만 실제 제작 설명은 남긴다. ‘심장은 펌프처럼 혈액을 보낸다’에서 심장은 보존한다.
- `keyword-context.js`·`content-keywords.js`·`semantic-layer.js`: 같은 검색용 소개문으로 등록 개념과 내용 어휘를 판단한다. 기존 분야 문맥 검사도 유지하며 규칙 버전은 `2026-10-15.1`이다. 원문 인용 위치와 문장 표시는 원문 기준이다.
- `discovery-search.js`·`discovery-genre.js`·`search-geographic-scope.js`·`request-content-plan.js`·`request-relation-evidence.js`·`request-clauses.js`: 후보/선호/형태/관계·제외 대조에 같은 범위를 적용한다. 교사 화면·구조화 요청 대조·검색 이유/우선 인용도 공통 검사로 연결한다.
- `broadcast-semantic-index.js`: 현재 원문의 제외 범위와 겹치는 기존 임베딩 구절은 순위/후보 근거로 채택하지 않는다. 원문 벡터를 은유 없는 내용 벡터로 재학습한 것은 아니며 SQLite 원본을 수정하지 않았다.
- `candidate-review.js`·`request-model-preparation.js`·`semantic-context.js`: 기존 API 준비 입력에 제외 범위/해석 지시를 전달한다. 자기회차 은유 구절을 직접 인용해 차용한 소재의 MATCH로 되살리는 응답은 거절한다. 실제 API 호출은 없다.

## 남은 한계

검사는 명시적 문법과 관용 표현에 근거한다. ‘처럼’이 있는 실제 유사 사례도 해당 어휘만 보류할 수 있으며, 같은 자료의 별도 실제 설명은 유지한다. 표지 없는 새로운 은유·긴 담화/화자의 의도를 전부 판별하는 의미 모델은 구현하지 않았다. 따라서 **모든 암시적 은유의100% 탐지/차단 완료를 뜻하지 않는다.** 향후 API 내용 검토에서는 이러한 모호한 구절을 자기회차 원문과 실제 소재 설명으로 대조하고 UNKNOWN을 보존해야 한다.
