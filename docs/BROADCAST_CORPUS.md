## 수집 경로와 재실행

- 다큐프라임: 기존 공식 시리즈 목록의 `newReplayList`에서 개별 `vodReplayView` 전개.
- [지식채널e 공식 다시보기](https://jisike.ebs.co.kr/jisike/replayListNew?c.page=1): 페이지 이동·공식 제목·소개문·회차 URL 수집.
- [기행 통합 공식 목록](https://home.ebs.co.kr/worldtrip/replay): 공개 `vodSearchList` 폼의 페이지·프로그램 조건으로 회차 수집. 설악·김제·평야·지평선·한라산·해안은 추가 검색.
- 목록 체크포인트 706개. 첫 대량 수집은 699 요청, 약 4분 16초에 5,522 ID 확보. 이후 지형 검색·상세 대조로 26 ID를 추가했다. 최초 결과는 `broadcast-collection.json`, 마지막 상세 재대조 결과는 `broadcast-enrichment.json`이다. 마지막 파일의 10요청은 200건 전체 대조 비용이 아니다.
- 공개 HTML만 요청한다. 영상·자막 다운로드, 로그인, 유료 LLM 호출은 없다. 호스트별 요청 간격 1.1초, 401/403/429 시 해당 호스트 중단, 실패 재시도는 최대 2회다.

제품 실행에는 Node.js 기본 SQLite만 사용한다. 수집·브라우저 검증은 별도 Playwright와 Chromium 설치 환경에서 실행하며 `CURI_PLAYWRIGHT_MODULE`로 설치된 모듈 경로를 지정할 수 있다.

```bash
# 기존 설치된 Playwright 모듈이 없다면 수집용 도구를 먼저 설치한다.
# 제품 실행 및 이미 확보한 데이터 검색에는 필요하지 않다.
npm run data:broadcast:collect -- --target=10000 --max-pages=1200
npm run data:broadcast:collect -- --refresh --max-pages=90
npm run data:broadcast:collect -- --enrich=200 --max-pages=250
npm run data:broadcast:check
```

기본 실행은 완료 목록을 건너뛰고 이전 지점에서 이어간다. 신규 게시물 확인은 `--refresh`로 앞쪽 페이지부터 재조회한다. 목표 건수는 기본 5,500으로 이미 충족되어 있으므로 과거분 확대 시 목표를 높인다. 요청 상한 도달 시 작업을 마치고 다음 실행에서 이어간다. 일일 자동 예약은 아직 연결하지 않았다. 목록 일부 실패·빈 결과로 기존 회차를 삭제하지 않는다.

회차 키는 `EBS:courseId:lectId`, 콘텐츠 ID는 그 해시다. 제목만 같은 다른 ID는 DB에서 합치지 않는다. 소개문이 없는 재수집은 기존 본문을 지우지 않고, 제목·주소 변경 시 기존 도착 대조를 무효화한다. 프로그램·제목 그룹은 화면 표현이며 승인·동일 영상 판정이 아니다.

## 검색 반영과 측정

`/` 및 `/api/curi/discover`는 새 DB를 함께 읽는다. 파일 변경을 감지해 카탈로그 캐시를 갱신하며 검색 중 외부 사이트·유료 모델에 접속하지 않는다. SQLite FTS 색인은 적재 시 생성하지만 현재 제품 질의는 캐시된 메모리 카탈로그에서 처리한다. 한국어 검색을 FTS 성능으로 표현하지 않는다.

| 확인 항목 | 확대 전 | 확대 후 |
| --- | ---: | ---: |
| 동고서저 결과 | 4 | 9 (일반방송 7·클립 1·짧은 강의 1) |
| 동고서저 개별 도착 대조 결과 | 1 | 8 |
| 수업 핵심어로 후보가 있는 시나리오 | 23/30 | 27/30 |
| 요청 문장 그대로 후보가 있는 시나리오 | 14/30 | 14/30 |
| 핵심어에 개별 페이지 대조 후보가 있는 시나리오 | 18/30 | 22/30 |
| 핵심어 전체 결과의 고유 자료 | 31 | 154 |

민주주의 8건, 기후 변화 8건, 화산 지형 15건, 해안 지형 1건이 나온다. 결과 존재는 관련성·정답률·교사 만족도 판정이 아니다. 지명만 같은 음식 방송은 동고서저 관계에서 제외한다. 장소와 지형 표현이 함께 있는 공식 텍스트를 근거로 삼는다.

설악산·김제 기존 모음 ID는 유지하고 [설악산 실제 회차](https://home.ebs.co.kr/worldtrip/replayView?siteCd=KH&courseId=BP0PAPD0000000022&stepId=01BP0PAPD0000000022&lectId=10295175), [김제 실제 회차](https://home.ebs.co.kr/worldtrip/replayView?siteCd=KH&courseId=BP0PAPD0000000022&stepId=01BP0PAPD0000000022&lectId=3054984)로 이동을 갱신했다. 이미 내려받은 파일은 자동 수정되지 않으므로 새로 내려받아야 한다.

상세 대조 전의 공식 목록 제공 링크는 `PUBLISHED`, ID·제목을 대조한 링크는 `MATCHED`다. 화면의 ‘개별 페이지가 확인된 자료만’은 후자만 보여준다. 5,548개 모두 재생 검증했다고 표시하지 않는다.

500/2,000/5,000건의 실제 수집물 재적재·FTS 색인과 메모리 검색 30회 측정은 [broadcast-simulation.json](broadcast-simulation.json)에 있다. 임시 메모리 DB 측정이므로 네트워크 수집·디스크 영속화·브라우저 표시 시간과 구분한다. 전체 검색 로컬 지연은 [local-simulation.json](local-simulation.json), 화면 검증은 [local-browser-simulation.json](local-browser-simulation.json)을 따른다.

## 1차 마감 범위

실제 수집·로컬 검색·출처 이동·모음·메모 내보내기는 구현했다. 긴 문장 해석, 부족한 소개문과 해안 사례, 프로그램 다양성 확대는 후속 기술 과제다. 실제 장면·학년 적합성·교육과정 승인·교사 효용은 사용자 요청에 따라 마지막 사람 판단 단계로 남긴다. 유료 API 기본 차단과 기존 승인 이력은 유지한다.
