# Curi 제출용 핵심 설명 — 트랙1

작성일: 2026-10-16 · 상태: 초안 작성·사용자 문안 확인 대기

현재 구현의 근거는 [개발 정리](CURI_DEVELOPMENT_SUMMARY.md), 작업 상태는 [PLANS](PLANS.md)를 따른다. 이 문서는 보고서·시연의 설명 문안이며 새 기능 구현이나 현장 효과 측정 결과가 아니다. 검색 보충 실험은 이번 설명 정리의 범위에서 제외한다.

## 1. 설명의 중심

**EBS 콘텐츠를 찾아, 교육과정과 연결하고, 수업에 쓸 구간까지 준비하는 Curi.**

교사의 수업 준비를 대표 사용 장면으로 보여주고, 이를 뒷받침하는 EBS 교육 메타데이터 구축·근거 관리 구조를 설명한다. 담당자의 메타데이터 관리와 교사의 자료 활용이 연결되는 것이 서비스의 핵심이다.

## 2. 과제명과 한 문장 소개

### 과제명

**Curi — 2022 개정 교육과정 기반 EBS 교육 메타데이터 구축·활용 Agent**

기존 과제명을 유지한다. 아래 설명 문구는 보고서 첫 장·영상 도입에 사용할 수 있다.

**EBS 콘텐츠를 수업 자료로 연결하는 교사 수업 준비 도구**

### 한 문장 소개

> Curi는 EBS 콘텐츠의 공개 메타데이터와 공식 교육과정을 활용해, 교사가 수업 주제에 맞는 자료를 찾고 교육과정·메모·영상 구간을 수업 폴더에 정리하도록 돕는 Agent 서비스입니다.

## 3. 누구의 어떤 문제를 해결하는가

### 주요 이용자: EBS 콘텐츠로 수업을 준비하는 교사

교사는 주제에 맞는 영상을 찾은 뒤 소개와 원문을 읽고, 교육과정과의 연결을 판단하고, 실제로 사용할 장면을 확인해야 한다. 다음 수업에 다시 쓰려면 영상 링크뿐 아니라 선택 이유와 구간도 기억하거나 별도로 정리해야 한다.

Curi는 이 과정을 자료 탐색, 원문 확인, 교육과정 연결, 수업 폴더 저장, 구간 구성의 흐름으로 연결한다. 최종 자료 선택과 수업 적합성 판단은 교사가 한다.

### 운영 이용자: EBS 교육 메타데이터·콘텐츠 관리 담당자

콘텐츠의 공개 제목·소개문만으로는 교육과정과의 연결을 충분히 설명하기 어려운 경우가 있다. 연결 후보를 만들더라도 어떤 원문을 근거로 했는지, 사람이 확인했는지, 원문 변경 후에도 유효한지 관리할 필요가 있다.

Curi는 교육과정 연결 후보와 원문 근거·판본·검사 상태를 보존하고, 담당자가 검토·수정·승인하거나 오류·변경을 재점검하는 경로를 제공한다. 이 관리 구조를 교사의 자료 탐색·활용과 연결한다.

위 내용은 제품이 대상으로 삼는 작업과 문제다. 특정 EBS 부서의 현행 업무 절차·업무량을 현장 조사로 확인했다는 의미는 아니다.

## 4. Agent가 수행하는 일과 사람이 결정하는 일

| 단계 | 현재 시스템의 역할 | 사람의 역할 |
| --- | --- | --- |
| 원천 정리 | 공개 회차 정보와 공식 설명을 수집·정리하고 출처·변경 이력 보존 | 원천 정보와 이용 범위 확인 |
| 자료 탐색 | 주제·질문의 내용과 조건을 로컬 규칙으로 해석하여 관련 후보·원문 제공 | 실제 활용할 자료 선택 |
| 교육과정 연결 | 공식 기준과 콘텐츠 표현을 대조해 연결 후보와 확인 가능한 근거 제공 | 요구 충족·학년·장면 적합성 판단, 필요 시 연결 수정 |
| 자료 축적 | 자동 검사 결과와 검토 상태를 보존하고 재사용 경로 제공 | 담당자의 선택적 관계 검토·승인 |
| 수업 구성 | 폴더·메모·교육과정·시간 구간·활용 순서 저장과 재열기 지원 | 수업 목표·선택 이유·사용 구간·활용 순서 결정 |

현재 핵심 탐색·연계는 원문·편집 어휘·로컬 규칙 기반이다. LLM이 모든 영상의 내용을 이해하거나 교사의 교육적 판단을 자동으로 완료하는 서비스로 설명하지 않는다. 구간 저장·폴더 정리는 웹·확장의 지원 기능이며 그 자체를 AI 추론 성과로 제시하지 않는다.

## 5. 차별성

### 교육과정과 원문 근거를 함께 제공

콘텐츠를 살펴보면서 공식 성취기준을 연결하고, 연결 후보를 판단할 원문을 확인할 수 있다. 공식 기준 확보, 표현 기반 후보, 자동 검사, 실제 사람 확인의 수준을 구분한다.

### 찾은 자료를 수업 단위로 축적

선택한 영상을 수업 폴더에 담고 교육과정·선택 이유·메모를 함께 보관한다. 같은 영상도 수업마다 다른 활용 기록을 남길 수 있다.

### 원본 영상의 활용 구간까지 구성

Chrome 확장에서 사용할 시간 구간을 지정하고 수업 영상 리스트의 순서와 합계 시간을 정리한다. 영상은 EBS 원본에서 이용하며, 파일을 잘라 별도 영상으로 제공하는 기능은 아니다.

### 운영 근거와 개인 활용 기록을 구분

원문·판본·자동 검사·담당자 검토 이력을 관리하면서 교사의 개인 저장과 공용 승인을 분리한다. 자료를 개인 폴더에 담았다는 이유로 검증 자산이나 승인 관계가 되지 않는다.

위 내용은 구현상 특징이다. 경쟁 서비스 전수 비교나 국내 최초·유일성을 검증한 주장이 아니다.

## 6. 보고서용 프로젝트 개요

> Curi는 EBS 콘텐츠의 교육 메타데이터 구축과 교사의 수업 준비를 연결하는 Agent 서비스 MVP입니다. 공개된 회차 정보와 공식 교육과정을 바탕으로 수업 주제에 맞는 자료와 교육과정 연결 후보, 원문 근거를 제공합니다. 교사는 선택한 자료를 수업 폴더에 담고 교육과정·메모·활용 구간과 순서를 정리할 수 있습니다. 관리자는 원문과 자동 검사·검토 상태를 확인하고 연결 관계를 관리합니다. 현재 로컬 웹과 Chrome 확장으로 구현했으며, 실제 교사의 시간 절감·반복 사용 효과는 후속 현장 검증 과제입니다.

## 7. 영상 도입·발표용 설명

다음 문안은 약 30~40초를 목표로 한 초안이다. 최종 영상 길이는 실제 낭독 후 확인한다.

> EBS 영상을 수업에 쓰려면 주제에 맞는 회차를 찾고, 교육과정과 연결하고, 필요한 장면을 다시 확인해야 합니다. Curi는 이 준비 과정을 하나로 연결합니다. 수업 주제로 자료를 찾고 원문을 확인한 뒤, 교육과정과 메모를 수업 폴더에 저장합니다. Chrome 확장에서는 사용할 구간을 지정해 수업 순서로 구성할 수 있습니다. 콘텐츠의 근거와 활용 기록을 쌓아 다음 수업에서도 재사용하도록 돕는 것이 Curi의 목표입니다.

도입 뒤에는 **자료 찾기 → 원문 확인 → 교육과정 선택·폴더 저장 → 구간 지정 → 수업 영상 리스트 재열기**를 대표 동선으로 보여준다. 관리자의 연결 근거·검토 상태는 해당 흐름을 뒷받침하는 운영 화면으로 짧게 설명한다. 구체 회차·검색어·촬영 분량은 다음 시연 준비 단계에서 확정한다.

## 8. 트랙1의 업무 개선 효과 설명

> 기대하는 개선은 자료 탐색, 교육과정 대조, 활용 장면 기록을 연결하여 수업 준비의 반복 작업을 줄이는 것입니다. EBS에는 교육 메타데이터와 연결 근거를 축적·관리하는 기반을, 교사에게는 선택한 영상과 구간을 수업 단위로 재사용하는 도구를 제공합니다. 현재는 기능 동작과 원문·인용·저장 정합성을 검증했으며, 현장 도입 효과는 실제 교사의 자료 선택·수업 준비시간·반복 사용과 담당자의 검토시간을 측정하여 확인할 계획입니다.

보고서에는 기존 기술 검증과 비용을 해당 표본·버전과 함께 제시한다. 시간 절감률·교육적 정확도·이용 증가율은 실측 전 수치로 제시하지 않는다.

## 9. 현재 구현과 향후 확장의 표현

| 구분 | 제출물에서 사용할 설명 |
| --- | --- |
| 현재 구현 | 로컬 웹의 자료 탐색·교육과정 연결·내 수업 자료, Chrome 확장의 지원 영상 구간 저장·재생 제어, 관리자 자료·품질 관리 |
| 현재 제약 | 개인 자료의 브라우저별 저장, 지원 플레이어·로그인·탭 연결 의존, 검색 누락·후보 적합성 확인 필요 |
| 현재 확인 수준 | 기술 검사·제한된 실제 영상 재생 기록 보유, 실제 교사 효용·시간 절감 미측정 |
| 향후 확장 | 교사 계정·서버 저장·기기 간 동기화, 권한 협의를 거친 EBS 공식 인증·메타데이터 연동 |

자동 후보 전체를 사람 검수 완료로 표현하지 않는다. 현재 사람 승인 자산은 0건, 별도 자동 공개는 1건이며 과거 승인·취소 이력과 구분한다. 세부 현황과 확장 문안은 [개발 정리](CURI_DEVELOPMENT_SUMMARY.md), [향후 확장 과제](SUBMISSION_FUTURE_EXPANSION.md)를 따른다.
