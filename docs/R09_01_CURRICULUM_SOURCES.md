# R09-01 공식 성취기준 확보·중1 편성 참고

2026-10-10에 저장소의 교육부 고시 제2022-33호 사회과·과학과 PDF를 대조했다. 추가 성취기준 **136개**를 별도 적재 파일에 작성했다. 이 파일의 작성은 기존 승인 자산이나 방송 자료의 교육과정 관계 승인이 아니다.

| 이용 과정 | 교과 | 성취기준 | 공식 범위 | 원문 PDF 쪽 / 인쇄 쪽 |
| --- | --- | ---: | --- | --- |
| 초등 3~4 | 사회 | 22 | `4사01-01`~`4사10-02`, 10단원 전체 | 25~33 / 19~27 |
| 초등 3~4 | 과학 | 51 | `4과01-01`~`4과16-03`, 16단원 전체 | 19~31 / 13~25 |
| 중1 참고 | 사회 | 37 | `9사(지리)01~06` 19개·`9사(일사)01~06` 18개 | 46·48~52·61~66 / 40·42~46·55~60 |
| 중1 참고 | 과학 | 26 | `9과01~07`, 7단원 | 46~52 / 40~46 |

모든 기준의 개별 코드·본문·단원·PDF 쪽·인쇄 쪽은 [적재 파일](../server/data/curriculum-expansion.json)에 있다. 기존 초등 5~6학년 78개와 합치면 214개다. 실제 저장소 적재·검색·화면 확인은 이 출처 확보 작업과 별도 단계다.

## 공식 원문과 판본

- [사회과 교육과정](../[별책7]%20사회과%20교육과정.pdf), SHA-256 `a852e8da3e6aea7d1c95690dcae140be02e014b779ac2e5cc0801200cfb16923`
- [과학과 교육과정](../[별책9]%20과학과%20교육과정.pdf), SHA-256 `0cf53427691d54366d6805767c428a15b0e817580807b4354947de7e3b58b738`

PDF의 구간 제목은 `초등학교 3~4학년`, `중학교 1~3학년`이다. 앱의 `gradeBand`에는 `3~4학년군`, `1~3학년군`을 사용하되, 실제 PDF 제목은 `officialGradeLabel`에 별도로 보존했다. 중1 참고 편성은 공식 중학교 학년군을 변경하지 않는다. 중학교 전체 성취기준을 중1로 적재하지 않았다.

## EBS 참고 편성과 한계

중학교의 기준별 `placement`에는 교재·개념 강좌 ID, ISBN, 공식 URL, 개정판, 대상 학년, 단원, 강의 구간, 확인일, 참고 편성 버전을 기록했다. 사회 12개·과학 7개 단원의 내용과 공식 단원의 대응을 확인했다.

- 사회: [뉴런 사회① 교재](https://ebook.ebs.co.kr/sub/middle/view?ebkId=EB100001989&prodClsCd=24&txbkId=TB1000012109), [개념 강좌](https://mid.ebs.co.kr/course/view?courseId=100006171). 교재 권장 대상 1학년, 강좌 대상 1·2학년. 지리 1~6단원과 일반사회 1~6단원만 포함한다.
- 과학: [뉴런 과학1 교재](https://book.ebs.co.kr/sub/middle/view?ebkId=EB100001990&prodClsCd=24&txbkId=TB1000012107), [개념 강좌](https://mid.ebs.co.kr/course/view?courseId=100006176). 교재와 강좌 모두 대상 1학년, 과학 1~7단원만 포함한다.

`REFERENCE_MAPPED`는 EBS 단원·강의 내용과의 참고 대응이다. 모든 기준의 수행 요구가 강의에서 충족되었다거나 개별 학교에서 중1에 가르친다는 판정이 아니다. 학교별 배치 확인은 전부 `schoolPlacementConfirmed:false`다. 각 기준은 `SOURCE_CHECKED`·`humanConfirmed:false`이고, 방송의 사람 승인·자동 연계 통과·학년 적합성은 부여하지 않았다. 공식 본문 대조가 미해결인 기준은 없으며, 학교별 배치는 미확인으로 남긴다.

## 추출·대조 방법

1. PDF의 문서 SHA-256을 먼저 고정했다. 단원 제목 뒤의 성취기준 본문만 추출하고 성취기준 해설, 탐구 활동, 적용 시 고려 사항은 합치지 않았다.
2. `pypdf 6.20.0`과 `pypdfium2 5.14.0`의 코드 집합 및 공백을 제외한 본문 글자열을 136개 전부 비교했다.
3. pypdf에서 자간 때문에 발생하는 `소 통 할 수 있 다` 등의 허위 공백은 PDFium의 내부 띄어쓰기를 사용해 처리했다. PDFium이 줄 끝에서 생략하는 단어 경계 공백은 pypdf의 줄 끝 공백으로 보완했다. 원 추출문은 `rawExtractedText`에 남겼다.
4. 초등 사회 첫 두 기준의 원문 코드 `4사01–01`, `4사01–02`에 있는 en dash를 식별자에서만 ASCII hyphen으로 바꾸고 `originalStandardId`에 원 표기를 남겼다. 중학 사회의 `(지리)`·`(일사)`를 유지했다.
5. 성취기준 상자 45개를 PDF에서 렌더해 코드·본문을 전수 시각 대조했다. 페이지 머리말의 인쇄 쪽과 1부터 시작하는 PDF 쪽도 대조했다.
6. 기준별 내용 지문은 UTF-8 `코드 + 줄바꿈 + 정규화 본문`의 SHA-256이다. `fingerprintMethod`는 `sha256-code-newline-text-v1`이며, PDF 전체 지문과 별도로 보존한다.

기준 수 136개, ID 중복 0개, 엔진 간 글자 불일치 0개, 미해결 원문 0개, 중1 참고 편성 누락 0개다. 본문 내용의 다른 표현으로의 교정·요약은 수행하지 않았다.

## 재현 명령

[재현 스크립트](../server/curriculum-expansion-source.py)는 원본 PDF와 적재 파일만 읽어 대조하며 `curi-store.json`을 읽거나 쓰지 않는다.

```sh
python3 -m pip install pypdf==6.20.0 pypdfium2==5.14.0
python3 server/curriculum-expansion-source.py --check
```

JSON을 새로 만들려면 `--check` 대신 `--write`를 사용한다. `--render-dir /private/tmp/r09-curriculum-render`를 덧붙이면 성취기준 상자 이미지를 출력한다. 검증 때는 임시 의존성 경로를 사용했다.

```sh
PYTHONPATH=/private/tmp/r09-pdf-deps python3 server/curriculum-expansion-source.py --check
```


## R07-10 보강 원문 — 2026-10-11

사용자가 추가한 `[별책3] 중학교 교육과정.hwp`는 교육부 고시 제2022-33호 총론·중학교 교과 교육과정 합본이다. SHA-256: `6ec3f748f176322c4437659fee3716287642a8931ac1a7b257a371f669e49bfc`. HWP5 문단 텍스트로 현재 중1 참고63기준(사회37·과학26)의 코드와 본문을 대조했다. 중학교 전체 기준을 새로 적재하지 않았다.

총론 추출 문단209(학년군별 지도 순서/비중 조정),341(학년별·학기별 수업 시수 자율 편성),342(3년간 이수 교과의 학년/학기 편성과 안내)를 공식 편성 설명에 연결했다. 위치는 추출 문단 번호이며 인쇄 쪽 번호와 다르다. 공식 중1~3 학년군과 EBS 뉴런 중1 참고를 구분하며 특정 학교 배치는 확인하지 않는다.

기존 별책7/9 PDF와 추가 HWP에서 214기준·73단원의 해설/적용 시 고려 사항을 생성했다. 개별 해설171·별도 해설 없음43, 단원별 고려 사항은214기준 전체에 연결된다. PDF는 pypdf의 쪽별 배열과 pypdfium의 띄어쓰기를 비공백 문자 단위로 대조하며 원문 파일 SHA·발췌 위치를 보존한다. 대응은 원문 코드와 본문의 일치로 결정하며 코드만으로 대체하지 않는다. HWP는 레이아웃 복원이 아니라 문단 추출이다.

`server/data/curriculum-guidance.json`과 [R07-10 작업/검증](../Tasks/task-r07-10-curriculum-guidance.md)에 보강 결과를 기록했다. 안내는 교사의 공식 요구·영상 인용 비교를 돕는 문서 근거이며 자동 규칙 추가·영상 학년 적합성 확인·사람 승인 근거가 아니다. 기존 R09-01 출처 및 뉴런 편성 기록은 보존한다.
