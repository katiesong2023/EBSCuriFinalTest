# R12-07 수업용 구간 북마크 구현 기록

2026-10-14 사용자 진행 요청으로 Chrome 확장 프로그램과 Curi 개인 구간 기능을 구현했다. 상태는 **진행중**이다. 설치 가능한 산출물과 로컬 기능 검증은 준비했으며 사용자 Chrome에 확장을 설치한 뒤 실제 두 회차의 저장→재열기→시점 이동→끝 정지를 확인하는 단계는 남아 있다.

**최신 상태:** Chrome 설치와 두 회차 재생 확인은 아래 후속 기록에서 완료했다. 이후 사용자 요청으로 별도 구간 페이지를 제거하고 내 수업 폴더에 통합했다. 현재 연결 대상은 `lesson.html`이며 확장0.2.0 실제 저장 안내를 확인했으며 사용자 통합 화면 결과 확인을 대기한다. 아래 초기 산출물 경로는 당시 기록이다.

## 산출물과 사용 흐름

- 설치 원본: `extensions/curi-segments/`. Manifest V3, 확장 팝업·연결·플레이어 제어를 각각 분리했다.
- 설치 ZIP: [curi-segments-extension.zip](../public/downloads/curi-segments-extension.zip). `node server/package-segment-extension.js`로 공통 시간/회차 계약을 복사하고 설치 파일만 묶는다. 개인 자료·API 키·영상 파일은 포함하지 않는다.
- Curi 화면: `/segment-bookmarks.html`. 내 자료·수업 폴더의 영상 아래 ‘수업용 구간’에서 연다. 구간 추가·시간/이름/메모 편집·삭제·원본 링크·설치 안내를 제공한다.
- 확장 팝업: Curi 주소 설정/연결→현재 영상과 개인 자료/폴더 대조→시작·끝 지정/직접 수정→구간 이름·메모→명시적 Curi 저장.
- 재사용: Curi에서 ‘저장 구간 보기’→지원 회차 열기→플레이어 준비/본편 식별→시작 시점 이동/재생→끝 일시정지. 실제 재생 상태는 EBS 위 확장 안내에서 표시한다. 자동 재생 제한 시 직접 재생을 안내한다.

## 첫 어댑터와 실제 조사

대상은 `jisike.ebs.co.kr/jisike/vodReplayView`의 `#mediaplayerWrap .mpv-device video`다. 주소의 courseId/stepId/lectId와 공개 `vodCommonIDs`, 현재 미디어 경로와 그 회차의 공개 품질 소스, 해당 품질의 본편 접근 상태를 대조한다. 다른 회차 연속재생·광고·미리보기·준비되지 않은 영상은 보류한다. 공개 선언을 실행하거나 인증/미디어 접근 제한을 우회하지 않는다. 서명된 미디어 쿼리나 계정 정보는 북마크에 저장하지 않는다.

Chrome의 실제 EBS 페이지에서 다음을 읽기 전용으로 확인하고 일반 재생/일시정지 버튼을 조작했다.

| 실제 회차 | lectId | 전체 길이 | 확인 |
| --- | --- | --- | --- |
| 지구의 자전 속도가 느려지는 이유 | 20349287 | 247.786667초 | 영상 요소1개·시간 진행·본편 품질 소스·회차 선언·일시정지 |
| 다윈의 예언 | 20349297 | 252.522667초 | 영상 요소1개·시간 진행·본편 품질 소스·회차 선언·일시정지 |

두 페이지의 구조 호환 조사이며 **확장 프로그램이 실제 EBS 영상을 지정 시점으로 이동하거나 끝에 정지한 검증은 아니다**. 그 확인 전 첫 어댑터의 실제 지원 확정을 완료 처리하지 않는다. 다른 EBS 플레이어는 지원하지 않는다.

## 개인 저장과 연결 경계

구간은 Curi 주소의 `curi.teacher.segments.v1`에 `{revision, records}`로 저장한다. 레코드는 id/resourceId/folderId/sourceUrl/variant/name/note/start/end/duration/capture/player/createdAt/updatedAt이다. folderId 빈 문자열은 내 자료, 폴더 ID는 그 폴더의 독립 구간이다. 자료를 폴더에 담는 것만으로 내 자료 구간을 복사하거나 기존 폴더 구간을 변경하지 않는다. 기존 자료/폴더 키와 개인 이유/승인/원본 DB는 수정하지 않는다.

확장 프로그램에는 정확한 Curi 주소와 회차별 입력 draft만 저장한다. 실제 저장은 지정 Curi 주소의 구간 화면에서 현재 개인 자료와 서버의 원본 ID·회차 URL·제목·판본을 다시 대조한 후 실행한다. 실패 시 입력을 유지하며 동일 ID/내용 재시도는 중복으로 추가하지 않는다. 저장 revision이 달라지면 편집 충돌로 멈춘다. 연계 제안·교육과정 승인·자동 공개 경로와 연결하지 않는다.

Chrome host 권한은 지식채널e와 localhost/127.0.0.1이다. 연결 주소는 그중 사용자가 설정한 정확한 origin/포트 한 개로 제한한다. HTTP 로컬 Curi만 첫 버전에서 지원한다.

## 검증 결과와 남은 확인

- `node server/segment-bookmarks-check.js`: **25개 통과**. 시간/회차/주소 검증·독립 저장·중복/충돌·저장 실패·손상 보호·내보내기, 합성 플레이어의 시작 이동/끝 정지/광고·다른 영상 거절, 서비스워커의 잘못된 origin/포트·입력 거절과 명시 IMPORT/회차 전달을 확인했다. [기록](r12-07-segment-check.json). 합성 플레이어·모의 Chrome API 검사다.
- 실제 Curi 서버의 별도 `127.0.0.1:43127` 주소에서 실제 자료1건을 담고 잘못된 끝 시간 거절, 0초 시작 구간 저장, 새로고침 유지, 시간 수정, 내 자료 표시, 미설치 시 오류/원본 안내, 폴더별 독립 구간과 구간 화면을 확인했다. 테스트 개인 기록은 이 별도 주소에만 있다.
- [실제 저장/설치 안내 화면](r12-07-segment-screen.png)을 저장했다. 변경 JavaScript13개 구문·manifest 참조·공통 계약 복사 동일성·화면 스크립트 로드 순서와 diff 공백 검사를 통과했다. 설치 ZIP은 명시한9파일만 포함한다.
- 추가 실행한 `node server/teacher-workspace-check.js`는 52행의 시간/학년/자막 경고 조건에서 실패했다. 앞선 목록/천문 경계/조건 보존 항목은 진행했으나 전체 통과로 기록하지 않는다. 이 검사는 새 구간 모듈을 호출하지 않는 기존 서버 검색 검사다. 이번 task는 해당 검색 해석 파일을 수정하지 않았으며 작업 시작 전부터 존재한 별도 검색 변경은 보존했다. 구간 검사25통과와 이 실패를 분리하고 전체 회귀 통과를 주장하지 않는다.
- 내 자료·수업 폴더 내보내기에 구간 이름·시작/끝·공식 회차 링크·메모를 포함했다. 파일 내보내기의 공통 출력은 기능 검사로 확인했으며 실제 브라우저 파일 다운로드/내용 대조는 사용자 결과 확인에 남긴다.
- 구간 끝 정지는 프레임 단위 편집이 아니며 브라우저 미디어 이벤트/타이머의 영향을 받는다. 실제 시점 오차와 백그라운드 탭 동작은 확장 설치 후 측정한다.
- 유료 API·영상 다운로드·클립 추출·스토어 공개 배포는 수행하지 않았다. 실제 교사 효용·교육과정 의미 정확도를 새 성과로 기록하지 않는다.

## 설치 후 확인

[설치 안내](../extensions/curi-segments/README.md)를 따라 Chrome에 로드한다. EBS와 Curi 페이지를 새로고침해야 새 content script가 연결된다. 먼저 지식채널e 자료를 같은 Curi 주소의 내 자료/폴더에 담고 확장 팝업에서 정확한 Curi 주소를 설정한다. 두 실제 회차에 서로 다른 구간을 저장하고 Curi에서 재열기해 실제 이동/정지 시각과 지정 시각의 차이를 기록한다. 설치·재생이 확인되기 전 task의 해당 확인 체크를 완료 처리하지 않는다.

## 사용자 Chrome 설치·실제 연결 — 2026-10-14

사용자가 직접 설치했고 Chrome 도구 모음과 실제 팝업에서 설치/시간 읽기를 확인했다. `http://localhost:3000`의 내 자료에 두 실제 회차를 연결하고 확장 프로그램의 명시 저장을 확인했다. ‘자전 속도’는 사용자가 지정한 이름과 47.995~83.230초를 유지했다. ‘다윈 · 구간 재생 확인’은 실제 본편에서 25.000~45.549초를 지정해 저장했다. 두 기록 모두 Curi에 ‘플레이어에서 지정’으로 반영됐다.

첫 회차 재열기에서 실제 currentTime=47.995초·paused=true로 시작 이동을 확인했고 자동 재생 제한 안내 후 직접 재생했다. EBS의 동일 계정 중복 재생 안내로 69.160940초에 멈춰 검증 원본 탭을 닫고 현재 기기의 ‘재생’을 선택해 진행했다. 끝 정지 안내는 83.244초(지정 끝 대비 +0.014초)에 발생했지만 후속 관찰에서 다시 재생되어 88.081970초·paused=false였다. 따라서 **정지 유지 검증은 실패/미완료**로 남겼다.

player.js가 끝 정지 직후 감시를 해제하던 동작을 수정해 명시적 재재생/제어 해제 전까지 끝 정지를 유지한다. 합성 플레이어의 재개 후 정지 회귀를 추가해 구간 검사 **26개 통과**했다. 설치 폴더/ZIP을 갱신했다. 사용자에게 Chrome 확장 카드 새로고침을 요청했으며 실제 두 회차 재검증은 수정본 로드 후 수행한다. 기존25검사·미설치·조사 기록은 각 당시 상태다. 구간 화면의 초기 안내도 설치 여부를 확인하지 않고 ‘미연결’로 단정하지 않게 정정했다.

두 회차 모두 종료 후 정지 상태를 유지했고, EBS 재생 버튼으로 구간 밖 재개를 시도해도 정지했다. 원본 전체 재생은 ‘구간 제어 해제’로 전환한다. 소표본 실측이며 다른 플레이어·환경의 동일 정밀도를 보증하지 않는다. ## 독립 페이지 제거·내 수업 저장 안내 — 2026-10-14

사용자 요청으로 독립 구간 HTML을 삭제하고 `segment-bookmarks.js`를 `lesson-segments.js`로 옮겼다. 내 수업 폴더에 모든 개인 구간의 목록을 표시하고 편집은 같은 페이지의 dialog에서 수행한다. 자료 카드의 구간 링크·Chrome 연결 대상도 `lesson.html`로 통일했다. 초기 페이지 URL은 서버 재시작 후 내 수업으로303 이동한다. 실제 개인 저장 키는 변경하지 않으며 폴더에 담지 않은 내 자료 구간도 내 수업의 목록에 보인다. 특정 폴더에 자동으로 담았다고 표시하지 않는다.

확장 popup은 성공 응답을 받은 뒤 ‘내 수업 페이지에 저장되었습니다 · 저장 위치 · 구간/시간’을 안내하고, 실제 저장을 수행한 내 수업 화면도 ‘내 수업 페이지에 구간이 저장되었습니다’를 표시한다. 실패·중복 재시도·충돌/회차 검증은 유지했다.

`segment-bookmarks-check.js`27개와 `lesson-segments-check.js`7개 통과. 후자는 내 수업에서 LIST/IMPORT를 실제 처리하는 함수를 모의 DOM/저장소에서 실행해 저장 안내·목록 반영·중복/충돌/다른 회차 거절·기존 자료 보존·독립 화면 삭제를 확인했다. [통합 검사](r12-07-lesson-integration-check.json). 변경6JavaScript 구문과manifest의lesson연결 확인, 실제Chrome에서 기존3구간(자전/다윈/도시 감염병) 표시·구간편집dialog열기닫기·브라우저오류0을 확인했다. 설치 ZIP은0.2.0으로갱신했으며 실제 확장 저장 안내도 사용자 새로고침 후 확인했다.

사용자 확장 새로고침과 기존 내 수업 탭 새로고침 후 다윈의 기존 구간을 그대로 저장했다. 팝업과 내 수업 페이지의 저장 완료 안내, 기존 세 구간 중복 없음을 확인했다. [실제 저장 안내](r12-07-extension-save-notice.png).
