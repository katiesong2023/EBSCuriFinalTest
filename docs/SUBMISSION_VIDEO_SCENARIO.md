> **EBS 콘텐츠를 찾아, 교육과정과 연결하고, 수업에 쓸 구간까지 준비하는 Curi.**

교사의 수업 준비 한 사례를 끝까지 보여준다. EBS 담당자의 근거·검토 관리는 후반에 연결한다. 영상의 중심은 실제 웹·확장 화면이며, 제목·설명 자막은 실제 화면 위에 얹는다.

기존 실제 확인 기록: [구간 재생 결과](r12-07-live-playback.json), [상세 경과](R12_07_SEGMENT_BOOKMARKS.md). 과거 성공은 최신 버전의 재확인을 대신하지 않는다.

### 촬영 환경

- 같은 Chrome 프로필에서 로컬 Curi와 EBS를 열고 확장프로그램을 연결한다.
- 확장과 Curi 탭을 갱신한 후 최신 연결 상태를 확인한다.
- EBS 로그인·시청 권한과 본편 재생을 확인한다. 계정 로그인 과정은 촬영 전에 끝낸다.
- 실제 개인 자료를 지우지 않고 별도 시연 폴더를 사용한다. 새 프로필 사용 시 확장 설치·로그인을 다시 준비한다.
- 관리자 화면은 미리 로그인하여 별도 탭에 둔다. 관리자 코드 입력·API 키·개인정보는 촬영하지 않는다.
- 1920×1080, 16:9를 권장한다. 화면 글자가 작으면 브라우저 배율을 조절하고 팝업·확장 패널이 잘리지 않는지 확인한다.
- 알림을 끄고 실제 조작을 장면별로 녹화한다. 내레이션은 편집 후 별도 녹음할 수 있다.

## 3. 장면별 촬영표 — 총 175초

### 장면 1 — 문제와 서비스 소개 / 00:00~00:15 (15초)

**화면:** Curi 첫 화면에 제목을 얹는다. `자료 찾기 → 교육과정 확인 → 구간 기록`을 짧은 자막으로 보여주고 검색창에 커서를 둔다.

**내레이션:**

> EBS 영상을 수업에 쓰려면 자료를 찾고, 교육과정을 확인하고, 사용할 장면을 기록해야 합니다. Curi는 이 준비 과정을 하나로 연결하는 Agent 서비스입니다.

**주요 자막:** `EBS 콘텐츠를 수업 자료로 연결하는 Curi`

### 장면 2 — 수업 주제로 자료 찾기 / 00:15~00:35 (20초)

**조작:** 검색창에 `지구의 자전` 입력 → `자료 찾기` → 결과의 프로그램·제목 확인 → 대표 회차를 화면 중앙에 둔다. 짧은 별도 컷에서 사회 보조 사례의 실제 검색 결과를 보여준 뒤 대표 회차로 복귀한다. 사회 컷은 최대 8초, 사전 확인한 경우에만 사용한다.

**내레이션:**

> 먼저 수업 주제로 관련 자료를 찾습니다. 사회와 과학 주제를 탐색하고, 프로그램과 소개를 비교해 사용할 후보를 고릅니다.

**주요 자막:** `주제 검색 · 프로그램/소개 비교` / 보조 컷: `사회 수업 활용 후보 예시`

**촬영 확인:** 제목·썸네일만 빠르게 지나가지 않게 결과를 잠깐 정지한다. 특정 사례 성공을 전체 자연어 검색 정확도로 표현하지 않는다.

### 장면 3 — 원문에서 선택 근거 확인 / 00:35~00:55 (20초)

**조작:** 대표 자료의 상세 설명을 펼침 → 방송 내용 안내·원문·출처 확인 → 실제 관련 문장이 보이는 위치에서 정지한다. 최신 화면의 펼침 버튼 문구는 리허설에서 확정한다.

**내레이션:**

> 자료를 고를 때는 제목뿐 아니라 원문과 출처를 확인합니다. Curi가 제공하는 내용과 연결 후보를 살펴보고, 수업에 맞는지는 교사가 판단합니다.

**주요 자막:** `원문·출처 확인 → 교사의 자료 선택`

**촬영 확인:** 제목 기반 안내나 별도 보조 설명이 있다면 실제 표식을 유지한다. 모든 안내를 공식 회차 소개문으로 부르지 않는다.

### 장면 4 — 교육과정 연결과 수업 폴더 저장 / 00:55~01:20 (25초)

**조작:** `가져가기` → 관련 후보 확인 → 필요 시 `전체 기준 보기`에서 공식 문장 확인 → 적절한 기준 선택 → `선택 완료` → 새 폴더 이름 입력 또는 기존 시연 폴더 선택 → `가져가기` → 완료 안내·`내 수업으로 이동`.

**내레이션:**

> 가져가기에서 관련 교육과정 후보를 확인하거나 전체 기준을 찾아 연결합니다. 선택한 자료는 수업 폴더에 담고, 수업 목표와 활용 메모를 함께 정리할 수 있습니다.

**주요 자막:** `교육과정 선택 → 폴더 저장` / `교육과정 연결은 선택 사항`

**촬영 확인:** 선택 기준과 해당 원문이 맞는지 사전 확인한다. 연관 후보가 부족하면 전체 기준에서 직접 고르는 실제 동선을 보여준다. 개인 기준 선택을 담당자 승인으로 설명하지 않는다. 메모 입력은 다음 장면 도입에 2~3초 포함할 수 있다.

### 장면 5 — 확장에서 사용할 구간 저장 / 01:20~01:50 (30초)

**조작:** `방송 보기`로 대표 회차 열기 → 본편 확인 → Chrome 확장 사이드 패널 열기 → 시연 폴더 확인 → 구간 이름·시작·끝 지정 → 명시적 저장 → Curi 내 수업에 반영된 구간 카드 확인.

**내레이션:**

> 영상에서 사용할 부분은 Chrome 확장으로 지정합니다. 시작과 끝, 구간 이름을 저장하면 내 수업 자료에 반영됩니다. 영상 파일을 복제하지 않고 EBS 원본의 시간 구간을 기록합니다.

**주요 자막:** `사용할 장면 지정 → 내 수업에 저장` / `원본 영상의 구간 북마크`

**촬영 확인:** 입력·저장·완료 안내·반영 결과가 이어지게 촬영한다. 대기·광고 구간은 편집할 수 있지만 저장 성공 화면을 다른 자료의 결과로 대체하지 않는다.

### 장면 6 — 수업 순서 구성과 재사용 / 01:50~02:17 (27초)

**조작:** 저장 구간의 `리스트에 추가` → 순서 변경·총길이 표시 → 폴더 재열기 → `저장 구간 보기` → EBS에서 지정 시작 이동·재생·끝 정지 확인.

순서 변경을 보여주기 위해 별도 구간 하나를 사전 준비할 수 있다. 이 경우 `사전에 저장한 구간과 함께 구성` 자막을 표시한다. 한 구간만 사용하면 순서 변경 대신 리스트 추가·총길이·재열기를 보여준다.

**내레이션:**

> 저장한 구간은 수업 영상 리스트로 구성합니다. 순서와 총길이를 확인하고 다음 수업에서도 다시 열 수 있습니다. 구간 보기에서는 지정한 위치로 이동하고 끝에서 정지합니다.

**주요 자막:** `수업 순서·총길이 확인 → 다시 활용`

**촬영 확인:** 35초 구간을 모두 넣으면 시간 예산을 넘기므로 시작 이동 후 재생 2~3초와 끝 정지 2~3초를 보여주고, 사이에 `중간 재생 생략`을 표시한다. 실제로 끝까지 재생한 녹화에서 편집한다. 최신 환경에서 끝 정지가 확인되지 않으면 해당 주장·컷을 빼고 실제 성공한 저장·재열기만 보여준다.

### 장면 7 — EBS 담당자의 근거·품질 관리 / 02:17~02:40 (23초)

**화면:** 관리자 탭으로 전환 → 자료·품질 관리 → 기존 실제 레코드의 원문·교육과정 연결 후보·검사/검토 상태 비교 → 교육과정별 확보 현황을 짧게 보여준다. 대표 자료에 해당 기록이 없으면 별도 레코드를 사용하고 `관리자 검토 예시 · 별도 자료` 자막을 표시한다.

**내레이션:**

> 운영 담당자는 콘텐츠와 교육과정의 연결 근거, 검사와 검토 상태를 관리합니다. 원문과 판본을 보존하고 자동 후보와 사람 확인을 구분해, 메타데이터를 재검토하고 활용하는 기반을 마련했습니다.

**주요 자막:** `원문·판본·검토 상태 관리` / `자동 후보와 사람 확인 구분`

**촬영 확인:** 실제로 남아 있는 기록만 보여준다. 현재 사람 승인 0건 상태를 유지하고, 촬영을 위해 공용 승인·취소·자동 공개를 실행하지 않는다. 실시간 수집·AI 생성 실행을 촬영하지 않았다면 관리 화면 조회로 설명한다.

### 장면 8 — 현재 성과와 기대효과 / 02:40~02:55 (15초)

**화면:** 완성된 수업 폴더와 구간 리스트로 복귀. 마지막 5초에 EBS CURI 로고·핵심 문구를 얹는다.

**내레이션:**

> Curi는 자료 탐색에서 교육과정 연결과 구간 활용까지 구현했습니다. 반복 준비 작업을 줄이는 것이 목표이며, 실제 교사의 시간 절감과 반복 사용 효과는 현장 검증으로 확인하겠습니다.

**주요 자막:** `찾고 · 연결하고 · 수업에 활용` / 작은 보조 자막: `현재 로컬 MVP · 개인 자료는 브라우저 저장 · 교사 효용 미측정`

## 4. 촬영·편집 순서

1. 시연 폴더와 대표 자료·교육과정·구간·관리자 조회 레코드를 확인한다. 현재 검색어·원문·영상이 맞는지 먼저 리허설한다.
2. 실제 사용하는 코드·데이터·확장 버전과 촬영일을 기록한다.
3. 장면2~4의 검색→원문→가져가기를 실제 동작으로 녹화한다.
4. 장면5의 EBS→확장→저장 완료→Curi 반영을 녹화한다.
5. 장면6의 리스트 구성·재열기·실제 구간 재생과 끝 정지를 녹화한다. 시작부터 끝까지의 원본 녹화는 보관한다.
6. 장면7의 관리자 조회와 선택적인 사회 보조 컷을 녹화한다.
7. 장면1·8의 자막을 만들고 175초 구성으로 편집한다. 대기·반복 입력부터 줄이고 실제 동작의 핵심은 남긴다.
8. 편집본에 맞춰 내레이션을 낭독·녹음한다. 제시한 시간은 목표이며 실제 낭독으로 확인한다.
9. 자막·음량·길이를 확인하고 MP4로 내보낸다. 최종 파일을 처음부터 끝까지 재생한다.

| 확장 연결 실패 | 확장·Curi 탭을 갱신하고 같은 주소·프로필·로그인 상태 확인 후 해당 장면 재촬영 |
| 저장 실패 | 실제 완료 확인 전 다음 장면으로 연결하지 않고 입력 유지·재시도로 복구 |
| 자동 재생 제한 | EBS 재생 버튼을 직접 누른다. 사용자 재생 동작을 자동 재생처럼 편집하지 않음 |
| 끝 정지 미확인 | 제어 동작을 재검증하거나 끝 정지 설명 삭제. 이전 영상으로 최신 성공을 대체하지 않음 |
| 관리자 상세 기록 부족 | 조회 가능한 별도 실제 레코드를 표시하고 현재 상태만 설명 |
| 전체 3분 초과 | 사회 보조 컷·반복 타이핑·페이지 전환 대기를 먼저 축소. 검색·원문·저장·구간·관리 근거·효과는 유지 |

## 6. 촬영 전·후 확인표

- [ ] 현재 버전의 검색 결과·원문·교육과정·대표 장면을 실제 대조했다.
- [ ] 실제 동선으로 리허설하고 장면별 소요시간을 기록했다.
- [ ] 초기화는 시연 폴더 범위로 제한하고 기존 개인·공용 자료를 보존했다.
- [ ] 실제 EBS 접근·구간 저장·재열기·촬영에 포함할 재생 제어를 확인했다.
- [ ] 사회 보조 컷과 관리자 별도 레코드는 준비된 예시임을 구분했다.
- [ ] Agent의 후보·근거 처리와 교사의 판단·수동 구간 지정이 구분된다.
- [ ] 사람 승인·현장 효용·검색 정확도·시간 절감의 미실측 결과를 만들지 않았다.
- [ ] 화면에 비밀값·개인정보가 없고 자막과 실제 동작이 일치한다.
- [ ] 최종 MP4가 3분 이내이고 실제 화면·음성·자막을 끝까지 확인했다.
