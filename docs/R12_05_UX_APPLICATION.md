# R12-05 UX 지시 반영 결과

2026-10-14. 검색·자료의 의미를 바꾸지 않는 UX 개선을 반영했다. 현재 실행 중인 로컬 서버에서 새 정적 화면을 확인했으며 서버 재시작·원천 수집·검색 로직·원본DB/승인/개인 저장 키 변경은 하지 않았다. 사용자의 실제 브라우저 기록을 읽거나 수정하지 않고 격리된 브라우저의 기존 형식 기록으로 호환을 확인했다.

## 고정 후보 비교

같은 다문화 검색 API 응답·후보9개/순서에서 변경 전 정적 파일과 변경 후 파일을 비교했다.390×844 화면의 첫 카드top은1,015→620px, 첫 카드높이는1,068→745px다. 기존 폴더에 저장하는 클릭은5→2회다. 자동 실행 경로시간은372→64ms였으나 도구 클릭/화면 이동 시간으로, 교사의 이해·선택 시간이나 준비시간 절감률로 보고하지 않는다. 후보 증가·관련성 개선은 이번 결과가 아니다.

[비교 기록](r12-05-fixed-ux-comparison.json)·[동선12검사](r12-05-ux-check.json)·[조건/손상 기록2검사](r12-05-condition-check.json)에 수치를 기록했다. 변경 전 파일은 이번 검증을 위한 임시 복사본, 기존R12-01 기준선/동결 묶음은 그대로 보존했다.

## 개인 기록·저장 확인

기존 형식의 여러 폴더·자료 메모·이전 발문/역할·두 선택 이유·수업 목표/활용 부분·보류 이유·개인 장면 확인을 넣은 격리된 브라우저에서 확인했다. 같은 자료를 담아도 기존 선택 이유를 빈 값으로 덮어쓰지 않고, 다른 자료를 추가해도 이전 자료/다른 폴더/내 자료는 보존했다. 같은 문맥의 빈 선택 이유 중복을 방지했다. 개인 목표 편집과 재열기, 폴더 저장 실패 입력 유지/재시도 중복 방지, 다른 탭 변경의 저장 차단, 손상된 폴더 값 덮어쓰기 방지를 확인했다. 기본 빈필드 보완은 기존readFolders 정규화다.

가로 넘침·페이지JavaScript 오류0. 연소 필요조건의 원문 미확인 안내 유지·0건 질문 편집·키보드 결과 접근·한국어 오류/재시도·조건 하나 해제/이전 주소 복원을 확인했다. 실제EBS 재생·영상/교사 적합성·실제 교사 시간/반복 사용은 미확인이다.

## 코드 책임

`teacher-folder-picker.js`는 검색 카드에서 폴더 선택/생성/저장 결과 표시를 맡고, 기존`lesson-folders.js`에 추가한 공통 자료 추가 함수를 폴더 화면과 함께 사용한다. 기존 저장 키·충돌 검사·내 자료 저장은 유지한다. 카드/출처 표현은`teacher-cards.js`·`teacher-source.js`, 검색 상태/포커스는`discover.js`, 개인 이유 편집 순서는`lesson-context.js`에서 처리한다.

## 사용자 결과 확인

- [ ] 자료 찾기를 새로고침하고 다문화/연소 질문의 모바일 결과·기존 인용과 남은 확인을 확인한다.
- [ ] 카드에서 수업 폴더에 담기를 누르고 기존 폴더를 선택해 저장한 뒤 내 수업 폴더에서 자료·메모·선택 이유를 확인한다.
- [ ] 기존 개인 목표·활용 부분·개인 확인을 열고 수정/재열기해 기록이 유지되는지 확인한다.
- [ ] 0건 질문 수정/조건 살펴보기와 필터 하나 해제 시 나머지 조건이 유지되는지 확인한다.
