# 표현이 다른 의미의 공통 검색

2026-10-15. 사용자 제보 ‘다문화 가족·다문화 어린이’의 0건을 확인하고, 다른 분야에도 적용하는 원문 의미 대조 경로를 추가했다. 새 사용자 사례는 기존 개발170에 섞지 않고 별도로 검증했다. 유료 API 호출은 0건이다.

## 공통 변경

- `source-meaning-rules.js`·`source-meaning.js`가 대상 관계·동의 표현·설명 관계를 공통으로 대조한다. 특정 두 검색 문자열에 결과를 지정하지 않는다. 가족/어린이/청소년/노인/이주/다문화/시민참여/선거/도서관/재활용/증발/응결/광합성/자전/중력/자석/꽃가루받이/온난화/서식환경/저출생의 20개 의미 단위·41개 요청 표현을 제공한다.
- 각 검색 분기의 개념·단어·OR 선택지에 직접 일치 또는 해당 의미 단서를 요구한다. 한 문서의 서로 다른 필수 대상을 다른 문서로 채우지 않으며 미지의 고유명·소재를 삭제하지 않는다. 기존 프로그램·지역·유형·기간·명시 AND·제외·관계 조건을 보존한다.
- ‘어린이’의 마지막 ‘이’를 조사로 잘라 ‘어린’으로 검색하던 문제를 수정했다. 어린이·고양이·종이 같은 실제 명사와 알려진 의미 단위의 붙여쓰기·복수형을 보존한다. 알 수 없는 단어 전체를 임의로 쪼개지는 않는다.
- 의미 대조는 공식 소개문과 은유를 가린 검색용 뷰를 사용한다. 제목 반복·편성 안내·작성한 간략 설명으로 내용을 추론하지 않는다. 반대 방향의 상태 변화·부정 표현·제작 대상 표기와 실제 인물, ‘자성의 목소리’/자석·세계 10대/청소년 등의 문맥을 구분한다.
- 단서는 `meaningMatches`의 `RELATED_SOURCE_CUE`로 반환한다. 원문 태그나 교육과정 승인으로 저장하지 않는다. 기존 로컬 E5 문장 유사도는 후보 순위에 계속 사용하며 유사도만으로 누락된 모든 필수 단어를 충족시키지는 않는다.
- 카드의 ‘다른 표현으로 찾은 관련 후보’에 검색어와 원문 표현을 함께 표시한다. 원문 펼침에서 강조하며 저장 사본의 인용도 자기 원문과 일치할 때만 표시한다.

## 개발170의 동일 자료 비교

수정 전 `meaning-before`와 최종 `meaning-stable`은 같은 입력 SHA와 5개 검색/원천 저장소 SHA를 사용했다. 두 실행 중 코드·저장소 변경은 0개다. 중간 candidate/final/verified 실행은 최종 효과 집계에 사용하지 않는다.

| 지표 | 수정 전 | 최종 |
| --- | ---: | ---: |
| 요청 수 | 170 | 170 |
| 빈 검색 | 154 | 154 |
| 후보가 있는 요청 | 16 | 16 |
| 요청별 상위5 후보 쌍 | 42 | 45 |

변경 요청은 2개이며 기존 결과 요청의 빈 결과 전환은 0개다. 최종 상위 후보·판본에서 인용 708건을 자기 원문과 대조했고 불일치는 0건이다. 원문·태그·의미 검색 SQLite·자동 자산·승인 JSON·교사 등록자료의 6개 저장소 지문은 유지됐다.

개발170의 모든 의미 충족을 통과했다는 뜻은 아니다. 지원 의미 단위 밖의 표현·복잡한 문장/필수 내용 해석·원문 부족 등으로 남은 154개 빈 검색은 계속 개선해야 한다. 새 사용자 사례의 2건/3건 해결과 기존170의 빈 검색 유지 수치를 분리한다. 실제 교사 선택·의미 정확도·누락률의 독립 평가도 미완료다.
