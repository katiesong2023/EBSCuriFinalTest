# 자연 다큐 설명·의미·장르 공통 보완

2026-10-15. 사용자 제보 ‘갯벌 생태계’의 1건과 ‘자연 다큐’의 프로그램명 오해를 함께 조사했다. 갯벌 전용 예외를 두지 않고 공식 설명 보충·다른 표현의 생태 단서·일반 장르와 프로그램 지정 구분을 공통 경로에 적용했다. 유료 API 호출과 영상 다운로드는 0건이다.

## 설명 보충

조사 범위는 하나뿐인 지구·이것이 야생이다·EBS 다큐프라임·과학 다큐 비욘드·경이로운 자연의 세계·자연 다큐·다큐 오늘의 설명 부족 1,362건이다. ‘자연 관련’이라는 이유로 프로그램 전체를 생태계 자료로 분류하지 않는다. 프로그램 안의 사회·생활 주제도 자신의 원문을 기준으로 검색한다.

- 공식 보도자료 목록 935개를 조사하고 제목·방송 시기 후보의 상세 245개를 대조했다. 프로그램·회차 제목·게시일/방송 시기를 확인한 175개 회차에 공식 보조 설명을 연결했다. 여러 회차를 함께 설명한 공지 2개는 보류했다.
- 회차 식별을 대조한 보조 설명의 원문·발췌 위치·응답 해시·회차/판본 스냅샷·연결 이력을 보존했다. 최대4,000자의 연속 발췌이며 다른 회차의 문장을 합성하지 않는다. 원래 소개문은 그대로 보존한다.
- 보조 설명이 없는 짧은 회차 761개를 공식 상세 페이지와 추가 대조했다. 원문 갱신196·동일417·불충분16·회차 불일치132다. 불일치 응답은 적용하지 않았다. 갱신 중 기존보다 긴 설명은100개이고, 9개가 원문 부족에서 내용 설명으로 개선됐다. 18개는 갱신 후에도 내용 없음 판정이다. ‘196개 모두 상세 설명 확보’로 집계하지 않는다.
- 기존 소개가 빈약할 때 ‘방송 내용 안내 · 공식 보조 설명’을 표시한다. 이 표시와 검색 근거는 공식 소개문·보조 원문을 구분한다. 보조 설명으로 기본 소개문의 품질이나 교육과정 승인을 승격하지 않는다.

회차 연결은 정규화한 전체 제목(최소6자)·프로그램명·공식 게시일을 실제 문서에서 확인하고, 목록 방송일과 게시일이 -1~14일 범위인 경우만 허용한다. EBS 목록일과 보도자료의 실제 방송일은 다를 수 있으며 동일 방송일로 보증하지 않는다. 짧은 제목·다른 제목/프로그램·연도가 다른 문서·여러 회차 공지는 보류한다. 이것이 전체 자연 다큐의 설명 확보 완료를 뜻하지는 않는다. 공식 공개 텍스트가 짧거나 없는 나머지 자료는 계속 부족 상태로 남긴다.

## 공통 검색 변경

`discovery-request.js`는 ‘자연 다큐’처럼 분야+장르인 일반 표현을 같은 이름의 프로그램에 고정하지 않는다. ‘자연’은 자연환경 내용 조건으로, ‘다큐’는 다큐멘터리 형태 조건으로 읽는다. 숲·습지·사막 등 주제와 함께 작동한다. 따옴표/‘프로그램’으로 명시한 이름과 상세 프로그램 필터는 프로그램 지정으로 유지한다. 다른 미지의 내용어와 필수 AND·OR·제외 조건을 삭제하지 않는다.

`source-meaning-rules.js`에 생태계·자연환경의 설명 관계를 추가했다. 생물/동식물과 서식·번식·적응·생존·먹이 활동, 지형과 형성·침식 등 같은 문장의 단서를 대조한다. 제목이나 프로그램만으로 생태 의미를 만들지 않고 소개문 또는 회차가 검증된 공식 보조 설명을 사용한다. 기존 은유 제외와 부정 검사를 통과한 인용만 의미 확장 후보로 제공한다. 모든 자연/생태 문장의 의미 판정을 보장하는 모델은 아니다.

`program-form-source.js`는 공식 프로그램 분류뿐 아니라 같은 프로그램·강좌·단계의 공식 소개 인용도 장르 근거로 사용할 수 있다. 현재 ‘이것이 야생이다’의 2017/2022 단계에 [2017 공식 소개](https://global.ebs.co.kr/board/bbs?boardId=31&boardTypeId=1&cmd=view&postId=10003320650)와 [2022 공식 소개](https://global.ebs.co.kr/board/bbs?boardId=31&boardTypeId=1&cmd=view&postId=30001132009)를 연결했다. 확인하지 않은 다른 단계로 전파하지 않는다. 일반 주제 분류를 다큐멘터리 형식으로 추정하지 않는다.

원문 소개와 보조 설명의 인용 오프셋은 각각 자기 원문에 대응한다. 보조 원문은 `supplementId`와 출처 URL을 포함한다. 기존 숨긴 카드 정보는 계속 숨긴 상태이며 방송 내용 안내에서 보충 설명을 읽을 수 있다.
