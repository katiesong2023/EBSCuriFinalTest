# EBS Curi

2022 개정 교육과정 기반 EBS 교육 메타데이터 구축·활용 MVP입니다.

**Curi 0.2**: 기본 화면에서 개념·장소·출처를 따라 자료를 탐색하고 수업 준비 메모를 내려받을 수 있습니다. 유료 API는 기본 차단됩니다. [로컬 사용법·3분 시연·검증 결과](docs/CURI_LOCAL_0.2.md)를 참고하세요.

2026-09-30 1차 마감: 일반방송 9개 프로그램의 **5,548 회차 ID**를 수집해 검색에 연결했습니다. [수집 실측](docs/BROADCAST_CORPUS.md)과 [마감 크리틱 1회·반영 결과](docs/USABILITY_CRITIQUE_02.md)를 참고하세요. 전체 화면에서 개별 페이지를 대조한 자료는 341건이며, 전체 영상 재생 가능성 검증과는 다릅니다.

현재 검색 목록은 6,031항목, 개별 자료 5,587건과 프로그램·회차 탐색 목록 444건으로 구분합니다. 신규 방송은 같은 프로그램·제목의 중복을 묶어 5,424개 제목으로 표시합니다. 개념 확장은 동고서저·화산 지형·해안 지형을 지원하며 그 밖에는 제목·소개문 단어로 검색합니다. 기존 검증 자산 검색은 `/index.html`에 있고 자동 승인으로 자료를 늘리지 않았습니다. 로컬 검증은 `npm run simulate`로 실행합니다.

## 로컬에서 시작하기

필요한 것은 Node.js 24.18.0 이상과 npm입니다. 다음 명령으로 설치 상태를 확인합니다.

```bash
node --version
npm --version
```

프로젝트 최상위 폴더에서 최초 설치 후 서버를 실행합니다.

```bash
npm ci
npm start
```

터미널에 표시된 `http://127.0.0.1:3000`을 브라우저에서 엽니다. 코드 수정 중에는 아래 명령으로 파일 변경 때마다 서버를 다시 시작할 수 있습니다.

```bash
npm run dev
```

서버를 종료하려면 실행 중인 터미널에서 `Ctrl+C`를 누릅니다.

## 콘텐츠 증분 가져오기

서버를 실행한 뒤 브라우저에서 `http://127.0.0.1:3000/ingestion.html`을 열면 CSV 또는 콘텐츠 한 건을 미리보기하고 저장할 수 있습니다. 저장 전에는 신규·변경·동일·비활성 후보·오류와 재검수 필요 여부를 확인합니다.

터미널에서도 같은 처리 경로를 사용할 수 있습니다. 기본은 미리보기이며, 정상 항목을 실제 저장할 때만 `--apply`를 붙입니다.

```bash
npm run data:ingest -- --csv 경로/콘텐츠.csv
npm run data:ingest -- --csv 경로/콘텐츠.csv --apply
npm run data:ingest -- --csv 경로/출처전체.csv --source-snapshot --apply
```

`--source-snapshot`은 하나의 출처 전체 내보내기일 때만 사용합니다. 파일에서 빠진 기존 활성 콘텐츠를 삭제하지 않고 `INACTIVE_CANDIDATE`로 바꿉니다. 오류 행이 있으면 비활성 처리는 수행하지 않습니다.

공식 API·Feed·내보내기 경로는 아직 확인·설정되지 않았으므로, 일일 예약 실행은 연결하지 않았습니다. 나중에 공식 원본이 확인되면 `.env`의 `INGESTION_SOURCE_FILE`에 CSV 경로를 설정하고 스케줄러에서 아래 명령을 호출합니다. 이 명령도 수동 실행과 같은 검증·미리보기·적용 모듈을 사용합니다.

```bash
npm run data:ingest:scheduled
```

## 검증 자산 검색 준비

검수 화면에서 사람 승인·수정 결과를 CuriBase에 저장하면 로컬 모델로 검색 자료를 준비합니다. 기존 저장 자산은 `검색 준비·재시도`를 누릅니다. 준비 실패는 CuriBase 저장 결과와 별도로 표시되며, 변경되지 않은 임베딩은 재사용합니다.

최초 실행에는 공개 모델 다운로드를 위한 인터넷 연결이 필요합니다. 모델은 Git에서 제외한 `server/data/.model-cache/`에 보관하고 이후 로컬에서 실행합니다. 별도 API 키와 유료 API 호출은 없습니다. 상태·버전·재시도 확인은 [Task 02-07](Tasks/task-02-07-search-index.md)의 결과 확인 절차를 따릅니다. 검증 자산 검색은 `/index.html`에서 사용합니다.

```bash
npm run data:search-index:check
```

위 검증은 실제 사람 검수 기록을 변경하지 않는 임시 저장소를 사용합니다.

## 수업 시나리오와 데이터 확장

수업 탐색의 현재 범위는 [30개 시나리오 실측](docs/CLASSROOM_SCENARIOS.md)에서 확인합니다. `npm run simulate:classroom`으로 유료 API 없이 다시 측정할 수 있습니다. 핵심어 후보는 23→27/30으로 늘었지만 요청 문장은 14/30으로 같아 문장 해석 개선이 남아 있습니다. [확장 설계](docs/DATA_EXPANSION_5000.md)의 5,000건 확보·검색 반영은 완료했으며 `npm run data:broadcast:check`로 데이터와 규모를 확인합니다. 모든 task의 현재 순서는 [PLANS](docs/PLANS.md)를 따르고 사람 판단은 최종 단계로 남깁니다.

## 개발 설정과 비밀값

기본 포트 3000은 설정 없이 동작합니다. 다른 포트가 필요할 때만 `.env.example`을 복사해 `.env`를 만들고 `PORT`를 변경합니다.

```bash
cp .env.example .env
```

`.env`는 Git이 추적하지 않습니다. 이후 외부 서비스 키가 필요해져도 실제 값은 `.env`에만 입력하고, 화면 파일·문서·로그·저장소에 넣지 않습니다. 현재 단계에서는 API 키가 필요하지 않습니다.

## 관리자 작업공간

터미널에서 `npm run admin:password`를 실행하면 비밀번호를 숨김 입력으로 두 번 확인한 뒤 `.env`에 저장합니다. 서버를 재시작하면 적용됩니다. 기존의 다른 설정은 유지합니다.

서버 재시작 후 `/admin.html`에서 수집·출처·태그·검수 대상을 확인합니다. 관리자 코드를 설정하지 않은 로컬 실행은 터미널에 이번 실행 코드를 출력합니다. 로그인 후 자료를 선택하면 기존 가져오기·CuriMap·사람 검수·승인 저장·검색 준비로 이어집니다. 교사 화면과 개인 수업 폴더는 로그인 없이 사용합니다.

고정 코드는 `.env`의 `CURI_ADMIN_TOKEN`으로 설정합니다(로컬8자 이상·운영32자 이상). 값을 바꾼 뒤 서버를 재시작하면 적용됩니다. 운영 HTTPS 주소는 `CURI_ADMIN_ORIGIN`으로 설정합니다. 운영 모드에는 둘 다 필수이며 HTTPS reverse proxy가 필요합니다. 세션은 8시간 또는 서버 재시작까지 유효합니다. 자세한 접근 정책과 결과 확인은 [R08](Tasks/task-r08-admin-workspace.md)을 참고하세요.

## 변경 확인과 되돌리기

작업 전후에는 아래 명령으로 변경 파일을 확인합니다.

```bash
git status
git diff
```

아직 커밋하지 않은 특정 파일의 변경만 되돌려야 한다면, 내용을 확인한 뒤 다음 형식으로 실행합니다.

```bash
git restore 경로/파일명
```

예: `git restore public/index.html`. 다른 작업의 변경을 지우지 않도록, 되돌리기 전에 `git status`와 `git diff -- 경로/파일명`으로 대상을 확인합니다.
