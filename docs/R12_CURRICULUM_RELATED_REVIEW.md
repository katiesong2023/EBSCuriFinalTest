# 자료 관련 교육과정 검토·검색 의도 순위

**2026-10-16 후속 반영:** 아래에 남은 한계로 기록한 앞200자 제한·다문화/독립운동 의미 누락·무관 후보를 공통으로 개선했다. 현재 동작과 검증은 [전체 소개문·공통 의미 대조](R12_CURRICULUM_CONTENT_MEANING.md)를 따른다. 아래는 R12-33 당시 기록이다.

2026-10-15. 사용자 검토 요청과 후속 “영상을 찾은 검색어를 활용한 관련도순” 요청을 함께 반영했다.

## 확인 범위

현재 로컬 검색의 갯벌 생태계·기후 변화·민주주의·다문화·독립운동·인체·화산·전기8주제에서 상위2개씩16개 실제 자료를 조회했다. 가져오기 화면과 같은 제목+소개문 앞200자로 관련 기준 API를 호출하고 원문과 대조했다. 변경 전 노출 후보87개·후보0개 자료2개. 표본은 검색 상위 자료이며 전체 추천 정확도나 교사 평가를 대표하지 않는다. 영상은 시청하지 않았다.

[변경 전 자료·후보](r12-33-related-before.json), [변경 후](r12-33-related-after.json), [기존 화면 순서 재현](r12-33-related-order-before.json).

## 최종 동작

`discover.js`는 현재 결과를 만든 검색어를 가져오기 선택기에 전달한다. 이미 저장된 자료를 다시 가져오는 경우에도 현재 검색어를 우선한다. 내 수업 자료에서 교육과정을 다시 선택하면 기존 자료의 `query`를 사용하며, 저장된 검색어가 없으면 자료 제목·소개문으로 후보를 만든다.

`curriculum-related.js`는 기존 제목·소개문 후보를 먼저 계산한다. 별도 `searchQuery`로 기준별 검색 의도 점수를 계산하고, 내용 후보 중 검색어에도 관련된 기준을 먼저 정렬한다. 같은 그룹 안에서는 내용 점수+검색 의도 점수2배를 비교한다. 검색어만 맞는 기준을 내용 후보 밖에서 추가하지 않는다. 정렬 후 최대8개를 반환한다. `searchQuery`도200자 이내 문자열로 검증한다. 기존q/교과/과정 호출을 유지한다.

`curriculum-selection.js`는 전체 보기에서는 기존 공식 목록, 관련 보기에서는 서버의 순서대로 표시한다. 보기 전환·다중 선택·단계 이동·저장 형식은 유지한다. 추천 이유/점수는 결과 검토용 응답이며 개인 교육과정의 공식 코드·원문을 바꾸지 않는다.

## 남아 있는 한계

현재 후보는 키워드/기존 개념 연결이다. 검색어와 같은 단어가 있다는 사실만으로 기준 전체의 활동·지역·시대가 맞는지는 판정하지 않는다. 다문화 교실에 아시아 종교/문화경관 기준9사(지리)02-02가 연결되고, 더 일반적인4사03-02가 빠지는 문제는 남아 있다. 일부 부차 소재 후보도 낮은 순위에 남는다. 관련 후보의 빈칸을 검색어만으로 채우지 않기 때문에 독립운동 같은 의미 표현 차이는 별도의 내용·기준 의미 연결 보강이 필요하다.

자료16개 중5개는 제목+소개문이200자를 넘고 현재 선택기는 앞200자만 사용한다. 뒤쪽 내용·공식 보조 설명은 이 추천 요청에 반영되지 않는다. 이번 변경은 검색 의도를 추가하고 순위를 보존하는 범위이며 이 문제와 은유/문맥 판별을 모두 해결한 것은 아니다.
