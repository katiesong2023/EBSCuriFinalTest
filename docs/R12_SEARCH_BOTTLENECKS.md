# R12-40 검색 병목 분석과 전후 검증

## 기생 후속 보강 — 국소 확인만 실행

공식 회차 목록에서 빠졌던 기생4회차를 추가하고, 생명의 전략 기생1부의 공식 보도자료783자를 해당 회차에만 보충했다. 시리즈/회차를 구분하고 제목·강좌·시리즈·회차 ID를 대조한다. 본문이 바뀌지 않았는데 동시 평가 후보에 따라 partial 판정이 달라진 회차는 내용 조건의 부분 판정 후보 최대3개를 원문별로 독립 재검사한다. unknown/contradicted·시간/장면/제외/형식 부분 판정은 이 경로로 승격하지 않는다.

사용자 지시로370개 전체 검증은 실행하지 않았다. 관련3문장과 동음이의어/인권2문장만 HTTP 확인했다. 생물 관계 검색은5→8이며 기존5회차를 모두 보존하고 기생1부·생명의 전략 기생1부를 반환한다. 숙주 관계6/공생과 기생2/조선 기생 역사3/지식채널e 인권4를 확인했다. 이는 해당5문장의 국소 확인이며 검색 전체 정확도·재현율의 새 지표가 아니다. 영상 재생·학년 적합성은 미확인이다.

[국소 확인](r12-40-parasitism-targeted-checks.json)·[검색 결과](r12-40-parasitism-targeted-results.json)·[수집 기록](r12-40-parasitism-source-refresh.json). 누적 보수적 비용$1.427397475/승인 잔여$0.572602525/미정산0. 방송 메타데이터 DB는 요청대로 보강했고 다른4저장소 SHA는 유지했다. 아래370 비교는 이번 후속 보강 이전 판본의 이력이다.

## 이전370 검증 판본 — 대상·활용 맥락 분리와 원문 조건 검증

사용자 추가$1 승인에 따라 총$2 원장을 유지했다. **학교급·학년·학기, 교과 수업, 교사용/학생용, 수업 도입·복습·마무리·활동 전 활용, 쉽게/눈높이/재미 선호**는 내용 단어의 필수 매칭에서 분리했다. 명시된 설명 방식이 있을 때 약한 순위 신호로 사용한다. 어린이 인권·교육용 로봇·얼음이 쉽게 녹는 이유처럼 실제 내용의 대상·성질은 보존하며 지역·시대·원인·비교·길이·자막·제외 요구는 제거하지 않는다.

후보를 보기 전에 질문의 필수를 원문 조각에 고정하고, 전체 소개문과 자기 회차의 공식 보조 원문에서 추린 구절 번호로 각 조건을 대조한다. 유사 소재·부분 일치·미확인은 자동 합치지 않는다. 프로그램명뿐인 회차에 다른 방송의 보조 원문이 섞이지 않도록 명시 방송일/회차 URL을 추가 대조했다. 원천23403건·보조 원문181건 중180건 검색 허용/1건 회차 미확인 보류이며 저장 원문은 수정하지 않았다.

**실제 교사 검색 함수로 같은370문장을 다시 실행했다.** 테스트의 기대 주제·정답·평가 라벨은 모델/운영 검색에 전달하지 않았다. 저장된 실제 API 응답만 캐시로 재사용했다. 같은 원문 라벨을 유지하고 새 상위3개12쌍을 원문으로 추가 평가해 미평가0을 확인했다.

빈 결과는 줄지 않았다. 새로 관련 자료를 찾은 질문과 엄격한 조건으로 결과가 사라진 질문이 함께 있다. 기존 로컬에서 관련으로 평가했던57개 질의/자료ID 쌍 중21개가 전체 결과에서 제외됐고31개가 상위3개에서 빠졌다. 이 값은 정확한 ID 기준이며 같은 제목의 다른 판본으로 교체된 사례도 포함한다. 다문화 이웃·도서관 역할·실 전화기·자석의 양쪽 비교·‘우리 지역’ 해석 등의 잔여 누락, 자막/장면/제외 부재를 원문으로 확인하지 못한 탈락을 구분해 확인해야 한다. **전체 재현율이나 누락 해결 완료로 해석하지 않는다.** [탈락 목록과 지표](r12-40-teacher-model-comparison.json)·[동일370 문장별 표](r12-40-teacher-model-query-comparison.md).

질문 전체를 다시 읽는 독립 재심사도 시험했으나 결과가 있는 질문을49(GPT-4.1)/48(Luna)개로 줄여 운영에 채택하지 않았다. 운영은 질문 계약과 구절별 조건 검증을 사용한다. 원문 인용380개와 메타데이터 근거41개, 보호5저장소 SHA 불변을 대조했다. 이 수치는 에이전트의 텍스트 잠정 평가이며 교사 효용·실제 영상·학년 적합성의 정답률이 아니다.

교사 GET 검색은 새 모델 경로를 활성화했다. 기본 포트3000 서버에 반영했고 총$2 예산을 기존 실험과 공유하며 자동 증액하지 않는다. 캐시 적중은 비용 없이 재사용하며 새 호출은 예산을 먼저 예약한다. 예산/API 실패는 검색 실패로 표시하고 미검증 결과로 채우지 않는다. CuriMap 등 다른 유료 기능의 전역 스위치는 켜지 않았다. 실제 HTTP6검사를 통과했고, 초등학생 자본주의 교육용 자료12건·같은 질문 재검색 추가 호출0을 확인했다. 누적 보수적 비용은$1.422129475/승인 잔여$0.577870525/미정산0이다. 실제 HTTP 검증과 최신 비용은 [연결 검사](r12-40-teacher-model-http-checks.json)에 기록한다. 비용은 캐시 할인 미적용·불명 시도 최대 예약액 유지의 보수적 집계이며 계정 잔액/실청구액이 아니다.

## 이전 총1달러 실험의 판단

2026-10-16 후속 실제 LLM 실험까지 총 **$0.8466296**를 사용했다. 승인 총$1 중 **$0.1533704**가 남으며 미정산 호출은0이다. 이번 비교는 예산 안에서 끝냈다. 현재와 같은370 전체의 후보 원문 재선별은 약$0.347가 들었으므로 남은 금액만으로 동일한 전체 유료 실험을 한 차례 더 실행하기에는 부족하다. 저장 응답의 재평가에는 추가 API 비용이 들지 않는다. 이 값은 계정 잔액이나 실청구액이 아니라 캐시 할인을 제외하고 불명2시도의 최대 비용까지 유지한 보수적 실험 집계다.

새 의미 검색·LLM 원문 대조·필수 조건 검증을 구현하고 **기존 결과를 보존하며 보충**하는 비교에서는 관련 자료가 상위3개에 있는 질문이31→50으로 늘었다. 그러나 부분 일치20→35, 무관2→3, 관련 노출 비율72.2→67.8%다. 누락 일부는 줄였지만 정확도까지 개선됐다고 보고할 수 없어 제품의 자동 유료 검색으로 활성화하지 않았다. 아래 로컬·첫 API 실험 이력은 그대로 보존하고 새 비교는 후속 절에 구분한다.

**공통 구조 보완으로 무관 결과는 줄었지만, 자연어 검색의 누락을 충분히 해결하지 못했다.** 같은370문장에서 관련 후보가 있는 질문은27→31개, 빈 결과는336→330개다. 반환된 상위3개 중 관련 판정 비율은73.8→72.2%로 개선되지 않았다. 부분 일치가12→20개로 늘었기 때문이다. 검색 완성이나 정확도 통과로 보고하지 않는다.

현재 일반 검색은 실제 LLM을 호출하지 않는다. 로컬 명사·문법 규칙이 범용 의미 해석을 대체하지 못한다. 아래 첫 전후 비교는 유료 호출0회의 로컬 구조 보완 결과다. 이후 사용자가 총1달러를 승인하고 키를 설정해 별도370문장 API 실험을 실행했다. 실험 비용·계약 해석과 검색 품질은 후속 절 및 `r12-40-llm-dollar-*` 산출물로 구분한다.

## 공통 구조 보완

1. `request-nouns.js`: 온전한 등록 명사를 보존하고 조사·명사형 동작의 활용형을 같은 표제어로 대조한다. 원문에 ‘가족’과 ‘가족은’이 함께 있어도 활용형을 별도 필수어로 남기지 않는다. 조사와 함께만 등장하는 원천 표제어도 조회한다. 고유명 끝 ‘이나’를 무조건 자르지 않는다.
2. `discovery-intent.js`: 복합 개념을 원래 구절로 먼저 해석한다. ‘달의 모양’의 내부 조사를 지워 다른 별칭에 강제 일치시키는 회귀를 막았다. 숫자 복합 표기도 여러 숫자로 분해하지 않는다.
3. `request-language.js`·`natural-request.js`: 요청 문법과 내용 동작을 구분한다. 뜻/필요성 등 설명 차원을 그 단어 자체의 필수 일치와 구분한다. 이것만으로 요청 충족을 보증하지 않으며, 관련 내용을 확인하지 못한 새 결과는 부분1로 평가했다.
4. ‘지역 특산물은’처럼 구절 전체를 중복 필수 문자열로 추가하던 경로를 제거했다. 대신 `sourceContext.localQualifiers`로 수식 대상과 지역 맥락의 연결을 보존한다. ‘지역 브랜드’를 일반 기업 브랜드 강의로 대체하지 않고 다른 OR 분기에 지역 조건을 적용하지 않는다.
5. `source-meaning.js`: 일반 검색과 같은 조사·하다/되다 활용 경계를 사용한다. `request-predicate-evidence.js`는 기존 의미 규칙을 요청과 자료 양쪽에 재사용한다. 자기 회차의 동작 근거가 있으면 E5 상위80개 밖이라도 대조할 수 있다. 명사·고유명·명시 AND·제외·장르 조건은 유지한다. **이 경로는 계약검사를 통과했지만 기존370의 추가 후보 복구는0문장이므로 실자료 개선으로 세지 않는다.**
6. `source-context.js`·`source-polarity.js`: 동음이의어, 제작·변화·차이의 요청 대상, 명시적 과정 부재를 검사한다. ‘고장 나자/고장 낸’은 지역이 아니며 ‘연소 과정 없이’는 연소 관찰 근거가 아니다. ‘차별이 아닌 공존’이라는 대조를 주제 부재로 잘못 제외한 회귀는 기존 관련 자료 보존 검사에서 찾아 복구했다.
7. `search-diagnostics.js`: 내부 평가에서만 단계·조건별 통과 수와 근접 후보를 기록한다. 일반 HTTP 응답에는 진단을 내보내지 않는다.
