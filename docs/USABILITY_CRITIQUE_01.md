# 사용성 크리틱 1회 — 심사위원·초등교사 관점

2026-09-28. 사용자 요청에 따른 에이전트의 관점별 모의 검토다. 실제 심사위원 심사, 교사 참여 평가, 수업 적용 실험을 수행했다는 의미가 아니다. 이 문서의 한 차례 검토에서 발견한 사항을 수정하고 동작을 확인했다.

## 총평

수정 전 가장 큰 문제는 검색 결과의 제목과 ‘원문 보기’의 실제 도착 콘텐츠가 다르다는 점이다. 화면이 동작하고 카드가 표시되는 검증만으로 시연 품질을 판단한 것은 부족했다. 개별 영상·소개문·목록의 차이도 교사가 바로 알기 어려웠다.

심사위원 관점에서는 ‘질의 → 추천 → 원문 확인’ 연결의 신뢰성을 입증하지 못한다. 교사 관점에서는 추천 이후 다시 제목을 검색해야 하므로 업무를 줄였다고 보기 어렵다. 링크 일치 확인을 가장 먼저 고쳐야 한다.

## 실제 확인 범위

- 입력 목록: 기존 교과 클립 68건·PD로그 92건, 시연용 소개/목록 5건.
- 개별 주소 식별: 교과 클립 67건·PD로그 76건. 제목이 정확히 일치하지 않는 항목의 URL을 추측하지 않았다.
- 도착 페이지 일치: **클립 67건·PD로그 75건 = 142건**. 나머지 18건은 정확한 개별 주소 미확인으로 분류한다.
- 별도 출처 확인: 방송 소개 1·상품 목록 1·강의 목록 3건. 개별 영상 수에 포함하지 않는다.
- 검색 목록 전체 기준: 개별 페이지 확인 142건, 소개·목록 확인 5건, 제목 검색 안내 462건.
- ‘일치’는 클립의 선택 ID 또는 회차 재생기 영역의 제목과 URL 식별자를 대조했다는 뜻이다. 로그인 없이 전체 영상이 재생된다는 의미가 아니다.
- 신규 기록은 [링크 대조 자료](../server/data/source-link-audit.json)에 저장했다. 기존 승인 자산·원본 CSV의 출처 이력은 바꾸지 않았다.

## 재발 방지와 확인 명령

`server/source-links.js`가 콘텐츠 ID·제목·원래 URL·대조 상태를 확인해 이동 링크를 결정한다. 제목이나 원래 주소가 변경되면 이전 결과를 그대로 신뢰하지 않고 제목 검색으로 전환한다. EBS 허용 도메인·HTTPS만 이동 주소로 사용한다. 임시 서명 영상 주소를 저장하지 않는다.

```bash
npm run data:source-links:check
npm run simulate
```

브라우저 확인은 `server/discovery-browser-check.mjs`로 수행한다. 링크 대조를 다시 수행하려면 Playwright가 설치된 환경에서 `server/source-link-audit.mjs`를 실행한다. 이 작업은 공개 EBS 페이지에 접속하며, 일반 로컬 검색·시뮬레이션에서는 실행하지 않는다.

## 수정 후 판단

2026-09-29 사용자 재확인에서 메모의 주 링크 외 ‘수집 당시 출처·근거 페이지’가 여전히 무관한 기본 영상을 여는 것을 발견했다. 앞선 검증이 주 이동 주소만 확인한 한계가 있었다. 추가 크리틱 회차를 수행한 것이 아니라 해당 결함을 후속 수정했다. 카드와 메모에서 구 수집 목록을 이동 링크로 제거하고, 메모 생성 직전에 현재 링크 대조 결과를 조회한다. 이전 브라우저 모음의 잘못된 링크를 재현해 올바른 clipId로 내려받는 것을 확인했다. 소개문 근거와 콘텐츠 식별 대조는 구분해서 안내한다. 이미 내려받은 파일은 재다운로드해야 한다. 후속 검증은 로컬 11개·브라우저 13개와 링크 계약을 통과했으며, 링크 조회 실패 시 예전 주소로 다운로드하지 않고 재시도를 안내한다.

원문 접근 신뢰성을 보강한 로컬 탐색 도구로 시연할 수 있다. 다만 일반방송의 원하는 장면·짧은 구간 자동 추천, 초등 학년 적합성, 교사 업무 시간 절감은 아직 입증되지 않았다. 자료 제목과 도착 페이지가 일치하는 것을 교육적 적합성이나 추천 정확도로 대신 보고해서는 안 된다.

디자인 개편은 이번 수정에 포함하지 않았다. 처음 ‘랜딩페이지’를 Curi 홈으로 오해해 시도한 배치 변경은 사용자 설명 이후 되돌렸다.
