# R12-24 검색·화면 성능 개선

2026-10-15. 사용자 검색 대기·화면 반응 지연 제보에 따른 개선. 사용자 결과 확인 대기.

## 원인과 변경

- 자동 공개 자산의 원문 대조가 검색 요청마다 방송 22,794건 전체를 읽었다. `broadcast-store.js`에 바인딩된 ID 조회를 추가하고 `automatic-evidence-service.js`에서 필요한 자료만 조회한다. 같은 요청 안에서만 ID별 사본을 공유하고 다음 요청은 현재 원문을 다시 읽는다.
- `semantic-layer.js`가 자료·별칭마다 정규식을 다시 생성했다. 기존 규칙의 정규식을 재사용하며 매번 검색 위치를 초기화한다.
- `discover.js`의 탭 복귀 이벤트가 API 검색 전체를 반복했다. 개인 수업의 담김 표시만 갱신한다.
- `teacher-cards.js`는 개인 수업 JSON이 바뀔 때만 저장 위치 색인을 다시 만들고, `curi-v11.js`는 전체 수업을 한 번 읽어 카드별 표시를 갱신한다. 연속 DOM 변경은 한 애니메이션 프레임에 모은다.

## 측정과 검증

- 변경 전 실행 중인 서버의 동일 `바다` 검색 API: 5,506 / 6,382ms. 변경 후 서버 재시작·초기 준비 후: 447 / 107ms. 초기 준비 뒤 반복 응답은 약 92~98% 감소했다. CPU를 사용하는 별도 평가 작업이 병행되어 엄밀한 벤치마크는 아니다.
- 재시작 직후 첫 요청은 36,316ms. 카탈로그·전체 의미 색인의 최초 생성 지연은 남아 있다. 반복 검색 수치와 구분한다. 현재 로컬 서버는 준비를 마친 상태다.
- 동일 검색 379건·상위 9건 순서뿐 아니라 결과 객체 전체가 변경 전과 일치했다. 검색 규칙·정렬·근거·키워드 데이터는 변경하지 않았다.
- 전체 방송 조회 2,240ms에 비해 4개 ID 조회 합계 140ms. 처음·중간·마지막·없는 ID를 전체 조회의 필터 결과와 대조해 일치했다.
- 실제 방송 120건의 기존/변경 후 의미 감사 전체 객체를 반복 대조해 일치했다.
- 격리 브라우저 1440/390px: 탭 복귀 추가 검색 0건, 외부 수업 변경 후 담김 표시 갱신, 저장·되돌리기, 버튼 같은 줄 정렬·가로 넘침 없음·브라우저 오류 0건 확인.
- 자동 자산 계약 26개, 자동 근거 검사 41개 통과. 기존 저장소와 승인/취소 이력 불변·유료 호출 0건. 잘못된 원문 조회 입력도 조회 전에 거부한다.

## 결과 확인

웹을 새로고침한 뒤 검색·다른 탭에서 돌아오기·스크롤·가져가기 반응이 개선됐는지 확인한다. 탭 복귀는 개인 수업 표시만 갱신하므로 관리자가 바꾼 방송 자료를 보려면 다시 검색하거나 새로고침한다.
