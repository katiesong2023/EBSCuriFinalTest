# R12-17 — B / 발견의 장면 적용

2026-10-15 사용자가 B안 적용을 선택했다. 교사 웹 자료 찾기·내 수업 자료와 Chrome 사이드 패널에 적용했다. 사용자 결과 확인 대기로 진행중이다.

## 실제 적용

- 차콜 `#111214` 탐색면, 아이보리 `#F6F3EB` 자료·입력면, 살구 `#FF9660` 주요 행동, 라일락 과학/선택 폴더, 살구 사회 분류를 사용한다. 분류색에는 글자를 함께 표시한다.
- B 프레임·중심점 SVG 워드마크와 심볼을 적용하고 어두운 사각 바탕의 PNG16/32/48/128을 생성했다. 이전 A/B 비교안 파일은 수정하지 않았다.
- 한국어는 B가이드의 시스템 산세리프, 시간/숫자에는 고정폭 숫자를 쓴다. 웹 제목48/32px, 카드20px, 본문16px, 확장 본문14px을 적용한다.
- 최대1360px 웹·48/24/16px 여백·카드3/2/1열과 아이보리20px 반경을 적용한다. 목록 보기는 별도 유지한다.
- 내 수업은 넓은 화면에서 폴더 탐색3:자료9 비율, 작은 화면에서 세로 순서다. 기존 폴더 그림·라벨 색·3:4 장면·재생 목록 기능을 유지한다.
- 확장0.8.0은 어두운 브랜드 헤더/밝은 조작부, 라일락 선택 폴더·살구 가져가기 버튼을 쓴다. 최소44px 조작, 좁은 폭의 시간1열, 필드·상태 대비를 적용했다.
- 버튼120ms, 모달220ms/10px, 모션 줄이기 즉시 표시를 적용했다. 카드 확대·로고 반복 점멸은 사용하지 않는다.

## 최신 사용자 요청과의 조정

B 원안의 검색 후 제목 축소 제안보다 이후 사용자 요청을 우선하여 검색 전후 제목·검색란 위치와 크기를 유지한다. 최근 자료·웹 폴더 독·삭제된 필터·카드의 숨긴 설명을 재도입하지 않는다. 교육과정→폴더 가져가기와 되돌리기, 확장의 영상 전체/구간 탭·회차별 초안·페이지 이동 잠금은 최신 기능을 유지한다. 시안의 가상 데이터나 저장 로직을 운영으로 복사하지 않았다.

## 파일과 확인

- `public/curi-tokens.css`는 공통 B/읽기 토큰, `public/curi-b.css`는 웹 시각 체계다. 이전 기능 스타일 뒤에 적용한다.
- `extensions/curi-segments/panel-b.css`는 패널 시각 체계다. 패키징 스크립트에 포함했다.
- `public/brand/`의 자산과 토큰을 확장 폴더에 동기화하고 `public/downloads/curi-segments-extension.zip`을 재생성했다.
- [격리 화면 검사](r12-17-browser-check.json): 12항목 통과, 웹6폭(1440/1280/1000/768/390/360)·내 수업3폭·패널3폭(320/360/480) 가로 넘침0, 브라우저 오류0. 카드·목록·검색 복귀·가져가기/되돌리기·기존 메모·장면 순서·리스트 총길이·모션·앱 아이콘을 확인했다. 모사 확장 API와 가상 자료를 사용했다.
- 기존 저장6·팝업13·구간35·구간 연동7 검사 통과. 개인 실자료·DB·검색 순위 변경 없음.
- 실제 설치 패널·실제 EBS 영상 재생·실기기·스크린리더와 사용자 최종 시각 확인은 이번 검증에 포함하지 않았다.

## 결과 확인

1. 기존 서버에서 웹을 강력 새로고침하고 자료 찾기·내 수업을 확인한다. 정적 파일 변경이므로 서버 재시작은 필요하지 않다.
2. 설치용 ZIP을 다시 풀어 기존 설치 폴더를 교체하거나 저장소 확장 폴더를 사용한다. Chrome 확장 관리에서 새로고침하고 열린 Curi/EBS 탭도 새로고침한다.
3. 실제 영상에서 폴더 선택·영상 전체/구간·시작/끝 지정·가져가기/되돌리기·저장 구간 재생을 확인한다.
