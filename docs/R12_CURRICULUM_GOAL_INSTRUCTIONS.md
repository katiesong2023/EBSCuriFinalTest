# R12 교육과정 기반 수업 목표·연계 기록 수정 지시

2026-10-14 사용자 제안을 기존 R12 실행 방향에 반영한다. 사용자 설계 제안·코드 대조에 기반한 지시이며 실제 교사 사용성 검증 결과가 아니다. 이번 기록은 실행 기준 정리이며 제품 적용/검색 효과와 구분한다.

## 핵심 결정

교육과정은 수업 목표·자료의 역할·근거를 연결하는 기준이다. ‘교육과정으로 좁히기’를 ‘교육과정에 맞춰 찾기’로 바꾸되 사용자가 요청한 상세 필터 내부 배치는 유지한다. 선택 기준 관련 후보 우선을 새 기본 동작으로 두고 후보 한정/확인 기록 한정을 명시적으로 선택하게 한다. 기존 필수 국내·제외·프로그램·원문 식별 조건은 어느 모드에서도 완화하지 않는다.

관련 후보와 일반 주제 결과는 별도 구분하며 일반 결과에 선택 기준 연계/확인 상태를 복사하지 않는다. 기준 선택으로 결과가 줄어드는 것만 성공으로 보지 않는다. 교사가 목표를 구체화하고 자료의 역할과 남은 확인을 이해하며 저장/재사용하는 동선을 검증한다.

## 검색·상태 계약의 결정 사항

- 목표 상태는 공식 기준ID·교육과정 판본·선택 요구ID·개인 수업 목표·원하는 활용 목적·검색 범위를 담는다. 공식 요구/원문은 서비스가 변경하지 않고 개인 목표는 별도다.
- 관련 후보 우선도 원래 검색어/국내/제외·기존 선택 조건은 유지한다. 기준 개념/사례/다른 표현에 따른 발견 경로를 남기되 그것을 영상 적합성으로 승격하지 않는다.
- 관련 범위와 확장 범위의 건수·페이지·전체 정렬을 정의한다. 페이지가 바뀌거나 최신순으로 정렬해도 범위 표시는 유지한다. 기준/요구 변경 직전 응답은 폐기한다.
- 현재 COMBINED 결과의 APPROVED/자동/원문 비교는 선택 기준에 대응하는 관계만 사용한다. 확장 자료에는 다른 기준의 확인 기록을 선택 기준 확인으로 복사하지 않는다.
- 기존 주소/저장값의 엄격 교집합 의미를 훼손하지 않게 검색 범위 버전을 명시하고 기존 주소는 한정 모드로 복원한다. 새로운 목표 선택 흐름은 관련 후보 우선으로 시작한다. 관련 후보 우선에서 확인 기록 필터/관계 상태를 선택하면 해당 기준 기록에 한정됨을 표시한다.
- 자유 수업 목표와 영상 활용 목적은 기본적으로 개인 문맥이다. 원문에 없는 모형/실험/수업 활동을 요청 충족 근거로 사용하지 않는다.

## 개인 저장·공용 제안 계약

개인 목표/역할/구간/메모는 브라우저의 기존 개인 저장과 호환한다. 폴더의 목표와 영상별 역할을 분리한다. 검색 목표를 자료에 붙인 것은 교사의 의도이며 공식 연계 확인 기록이 아니다. 기존 lessonGoal/usePart/추가 내용과 새 목적/선택 요구를 버전 검증으로 복원한다.

공용 제안은 사용자가 명시적으로 제출할 때만 생성한다. 자동 공개·사람 승인·개인 활용 기록을 혼합하지 않는다. 제출 내용은 영상ID/판본·기준ID/교육과정 판본·요구·정확한 원문 인용/위치·공식 출처/원문 지문·확인 시점·미확인 요구를 담는다. 개인 메모/학생 정보/원하는 사용 구간은 기본 제출 대상에서 제외하고 공개될 필드를 검토한다.

원문이 변경되거나 인용이 다르거나 회차/기준이 불일치하면 제안은 보류한다. 사용자 작성 연결 이유와 검증 가능한 원문 사실을 별도로 저장한다. 관리자 검토 후 기존 자동/사람 확인 관계 경로를 사용한다. 기능 구현과 실제 제안 제출·승인은 구분한다.

## 실행 순서

1. CG-01~04: 목표 선택 및 검색 범위 계약을 R12-03/05에 연결한다. 이름만 바꾸고 교집합을 그대로 두는 것으로 완료하지 않는다.
2. CG-05~07: 결과의 연결 이유·인용과 개인 저장/폴더 목표를 같은 동선으로 검증한다. 기존 빠른 저장을 재사용한다.
3. CG-08: 공용 제안 접수와 기존 관리자 검토 경로를 연결한다. 담당자 없는 상태는 미검토 후보로 남긴다.
4. CG-09: 기술 검사·의미 관련성·실제 교사 선택/재사용을 분리해 평가한다. 실제 참여/사용이 없으면 효용 완료로 표시하지 않는다.

전체 기능은 미적용이다. 제품 파일·서버·원본 저장소·유료 API 변경 없이 지시/계약을 정리했다. 교육부 발표 링크는 사용자가 제공한 정책 참고 출처이며 웹 도구가 반환한 페이지에서는 본문을 확인하지 못했으므로 구체적 정책 구절을 이번 결정의 검증 근거로 인용하지 않는다. 설계는 사용자 제안과 현재 코드 대조에 근거한다.
