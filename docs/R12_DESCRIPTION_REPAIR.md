## 공식 소개문 보충

제목 반복도 “한국기행에서 제공하는 ‘강원도 겨울연가, 4부 겨울 설악’ 회차입니다”처럼 설명을 작성한다. 제목 기반임을 표시하고 확인되지 않은 장면·내용을 덧붙이지 않는다. 짧은 단서는 인용 범위와 한계를 표시한다. 잘리거나 손상된 원문은 온전한 문장만 사용하며 원래 문제는 `sourceIssues`와 펼친 원문에 보존한다.

작성 안내는 `contentPreview.text`이고 공식 소개는 `summary`다. 작성 안내를 원본 소개문·검색·태그·API 내용 판단 근거로 저장하지 않는다. 이전 오류 의심 문구를 대신해 보충한 설명과 작성 근거를 보여준다. 원문의 모든 오류나 영상과의 일치가 확정됐다는 뜻은 아니다.
