# R12-02 지정 프로그램·NEWS 클립 추가

2026-10-15 사용자 요청으로 공식 EBS 메타데이터를 CuriBase 검색 카탈로그에 추가했다. ‘AI인물사’는 사용자 확인을 받은 공식 명칭 **AI 드라마 - 부활수업**으로 등록했다. 사람 교육과정 승인 자산과 개인 자료를 변경하지 않았다.

| 대상 | 추가 | 확보한 근거·상태 |
|---|---:|---|
| 덩이랑 쾡이랑 인물 한국사 |13회차| 공식 표시13/식별13 일치. 제목과 회차 주소 확보, 소개문0 |
| AI 드라마 - 부활수업 |28회차| 공식 표시28/식별28 일치. 소개문28 |
| EBS AI 문학관 |프로그램 정보1| 공식 발표/공개 회차 준비 중. 공개 회차0, 영상으로 집계하지 않음 |

방송 저장소는 기존22,753→22,870건으로117건 증가했다. AI 문학관 발표 정보는 별도 프로그램 목록 자료로 검색에 포함한다. 전체 카탈로그·방송 원천·회차/클립·발표 자료의 분모를 혼용하지 않는다.

## 공식 출처와 수집 범위

[인물 한국사](https://home.ebs.co.kr/dqhistory)·[부활수업](https://home.ebs.co.kr/aidrama)의 공식 프로그램 검색 목록·다시보기/회차 페이지에서 고유course/step/lect ID를 보존했다. 애니키즈로 연결되는 회차도 원래 ID로 중복 방지한다. 알려진 특정 회차에 설명을 생성하지 않았다.

[AI 문학관 공식 발표](https://global.ebs.co.kr/board/bbs?boardId=31&boardTypeId=1&cmd=view&postId=30005523435)는10월16일 첫 방송 예정으로 안내한다. 현재 공식 프로그램 검색 목록에 공개 회차가 없어 공식 발표 문장과 출처를 프로그램 정보로 등록했다. 실제 회차/재생 가능한 영상으로 꾸미지 않았으며 발표 링크·첫 방송 예정일·‘공개 회차 준비 중’을 표시한다.

[NEWS 전체 목록](https://news.ebs.co.kr/ebsnews/menu1/newsAllList)의 현재 최신순 목록에서100개 고유 경로를 조사했다. 공식 개별 기사페이지의 영상 플레이어/영상 경로 존재·공개 본문·제목과course/step/lect 식별을 함께 확인했다. 일부 목록 항목은‘2026년… EBS 뉴스/뉴스12’형식의 일일 전체 방송으로 본문이 없는 이유를 재대조하여24건을클립 대상에서 제외했다. 최종 실패0. 재대조 포함142개 공개 HTTP 요청·영상/오디오 파일 다운로드0·유료 API0.

## 검색·표시·기록 보존

NEWS는 기존 방송 SQLite의 동일 EBS 회차 식별 계약을 사용하되 공식 기사 경로와 페이지 식별을 추가 대조한다. 판본NEWS_CLIP·자료 유형clip·뉴스 클립 라벨과 개별 기사 주소를 보존한다. 뉴스의 게시일은publishedDate로 저장하여 방송일로 추정하지 않고 화면에도 **뉴스 게시일**로 구분한다. 전체 클립 필터 명칭은 교과 클립에서클립으로 정리했다.

AI 문학관은kind=collection·sourceSystem=EBS_PROGRAM_ANNOUNCEMENT·playbackStatus=NOT_AVAILABLE이다. 프로그램/회차 목록에서 공식 발표를 볼 수 있다. 회차 없는 프로그램 안내를 재생·교육과정 적합성 확인으로 표시하지 않는다.

동일자료 식별 재적재는 추가0이며 잘못된 NEWS ID는 거절한다. 수집 전 백업과대조해 기존22,753행의 삭제/내용 지문 변경0, 승인/자동자산/교사등록 저장소SHA동일을 확인했다. 사람 승인·개인 폴더/기준/메모/구간은 그대로다.

기존 검색과 같은 규칙의시맨틱 저장소와로컬 의미 검색 색인을 갱신했다. 의미 색인23,479자료/28,777구절, 새117자료 모두 현재원문지문으로 반영·유료0이다. 원문 표현과 유사도는 실제 개념 설명·장면·학년 적합성의 승인이 아니다. 실제 영상 재생/수업 효용은 미검증이다.

## 검증과 한계

- 실제 Curi GET API에서 인물한국사13·부활수업28·NEWS클립76·문학관발표1을 확인했다.
- 390px 격리브라우저에서 프로그램4종 수, NEWS클립/게시일과폴더 가져가기, 문학관발표/미공개회차구분·오류/넘침0을 확인했다.
- DB/FTS 무결성·기존행보존·재적재/잘못된ID·기사/발표유형·보호저장소 검증 통과. 기존프로그램/장르12·방송형태9 회귀 통과.
- 기존broadcast-check의 ‘5개 주제 모두양수’검사는동고서저0으로실패했다. 수집전백업으로도0이며 나머지4질의는전후16/38/24/8동일이다. 이기존 검색공백은 이번신규수집 회귀로간주하지 않았으며 실패를 숨기지 않았다.
- 첫 실제API검사는전체색인준비 중 시간제한에걸렸고, 준비후4종GET/화면검사는성공했다. 검색효용 개선률이나전체NEWS수집완료를주장하지 않는다.
