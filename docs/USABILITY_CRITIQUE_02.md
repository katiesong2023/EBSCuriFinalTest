# 1차 마감 전 크리틱 1회

2026-09-30. 요청에 따라 일반방송 확대 후 버전을 교사·심사위원 관점에서 한 번 점검하고 아래 수정을 반영했다. 실제 교사·외부 심사위원의 평가를 받은 것은 아니다.

판정: 원문을 비교하고 수업 자료를 모으는 로컬 탐색 시연은 가능하다. 현업 완성품·범용 자연어 추천·교육과정 승인 완료로 제출하면 과장이다. 5,000건 확보는 모집단의 진전이며, 의미 검색과 수업 적합성의 완성을 뜻하지 않는다.

| --- | --- | --- |

## 확인 근거

- `npm run simulate`: 검색·API·유료 호출 차단·실제 저장소 불변 11개 시나리오.
- `npm run data:source-links:check`: 정확한 클립·회차 ID, 낡은 링크 무효화, 모음 링크 갱신.
- `npm run simulate:classroom`: 30개 가상 요청의 전후 비교. 후보 존재를 정답률로 보고하지 않음.
- `npm run data:broadcast:check`: 실제 5,548 ID, 중복 적재·실패 롤백·본문 보존·500/2,000/5,000건 규모 검증.
- `server/discovery-browser-check.mjs`: 데스크톱·모바일·검색 예시·프로그램 조건·뒤로가기·저장·다운로드·오류 복구 14개 흐름. 실제 화면은 `curi-local-desktop.png`, `curi-local-mobile.png`.

## 마지막에 판단할 사항

초등 학년별 적합성, 수업 장면·구간, 교육과정 직접 연계 승인, 교사 효용, 유료 모델 선택과 비용 허용, 외부 배포·최종 제출 승인을 남긴다. 지금 사용자에게 25건 검수·태깅을 요청하지 않는다. 자동 승인·가상 사람 평가·미실행 검수 기록도 만들지 않는다.

추가 기능 구현은 이번 1차 마감 범위에서 종료한다. 다음 작업의 상태·순서는 [PLANS](PLANS.md), 수집 실측은 [BROADCAST_CORPUS](BROADCAST_CORPUS.md)가 정본이다.
