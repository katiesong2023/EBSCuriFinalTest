# 교육과정 후보의 전체 소개문·공통 의미 대조

2026-10-16 사용자 요청. R12-33의 앞200자 제한과 표현 차이에 따른 누락, 무관한 후보를 개선했다.

## 반영 내용

가져오기와 자료의 교육과정 선택기는 제목·소개문 전체를JSON 본문으로 보낸다. 기존GET q는 검색어 조회 호환용으로 유지하고, 자료 조회는 읽기 전용POST `/api/curi/curriculum/related`를 사용한다. 자료 내용과 원 검색어는 별도 필드다. 제목2000자·소개문200000자·요청1MB의 입력 상한을 두며 허용 범위 안에서 앞부분을 잘라 쓰지 않는다. 잘못된 입력·혼합 조건은 오류로 처리한다.

`server/curriculum-content-match.js`는 기존 개념 어휘와 공통 의미 표현 묶음을 자료와 공식 기준 양쪽에 적용한다. 특정 기준ID의 추천 목록이나 사용자가 제공한 문장별 예외는 두지 않는다. 예를 들어 이주 배경·다문화·문화 다양성·다양한 문화를 같은 의미 묶음으로 비교하고, 독립운동·항일투쟁·국권 회복을 일제 식민 통치/저항 표현과 연결한다. 먹이 관계, 신체 기관/질병, 전자기, 대표 선출 등도 같은 경로를 사용한다.

같은 단어만으로 기준 수를 채우지 않는다. 소재가 분명한 기준 핵심어, 문맥이 맞는 기존 별칭, 의미 묶음 중 실제 자료 근거가 있어야 한다. 일반 수행어·실험·원리·역사·과거 같은 넓은 표현만의 일치는 제외한다. `source-literal`·`source-editorial`의 은유/제작 안내 마스킹을 재사용하고 명시적인 부정과 별도 통계·동음이의어 문맥을 검사한다. 지역·대륙·역사 시대, 인구 분포, 학교 자치, 미디어, 연소, 회로 등 기준의 중심 범위가 다르면 제외한다. 공식 기준 원문과 원래 제목·소개문은 변경하지 않는다.

검색어는 내용에서 근거가 확보된 후보 안의 순위만 조정한다. 검색어만 맞는 후보를 추가하지 않는다. 관련도 순서, 전체214기준 보기, 다중 선택과 저장 동작은 유지한다. 후보별 의미 연결/공통 소재와 원문field/start/end/quote를 응답해 검토할 수 있다. 소개문 뒤쪽의 근거도 실제 UTF-16 원문 위치로 제공한다.

## 검증

- 공통 의미·부정/범위/동음이의어·긴 소개문·입력 검증38건: `node server/curriculum-content-meaning-check.js`. [결과](r12-34-content-meaning-check.json).
- 검색 의도 순위·내용 근거 없는 후보 추가 방지·기존GET/필터6건: `node server/curriculum-related-context-check.js`. [결과](r12-34-related-context-check.json). 기존 인구/건강 혼합 표본은 분포 내용이 실제로 있어야 후보가 되도록 “인구 분포”가 명시된 자료로 갱신했다.
- 임시 서버의 전체 소개문POST·GET 호환·잘못된JSON/본문/길이/주소 조건4건: `node server/curriculum-content-http-check.js`. [결과](r12-34-content-http-check.json).
- 실제 검색 화면의 현재/저장 검색어·관련 순서·다중 선택·전체214보기·단계 이동·소개문 뒤쪽 내용5건: `node server/curriculum-related-context-browser-check.js`. [결과](r12-34-related-context-browser-check.json), [모바일](r12-34-related-ranked-390.png), [PC](r12-34-related-ranked-1440.png).
- 기존 가져가기/폴더 저장·메모 보존·취소·중복 방지·저장 실패 재시도11건 통과. 기존 `teacher-bring-browser-check.js`를 산출물 이름만 분리한 임시 복사본으로 실행했다. [결과](r12-34-bring-curriculum-subject-check.json).
- 실제16자료 및51근거 대조: `node server/curriculum-content-audit.js`.

검증 중 POST 메서드 허용 누락을 발견해 수정했고 최종HTTP 검증은 통과했다. 브라우저는 격리 저장소를 사용했다. 유료API호출0, 실제 개인 기록·원문/승인 저장소 변경 없음. 자료 검색 로직 자체는 변경하지 않아200/170 검색 결과 평가는 재실행하지 않았다. 최종 서버의 최초 검색 준비를 기다린 뒤 화면을 확인한다.

## 해석 범위

이 구현은 로컬 어휘·문맥 규칙으로 찾는 교육과정 관련 후보다. 영상 장면·학생 수행·기준 전체 충족을 판정하지 않는다. 알려지지 않은 동의 표현은 여전히 누락될 수 있으며, 모든 가능한 문맥의 정확성을 보장하는 모델 평가로 집계하지 않는다. 특정 지역·시대가 명시된 기준은 해당 근거를 요구해 일반 문화·역사 자료에서 후보 수가 줄 수 있다. 전체 기준 직접 선택과 기존 개인 기록은 유지한다.
