# R12-39 요청 역할과 내용 검색의 공통 구조

## 해결 대상

기존 검색은 시청 대상이 이미 인식돼도 같은 단어를 내용 AND 조건으로 다시 검사했다. 구조화 해석 계약은 준비되어 있었지만 일반 GET 검색에는 적용되지 않았고, 공급된 계약도 원래 문자열을 다시 검사하면서 목적·선호·연도에 막혔다. 일부 명사는 조사 제거 과정에서 훼손됐다. 과거 200/170 실행의 오류 없음·결과 있음 건수는 의미 정확도 통과를 뜻하지 않는다.

## 적용한 구조

`request-context-roles.js`는 원문 위치를 보존하면서 명시적 대상·목적과 내용 투영을 구분한다. 일반 검색은 보수적인 로컬 역할 추출을 사용하고, 검증된 구조화 해석은 계약의 역할을 사용한다. 검색용 투영만 공백으로 가리며 사용자 원문과 역할별 근거는 `understanding.requestProjection`에 남긴다. 교육용 로봇·어린이 인권 등 내용 대상은 보존한다. 이 모듈은 범용 한국어 의미 분석기가 아니다.

구조화 경로의 프로그램·형태·날짜·제외 조건은 기존 실행식에서 대조한다. 검증된 문법 구절도 투영 경계에서 분리한다. 원문 문맥은 각 내용 절을 검색할 때 확인하고 전체 요청의 필수/제외 조합은 검증된 논리식으로 결정한다. 원래 문장의 어휘 AND 검사를 뒤에서 다시 적용하지 않는다. 목적·대상·선호가 내용 필수어로 재유입되지 않도록 같은 투영 경계를 적용했다. 명시된 주제 절은 `interpretContext:false`로 검색해 시청 대상으로 다시 분류하지 않는다. 캐시에도 해석 모드를 포함한다. 원문 인용·AND/OR·기존 선택 필터·후보 재검토 검사는 유지한다. 문맥으로 주제를 숨기거나 원문 선호 표시 없이 필수 내용을 선호로 낮추는 계약은 거절한다.

`request-nouns.js`는 기존 콘텐츠 어휘·의미 규칙·단원 어휘와 실제 카탈로그의 완전한 어절을 공유한다. 온전한 등록 명사를 우선하며, 한 글자 조사를 제거할 때는 확인 가능한 기본형만 사용한다. 여러 음절의 명시적 격 표지는 별도로 처리한다. 미지의 끝음절을 무조건 자르지 않는다. 원천 어절 조회는 요청에 필요한 형태만 확인하고 최대 512개 판정을 보관한다. 전체 소개문의 어절 집합을 복제하지 않는다. 원천 어절은 형태 정규화에만 사용하며 단어의 존재를 관련성이나 적합성으로 승격하지 않는다.

내용 없이 대상·목적만 입력한 경우 전체 자료를 반환하던 우회를 막고 `TOPIC_REQUIRED`를 반환한다. 대상 적합성은 `UNCONFIRMED`다.

반복 실행의 메모리 사용을 제한하기 위해 `search-term-matching.js`의 유니코드 경계·조사 검사를 공유한다. 단어별 리터럴 검색과 경계 검사를 분리하며 최대 2,048개 패턴을 보관한다. 기존 어휘·조사·유니코드 경계·기존 결과 본문에서 30,275회 비교 결과가 동일했다. 앞선 중간 실행의 메모리 종료는 성공으로 세지 않으며 보완 코드로 전체 검증을 재실행했다.

## 재사용한 기존 작업

입력 봉투, v1 해석 Schema, 원문 위치·논리 검증, 계약 실행기, 원문 근거 검사, 후보 재검토 및 모델 요청 준비 기능을 재사용했다. 새 주제별 답안·콘텐츠 ID·질의별 결과 목록을 추가하지 않았다. 모델 요청 준비와 실제 모델 호출은 구분하며 유료 API는 실행하지 않았다.

## 검증

새 성공 예문 세트 대신 기존 370문장 각각에 동일한 문맥 변형 두 종류를 적용해 내용·제외·장르·시간 조건 불변 740회를 검사했다. 등록 어휘 1,211개의 온전한 명사 보존, 기존 요청 계약 10개, 로컬/구조화 제품 경로와 문맥만 있는 요청을 확인했다. 사용자 재현 질의는 원인 재현용이며 새 정확도 표본으로 집계하지 않는다.

기존 연결 검사에서 과거 원천 파일의 고정 SHA를 현재 데이터에 비교하던 부분은 실행 전후 SHA 보존 검사로 수정했다. 검색 계약을 완화하지 않았으며 현재 원천 판본에서 부수 변경을 감지한다.

실제 370문장 실행을 완료했다. 실행 중 다른 작업의 파일 변경이 검색 엔진에 섞이지 않도록 평가 프로세스가 서버 JS 원문을 고정하고 그 해시를 기록한다. 데이터 전후 해시도 별도 기록한다.

## 남는 범위

로컬 역할 분석은 명시적 표현에 한정된다. 낯선 문장 전체의 의미 이해, 원문에 없는 동의 표현, 관계 충족, 소개문 부족은 모두 해결됐다고 주장할 수 없다. 실제 모델 실행·검색 후 후보 내용 검토의 연결과 별도 관련성 평가가 필요하다. 기존 370문장의 빈 결과 감소만으로 자연어 검색 완성을 선언하지 않는다.

22,161개 대표 자료 카탈로그에서 370문장 모두 로컬 E5 경로로 실행했다. 입력의 참고 교과/학년/기대 유형은 검색 조건에 주입하지 않았다. 실행 중 서버 JS와 보호한5저장소의 변경0, 실행 소스와 최종 디스크 소스 지문 차이0이다. 최종 실행은 약3분22초이며 기본 Node 설정으로 완주했다. 주 프로세스 heap 관측 최대1,158MiB는 배포 RSS/필요 메모리 측정치가 아니다. 중간 메모리 종료를 최종 성공 건수로 합치지 않았다.

결과가 있는34문장은 정확한 정답34개라는 뜻이 아니다. 빈336문장도 미보유나 오답으로 확정할 수 없다. 과거23/17 등은 다른 코드 판본이므로 이를 직접 전후 정확도 비교로 사용하지 않는다. 이번 변경으로 모든 자연어 해석/누락을 해결했다고 보고하지 않는다.

사용자 재현 요청은 실제 로컬 HTTP에서 `자본주의`29건, `자본주의 초등학생 교육용 자료`0→29건으로 확인했다. 변경 후 두 요청의 결과 ID/순서가 동일하며, `초등학생 교육용 자료`는 내용 주제를 요청하는 `TOPIC_REQUIRED`를 반환한다. 29건의 초등 적합성을 확인했다는 뜻은 아니다. 검증된 v1 해석을 공급한 구조화 POST에서도 채택=true/29건/동일 ID·순서를 확인했다. LLM 공급자의 실제 호출은 제품 검색에 활성화하지 않았으며, 해석 응답을 공급받아 실행하는 경로를 검증한 것이다. 로컬 서버에 최종 코드를 반영했다. 유료 API 호출0회다.
