# R12-01 수업 준비 요청 출처·현재 제품 기준선

2026-10-14. **실제 교사 요청 확인0건, 기존 대리 사례의 제품 기준선 측정 완료.** 사용자가 “실제 교사가 요청한 사례가 아닙니다”라고 확인했다. 실제 요청24개·새 평가12개·교사 선택 성공률은 아직 확보/측정하지 않았다. 대리 사례와 에이전트 원문 검토를 실제 교사 효용으로 보고하지 않는다.

## 현재 자료와 제품 버전

실제 방송·저장 자료를 복제한 임시 서버에서 현재 제품 코드를 실행했다. 합성 방송 자료는 실제 방송DB 복제본으로 교체했다. 실제 로컬E5·현재 교사 검색 API·기존9개 페이지 단위를 사용했다. 상위20개 확보에 최대3페이지를 조회했다. 모델 호출/원천 수집/영상 재생은 하지 않았다.

- 고유 자료23,360: 대표22,118 + 보존 판본1,242. 현재원문 최소기준 통과4,717/23,360(20.2%). 이는 요청/교육과정/영상 적합성 통과가 아니다.
- `source-text-v3` 분포: 소개문 없음13,078 · 제목 반복1,208 · 편성/제작 중심426 · 짧은 설명7,789 · 구체적 설명859. 짧은 설명 중 최소기준 통과 여부는 따로 판단한다.
- 과거4,713과 현재4,717은 같은 시점의 수치가 아니다. 이전 복구가능4회차는 이번 시작 시점에 이미 설명이 변경돼 있었다. 이번 작업이 복구한 실적으로 집계하지 않는다.
- 코드/원본/검색색인 지문과 [동결 묶음](r12-01-baseline-snapshot.zip)·[파일 명세](r12-01-snapshot-manifest.json)를 보존했다.252파일의 코드·JSON·CSV·SQLite를 포함하고 `.env`·키·브라우저 개인 저장값·모델 가중치는 제외했다. 재현에는 기존Node24.18.0·패키지·로컬E5 캐시가 필요하다.

사회 우선 원인군은 **제외·선호 조건/주민 협력·산업 변화 관계**다. 개발용H06/H10 및 동네 공동결정 요청을 묶는다. 과학 우선 원인군은 **연소 필요조건·비교 실험의 내용 근거/발견 공백**이다. H04/H07과 연소/동물 비교를 묶는다. 각군은 질문 의미→실제 관련 회차 확보→검색/순위→선택근거로 대조하며, 정답 미확보 상태에서 전량 수집/해석만으로 해결을 단정하지 않는다.

사회 수집은 극한 직업/위대한 수업의 같은 상세 경로를 우선 조사한다. 과학은 자석·연소의 요청을 설명할 공식 회차/교과 클립과 공개 학습 원문 확보를 함께 조사한다. 우리집 유치원·뿡뿡이의 주소/회차 대조 문제는 별도 경로군으로 조사하되 유아방송을 초등 수업 적합 자료로 자동 판정하지 않는다. [현재 프로그램군/이전12후보 대조](r12-01-source-groups.json)에서 이전4회차 변경과 여전히 남은6식별/2텍스트 부족을 구분했다. 공식 원문 재확인/신규 수집은 R12-02에서 수행한다.

## 실제 요청 확보와 미완료

실제 요청24개와 새 미노출 평가12개는 준비되지 않았다. [입력 양식](r12-01-teacher-request-template.json)의24공란은 요청 데이터가 아니다. 교사가 자신의 예정 수업에 대해 익명 역할·원문 요청·수업 목표·활용 목적·필수/선호·확인 필요한 조건을 작성하고, 출처를 확인한 뒤 유사 주제군 기준으로 개발/평가를 분리한다. 이름·학교·연락처는 입력하지 않는다. 연락/초대 발송은 수행하지 않았다.

자료 선택 성공의 기존 목표(12회 중10회·과목별5/6, 기준선 대비3회 증가 또는 고성공군 시간30%감소)는 아직 개발 전의 잠정 목표다. 실제 요청의 난이도/기준선을 확보해 변경 전에 고정한다. 실제 요청 미확보와 미실행 사람 판단은 task 미완료로 남긴다. 대리 사례 기반 수집/검색 진단과 UX 검토는 이어갈 수 있다.
