# R09-01 학년 확장 구현·검증 결과

후속 운영 변경: 2026-10-10 사용자 요청으로 기존 사람 승인4건을 취소하여 현재 승인/승인 검색 투영은0건이다. 이전 승인·취소 이력은 보존했고 자동 공개1건은 유지했다. 아래 수치와 회귀 결과는 승인 취소 전 확장 구현 시점의 기록이다. [취소 기록](r09-01-approval-revocation.json)

2026-10-10 구현과 에이전트 검증을 마쳤다. 사용자 결과 확인은 대기한다. 실제 사람의 교육과정 적합성·수업 효용 평가는 수행하지 않았다.

## 적용 범위와 콘텐츠 증가

공식 성취기준136개를 추가해214개를 제공한다. 초등3~4 사회22·과학51, 기존 초등5~6 사회27·과학51, 중1 EBS 참고 사회37·과학26이다. 신규 기준은 `SOURCE`/`SOURCE_CHECKED`, `humanConfirmed:false`로 저장했다. [공식 PDF와 뉴런 교재·강좌 대조 기록](R09_01_CURRICULUM_SOURCES.md)에 문서 지문·원문 코드/쪽·편성19개와 한계를 기록했다.

같은 현재 카탈로그를 대상으로 기존78개만 적용한 결과와 확장214개 결과를 비교했다. 학년 확장으로 **고유 탐색 후보는1,015→2,894개(+1,879개)**, 자료×성취기준 후보 관계는1,816→8,531개로 늘었다. 최소 소개문이 있는 고유 후보는544→1,324개다. 신규 영상 수집이나 승인 증가를 뜻하지 않는다. 같은 자료가 여러 기준에 대응할 수 있으며, 구간별 고유 수를 합하면 전체 고유 수와 다르다.

초기 일반어 추출의 고유 후보4,753개는 최종값으로 사용하지 않는다. 수행어·어미까지 일치하는 과도한 후보를 제외하고, 추가45단원의 구체 중심어 중 공식 본문에 실제 있는 표현만 대조한 위 수치를 사용한다. 기존78개 탐색어와 기준별 결과는 이전 R08-05 보고서 및 같은 카탈로그 기준선과 동일하다.

## 연결한 동작과 보존 경계

- 초등3~6·중1 단일 학년, 학년군, 복수 학교급 열거를 해석한다. 학교급 없는1/2학년·초1·중2는 확인이 필요하다. 명시한 지원 학년 선택은 문장보다 우선하고 충돌을 알린다.
- 교사 단일 목록과 기존 승인 검색은 과정·교과에 해당하는 판본별 관계만 표시한다. 원본 방송에 학년이 없어도 주제 후보는 남긴다. URL·뒤로가기·새로고침에 선택을 보존한다.
- 교육과정 역방향 탐색과 관리 공백 화면에 과정별 기준·후보·원문·규칙·현재 공개/승인을 표시한다. 저장된 실제 자동 검사·무효 상태와 사람 결정/현재 승인은 별도로 집계한다. 실행 이력이 없는0과 규칙 미지원 범위를 혼동하지 않는다.
- 후보→CuriMap 초안→legacy 사람 검토→승인 저장과 관계별 자동/사람 경로에서 과정 충돌을 거절한다. 원본 콘텐츠 학년 Seed와 수업용 `curriculumGradeBand`를 분리한다. 신규 기준의 공식 원문·편성 버전 변경은 해당 관계를 재평가한다.
- 폴더의 대상 학년과 자료별 선택 성취기준을 저장·재열기·내보내기에 유지한다. 이전 폴더와 신규 빈 폴더는 학년을 추정하지 않는다. 난이도·선행 개념·장면·사용 구간은 미확인으로 남긴다.
- 기존78개 기준, 승인4개, 무효 이력2개, 연계6개, 초안 실행14개, 검색 투영4개를 보존했다. 자동 공개1개와 방송/시맨틱/자동 SQLite의 파일 지문도 유지했다. 신규 사람 결정은 실제 저장소에 쓰지 않았다.

## 재현과 후속 확인

현재 저장소에 적재 완료했다. 새 작업 사본에서는 공식 PDF와 기존 저장소를 준비하고 `node server/curriculum-expansion-import.js`로 사전 검사, `node server/curriculum-expansion-import.js --apply`로 병합한다. 반복 적재는136개 unchanged다. 개별 검증은 `node server/grade-curriculum-check.js`, `node server/grade-discovery-check.js`, `node server/grade-evidence-check.js`, `node server/grade-search-check.js`, `node server/grade-legacy-review-check.js`로 실행한다.

사용자 확인 절차는 [task](../Tasks/task-r09-01-grade-expansion.md)에 있다. 실제 승인 증가에는 공개 원문과 관계 규칙 또는 선택적 사람 검토가 추가로 필요하다. 후보 없는 기준과 최소 원문 부족 자료는 교육과정 공백 화면에서 후속 보강 대상으로 확인할 수 있다.
