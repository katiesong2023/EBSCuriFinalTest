## 디자인 기준

Curi를 따뜻한 교육 매거진처럼 표현한다. 크림 배경에 큰 이미지와 굵은 제목을 두고 필 형태 버튼·태그로 행동과 분류를 안내한다. 사용자 원문이 시각 정본이며 이 문서는 실제 구현과 관리자 확장·기존 기능의 적용 범위를 정리한다. 참고 사이트는 [Creative Boom](https://www.creativeboom.com/)이며 그 사이트의 로고·이미지·문구는 복사하지 않았다.

## 로고와 서체

- 소문자 `curi`: Instrument Sans600, 자간−4%의 실제 글리프 윤곽을 SVG로 제작했다. 웹32px·확장24px 시각 크기에 맞춘다.
- 심볼 `c:`: 같은 서체의 소문자 c와 시작/끝을 뜻하는 두 점. Ink/Cream 두 버전이다.
- 앱 아이콘: Sun 사각 배경에 Ink 심볼.16/32/48/128px PNG와 SVG를 제공한다.
- 헤더의 워드마크는80px 스크롤 후 심볼로 전환하고 높이를72→56px로 줄인다. 관리자·확장과 명령 검색에서도 동일 브랜드를 쓴다.
- 한국어: Gothic A1 400/500/700/800. 라틴·숫자·컨트롤: Instrument Sans400–700 + Gothic A1 fallback.
- Google Fonts 공식 저장소에서 받은 TTF와 각 OFL 라이선스를 `public/fonts/`에 로컬 제공한다. 외부 CDN 없이 웹/확장에 같은 원본을 포함한다. 별도 폰트 설치는 필요 없다.

| 역할 | 크기/행간 | 굵기 |
| --- | --- | --- |
| 홈 질문 |56/60, 모바일36/40 |700 |
| 섹션/특집 |28/36 |700 |
| 자료 제목 |20/26 |700, 최대2줄 |
| 본문 |16/26 |400 |
| 메타·버튼 |14/20 |400/700 |
| 태그 |12px, +3% 자간 |700 |

한국어 제목은 단어를 보존해 줄바꿈하고 `text-wrap:balance`를 사용한다. 숫자·시간은 tabular-nums다. 운영 화면에서 임의로 다른 글자 굵기/서체를 혼용하지 않는다.

## UI와 그리드

- 최대1320px, 데스크톱 좌우40px/거터24px·3열, 태블릿24px/20px·2열, 모바일16px/16px·1열이다.
- 홈은 특집8:최근 목록4 비율. 일반 카드 이미지는4:3, 특집16:9, 반경14px다.
- 자료 카드는 테두리/그림자 없이 이미지→유형/교과 필→제목→날짜/저장 상태→내용 안내→원문/담기로 이어진다.
- 버튼·태그는999px pill, 주요 버튼은 Ink/Cream→Coral/Ink hover, 담기 강조는 Sun/Ink, 보조 행동은 Ink outline이다.
- 입력은 읽기 면과 경계로 구분하며 주요 조작 목표는44px 이상을 기본으로 한다. 좁은 관리자 표는 내부 가로 스크롤을 허용한다.
- 다크 밴드는 Ink 면·Cream 글자·24px 반경·28px 안쪽 여백이다. 링크는 밝은 outline pill이다.
- 검색 팔레트는 최대520px·Cream 면·16px 반경·Ink45% backdrop·전용 그림자다.

## 웹 적용

홈의 질문은 ‘어떤 수업을 준비하세요?’다. 검색과 예시 펼침, 새로 살펴볼 자료·최근 방송 자료·개인 수업 폴더 다크 밴드를 제공한다. 홈 자료는 공식 카탈로그 API의 방송일 최신순을 읽는다. 수집일이나 교사 추천 점수로 표시하지 않는다. 홈에서 가져가기도 기존 교육과정→폴더 저장 흐름을 사용한다.

결과는3/2/1열 카드형이다. 정렬은 오른쪽, 검색 조건 블록은 상세 필터 위, 상세 필터는 주제→자료 유형→프로그램명 순서다. 사용자 요청으로 숨긴 장문의 안내·확인 옵션은 다시 표시하지 않는다. 검색 제출/Enter/주제 예시에서 결과로 이동하며 정렬·필터 변경으로 임의 스크롤하지 않는다.

내 수업은 폴더 필4단+자료8단으로 구성하고 선택 폴더를 Ink 면으로 반전한다. 오른쪽에 Sun 폴더 헤더·자료/메모/구간·다크 재생 목록을 둔다. 좁은 폭은 세로 순서다. 기존 폴더 삭제·위치별 기록·교육과정·메모·구간·재생 순서·내보내기·되돌리기는 같은 저장 계약을 사용한다.

## Chrome 확장

현재 영상은 흰16px 카드·16:9 이미지이며 원본 영상 선택 상태를 식별한다. 폴더는 개수와 함께 pill로 선택한다.5개 이하는 펼침,6개 이상은 기존 검색/최근3개 정책을 유지한다. 드롭다운은 기존 내부 동기화용 hidden 요소만 남긴다.

현재 영상/폴더 선택→영상 전체 또는 구간 지정→폴더명에 담기→확인된 결과 순서다. 전체 모드에는 구간 입력을 강제하지 않는다. 시작 시간 읽기·끝 지정·타입/길이 검증·영상별 초안·다른 영상으로 이동 시 저장 잠금·폴더 조회 실패/재시도를 유지한다. 설정은 접힌 영역에 있고 기본 화면에서 주소를 노출하지 않는다. 패널 폭은 Chrome이 결정하며320/360/480px에서 확인한다.

## 관리자 적용 규칙

| 영역 | C 적용 | 유지하는 업무 계약 |

| 로그인 | curi 헤더·흰 패널·Ink 주요 버튼 | 관리자 코드/세션·실패 안내 |
| 관리 목록 | 크림 바탕·흰 지표/자료·Sun 지표 강조·필 버튼/배지 | 오류 우선·선택·페이지·작업 준비 |
| 관리 상세 | 두 열 비교·명확한 근거/상태 위계·읽기 면 | 원문/자동 후보/사람 결정 분리·미저장 입력 |
| 교육과정 | 공통 검색·선택창·요약표·흰 패널 | 공식 기준·공백/미지원·관계별 비교 |
| 가져오기/CuriMap | 공통 헤더/입력/단계 패널 | 미리보기·검사·명시적 저장 |
| 검수 이동·기존 검색 | 동일 브랜드/팔레트/타이포 | 기존 이동/승인 검색 경로 |

관리 화면에서는 자동 처리가 사람 승인처럼 보이지 않도록 상태 문구를 유지한다. 위험한 쓰기를 시각 시연용으로 실행하지 않는다. 이번 관리 브라우저 확인은 임시 저장소와 세션으로 진행했고 사용자 DB/개인 기록은 바꾸지 않았다.

## 인터랙션·키보드

- ⌘K/Ctrl+K·헤더 칩: 같은 검색 팔레트. 입력·↑/↓·Enter·Escape·배경 클릭·포커스 복귀, 네이티브 모달 포커스 제한을 제공한다.
- 다른 모달 작업 중에는 팔레트를 열지 않아 입력 문맥을 지킨다. 확장 팔레트의 검색/내 자료는 설정한 localhost Curi 탭으로 연다.
- 이미지 hover/키보드 focus1.04배·제목 밑줄,500ms. 담기 강조 hover−2px,150ms.
- 결과 갱신 전후 같은 자료 ID의 위치만300ms FLIP 이동한다. 사용자가 스크롤했거나 모션 줄이기면 이동하지 않는다.
- 저장 토스트는 Green/Ink,200ms 진입·기본2.4초. 키보드 포커스/hover 중에는 사라지지 않는다. 실제 저장 성공만 완료로 알린다.
- 모션 줄이기는 확대·이동·등장 애니메이션을 끈다. 내용·행동은 즉시 표시한다.

## 원문에서 현재 제품으로 조정한 범위

- 실제 공유 폴더 서비스가 없어 ‘다른 선생님들의 폴더’를 만들지 않았다. 개인 수업 폴더 다크 밴드로 연결한다.
- 수작업 특집/추천 점수 대신 실제 방송일 최신순 자료를 사용한다. 정지 화면이 없으면 유형 컬러와 실제 메타데이터를 쓴다.
- 서버 검색/페이지 계약(현재9개)과 기존 페이지 탐색을 유지한다. 원문의12개/더보기·필터태그 복구는 별도 기능 변경으로 간주하고 구현했다고 표시하지 않는다.
- 직전 사용자 요청의 결과 제목 검색어 제거·유형 선택의 상세 필터 이동·관련 목록 분리·카드형 고정은 유지한다.
- 기존 초안/폴더를 파괴할 수 있는 기능 계약은 스타일 문서의 간략 와이어프레임으로 대체하지 않는다.

## 정본 파일과 검증

공통 `public/curi-tokens.css`, `fonts/magazine.css`, `curi-c-ui.css`, `curi-c.js`, `brand/`가 정본이다. 웹은 `curi-c-web.css`·`curi-c-home.js`, 관리자는 `curi-c-admin.css`, 확장은 `panel-c.css`를 사용한다. 이전 CSS는 기존 기능 배치의 토대/이력으로 남기고 C 레이어가 최종 시각 체계를 담당한다. 활성 HTML에서 이전 색/아이콘 보정 CSS를 로드하지 않는다.

격리 웹·확장12검사(웹6폭·내 수업3폭·패널3폭), 임시 관리자 로그인과7화면×2폭, 대비12조합, 기존 저장6/팝업13/구간35/구간 연동7/관리 문맥7 검사를 통과했다. 실제 설치 패널·실제 영상 재생·스크린리더·실기기와 사용자 최종 디자인 확인은 남아 있다.
