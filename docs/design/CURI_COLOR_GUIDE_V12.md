# Curi 컬러 가이드 v1.2 — 밝은 바탕과 선명한 포인트

2026-10-15 · 사용자 요청 반영 · 웹·Chrome 확장 공통

기존 [스타일 v1.1](../../Curi%20스타일%20가이드%20v1.1.md)의 레이아웃·IBM Plex Sans KR·기본 로고 배치·글자 굵기를 유지한다. 2026-10-16 사용자 확정으로 운영 로고는 점 없는 **폴더 심벌 + EBS CURI**다. [심벌 비교안](ebs-curi-logo-options.html)의 C안을 적용하며 작은 크기의 가독성을 위해 짙은 윤곽선을 사용한다. 이번 가이드는 컬러와 파일·폴더 아이콘 보정만 대체한다. [B안](option-b/CURI_STYLEGUIDE_B.md)의 살구·라일락·연두·블루를 밝은 크림 바탕에 맞춰 재배치했다. B안의 차콜 전체 배경·대형 타이포·프레임 로고는 적용하지 않는다.

포인트 위에는 Ink 글자를 쓴다. 연한 포인트의 기본 글자는 Ink다. 단, 사용자 지정 예외인 썸네일 대체 면의 제목·프로그램명은 흰색이며 프로그램명은11px, 회차명은PC21px/모바일18px·굵기700으로 표시하고 글자 그림자를 더한다. 오류는 기존 빨강+오류 문구, 완료는 실제 저장 응답+폴더명으로 표시한다. 연두만으로 완료를 전달하지 않는다. 사회·과학 분류와 저장/승인 상태는 별개다. 자료 유형 색의 기존 매핑은 유지하고 색 값만 교체한다. 버튼의 행동과 분류는 문구·위치·컴포넌트 형태로 구분한다.

## 적용 규칙

- 크림/흰 면의 기존 넓이와 레이아웃을 유지하고 주요 버튼·선택·폴더/유형 색을 선명하게 한다. 큰 패널 전체를 포인트색으로 채우지 않는다.
- 주요 행동은 살구+Ink, 선택은 보라 링+옅은 라일락이다. hover·선택·완료에 같은 의미를 부여하지 않는다.
- 웹과 확장은 같은 `curi-tokens.css`·`curi-colors.css`를 사용한다. 기존 색 키 coral/sun/lilac/mint는 저장 호환을 위해 유지하되 표시명은 살구/연두/라일락/블루다.
- 일반 텍스트4.5:1, 경계·포커스3:1을 기준으로 실제 조합을 [검사 기록](../r12-18-color-check.json)에서 확인한다.

검색 카드의 썸네일 연결이 실패하면 살구·라일락·연두·블루 중 한 색을 콘텐츠별로 배정하고 은은한 명도 그라데이션을 적용한다. 반분·줄무늬·격자 패턴은 사용하지 않는다. `teacher-cards.js`는 콘텐츠ID를 기준으로 같은 자료에 같은 색을 유지하며, 여러 자료가 같은 색을 사용할 수 있다. 정상 썸네일은 이 배경 위에 표시하고 제목·방송 링크는 기존대로 유지한다. 운영 표시 규칙은 `public/curi-v11.css`의 `.resource-thumbnail-link`에 둔다.

## 파일·폴더 형태와 선택

폴더는 탭에서 본체로 경사지게 이어지는 실루엣과 앞 주머니로 표현한다. 뒤판·사진·앞면을 다른 레이어에 놓아 사진이 폴더 안에 들어간 인상을 유지한다. 확장은 같은 SVG 실루엣을 쓰며 탭 전체를 버튼 경계 안에 둔다.

파일/장면은 종이 모양과 오른쪽 위16px 접힌 모서리로 구분한다. 기존3:4 비율·장면 번호·캡션·레일 기능은 유지한다. 선택 링은 clip-path가 적용된 이미지에 두지 않는다. 폴더 선택 버튼과 장면 바깥 래퍼에 안쪽2px 링을 두며 키보드 포커스도 안쪽 여백을 사용한다. 스크롤 레일에는4px 여백을 확보한다.

## 운영 파일

`public/curi-tokens.css`, `curi-colors.css`, `curi-icons.css`, `brand/folder-shape.svg`가 정본이다. 확장 패키징 때 공통 파일을 복사한다. 기존 B CSS는 비교/이력용으로 보존하지만 운영 HTML에서는 로드하지 않는다. 개인 자료·폴더 ID·색 키·메모·구간·검색 순위는 변환하지 않는다.

## EBS CURI 폴더 로고·크롬 아이콘

이름 왼쪽에 `public/brand/ebs-curi-folder.svg`를 배치한다. 살구색 뒤판·밝은 살구색 앞면·짙은 갈색 윤곽으로 작은 크기에서도 폴더를 구분한다. 점/문자를 폴더 안에 넣지 않는다. 웹 탭과 확장16/32/48/128px PNG는 같은 SVG를 사용한다. `node server/render-brand-icons.js`로 PNG를 생성하고 기존 패키징 도구가 확장에 동기화한다.
