## 1. 레퍼런스와 해석 방향

참고는 [Illuminating Radioactivity / 5](https://illuminating-radioactivity.com/5/?ref=httpster.net)다. 기존 **2안(B)과 같은 레퍼런스를 사용하는 별도 해석**이다. 새 레퍼런스나 사이트의 새로운 판본으로 소개하지 않는다. 사용자 피드백에 따라 3.1은 **미색 지면·짙은 글자·원형 장 번호·얇은 대형 타이포**를 중심으로 다시 구성했다. 살구·라벤더는 작은 포인트와 예시 미디어에 사용한다. 어두운 무대를 쓰는 2안과 달리 웹·확장·메뉴를 밝게 연결한다. A/B 원본은 그대로 보존한다.

2026-10-15 Chrome에서 초기 화면의 큰 흰 문장·포스터 위치를 다시 확인했다. 같은 날 R12-11/12에서 직접 확인한 메뉴·장 링크·밝은 구역·390px 기록은 [공통 원본 관찰](../reference-grid-interaction-observations.json)을 재사용한다. 관찰과 제안의 구분은 아래 표를 따른다.

| 실제 원본 관찰 | 3안의 Curi 해석 |
| --- | --- |
| 검정 배경·흰 큰 문장, 아래 흰 장으로 전환 | 큰 문장과 여백은 유지하고 배경은 사용자 요청에 따라 미색으로 재해석 |
| 이미지 위 모서리의 같은 기준선, 넓은 열 간격 | 자료 프레임3열과 제목/캡션 정렬 |
| 원형 아이콘 메뉴와 컬러 원의 장 번호 | 원형 ‘단계 메뉴’와 번호, 살구색 번호와 짙은 글자로 단계 표시 |
| 큰 산세리프와 작은 mono 캡션 | 시스템 한국어 산세리프 + 번호/시간용 mono |
| 메뉴의 장 링크가 다른URL로 이동 | 사용자가 탐색/근거/정리를 선택, 필수 순서 강제 금지 |
| 390px에서 원본의 가로 잘림 | 화면 내용은4열1단으로 재배치, 가로 잘림 복제 금지 |

1440px 초기 화면의 포스터는 약 x44/449/851, y394, 폭316px이고 사이 간격은 약89/86px이었다. 실제 DOM은 상대 캔버스 안의 절대 좌표 배치였다. **원본이12열 CSS Grid라는 뜻이 아니다.** 아래12/8/4열·모션 시간은 Curi 설계값이다. 원본 전체 장·터치·스크롤 애니메이션의 정확한 ms/easing은 전수 확인하지 않았다.

원자 기호·방사선 경고·포스터·원문 문장·글꼴 파일·코드를 복제하지 않는다. 시안의 추상 도형과 자료는 직접 만든 가상 예시다.

## 2. 포지셔닝과 적용 범위

**한 줄 방향:** 미색 지면에서 크게 질문하고 차분히 근거를 읽는 탐색 도구.

| 요소 | 3안 방향 | 2안(B)과의 차이 |
| --- | --- | --- |
| 색 | 미색 + 먹색 + 살구 포인트 | 어두운 무대를 밝은 연속 지면으로 전환 |
| 타이포 | 얇고 넓은 대형 문장·작은 번호 | 여백과 크기 차이로 장 구분 |
| 박스 | 넓은 이미지 곡률·각진 입력 | 입력은4px, 미디어18px로 역할 분리 |
| 로고 | 빛의 틈을 둔 분할 원 | 열린 사각 프레임·중심점과 다른 형태 |
| 웹 | 미색 질문→미색 자료 목록 | 선·간격·제목으로 읽기 문맥 구분 |
| 확장 | 미색 브랜드 띠 + 미색 조작부 | 웹의 큰 장면 장식을 넣지 않음 |

기능 범위는 기존 Curi와 같다. 자연어 탐색, 원문·미확인 조건, 두 단계 가져가기, 내 수업의 위치별 기록, 전체/구간 저장 계약을 유지한다. 사람 확인·교육과정 의미·학년 적합성은 디자인 신호만으로 확정하지 않는다. 사용자 선택 전에는 이 스타일을 운영 웹·확장·로고에 적용하지 않는다.

## 3. 컬러

3.1의 기본 배경은 미색 `#F4F0E6`이다. 레퍼런스 5페이지 초기 화면의 실제 배경은 검정이며, 이 미색은 사용자 요청을 반영한 Curi 제안값이다. 원본에서 추출한 색으로 소개하지 않는다.

텍스트4.5:1, 조작 경계/포커스3:1을 점검한 조합은 [대비 기록](contrast-checks.json)에 남긴다. 장식선은 입력 경계로 재사용하지 않는다. 전체 접근성 감사는 아니다.

한국어는 OS 기본 산세리프, 시간/영문 번호는 `ui-monospace`를 사용한다. 외부 폰트를 내려받지 않는다. 원본의 `custom_19789`, `custom_20744` 같은 별칭을 실제 글꼴명으로 단정하지 않는다. 긴 한국어 문장의 자간을 억지로 줄이지 않으며 필수 조건·메모를 생략하지 않는다.

간격4/8/12/16/24/32/48/64/96px. 브랜드 구간64–96, 읽기 구간32–48, 카드 내부20–24, 목록 간24→20→16, 입력 라벨8px. 검색 이후에는 큰 브랜드 문장이 결과를 밀어내지 않게 접거나 줄이는 것이 실제 적용 기준이다. 시안은 최초 화면과 스타일 비교를 위해 큰 문장을 함께 보여준다.

## 6. 웹

1. **탐색:** 로고, 자료 찾기, 내 수업 자료를 유지한다. ‘단계 메뉴’는 보조 진입점이다. 메뉴는 탐색→근거→정리를 나열하지만 필수 절차가 아니다.
2. **검색:** 넓은 입력·단일 주요 버튼. 팝업 검색은 입력을 별도로 임시 편집하고 제출 때만 결과에 적용한다. Enter와 버튼은 같다. 최신 응답만 반영, 기존 입력/결과 유지, 빈 결과는 직접 수정·재시도할 수 있게 한다.
3. **자료:** 제목→프로그램/날짜/소개문 상태→인용/요청 근거→미확인→원문/가져가기. 도형 프레임은 실제 장면인 것처럼 보이지 않게 예시라고 표시한다.
4. **근거:** 밝은 불투명 면에서 전체 제목·출처·남은 확인을 읽는다. 색으로 사람 검수나 정확성을 암시하지 않는다.
5. **가져가기:**1/2교육과정 또는 선택 안 함→2/2기존/새 폴더→최종 가져가기. 이전 복귀로 선택/폴더 이름 유지. 빈 이름·실패는 입력을 유지하고 위치를 포함한 성공은 확인 후 표시한다.
6. **내 수업:** 전체/폴더/미지정의 실제 저장 계약을 유지하고 같은 자료의 위치별 메모·목표·기준·구간을 합치지 않는다. 시안은 세션 내 가상 가져오기 목록만 제공한다.

시안의 가상 자료3개 검색/필터·근거 대화상자·메뉴·두 단계 가져가기·중복 재추가 방지를 직접 확인할 수 있다. 실제 의미 검색·출처·개인 자료를 읽지 않는다. 현재 운영 제품이 큰 장 전환을 이미 적용한 것처럼 표시하지 않는다.

## 7. Chrome 확장

비교 기준 폭360px, 내부16px. 실제 폭은 Chrome 패널 크기에 맞춘다. 미색 헤더에 짙은 심볼·CURI, 미색 몸통에 **현재 영상→폴더→전체/구간→가져가기→결과**. 웹의68px 제목이나12열을 축소해서 넣지 않는다.14px 본문/13px 메타·44px 조작·시간 숫자의 고정폭을 지킨다.

| 상태 | 표시/행동 |
| --- | --- |
| 연결 필요 | 이유와 다시 연결, 저장 차단, 초안 유지 |
| 조회 중 | 폴더·영상 조회 안내, 이전 초안 유지 |
| 준비 | 현재 영상·폴더·범위 명시 |
| 시간 미확인 | 직접 입력 안내, 읽었다고 주장하지 않음 |
| 오류 | 구간 이름·시간·끝>시작·알려진 길이 검증 |
| 저장 중 | 같은 버튼의 대기 문구, 중복 차단 |
| 완료/일부 완료 | 확인된 위치·영상/구간 수, 실패 위치는 별도 구분 |

시안은 전체/구간 전환, 연결 복구, 가상08:30 길이 검사, 예시 현재 시간, 저장 대기·실패·재시도를 제공한다. 실제 플레이어·chrome.storage·서버는 사용하지 않는다. 실제 적용 때는 영상별 `draft:{source.identity}`, `folderPreferences`, 마지막 확인된 결과·개인 폴더/구간 키를 보존한다. 다른 영상에 이전 시간을 적용하지 않는다. 영상 파일 추출이 아니라 원본 링크·시간 구간 기록이다.

## 8. 로고

**분할 원과 빛의 틈**이3안의 심볼이다. 한 장면을 다른 관점에서 읽는다는 의미를 두 반원 사이의 수직 여백으로 표현한다. 대문자 CURI는 얇은 기하학적 획으로 직접 그렸다. 원자 궤도·방사선 기호를 쓰지 않는다.

웹 워드마크 폭116–144px(최소96), 확장 심볼24/32, 툴바16/32, 설치48/128. 외곽 여백은 심볼 한 변의1/4 이상.16px에서 중앙 틈이 뭉개지지 않는지 실제 크기로 확인하고 최종 선택 후 픽셀 정렬·광학 보정과 PNG를 내보낸다. 이번은 SVG 제안이며 설치 아이콘을 교체하지 않는다. 비율·틈·획을 바꾸거나 그림자·그라데이션·알림 배지로 변형하지 않는다.

## 9. 그리드

원본의 절대 좌표를 복사하지 않고 다음과 같이 읽기 가능한 격자로 해석한다. 컨테이너는 border-box, 내부폭G, 열폭 `u=(G−(N−1)×gutter)/N`이다.

| 화면 폭 | 최대폭 / 양쪽 패딩 | 열 / gutter | 점유 |
| --- | --- | --- | --- |
| ≥1200 |1360 /48씩 |12 /24 | 소개8+4, 자료4열×3 |
| 768–1199 |100% /24씩 |8 /20 | 제목 전체, 자료4열×2 |
| <768 |100% /16씩 |4 /16 | 제목→프레임→자료,1열 |

1440px에서 내부1264px,4열≈405.3px,8열≈834.7px.390px에서 내부358px. 시안의 제품 프레임 안은 프레임 패딩을 제외한 폭으로 다시 계산한다. 내 수업은 폴더3+자료9열을 권장하고 좁은 폭에서는 폴더 선택을 위로 옮긴다. 확장은 독립1열이며 시간 입력만2열이다. 모달은 격자 위 top layer에 놓고 배경 스크롤 위치를 보존한다.

| 단계 메뉴 클릭 | 미색 메뉴220ms·최대10px, 현재 문맥 표시 | 모달,Tab 범위,Escape/닫기·호출 버튼 복귀 |
| 장면/문맥 선택 | 탐색/근거/내 수업으로 이동 | 질의·선택·입력 보존, 자동 저장 없음 |
| 검색 팝업 | 입력 초안→제출 때 결과 적용 | Escape는 기존 질의를 바꾸지 않음 |
| 근거/가져가기 | 불투명 밝은 대화상자220ms | 배경 차단·포커스 복귀·이전 선택 유지 |
| hover/선택 |120ms 색/경계 | touch/키보드에서도 같은 행동 |
| 스크롤 | 미색 질문 구역→미색 읽기 구역 | 자연 문서 스크롤, 가로채기·강제 이동 없음 |
| 모션 감소 | 전환0ms | 내용/완료 문구는 유지,OS 설정 변경 없음 |

원본의 Escape·포커스 동작을 접근성 표준으로 복제하지 않는다. Curi는 명시적 닫기·양방향Tab·Escape를 제공한다. 원본의 정확한 모션 시간은 미측정이며 위 시간은 설계값이다. 시안의 모션 줄이기와 `prefers-reduced-motion`에서 애니메이션을 끈다.

## Chrome 사이드 패널 적용 기준 — R12-14

확장0.6.0은 아이콘 아래 임시 팝업 대신 Chrome 사이드 패널을 사용한다. 기본 문서는 기존 `popup.html`이며 `side_panel.default_path`로 열린다. 웹페이지 옆의 세로 작업 공간으로 화면 전체 높이를 사용하고 내부를 독립 스크롤한다. 본문 클릭 시에도 패널을 유지한다. 오른쪽 배치와 폭은 Chrome 사용자 설정/조작을 따른다. 360px은 비교 시안의 기준 폭이며 실제 폭을 고정하거나 좌우 비율을 강제하지 않는다. 좁은 폭에서는 시간 입력/현재 시간 버튼을 한 열로 바꾼다.

선택한 EBS 페이지가 저장 대상이며 다른 탭을 눌렀다고 대상을 자동 변경하지 않는다. 페이지 이동/닫힘 시 이전 영상의 저장과 시간 읽기를 잠그고 ‘열린 영상 목록 새로고침’으로 재확인한다. 영상별 초안·폴더 선택·기존 저장 결과는 보존한다. 이 기준은 확장 표시 방식의 공통 변경이며 디자인안 선택을 뜻하지 않는다. 3/4안의 확장 시안은 왼쪽 가상 영상 영역/오른쪽 세로 패널 배치를 보여 준다. 작은 화면에서는 비교를 위해 위아래로 쌓이며 실제 데스크톱 Chrome 배치와 구분한다.
