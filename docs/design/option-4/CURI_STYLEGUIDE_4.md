## 1. Creative Boom 분석

참고는 [Creative Boom](https://www.creativeboom.com/?ref=httpster.net)이다. 2026-10-15 Chrome에서 홈1440×960, 검색 대화상자, Inspiration 링크 이동,390×844의 해당 분류 화면과 전체 메뉴를 관찰했다. 기사 본문·회원/구독/채용 동작은 확인 범위 밖이다. 텍스트 웹 도구는 접속하지 못해 브라우저 화면·읽기 전용DOM을 사용했다.

| 실제 관찰 | Curi4안 해석 |
| --- | --- |
| 크림 지면·검정 타이포·흰 헤더 | 밝은 편집 지면으로 탐색과 원문 읽기를 연결 |
| 중앙 대형 기사와 작은 좌우 자료 | 중심 자료6열·주변 자료3+3열 |
| 작은 윤곽 분류 배지·얇은 구분선 | 사회/과학·원문 상태는 글자와 선으로 구분 |
| 메뉴 앞 컬러 점과 선택 배경 | 분류에만 노랑/핑크/민트, 행동은 검정 |
| 검정 검색 창과 어두워진 배경,Esc표시 | 단축 진입 검색 대화상자·제출 시 반영 |
|390px에서 중심 기사가 먼저 보임 | 모바일 DOM/시각 순서 모두 주요 자료 우선 |
| 모바일 검정 메뉴·큰 컬러 행·화살표 | 분류 메뉴를 명시적 버튼으로,카테고리 이름 유지 |

관찰한 홈 지면색은 `rgb(251,247,239)`(`#FBF7EF`), 헤더/바탕 일부는 흰색, 검정 면과 분홍/노랑/청록 계열이 쓰였다. 본문 계산 글꼴은 `ABC Diatype`, 기사 제목은 `Roobert`가 나타났으며 제목 일부는20/40px·500굵기였다. Curi는 해당 글꼴 파일을 가져오지 않는다. 아래 타이포는 한국어를 위한 별도 설계값이다.

1440px에서 콘텐츠 기준선은 x104–1336,폭1232px이었다. 중앙 이미지 약604px와 옆 자료 약290px, 간격24px은 **1:2:1 비례의 편집 구도**를 보여준다. CSS에서4×290px 열·24px간격과604px의2열 묶음도 관찰했다. 이를 사이트 전체가12열이라는 주장으로 확대하지 않는다.

검색 버튼으로 열린 검정 대화상자는 약x360/y72,720×70px의 입력 중심 창이었다. 입력 없이 닫기/분류 이동을 관찰했다. Esc표시는 확인했으나 원본의 정확한 포커스 복귀·전환 시간·검색 응답 품질은 측정하지 않았다. 모바일 메뉴의 큰 컬러 행은 관찰했지만 모든 하위 메뉴·hover는 전수 확인하지 않았다.

## 2. 디자인 방향과 네 안의 차이

**한 줄 방향:** 제목과 원문을 편집하듯 읽고, 수업에 쓸 자료를 모으는 밝은 교사 자료실.

| 안 | 인상 | 공간/색·행동 |
| --- | --- | --- |
|1 / A | 조용한 업무 공간 | 따뜻한 흰색·녹색·목록과 근거 재배치 |
|2 / B | 다색의 발견 무대 | 차콜·살구/라일락·큰 제목과 프레임 |
|3 | 밝은 시선의 전환 | 미색·먹색·살구 포인트·큰 질문과 넓은 여백 |
|4 | 편집된 자료 지면 | 크림·검정·얇은 선·중앙/주변 자료의 위계 |

4안은 신문/매거진의 정보 위계를 쓰되 콘텐츠를 홍보 상품으로 다루지 않는다. 중앙에 크게 놓았다는 이유로 ‘추천 확정’,‘검수 완료’,‘수업 적합’이라고 부르지 않는다. 실제 검색에서는 질의·정렬·선택 이유가 순위를 결정하며 편집 레이아웃이 관련성 점수를 바꾸면 안 된다. 탐색 첫 화면에 주제 묶음을 넣더라도 교육과정 선택을 검색의 필수 단계로 만들지 않는다.

분류색 위 글자는 검정이다. 색점만으로 교과나 확인 수준을 설명하지 않는다. 미색 지면·흰 헤더·검정 타이포를 기본으로 하고, 기본 카드에 무작위 배경색을 붙이지 않으며, 색은 분류·묶음의 작은 면에 제한한다. 예시 미디어는 중립 바탕 위 직접 만든 편집 도형으로 구분한다. 원본의 다채로운 기사 이미지가 브랜드 UI 배경색이라는 뜻은 아니며 사진은 복제하지 않는다. 검정 버튼이 가장 강한 행동, 윤곽 버튼은 보조 행동이다. 가는 장식선과 입력 경계를 구분한다. 일반 텍스트4.5:1·조작3:1을 점검한 조합은 [대비 기록](contrast-checks.json)에 남긴다.

시스템 한국어 산세리프를 사용한다. 원본의 얇고 명확한 제목 계층은 참고하되 한국어 본문을 작게 줄이지 않는다. 시간만 tabular-nums/mono, 기사형 문장은 산세리프다. 소문자/대문자 영문이 실제 기능 이름을 대신하지 않게 한다. 제목은 줄바꿈하고 전체 제목을 확인할 수 있게 하며 필수 조건·오류·개인 기록을 자르지 않는다.

간격4/8/12/16/24/32/40/48/64px. 지면의 가로 기준선·세로 구분 간격을 공유한다. 큰 기사와 작은 기사가 서로 다른 글자 크기를 쓰더라도 분류→제목→설명의 순서는 같다. 리스트 간24px, 구역32–64px, 카드 내부20px, 입력 라벨8px. 카드마다 상자를 두껍게 둘러싸기보다 선·여백으로 구분한다.

| 컴포넌트 | 형태 | 상호작용 |
| --- | --- | --- |
| 기사/자료 카드 | 기본 외곽 박스 없음,상단/하단1px선 | hover는 제목/선 변화,전체 카드 확대 없음 |
| 미디어 | 사각형0px,원본 비율 유지 | 내용과 무관한 생성 이미지로 빈 썸네일을 채우지 않음 |

| 주 버튼 | 검정 pill,흰 글자,44px 이상 | hover/pressed 대비 유지,대기 문구 같은 위치 |
| 보조 버튼 | 투명/밝은 윤곽 pill | 활성·선택 배경은 연한 크림 |

반경0px의 콘텐츠와 pill 버튼을 섞는 이유는 ‘읽을 면’과 ‘누를 면’을 구분하기 위해서다. 모든 요소를 둥근 카드로 만들지 않는다. 기본/hover/focus/pressed/disabled/loading/selected/success/error/empty를 제공한다. 저장 실패의 이유와 입력은 남기고,성공은 실제 확인 후에만 표시한다.

## 6. 웹

**헤더.** 작은 CURI 워드마크,자료 찾기/내 수업 자료,검색/분류 메뉴. 모바일에서도 주요 기능 이름을 숨기지 않는다. 원본의 기사 분류를 Curi 데이터와 무관하게 메뉴로 옮기지 않는다.

**첫 탐색.** 중앙 리드 자료와 주변 자료/확인 메모를3+6+3열로 보여주는 편집 구도를 제안한다. 대표 자료는 레이아웃 예시이며 사람 검수·추천 품질의 인증이 아니다. 실제 질의 입력 이후에는 큰 편집 구역을 접거나 줄이고 단일 결과 목록을 우선한다. 시안은 스타일 비교를 위해 최초 탐색 구도를 함께 보여준다.

**검색.** 검정 검색 대화상자에 넓은 입력·명시적 제출·닫기. 클릭뿐 아니라Enter/Escape를 지원하고 닫은 뒤 호출 버튼으로 돌아간다. 원본의 배경 블러는 Curi의 읽기 면에 사용하지 않는다. 검색 중 기존 입력/결과를 유지하고 늦은 이전 응답을 버린다. 빈 결과에 원인·직접 수정·재시도를 제공한다.

**자료/근거.** 제목·프로그램·날짜·소개문 확보 상태를 읽고,실제 인용과 요청 해석을 구분한다. 보강 설명과 원문은 다른 이름으로 표시한다. 교육과정의 사람 확인·자동 검사·미확인은 색 배지가 아니라 문구·근거로 드러낸다. 원문이 부족하면 확인한 것처럼 빈 칸을 채우지 않는다.

**가져가기/내 수업.** 현재 두 페이지인 교육과정 선택/선택 안 함→폴더/새 이름→최종 가져가기를 유지한다. 이전으로 돌아가도 입력을 보존하고 저장 위치를 마지막에 재표시한다. 위치별 개인 목표·메모·교육과정·구간은 합치지 않는다. 전체/폴더/미지정 구조와 내보내기·삭제의 적용 위치 계약을 유지한다.

시안은 가상 검색/필터·근거·두 단계 가져오기·동일 폴더 중복 방지·가상 내 수업을 제공한다. 실제 검색 엔진·공식 원문·개인 저장소는 호출하지 않는다.

## 7. Chrome 확장

비교 기준 폭360px의 세로 패널에서 밝은 크림 지면과 가는 선을 유지한다. 실제 폭은 Chrome 패널 크기에 맞춘다. 상단에는 심볼·CURI,현재 영상·폴더·범위·저장 순서를 분명히 표시한다. 기본14px/보조13px·44px버튼·시간 숫자는 고정폭이다. 웹의3+6+3열이나 중심 기사 크기를 축소해서 넣지 않는다.

전체 영상은 구간 입력을 강제하지 않는다. 구간은 이름·시작/끝·끝>시작·알려진 영상 길이를 검사하고,길이를 읽지 못하면 확인된 값으로 표시하지 않는다. 예시 현재 시간 버튼은 실제 기능이 아님을 명시한다.

연결 필요→조회→준비→저장 중→확인된 완료/실패/일부 완료를 각 문구와 다음 행동으로 구분한다. 시안은 연결 차단/재연결·전체/구간·08:30예시 검증·대기·실패·재시도를 제공한다. 일부 완료나 실제 폴더 조회는 운영 계약이며 이 시안이 구현했다고 표시하지 않는다.

실제 적용에서는 회차별초안·`folderPreferences`·최근 확인된 결과·브라우저 개인 키를 그대로 보존한다. 패널을 다시 열거나 연결이 끊겨도 입력을 복구하고 다른 영상에 이전 제목/시간을 적용하지 않는다. CuriBase 등록과 개인 자료 저장의 실제 확인 범위를 맞추며 영상 파일·클립 추출을 제공하는 것처럼 보이지 않게 한다.

## 8. 로고

**겹친 페이지와 C**가4안의 심볼이다. 자료를 읽고 수업 폴더로 편집하는 행위를 두 장의 지면으로 표현한다. 대문자 CURI 워드마크는 두꺼운 둥근 획과 밑줄을 직접 작성했다. Creative Boom 워드마크·글꼴·컬러 점 조합을 로고로 복제하지 않는다.

웹 워드마크116–144px,최소96px. 확장 심볼24/32px,툴바16/32px,설치48/128px. 여백은 심볼 한 변의1/4 이상이며 SVG 내 여백과 컨테이너 여백을 모두 고려한다. 작은 크기에서 겹친 페이지와 C의 빈 공간을 확인하고 최종 선택 뒤 PNG/광학 보정을 한다. 왜곡·늘임·그림자·그라데이션·자동 회전은 사용하지 않는다. 현재 설치본 로고를 교체하지 않는다.

## 9. 그리드

실측1232px의1:2:1 편집 구조를 Curi의12/8/4열로 해석한다. 원본이12열이라는 주장은 하지 않는다. 컨테이너는 border-box,내부폭G,열폭 `u=(G−(N−1)×gutter)/N`이다.

| 폭 | 최대폭 / 양쪽 패딩 | 열 / gutter | 구도 |
| --- | --- | --- | --- |
| ≥1200 |1280 /40씩 |12 /24 | 좌3 + 중앙6 + 우3,일반 자료4×3 |
| 768–1199 |100% /24씩 |8 /20 | 리드8열→주변4+4,자료4×2 |
| <768 |100% /16씩 |4 /16 | 리드→주변→확인 메모,자료1열 |

1440px에서 내부1200px,3열282px·6열588px·사이24px씩.390px에서 내부358px. 시안의 안쪽 제품 프레임에서는 남은 사용폭으로 다시 계산한다. **DOM/스크린리더 순서도 리드 자료를 먼저** 두고 CSS로만 중요 순서를 뒤집지 않는다. 자료 목록에서는 카드 높이를 억지로 같게 잘라내기보다 제목/정보의 기준선을 맞춘다.

내 수업은 폴더3+목록9열,모바일은 폴더 선택을 위로. 읽기 근거 문단은 약60자 이내의 편한 폭을 권장한다. 검색/가져가기 모달은 격자 위에 놓되 배경 스크롤 위치를 보존한다. 확장은 독립1열,시간만2열이다. 수동 가로 탐색을 사용한다면 양끝 버튼 상태·현재 위치·키보드 조작을 제공하고 자동 회전하지 않는다. 현재 시안은 캐러셀을 새로 넣지 않는다.

모션 시간은 원본에서 추출한 값이 아니라 Curi 설계값이다. `prefers-reduced-motion`과 모션 감소 시안에서는 전환을0ms로 하고 내용과 상태는 그대로 둔다. 원본 키보드·검색 품질을 그대로 보장한다고 주장하지 않는다. Curi 모달에는 명시적 닫기·Tab/Shift+Tab 순환·Escape를 제공한다.

## Chrome 사이드 패널 적용 기준 — R12-14

확장0.6.0은 아이콘 아래 임시 팝업 대신 Chrome 사이드 패널을 사용한다. 기본 문서는 기존 `popup.html`이며 `side_panel.default_path`로 열린다. 웹페이지 옆의 세로 작업 공간으로 화면 전체 높이를 사용하고 내부를 독립 스크롤한다. 본문 클릭 시에도 패널을 유지한다. 오른쪽 배치와 폭은 Chrome 사용자 설정/조작을 따른다. 360px은 비교 시안의 기준 폭이며 실제 폭을 고정하거나 좌우 비율을 강제하지 않는다. 좁은 폭에서는 시간 입력/현재 시간 버튼을 한 열로 바꾼다.

선택한 EBS 페이지가 저장 대상이며 다른 탭을 눌렀다고 대상을 자동 변경하지 않는다. 페이지 이동/닫힘 시 이전 영상의 저장과 시간 읽기를 잠그고 ‘열린 영상 목록 새로고침’으로 재확인한다. 영상별 초안·폴더 선택·기존 저장 결과는 보존한다. 이 기준은 확장 표시 방식의 공통 변경이며 디자인안 선택을 뜻하지 않는다. 3/4안의 확장 시안은 왼쪽 가상 영상 영역/오른쪽 세로 패널 배치를 보여 준다. 작은 화면에서는 비교를 위해 위아래로 쌓이며 실제 데스크톱 Chrome 배치와 구분한다.
