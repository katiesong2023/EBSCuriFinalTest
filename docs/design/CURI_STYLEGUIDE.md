# Curi 공통 스타일·인터랙션 가이드

버전 0.1 · 2026-10-15 · **원본 디자인 제안**

[그리드·인터랙션 비교 시안](grid-interaction.html)

2026-10-15 후속 사용자 적용 요청으로 [R12-10](../../Tasks/task-r12-10-design-application.md)에서 자료 찾기·내 수업 자료·확장0.5.0·브랜드 자산에 반영했다. 아래 ‘이번 요청’과 ‘운영 미적용’은 원본 가이드 작성 당시 범위다. 운영 화면 확인 기록은 [application-checks.json](application-checks.json)과 `applied-*.png`를 따른다.

웹사이트, Chrome 확장 프로그램, 로고를 **조용한 수업 작업공간**이라는 한 방향으로 묶는다. 자료를 찾고, 근거를 확인하고, 수업에 가져가는 행동이 화면의 중심이다. 중립적인 바탕과 작은 브랜드 표시로 시각적 소음을 줄이고, 녹색은 주요 행동과 현재 선택에 제한해서 사용한다.

## 1. 참고 사이트 분석

[GO:OD Design Studio](https://go-od.co/?ref=httpster.net)를 실제 브라우저에서 데스크톱 1440×960, 모바일 390×844로 관찰했다. 관찰 당시 사이트는 정식 포트폴리오 공개 전의 티저였다. 아래 분석은 홈, Studio/Contact 펼침, 폴더 선택·영상 열기·닫기에 한정한다. 프로젝트 목록·상세·저장 흐름을 확인한 것으로 해석하지 않는다.

| 요소 | 실제 관찰 | Curi 적용 방향 |
| --- | --- | --- |
| 화면 밀도 | 거의 흰 캔버스, 중앙 폴더, 작은 상단 로고·메뉴 | 헤더와 검색 영역에 여백. 결과 목록과 확장은 필요한 정보 밀도 유지 |
| 색 | 바탕 #FAFAFA, 본문 #636363, 패널 #F6F6F6, 선택 #E3E3E3 | 따뜻한 중립색 + 기존 Curi 녹색 계열을 하나의 토큰으로 통일 |
| 타이포 | Europa Prima, 관찰 본문 14px, 얇고 담백한 인상 | 한국어는 기본 16px. 확장은 14px, 출처·보조 정보는 13px |
| 로고 | 약 130px의 작은 기하학적 워드마크 | 작은 Curi 워드마크와 단색 심볼. 참고 로고의 글자 조합·형태 복제 없음 |
| 메뉴 | 선택 배경이 이동하고 Studio/Contact가 제자리에서 확장 | 탭은 고정 위치에서 선택 표시. 상세는 목록 문맥을 유지하는 패널 |
| 창 | 제목 바·닫기, 둥근 모서리, 부드러운 그림자 | 상세·가져가기 대화상자에만 깊이. 일반 카드는 선과 여백으로 구분 |
| 화면 관계 | Studio를 열면 영상 창이 720→432px로 축소 | 배경 목록 위치 유지. 내용·글자 자체를 축소하지 않음 |
| 모바일 | 로고 아래 메뉴, 세로 흐름으로 펼쳐짐 | 메뉴·검색·목록 순서 고정. 상세·저장은 화면 안에서 세로 스크롤 |
| 폴더 | 단일 클릭은 선택, 더블클릭은 영상 열기 | 폴더 이름을 단일 클릭/Enter로 열기. 탐색 행동은 항상 보여주기 |
| 영상 | 무음 자동 재생·반복, 기본 컨트롤 없음 | 교사가 재생을 누를 때 시작. 시간·구간 조작을 명확히 제공 |
| 움직임 | 메뉴 약 200–300ms, 패널 약 250ms | 상태 120ms / 펼침 180ms / 패널 240ms, 이동 최대 12px |

측정된 데스크톱 메뉴는 폭 360px·닫힘 높이 약 29px·반경 10px이고 배경은 rgba(246,246,246,.8)와 blur(10px)다. 영상 창 그림자는 rgba(0,0,0,.25), 0 24px 48px였다. 이 값은 참고 관찰값이며 아래 Curi 토큰과 구분한다.

참고의 Studio/Contact 요소는 관찰 DOM에서 div, tabindex -1이고 닫기는 span이었다. Tab 이동에서 해당 메뉴를 건너뛰는 것을 확인했다. Curi는 실제 button과 의미 있는 상태 속성을 사용한다. 참고 사이트의 드래그 이동과 Escape 닫힘은 확인하지 못했다. 전체 접근성 감사 결과로 일반화하지 않는다.

## 2. 공통 색상 토큰

| 용도 | 토큰 / 값 | 사용 규칙 |
| --- | --- | --- |
| 바탕 | canvas #FAFAF8 | 웹·확장 전체 배경 |
| 내용 | surface #FFFFFF | 카드·입력·대화상자 |
| 보조 영역 | surfaceMuted #F2F3F0 | 헤더·탭·폴더 탐색 배경 |
| 본문 | ink #202523 | 제목·입력·주요 정보 |
| 보조 글자 | muted #626963 | 프로그램·출처·날짜. 중요 정보 숨김에 사용하지 않음 |
| 구분선 | line #E1E4DE | 장식 구분만. 입력 식별·포커스에 사용하지 않음 |
| 입력 경계 | controlBorder #849087 | 흰색·캔버스 위 입력 식별 |
| 주요 행동 | primary #1E5843 / hover #164534 | 검색·가져가기·최종 저장 |
| 선택 바탕 | primarySoft #E7EFE9 | 선택 폴더·선택 상태. 글자는 primary |
| 키보드 포커스 | focus #266EAA | 2px 외곽선 + 2px 간격 |
| 확인 필요 | warning #8C6114 / #FFF4DF | 미확인 조건·연결 필요, 문구와 함께 |
| 오류 | error #A33A35 / #FBEAE7 | 실패 이유·재시도, 문구와 함께 |

한 패널에는 주요 행동 하나를 우선한다. 검색 카드 여러 개의 가져가기 버튼은 같은 단계의 반복 행동이므로 허용한다. 저장 성공의 녹색은 저장 결과만 뜻하며 사람 검수·교육과정 적합성을 뜻하지 않는다. 자료 종류별 무지개색 배지는 사용하지 않는다.

색 대비 계산은 [contrast-checks.json](contrast-checks.json)에 기록한다. 일반 글자 4.5:1, 큰 글자 3:1은 [WCAG 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)을 따른다. 장식 구분선을 제외한 조작 경계·포커스는 인접한 바탕과 3:1 이상을 목표로 한다. 실제 화면의 겹침·투명 배경·사진 위 글자는 별도 검사한다.

## 3. 타이포그래피·공간

기본 글꼴은 Pretendard를 제안한다. 적용 때 공식 배포 파일을 자체 호스팅하고 [공식 라이선스](https://github.com/orioncactus/pretendard/blob/main/LICENSE)를 함께 보존한다. 현재 시안은 외부 폰트 다운로드 없이 시스템 한국어 폰트로 대체될 수 있다. 참고 사이트의 Europa Prima 파일은 가져오지 않는다.

| 역할 | 웹 | 모바일 / 확장 | 굵기 |
| --- | --- | --- | --- |
| 페이지 제목 | 36px | 모바일 28px / 확장 20px | 600 |
| 영역 제목 | 22px | 18–20px | 600 |
| 카드 제목 | 18px | 16px | 600 |
| 본문·입력 | 16px | 모바일 16px / 확장 14px | 400 |
| 버튼·탭 | 14–16px | 14px | 500–600 |
| 출처·보조 정보 | 13px | 13px | 400 |

본문 행간 1.6, 짧은 제목 1.25–1.35. 긴 한국어 문장을 과도하게 자간 축소하지 않는다. 카드 제목은 최대 두 줄로 요약하고 상세에서 전체 제목을 확인할 수 있게 한다. 필수 조건·오류·수업 메모는 임의 생략하지 않는다. 시간·개수는 tabular-nums를 사용한다.

간격은 4/8/12/16/20/24/32/48/64px. 입력과 설명 8px, 카드 내부 20–24px, 목록 카드 간 16px, 큰 영역 간 32–48px를 기본으로 한다. 웹 최대 폭 1240px, 데스크톱 바깥 여백 최소 32px, 모바일 16px. 데스크톱 12열 / 모바일 4열을 설계 기준으로 사용한다. 결과 카드는 데스크톱 3열 또는 근거를 읽는 1열 목록, 모바일 1열이다.

컨트롤 반경 8px, 패널 12px, 미디어 8px. pill은 탭·짧은 상태에 한정한다. 카드마다 강한 그림자나 서로 다른 곡률을 넣지 않는다. 조작 영역은 최소 44×44px를 Curi 기준으로 둔다. 이 값은 프로젝트 선택이며 WCAG의 모든 목표 크기 조항이 44px라는 뜻은 아니다.

## 4. 웹사이트

### 탐색과 검색

상단에는 워드마크, 자료 찾기, 내 수업 자료를 둔다. 현재 위치는 밑줄 또는 선택 배경과 aria-current로 표시한다. 관리자 도구는 교사 주요 탐색과 분리한다. 모바일에서도 두 주요 경로의 이름을 유지하고 아이콘만으로 숨기지 않는다.

검색 입력은 학년·수업 목적·필수·제외 조건을 문장으로 입력하는 넓은 영역이다. Enter와 검색 버튼이 같은 행동을 한다. 검색 후 예시는 접고 입력과 적용 조건은 남긴다. 결과 제목 아래에 요청 해석, 결과 수, 정렬을 모아 둔다. 교육과정 선택을 검색의 필수 단계로 되돌리지 않는다.

카드는 자료 제목 → 프로그램·원문 정보 → 요청에 대한 근거/미확인 조건 → 원문 보기·가져가기 순서로 구성한다. 실제 소개문 인용과 검색 해석을 시각적으로 구분한다. 제목만 있는 자료는 소개문 확인처럼 보이게 만들지 않는다. NEWS 게시일과 방송일은 정확한 이름으로 표시한다. 불명확한 조건은 ‘확인 필요’로 적는다.

로딩 중 입력값·기존 결과를 유지하고 ‘검색 중’ 상태를 보여준다. 늦게 끝난 이전 검색 응답은 최신 요청을 덮어쓰지 않는다. 빈 결과에는 원인을 보여주고 사용자가 조건을 직접 바꾸게 한다. 자동 조건 완화로 결과 수를 채우지 않는다.

### 자료 상세와 가져가기

자료 상세는 데스크톱 4열(대체로 360–420px)의 옆 패널을 제안하며, 아래 9절의 그리드 계산을 우선한다. 좁은 화면에서는 목록 아래 전체 폭으로 배치한다. 배경 목록의 스크롤 위치를 보존한다. 중요한 읽기 영역에는 반투명·블러를 사용하지 않는다. 모바일에서 하단 버튼이 원문·메모나 화면 키보드를 가리지 않게 한다.

**가져가기는 현재의 두 페이지를 유지한다.** 1페이지는 교육과정 다중 선택 또는 선택 안 함, 2페이지는 기존 폴더 선택 또는 새 폴더 이름과 최종 저장이다. 두 원 표시와 함께 ‘1 / 2 교육과정’, ‘2 / 2 폴더’라는 글자를 제공한다. 선택 후 이동해도 아직 저장하지 않는다. 이전·선택 변경은 입력을 보존한다. 마지막 화면에는 대상 폴더, 자료 제목, 연결 교육과정 수와 ‘가져가기’를 보여준다.

빈 폴더 이름·중복 이름·저장 실패를 해당 입력과 연결해서 설명한다. 실패 때 선택과 입력을 유지한다. 성공은 실제 저장 확인 뒤 ‘물의 상태 변화 폴더에 가져왔어요’처럼 위치를 포함한다. 마지막 초안·저장 결과 보존은 기존 저장 계약을 따른다. 시안의 저장은 화면 시뮬레이션이며 운영 자료에 쓰지 않는다.

### 내 수업 자료

전체 / 폴더별 / 폴더 미지정 보기를 한 화면에 둔다. 데스크톱은 폴더 탐색 영역과 목록, 모바일은 폴더 선택과 목록을 세로로 배치한다. 목록 수는 현재 보기에 맞춘다. 전체에서 같은 자료가 여러 위치에 있을 때 폴더 칩을 표시하고 편집할 위치를 명시한다.

위치별 교육과정·수업 목표·메모·선택 이유·구간은 합치거나 덮어쓰지 않는다. 기존 폴더 미지정 자료와 개인 기록도 유지한다. 이동·복사·삭제는 어떤 위치에 적용되는지 문장으로 안내한다. 화면 통합을 저장 구조 통합으로 해석하지 않는다.

## 5. Chrome 확장 프로그램

폭 360px, 내부 여백 16px를 제안한다. 웹과 같은 심볼·폰트·녹색·반경을 사용한다. 현재 확장의 서로 다른 기본 녹색·작은 설명 글자를 공통 토큰으로 맞춘다. 웹 전체 메뉴를 축소해서 넣지 않는다.

팝업 순서는 **현재 영상 → 대상 폴더 → 영상 전체/구간 선택 → 가져가기 → 저장 결과**다. 연결이 안 됐을 때는 상단에 연결 필요와 ‘Curi 연결’을 보여주고 선택/초안은 보존한다. 현재 영상의 프로그램·회차 제목은 계속 보여준다. 접힌 영역에도 선택 폴더와 구간 수를 남긴다.

| 상태 | 표시와 다음 행동 |
| --- | --- |
| 연결 필요 | 연결 필요 + 연결 버튼. 저장 불가 이유 표시 |
| 조회 중 | 폴더를 불러오는 중. 입력 초안 유지 |
| 준비됨 | 연결됨 + 현재 폴더 이름 |
| 실패 | 이유 + 다시 시도. 막연한 ‘오류’만 표시하지 않음 |
| 저장 중 | 같은 위치의 버튼 ‘가져오는 중’, 중복 실행 차단 |
| 완료 | 저장한 제목·폴더·영상/구간 수와 내 수업 자료 보기 |
| 일부 완료 | 확인된 저장 위치와 실패 위치를 나눠 표시. 미확인 성공 선언 없음 |

구간의 시작·끝은 mm:ss 또는 hh:mm:ss로 표기한다. ‘현재 시간으로 시작/끝’ 버튼과 직접 입력을 함께 제공한다. 끝 > 시작, 알려진 영상 길이 안인지 검사한다. 길이를 못 읽었으면 확인된 것으로 표시하지 않는다. 시간을 읽지 못하면 직접 입력 안내를 제공한다. 실행 가능한 플레이어·지원 페이지 범위는 실제 기능의 지원 계약을 따른다.

draft:{source.identity}, folderPreferences 등 기존 chrome.storage.local 초안/폴더 선택 계약을 보존한다. 팝업 재열기에서 초안과 최근 확인된 완료 안내를 복구하되 다른 영상에 이전 제목·시간을 적용하지 않는다. 영상 전체 저장을 위해 구간 입력을 강제하지 않는다. 저장 경로(Curi 개인 자료/CuriBase)를 기존 기능 계약과 일치시킨다.

## 6. 공통 인터랙션

| 대상 | 입력과 반응 | 보존/접근성 |
| --- | --- | --- |
| 버튼 | 단일 클릭, Enter/Space. hover는 바탕색, pressed는 더 진한 색 | 실제 button. 아이콘 버튼은 접근 가능한 이름 |
| 폴더·탭 | 단일 클릭/Enter로 전환. 선택 배경 이동 120ms | 이름·현재 상태 표시. 진짜 ARIA tab을 쓰면 화살표 이동도 구현 |
| 펼침 | 제목 영역의 버튼으로 열기/닫기 180ms | aria-expanded, 대상 연결. 열릴 때 본문 글자 축소 없음 |
| 대화상자 | 240ms 투명도 + 최대 12px 이동 | 초기 포커스, Tab 범위 제한, Escape/닫기, 닫은 뒤 호출 버튼으로 복귀 |
| 검색 결과 | 내용이 준비되면 결과 수를 조용히 알림 | aria-live polite, 자동 스크롤·포커스 이동 남발 금지 |
| 저장 | 준비→저장 중→확인된 완료/실패 | 중복 차단, 실패 시 입력 보존, 위치 포함 안내 |
| 삭제 | 대상 이름과 적용 위치 확인 | 실수 복구 가능한 경로. 기존 기록의 파괴적 재구성 없음 |
| 구간 | 시간 입력·읽기·이동을 별도 행동으로 표시 | 숫자 의미·단위·검증 오류 연결 |

주요 상태는 기본/hover/focus/pressed/disabled/loading/selected/success/error/empty로 설계한다. disabled는 이유를 인접한 문구로 제공한다. 선택 상태·오류·완료는 색에만 맡기지 않는다. 모달은 배경 상호작용을 차단하고 비모달 옆 패널은 불필요한 포커스 가두기를 하지 않는다.

움직임은 상태 연결을 보여주기 위한 것이다. 재생 자동 시작, 로고 회전, 큰 zoom, 스크롤 따라 강제 이동, 커서 전용 메뉴, 더블클릭 필수 행동은 사용하지 않는다. prefers-reduced-motion에서는 이동·축소·전환 시간을 0으로 바꾸고 상태는 즉시 전달한다. [상호작용 애니메이션 비활성화](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)는 WCAG AAA 항목이며 여기서는 Curi의 공통 설계 기준으로 채택한다.

## 7. 로고 시스템

[워드마크](curi-wordmark.svg)와 [심볼](curi-symbol.svg)은 이 가이드를 위해 직접 작성한 벡터 **제안**이다. 워드마크는 둥근 획의 소문자 curi, 심볼은 열린 c와 가운데 연결점이다. 열린 c는 자료를 탐색하는 공간, 점은 자료와 수업의 연결을 표현한다. 참고 브랜드의 형태·글꼴 파일을 재사용하지 않는다.

| 사용처 | 형태 | 최소 크기 / 기본 권장 |
| --- | --- | --- |
| 웹 헤더 | 단색 워드마크 | 폭 80px / 96px |
| 확장 헤더 | 심볼 + 텍스트 curi | 심볼 24px |
| 툴바·파비콘 | 심볼 | 16px, 24/32px에서 함께 확인 |
| 설치/스토어 | 심볼 | 48/128px 파생 PNG 준비 |
| 어두운 배경 | 반전 심볼 | 흰색 [반전 SVG](curi-symbol-inverse.svg) |
| 주요 브랜드 표기 | 녹색 심볼 | [녹색 SVG](curi-symbol-green.svg) |

심볼 여백은 심볼 한 변의 1/4, 워드마크는 높이의 1/4 이상을 외곽에 둔다. 제공 SVG의 viewBox 여백과 배치 컨테이너 여백을 함께 계산한다. 원본 비율·획·점 위치를 유지한다. 늘이기, 윤곽선 추가, 그라데이션, 그림자, 점의 알림 배지 전용화, 로고 자체 애니메이션은 피한다.

심볼의 기본 형태는 16px에서도 확인했지만 작은 크기의 획·점은 적용 전 광학 보정 대상이다. 확장 설치용 16/32/48/128px PNG와 고해상도 워드마크는 최종 형태 확정 뒤 내보낸다. 이번 SVG는 배포 중인 확장 아이콘이나 Curi 로고를 교체하지 않는다.

## 8. 적용 순서와 확인 기준

**P0 공통 기반:** 색·타입·간격 토큰, 버튼·입력·포커스, 헤더/탐색, 출처·미확인·저장 상태. 웹과 확장의 같은 행동은 같은 이름으로 표시한다. 현재 두 단계 가져가기와 기존 기록 보존 계약을 먼저 확인한다.

**P1 주요 화면:** 검색 카드/상세, 내 수업 자료 폴더 탐색, 가져가기 두 페이지, 확장의 영상/폴더/구간/결과. 심볼·워드마크 적용과 작은 아이콘 내보내기를 함께 한다.

**P2 움직임:** 패널·선택·펼침 전환과 reduced-motion. 내용·저장 상태의 정확성을 확인한 뒤 추가한다.

이 순서는 적용 제안이다. 이번 요청에서는 제품 CSS/JS, API, 저장 키, DB, 개인 메모, 브라우저 확장 설치본을 바꾸지 않는다. 기술 코드 규칙은 기존 [STYLEGUIDE](../STYLEGUIDE.md)를 따른다.

| 확인 | 합격 기준 |
| --- | --- |
| 화면 | 웹 1440/1280/390/360, 확장 360px에서 가로 넘침·버튼 겹침 없음 |
| 확대 | 200%에서 주요 경로·출처·저장 조작 가능 |
| 키보드 | 모든 행동 접근, 보이는 포커스, 대화상자 Escape/포커스 복귀 |
| 상태 | 연결/빈 결과/저장 대기·실패·완료가 다른 문구와 행동으로 구분 |
| 데이터 | 기존 자료·위치별 개인 기록·구간·초안 보존, 중복 저장 방지 |
| 근거 | 소개문 없음·조건 미확인·자동 결과가 사람 확인으로 보이지 않음 |
| 반복 사용 | 교사가 폴더를 찾고 자료를 가져온 뒤 다시 열 수 있음 |

이번 시안의 확인 범위는 [preview-checks.json](preview-checks.json)에 기록한다. 시안의 브라우저 확인과 색 대비 계산은 운영 제품 전체 접근성·저장 통합 검사나 실제 교사 효용 검증을 대신하지 않는다. 실제 교사에게는 ‘자료 선택에 필요한 근거를 찾았는가’, ‘어느 폴더에 저장되는지 설명할 수 있는가’, ‘다음 수업에 다시 찾을 수 있는가’를 관찰 질문으로 사용한다.

## 9. 그리드와 공간 전환 — GO:OD에서 Curi A로

2026-10-15 사용자 추가 요청으로 보강했다. [원본 관찰 기록](reference-grid-interaction-observations.json) · [A/B 그리드·동작 비교 시안](grid-interaction.html).

### 원본에서 관찰한 배치

GO:OD는 당시 완성 포트폴리오가 아닌 티저였으며, 일반적인 카드 목록의 열 수를 확인한 것은 아니다. 실제 관찰의 핵심은 **뷰포트에 고정된 헤더/메뉴 + 중앙에 놓인 독립 영상 창 + 그 뒤의 폴더**다. 이를 원본의12열 CSS Grid라고 기록하지 않는다.

| 1440×960의 원본 실측 | 위치·크기(반올림 px) | 읽어야 할 구성 원리 |
| --- | --- | --- |
| 로고 | x655/y20,130×31 | 화면 중앙축 고정 |
| 닫힌 우측 메뉴 | x1060/y20,360×29 | 바깥20px 기준선, 내용과 무관하게 고정 |
| Studio 펼침 | 같은 x/y,360×629 | 앵커를 유지하고 아래로 확장 |
| Contact 펼침 | 같은 x/y,높이191 | 같은 껍질에 다른 내용, 높이는 내용에 맞춤 |
| 기본 영상 창 | x360/y168,720×585 | 중앙 정렬된 독립 창 |
| 메뉴 펼침 중 영상 | x504/y285,432×351 | 중앙축을 유지한0.6배 축소 |

390×844에서는 로고가 x130/y30, 메뉴가 x29/y80·333px폭으로 로고 아래에 놓인다. Studio는 약646px높이까지 펼쳐지고, 관찰 상태에서 영상은222px폭으로 작아져 패널 뒤에 겹쳤다. **패널의 위치 고정과 상태에 따른 공간 변화**는 차용하되, 겹침·블러·텍스트 축소를 Curi의 읽기 UI에 그대로 쓰지 않는다. DOM에서 크기가 잡혀도 패널 뒤에 가려진 내용은 사용자가 읽을 수 있는 영역으로 계산하지 않는다.

### Curi A의 그리드 규칙 — 새 설계값

폭은 CSS px이며 아래 수치는 원본 사이트 값이 아니다. 바깥 컨테이너는 border-box, 안쪽 사용폭을 `G`로 둔다. 열 너비는 `u = (G − (N−1)×gutter) / N`, n열 점유폭은 `n×u + (n−1)×gutter`다. 최대폭과 여백·gutter를 모두 한 번씩만 계산한다.

| 브레이크포인트 | 바깥 컨테이너 / 양쪽 패딩 | 열 / gutter | 동작 |
| --- | --- | --- | --- |
| ≥1200 | 최대1240 /32씩 |12 /16 | 검색 결과3×4열, 내 수업3+9열 |
| 768–1199 | 뷰포트100% /24씩 |8 /16 | 결과2×4열, 폴더 탐색은 위로 이동 |
| <768 | 뷰포트100% /16씩 |4 /16 | 결과4열 전체폭, 모든 입력/읽기 세로 흐름 |

예를 들어1440px에서 `G=1240−64=1176`, `u≈83.33`.4열 카드는 약381.33px,3열 폴더 탐색은282px,9열 목록은878px이다.390px에서는 `G=358`,4열 전체폭358px다. 콘텐츠가 길면 열 수보다 읽을 수 있는 최소폭을 우선하고 가로로 밀어내지 않는다.

| 화면/상태 | 데스크톱 점유 | 좁은 화면/확장 |
| --- | --- | --- |
| 헤더 | 로고4열 / 주 탐색8열, 이름 유지 | 로고→주 탐색, 아이콘으로 이름 대체 금지 |
| 질문 입력 |12열, 입력+검색 버튼 한 그룹 |4열, 필요 시 버튼 다음 줄 전체폭 |
| 결과 기본 |12열 안에4열 카드3개 |8열에서4열2개 /4열에서1개 |
| 근거 패널 열림 | 목록8열 + 패널4열, gutter16 | <1200에서는 목록 아래 전체폭; 자동으로 본문을 축소하지 않음 |
| 내 수업 | 폴더3열 + 자료9열 | 폴더 선택/검색 위, 자료 아래 |
| 두 단계 가져가기 | 중앙 modal, 최대520px, 그리드와 별도 top layer | 화면−32px, 내부 스크롤, 하단 조작 가림 방지 |
| Chrome 확장 | 웹12열을 축소하지 않음 |360px의 독립1열, 내부16px, 시간2열→아주 좁으면1열 |

자료 상세의4열 폭은 대체로360–420px 범위가 될 수 있으나 위 그리드 계산을 우선한다. 목록은 패널 때문에8열로 재배치하고 카드 글자 크기는 유지한다. 기존 운영 UI는 이 제안의 적용 여부와 별개다.

| 연결·저장 | 원본 대응 없음 |360px1열, 대기 문구→확인된 완료/실패 | 중복 차단, 실패 시 필드/폴더/구간 보존 |
| 스크롤 | 고정 헤더/메뉴/독립 창 | 교사 목록은 자연 스크롤; 긴 근거만 패널 내부 스크롤 | 스크롤 가로채기·원본 영상 자동 재생을 적용하지 않음 |

참고 사이트의Contact가 열린 상태에서Escape를 눌러도 관찰된 높이191px이 유지됐다. Curi에서는 이를 그대로 따르지 않고 명시적 닫기와Escape를 제공한다. 참고의 `.2–.3s` 계열 값은 이전 계산 스타일 관찰이고, Curi의120/180/240ms는 별도 설계 토큰이다. 원본 모션을 프레임 단위로 실측했다는 뜻이 아니다.

`prefers-reduced-motion`에서는 폭/위치/투명도 전환을0ms로 두고 최종 배치를 즉시 보여준다. 접근성 문구·결과는 줄이지 않는다. 비교 시안의 ‘모션 줄이기’는 그 동작의 데모이며 시스템 설정을 바꾸지 않는다.


## Chrome 사이드 패널 적용 기준 — R12-14

확장0.6.0은 아이콘 아래 임시 팝업 대신 Chrome 사이드 패널을 사용한다. 기본 문서는 기존 `popup.html`이며 `side_panel.default_path`로 열린다. 웹페이지 옆의 세로 작업 공간으로 화면 전체 높이를 사용하고 내부를 독립 스크롤한다. 본문 클릭 시에도 패널을 유지한다. 오른쪽 배치와 폭은 Chrome 사용자 설정/조작을 따른다. 360px은 비교 시안의 기준 폭이며 실제 폭을 고정하거나 좌우 비율을 강제하지 않는다. 좁은 폭에서는 시간 입력/현재 시간 버튼을 한 열로 바꾼다.

선택한 EBS 페이지가 저장 대상이며 다른 탭을 눌렀다고 대상을 자동 변경하지 않는다. 페이지 이동/닫힘 시 이전 영상의 저장과 시간 읽기를 잠그고 ‘열린 영상 목록 새로고침’으로 재확인한다. 영상별 초안·폴더 선택·기존 저장 결과는 보존한다. 이 기준은 확장 표시 방식의 공통 변경이며 디자인안 선택을 뜻하지 않는다. 3/4안의 확장 시안은 왼쪽 가상 영상 영역/오른쪽 세로 패널 배치를 보여 준다. 작은 화면에서는 비교를 위해 위아래로 쌓이며 실제 데스크톱 Chrome 배치와 구분한다.
