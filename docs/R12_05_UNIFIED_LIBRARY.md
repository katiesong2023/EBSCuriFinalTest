# R12-05 내 자료·수업 폴더 화면 통합

2026-10-14 사용자 요청으로 검색의 ‘내 자료’ 대화상자와 ‘내 수업 폴더’를 **내 수업 자료** 한 화면으로 정리했다. 검색의 내 수업 자료 메뉴는 기존 `/lesson.html`로 이동한다.

## 사용 동선

- **전체 자료**: 기존 내 자료와 모든 수업 폴더의 자료를 함께 보여준다. 같은 ID·제목·판본의 자료는 한 항목으로 묶고, 항목 안의 위치별 개인 기록을 펼쳐 확인·편집한다.
- **수업 폴더 선택**: 해당 폴더의 자료·메모·수업 목표·다중 교육과정을 확인하고 편집한다.
- **폴더 미지정**: 이전 내 자료 모음의 자료를 볼 수 있다. 새 폴더로 가져가거나 기존 개인 기준·목표·메모를 편집할 수 있다.
- **저장한 자료 찾기**: 현재 보기 범위에서 제목/프로그램/폴더/교육과정/개인 기록을 검색한다. 전체 검색에서 한 위치의 기록이 일치하면 같은 자료의 다른 위치도 확인할 수 있다.
- **전체 목록 내려받기**: 자료별 저장 위치·폴더 목표/기준·개인 메모·선택 이유·구간을 포함한다. 폴더별 목록 내려받기도 유지한다.

자료 카드의 가져가기에서는 기존/새 폴더 지정과 교육과정 다중 선택을 그대로 사용할 수 있다. 기존 자료의 위치별 ‘다른 폴더로 가져가기’도 같은 선택 화면을 사용한다. 저장한 수업용 구간과 편집/영상 열기는 통합 화면에서 유지하며 구간 목록은 접어둘 수 있다.

## 기존 기록 보존

전체 보기의 묶음은 화면 표시용이다. 기존 `curi.discovery.shelf.v1`·`curi.teacher.folders.v1`·`curi.teacher.lesson.v1`·`curi.teacher.segments.v1`를 강제로 합치거나 삭제하지 않는다. 폴더 미지정은 기존 모음의 가상 위치이며 새 폴더로 자동 이전하지 않는다.

같은 자료가 수업 A·수업 B·폴더 미지정에 있어도 각 위치의 교육과정·목표·메모·선택 이유·개인 영상 확인과 구간 연결을 별도로 보존한다. 수정은 해당 위치의 기존 키에만 저장한다. 기존 모음의 추가 개인 메모는 personalLibraryNote로 저장하고 이전 note 값도 유지한다. 폴더 기준과 자료 기준도 독립적으로 유지한다.

전체/폴더 전환과 검색만으로 저장 원본을 변경하지 않는다. 실패한 입력은 현재 화면에 유지하며 ‘지금 저장’으로 재시도한다. 다른 창이나 확장 프로그램의 변경을 받았을 때 미저장 입력이 있으면 자동 새로고침을 멈춘다. 기존 이전 준비안의 폴더 이관 경로와 원본 보존도 유지한다.

## 구현·검증

`teacher-library.js`는 기존 두 저장 경로를 읽는 가상 위치·자료 묶음·검색을 구성한다. `lesson.js`는 통합 보기와 위치별 편집/저장을 연결하고 `discover.js`는 별도 모음 대화상자를 사용하지 않는다. 기존 저장 키와 승인/검색 서버의 데이터 구조는 변경하지 않았다.
