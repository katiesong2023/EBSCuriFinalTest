# 과거 장소·풍경 검색 보완 — 2026-10-15

## 원인과 결과

‘과거 서울의 모습’은 수정 전4건을 반환했다. ‘과거’와 ‘서울’이 서로 다른 문장에 있어도 포함됐으며, 시장 배경·미래 학교·전기차·수해 대책이 결과에 섞였다. 보조 설명의 단어 일치를 프로그램명에서 확인한 것처럼 안내하는 경우도 있었다. 반면 ‘서울의 옛 모습’처럼 표현이 다른 직접 관련 자료는 빠졌다. [작업 전 응답](r12-historical-place-before.json).

장소와 과거 풍경·생활이 연결되는 원문을 대조하도록 변경했다. 단어가 멀리 떨어져 있거나 다른 지역 여행의 출발점으로만 등장하면 제외한다. 다른 문장·절의 단어를 합쳐 관계를 만들지 않는다. 부가 주제는 유지하고 ‘옛 모습/당시 생활’ 같은 표현과 명시된 역사 지명도 대조한다.

## 적용 범위와 근거

기존 장소 어휘와 추가 명시 장소에 공통 적용한다. 미등록 지명을 임의 추정하지 않으며 기존 검색어로 보존한다. 서울의 역사 지명 연결은 [서울역사편찬원](https://history.seoul.go.kr/archive/content.do?key=2211240006)을 근거로 한양·경성·한성부·경성부를 연결한다. 이 확장은 과거 장소 요청에만 사용하고 현대 행정 경계를 동일하다고 판정하지 않는다. 명시적 시대/추가 주제·부정은 기존 필수 조건으로 남긴다.

소개문과 유효한 같은 회차의 공식 보조 설명만 사용한다. 근거 인용은 원문 문자열의 위치와 일치한다. 실제 옛 영상·장면·학생 적합성을 자동 확인하지 않았다. 보충 문장을 새로 작성하거나 원본·승인·개인 저장·검색 색인을 변경하지 않았다. 유료API 호출0이다.
