2026-10-14. 동일 개발170·동일 원천 자료에서 원문으로 확인했던 검색 누락 4개를 모두 상위5에서 발견했다. 빈 결과는160→157, 주제 원문 근거가 있는 요청은6→10으로 개선됐다. 전체 검색 품질 목표는 아직 미달이며 R12-03은 진행중이다.

## 평가 범위와 실패 분류

## 공통 개선

- 요청 문법과 교실 활동을 필수 내용어에서 분리했다. 그리기·분류·맞혀보기는 활용 문맥으로 보존한다.
- 등록 개념에 없는 명사도 OR 선택지로 보존하며 조사와 ‘중 한 곳’ 같은 제어 표현을 이름에 붙이지 않는다. 유효한 OR/관계 요청을 전체 목록으로 자동 완화하지 않는다.
- 붙는 것/붙지 않는 것 비교, 생물의 먹이 관계를 구조화하고 자기 회차 소개문·식별 확인된 보조 원문에서 술어 단서를 함께 찾는다. 먹이 관계는 생물 문맥을 요구해 경제적 비유를 차단한다.
- ‘지역 브랜드’ 같은 명사 수식 조건을 유지하여 일반 기업 브랜드로 바꾸지 않는다. 명시적 필수 장소는 유지하고 예시 상황은 실제 장면 미확인으로 남긴다.
- 결과에 원문 문장·위치·회차 식별과 요청 상황의 남은 확인을 표시한다. 모바일 해석에도 OR/관계와 교실 활동을 구분해 보여준다.

제품 코드에는 질문 ID·후보 ID별 예외가 없다. 현재 관계 지원은 위 두 유형의 공통 규칙이며 모든 관계·고유명·의미적 제외를 해결한 상태는 아니다. 새 표현·필수 장소·고유명 AND·긍정문을 비교 요청으로 강화하지 않는 부정 대조8개도 확인했다. 부정 술어만 있는 원문은 긍정·부정 비교로 인정하지 않는다.

## 같은170개 전후

직전 재검사 버전을 기준으로 비교했다. 이전 최초 수정 전163빈과 이번160빈을 혼용하지 않는다.

| 지표 | 직전 버전 | 이번 버전 |
|---|---:|---:|
| 빈 결과 요청 |160|157|
| 후보 있는 요청 |10|13|
| 반환 상위5 검토 쌍 |35|36|
| 주제 원문 근거 후보 |11|15|
| 주제 원문 근거 있는 요청 |6|10|
| 부분 관련 후보 |9|8|
| 무관 후보 |7|4|
| 원문 부족 후보 |8|9|
| 알려진 보유 원문 진단 앵커 상위5 발견 |0/4|4/4|
| 확인된 경제 비유 제외 위반 |1|0|

4/4는 기존에 확인한 진단 앵커의 재발견이다. 독립 정답 집합의 재현율이나 실제 교사의 자료 선택 성공률이 아니다. 도서관/주민센터 OR·자석 비교·먹이 관계·냉장고 예시의4요청이 원문 후보를 찾았다. 냉장고 실제 장면은 미확인이다. 두 기존 요청은 경제 비유/일반 브랜드 등 부적절 후보 제거로 결과 수가 줄었다.

반환36쌍을 모두 텍스트 검토했다. API 인용66개는 원문 문자 위치와 자기 회차 식별이 일치했다. 제외 조건이 있는8후보쌍은 영상 부재를 확인하지 않았으므로 모두 미확인으로 남긴다. 정확한 인용과 전체 요청 충족은 별개다.

[최종 API170](r12-03-content-verified170.json)·[요청별 전후/36판정/66인용](r12-03-content-comparison.json). 원천·색인·승인 관련5저장소 SHA가 전후 동일하고 API 실행 중 코드/저장소 변경은0이다. 수집·유료 API·개인 기록 쓰기는0이다. 앞선 content-after170은 중간 진단 결과이며 최종 비교에 사용하지 않았다.

## 검증과 다음 우선순위

새 공통 요청8·질의 회귀27·기존 제외19·프로그램12·형식9·결합20·학년6 검증이 통과했다. 실제 API170 오류0(응답 관측 p50 557ms·p95 1329ms; 초기 구성/캐시 포함, 성능 개선 비교는 아님), 390px 모바일2화면 오류/가로 넘침0, 장면 미확인 표시를 확인했다. 개인 기록 저장 코드/키는 이번 검색 수정에서 변경하지 않았다.

무관 비율은7/35(20%)→4/36(11.1%)로 줄었지만10% 이하 목표에 미달한다. 원문 근거 요청10개도 목표20개에 미달한다. 도서관 상위5에는 수학자의 대출 일화·사람책 비유 등 무관2, 부분1, 원문 부족1이 남는다.

1. **R12-03 순위/의미 범위**: 기관의 역할을 설명하는 원문과 배경 일화·비유를 구분한다. 남은51단서군에서 독립 원문 판단 후 고유명·필수/OR·관계 단위의 탈락 지점을 확인한다. 명사 삭제나 전체 목록 완화로 빈 결과를 줄이지 않는다.
2. **R12-02 원문 공백 조사**:95미확인군과51단서군을 분리해 사회 공공기관/지도·교통통신/역사·제도, 과학 자석·회로/상태변화·열/생태관계6군 각10회차를 선대조한다. 효과 있는 군만 사회100/과학100·합계200 범위로 확장한다. 이번 수집은 미실행이다.
