# Curi 향후 확장 과제

기준일: 2026년 10월 16일

Curi는 현재 로컬 환경에서 교육 메타데이터를 검색하고, 수업 자료와 구간 클립을 구성하는 MVP를 구현하였다. 향후 사용자별 자료를 관리하는 웹서비스로 전환하고, EBS 공식 메타데이터 제공 체계를 기반으로 시맨틱 레이어를 재구성한다. Curi 자체 개발로 추진할 수 있는 기능과 EBS의 인증·데이터·콘텐츠 권한 협의가 필요한 기능을 구분하여 단계적으로 확장한다.

## 현재 구현 범위

| 영역 | 구현 범위 | 현재 제약 |
| --- | --- | --- |
| 자료 검색과 교육과정 연결 | 공개 페이지 등에서 수집·추출한 메타데이터를 로컬 저장소에 적재하고, 원문 근거와 교육과정 연결 후보를 활용하여 검색한다. | EBS 내부 메타데이터 DB와 직접 연결되어 있지 않으며, 원천 변경은 별도의 수집·갱신 과정으로 반영한다. |
| 개인 수업 자료 | 폴더, 영상 노트, 교육과정 선택, 구간 클립과 수업 영상 리스트를 관리한다. | 교사용 계정이 없으며, 개인 자료는 브라우저 프로필과 접속 주소별 저장 공간에 보관된다. 사용자별 서버 저장과 기기 간 동기화는 향후 과제다. |
| 확장프로그램 연동 | 같은 Chrome 프로필에서 설정한 로컬 주소의 내 수업 자료 탭과 통신하여 폴더를 조회하고 영상·클립을 저장한다. 지원 EBS 페이지에서는 재생 시간 읽기와 구간 이동·끝 정지 기능을 제공한다. | 계정 기반 연결이 아니며 웹 탭의 연결 상태에 영향을 받는다. 실제 재생은 EBS 로그인·시청 권한과 플레이어 상태에 따라 달라진다. |
| 저장과 접근 구분 | 영상 원천 정보의 CuriBase 등록과 개인 폴더·클립의 브라우저 저장을 구분한다. 관리자 화면에는 별도의 관리자 코드 인증이 있다. | 관리자 인증은 교사용 로그인이나 EBS 계정 연동을 의미하지 않는다. |

기능 구현과 실제 영상·수업 적합성 검증은 구분한다. 검색 후보와 교육과정 연결 후보 전체가 사람의 검수를 완료한 자산이라는 의미는 아니다.

## 과제 1 계정 기반 웹서비스와 확장프로그램 연동

교사용 Curi 로그인과 사용자별 서버 저장을 도입한다. 확장프로그램은 로그인한 Curi 계정의 자료에 연결하고, 연결 계정·저장 폴더·저장 완료 상태를 명확하게 표시한다. 이를 통해 현재 브라우저별로 분리된 개인 자료를 계정 단위로 관리하고 여러 기기에서 이어서 사용할 수 있도록 한다.

| 구분 | 추진 내용 |
| --- | --- |
| Curi 자체 개발 | 교사용 로그인, 사용자별 자료 접근 통제, 폴더·노트·클립의 서버 저장, 확장프로그램의 Curi 계정 연결, 기존 브라우저 자료 이전과 기기 간 동기화를 개발한다. Curi 로그인 제공자는 별도로 선정한다. |
| EBS 권한 협의 | EBS가 외부 서비스에 제공하는 인증 방식과 연동 가능 여부를 확인한다. 공식 지원 범위에 따라 OAuth/OIDC 또는 SSO 적용, 앱 등록·승인, 제공 정보와 사용자 동의 범위를 협의한다. |
| 콘텐츠 이용 협의 | 인증 연동과 별도로 콘텐츠 시청 권한의 확인 방식, 외부 서비스에서 허용되는 재생 제어와 플레이어 연동 범위를 협의한다. |

EBS 외부 인증 연동의 제공 여부와 적용 방식은 미확정이다. Curi 로그인이나 EBS 계정 연결만으로 유료·제한 콘텐츠의 시청 권한을 부여하지 않으며, 영상 접근은 EBS의 시청 정책과 이용자 권한을 따른다.

## 과제 2 공식 메타데이터 기반 시맨틱 레이어 재구성

현재의 로컬 수집·추출 DB 중심 구조를 EBS 공식 메타데이터 제공 체계와 연결한다. 시맨틱 레이어는 프로그램·회차와 주제·교육과정·원문 근거의 관계를 검색에 활용하는 계층으로, 제공받은 공식 식별자와 필드를 기준으로 다시 구성한다. EBS 내부 DB 직접 접근을 전제로 고정하지 않고 승인된 API, 데이터 내보내기 또는 정기 공급 방식에 맞춘다.

| 구분 | 추진 내용 |
| --- | --- |
| Curi 자체 개발 | 공식 제공 스키마에 맞춘 데이터 변환·검증, 회차 식별자와 판본 대응, 주제·교육과정 관계 및 근거·출처 관리, 시맨틱 검색 색인 재구성을 개발한다. 변경·삭제·비공개 전환에 따른 검색 제외와 관계 재검사 절차를 마련한다. |
| EBS 권한 협의 | 메타데이터 DB·API·파일의 제공 가능 여부, 대상 프로그램·회차, 제공 필드, 갱신 주기, 접근 인증과 호출 한도를 협의한다. |
| 데이터 활용 협의 | 소개문·분류·썸네일·자막 등 항목별 제공 여부와 저장·가공·임베딩·검색 결과 표시·재제공 허용 범위를 확인한다. 자막과 영상 원본은 메타데이터 제공만으로 확보되는 것으로 간주하지 않는다. |

공식 데이터 연결 후에는 누락·중복·갱신 반영과 검색 관련성을 기존 로컬 기준선과 비교한다. 데이터 접근 확보 자체를 검색 품질이나 교육과정 적합성 향상의 검증 결과로 제시하지 않는다.

## 단계별 추진과 협의 의존성

1. **Curi 서비스 기반 구축:** 교사 계정, 사용자별 서버 저장과 접근 통제, 확장프로그램 연결 흐름을 설계·개발한다. EBS 연동과 독립적으로 추진할 수 있다.
2. **EBS 제공 범위 협의:** 인증 연동, 콘텐츠 이용, 메타데이터 제공·활용을 각각 확인하고 허용된 연동 방식을 확정한다.
3. **공식 연동 적용과 검증:** 승인된 인증·데이터 경로를 적용하고, 개인 자료 이전·기기 간 이용·원천 갱신 반영·검색 품질을 확인한다. 인증과 데이터 연동은 각 협의가 완료된 범위부터 적용한다.

EBS 인증·데이터 제공 경로가 확보되기 전까지는 현재의 로컬 시연과 EBS 원문 이동 방식을 기준으로 설명한다. 공식 연동 승인과 서비스 전환은 향후 확장 범위다.

## 제출용 요약 문안

> 본 MVP는 로컬 환경에서 교육 메타데이터 검색과 수업 자료·구간 클립 활용 흐름을 구현하였다. 향후 Curi 계정 기반 웹서비스와 확장프로그램 연동을 통해 사용자별 자료 관리 및 기기 간 연속 이용을 지원하고, EBS 공식 메타데이터 제공 체계를 기반으로 시맨틱 레이어를 재구성할 계획이다. Curi 로그인과 사용자별 저장은 자체 개발 과제로 추진하며, EBS 인증 연동, 콘텐츠 시청·재생 제어, 메타데이터 제공·활용 범위는 공식 지원 여부와 권한 협의를 거쳐 단계적으로 적용한다.
