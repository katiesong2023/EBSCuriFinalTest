# R12-26 검색 후 주제 필터 결과 복구

2026-10-15 사용자 요청. 구현·실제 화면 검증 완료, 사용자 결과 확인 대기.

## 재현과 원인

현재 실제 API의 검색6종(갯벌 생태계·다문화·과거 서울·어깨관절·민주주의·지식채널e 인권)에서 양수 주제/묶음85개를 선택한 결과는 표시 건수와 모두 일치했다. Chrome에서도4검색의 주제63개를 정상 완료 후 선택했을 때0건은 재현되지 않았다. 따라서 정상 완료된 필터의 서버 조건을 완화하거나 주제를 임의 해제하지 않았다.

대신 새 검색을 기다리는 동안 이전 결과의 주제 목록과 건수가 활성화돼 있는 문제를 재현했다. ‘민주주의’의 ‘민주주의·법·인권 전체32건’이 남아 있는 상태에서 ‘갯벌 생태계’ 검색을 시작하고 해당 이전 주제를 선택하면 검색어는 갯벌·주제는 민주주의가 되어 실제0건/빈 결과가 표시됐다. 새 검색이 준비한 필터가 아닌 이전 검색의 선택지를 사용할 수 있던 화면 상태 문제다. 이 흐름을 실제API와 지연 응답으로 확인했다. 사용자가 경험한 모든 조합을 확인한 것은 아니며, 구체 검색어/주제의 추가 제보는 별도로 대조할 수 있다.

## 수정

`public/discovery-filters.js`에서 검색 대기 중 주제·프로그램·자료 유형 및 결과 건수에 종속된 선택 조건을 비활성화한다. 프로그래밍 방식으로 change 이벤트가 들어와도 준비되지 않은 선택은 적용하지 않는다. 최신 응답을 렌더링해 새 선택지/건수/선택 상태를 함께 갱신한 뒤 활성화한다.

`public/discover.js`는 현재 요청 실패 시 필터에 실패 상태를 알린다. 실패 후에는 이전 검색의 선택지/건수를 지우고 ‘검색 완료 후 선택’으로 표시해 재사용을 막는다. 검색어 수정·다시 시도·조건 해제는 유지한다. 이전 요청 취소/늦은 응답은 기존 요청 번호 검사로 최신 필터 상태를 변경하지 않는다. 필터 실패 처리도 같은 검사 뒤에 적용한다.

주제 사전·검색 관련성/AND 조건·원본·키워드/색인·교육과정·개인 자료는 변경하지 않았다. 이미 열려 있는 화면은 새로고침해야 새 스크립트를 적용한다.
