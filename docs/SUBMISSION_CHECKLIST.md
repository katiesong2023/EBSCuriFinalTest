# Curi 트랙1 제출 준비 목록과 순서

작성 기준일: 2026-10-16 · 신청 부문: 트랙1(Now Agent)

검색 보충은 별도 작업으로 두고 현재 구현을 기준으로 제출을 준비한다. 이 문서는 실행 순서와 점검 목록이며, 미실행 작업의 완료를 뜻하지 않는다. 현재 task 상태는 [PLANS](PLANS.md)를 따른다.

## 1. 제출 조건

저장소의 [대회 요강](../AI_Agent_Hackathon.pdf) 4~6쪽·서식5를 기준으로 정리했다. 사내 변경 공지는 별도 확인한다.

| 항목 | 요강상 조건 |
| --- | --- |
| 마감 | 2026-10-16(금) 18:00 |
| 수신처 | axteam@ebs.co.kr |
| 메일 제목 | `[과제제출_트랙1] 과제명_대표자성명` |
| 보고서 | 서식5 프로젝트 개발 보고서, PDF, 분량 제한 없음 |
| 영상 | 실제 작동 시연, 3분 이내, MP4 |
| 프로토타입 | 웹 URL·소스 코드·봇 링크 등 택1 이상 |
| 제출 방식 | 보고서·영상·산출물을 ZIP 하나로 제출, 대용량은 다운로드 링크 가능 |

웹 공개 배포는 필수가 아니다. URL을 제출하지 않는 경우 심사자가 실행할 수 있도록 소스·필요 데이터·설정 예시·실행 안내를 준비한다.

## 2. 권장 진행 순서와 현재 위치

앞서 대화에서 정한 1~10번 순서를 유지한다. 현재는 **2번 핵심 설명 초안 작성·사용자 확인 대기** 상태다. 개발 정리는 별도 기초 자료로 작성했다.

| 순서 | 준비할 일 | 결과물·완료 기준 | 현재 확인된 상태 |
| --- | --- | --- | --- |
| 1 | 신청 정보·제출 범위 확정 | 신청 정보, 제출 버전, 지원 범위 기록 | 트랙1 확인. 나머지 미확인 |
| 2 | 핵심 설명 정리 | 문제·이용자·Agent 역할·차별성·효과 문안 확인 | 초안 작성, 사용자 확인 대기 |
| 3 | 시연 시나리오·리허설 | 대표 자료·순서·원문 링크·동작 확인 기록 | [시나리오 초안](SUBMISSION_VIDEO_SCENARIO.md) 작성, 실제 리허설 미완료 |
| 4 | 제출 버전 안정화 | 시연·실행을 막는 결함 해결, 버전 재고정 | 최종 제출 버전 점검 미완료 |
| 5 | 보고서 근거·화면 확보 | 최신 캡처·구조도·같은 버전의 수치·비용·한계 | 기존 기록 있음, 제출용 선별 미완료 |
| 6 | 서식5 보고서 작성·PDF 확인 | 필수 정보·네 항목 작성, 최종 PDF 시각 확인 | 최종 PDF 미완료 |
| 7 | 3분 이내 영상 제작 | 실제 구동 MP4, 길이·가독성·음성·재생 확인 | 미완료 |
| 8 | 실행 가능한 산출물 준비 | URL 또는 소스·데이터·실행/확장 설치 안내 | 최종 묶음 미완료 |
| 9 | 출처·패키지 점검 | 출처·라이선스·비밀값 제외·ZIP 해제 후 확인 | 미완료 |
| 10 | 발송·접수 확인 | 메일·첨부/링크·발송 및 접수 기록 | 미확인 |

3번에서 실제 흐름을 점검하고 4번에서 필요한 결함만 수정한다. 수정 후 해당 동선을 다시 확인한 버전으로 5~8번을 준비한다. 보고서와 영상은 같은 버전을 사용하며 촬영·편집 과정의 변경은 서로 반영한다. 8번 실행 안내의 초안은 버전 고정 후 준비할 수 있지만 최종 실행 확인은 패키지에 포함될 실제 파일로 수행한다.

## 4. 이번 제출 준비와 분리할 일

- 검색 보충·유료 모델 실험과 제품 채택 판단.
- 교사 계정·서버 동기화·EBS 공식 인증/메타데이터 연동 신규 개발.
- 대량 사람 승인과 영상 전수 검증. 미완료 범위를 명시하며 제출 준비의 일괄 선행 조건으로 두지 않는다.
- 실제 교사 효용 검증. 수행 전에는 시간 절감·수업 효과를 기대효과로 표현한다.
- 본선 PT·질의응답 자료. 진출 후 별도 안내에 맞춰 [본선 task](../Tasks/task-05-01-finalist-pt.md)로 준비한다.
