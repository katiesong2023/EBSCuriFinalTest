- 압축 해제 카탈로그 SHA-256: `803bb0dd1cfd73d9a890edf4f679a75b4200425bada493643b095f7ccc0101ec`. 전후 동일한 스냅샷·질문을 사용했다. 질문·코드 해시는 각 결과 JSON에 있다.

## 사람 평가 규모와 확인 요청

기존 25/25/100~150건은 이번에 실행한 수치가 아니다. 사용자 검수 여력 답변 전까지 확정 목표를 대체하지 않는다. 제안은 **새 사용자 요청 사회 2·과학 2개**, 각 최대 2자료(최대 8개, 후보가 없으면 0개 그대로), 기존 검수 후보 4개 중 실제 사용할 자료 우선이다. 이 수량은 제안이며 합의·사람 평가 완료가 아니다.

사람은 요청별 실제 사용할 자료·선택 이유·제외 이유, 원문/재생 여부, 준비 시작·종료 시각을 직접 기록한다. 기존 감사 후보 4개(지방의회 3부 시민·다문화 초등교실·꿀벌 3부·1g 과의 전쟁)의 우선순위와 출처 복구 대기 제외를 확인한다. 실제 입력 전 사람 판단·시간·학년·교육과정 승인은 비워 둔다.

## 재현

저장소 루트에서 Node 24.18 이상을 사용한다. `.env`를 로드하지 않으며 실 API 키가 필요하지 않다. 기존 보고서를 보존하도록 검사 스크립트에 `CURI_REPORT_PATH` 또는 `CURI_REPORT_PREFIX` 출력 경로를 추가했다.

```sh
node server/quality-workspace-check.js
CURI_REPORT_PATH=docs/r09-source-gates.json node server/quality-gates-check.js
CURI_REPORT_PATH=docs/r09-workspace-contract.json node server/teacher-workspace-check.js
CURI_REPORT_PATH=docs/r09-query-regression.json node server/query-regression-check.js --phase=after
CURI_REPORT_PATH=docs/r09-teacher-query.json node server/teacher-query-check.js --phase=after
CURI_REPORT_PATH=docs/r09-semantic.json node server/semantic-check.js
CURI_REPORT_PATH=docs/r09-verified-topic.json HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 node server/verified-topic-check.js
CURI_REPORT_PATH=docs/r09-http.json node server/discovery-check.js
node server/verified-save-check.js
node server/review-actions-check.js
```

Playwright 모듈과 브라우저 실행 파일을 `CURI_PLAYWRIGHT_MODULE`·`CURI_BROWSER_EXECUTABLE`로 지정한 환경에서는 다음 두 명령이 각각 임시 서버를 시작하고 종료한다. 새 교사 검사는 3339, 관리자 검사는 3328 포트를 기본 사용한다. 다른 포트는 `CURI_R09_TEST_PORT`·`CURI_ADMIN_TEST_PORT`로 지정한다. 브라우저 쓰기는 격리된 새 브라우저 저장 공간에서만 수행한다.

```sh
node server/quality-workspace-browser-check.mjs
CURI_REPORT_PREFIX=docs/r09- node server/admin-workspace-check.mjs
```

기존 브라우저 회귀는 테스트 서버를 별도로 실행한 뒤 `CURI_TEST_URL`과 서버와 동일한 테스트용 `CURI_ADMIN_TOKEN`을 전달한다. 아래 두 명령 중 탐색 검사는 관리자 로그인도 확인하므로 토큰이 필요하다. 실제 키를 출력하거나 `.env`를 읽을 필요는 없다. 테스트 서버의 유료 API 설정은 `CURI_ALLOW_PAID_API=false`로 둔다.

```sh
CURI_REPORT_PREFIX=docs/r09- node server/teacher-workspace-browser-check.mjs
CURI_REPORT_PREFIX=docs/r09- node server/discovery-browser-check.mjs
```
