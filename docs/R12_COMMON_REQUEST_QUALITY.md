# R12-23 질문·구어체와 무관 결과 공통 개선

2026-10-15 사용자 요청. 상태: 진행중, 구현·전체370개/기능/실제 API/화면 확인 완료, 사용자 결과 확인 대기.

## 변경 범위

개별 테스트 문장·ID·콘텐츠ID에 대한 반환 예외를 만들지 않았다. 원본 소개문·방송/의미 색인·교육과정 승인·개인 자료를 변경하지 않고 요청 해석과 결과 통과 조건을 수정했다. 새200개는 이번부터 개선에 사용하는 개발 회귀 집합이며 실제 교사 효용/독립 최종 평가와 구분한다.

`request-language.js`는 질문의 기능어·수업 활용 문구·시청 대상과 설명 요청을 분리한다. 의문 어미와 알려진 요청/서술 동작을 제한적으로 해석하며 미지 명사와 고유명사를 지우지 않는다. ‘숨을 쉬는’ 동작을 호흡으로 확장하고 원래 구절을 남긴다. 교정된 원문을 만들어 대체하지 않으며 사용자 원문과 분리된 요청 문구를 보존한다.

`natural-request.js`는 이 결과를 기존 의미 해석에 연결한다. 낮·밤을 언급했다고 모두 자전으로 대체하지 않고 직접적인 낮과 밤의 변화 요청에서만 확장한다. 해륙풍처럼 낮·밤이 다른 현상의 조건인 경우에는 원래 내용을 유지한다. `discovery-intent.js`는 조사·복수형을 보완하고 한 글자 명사는 제한된 목록만 처리한다. `discovery-request.js`는 시청 목적에 붙은 학습 대상과 콘텐츠 속 어린이·학생을 구분한다. `request-content-plan.js`는 ‘지역 수업자료’ 같은 요청 문구를 ‘지역 특산물’과 같은 필수 대상 구절로 오인하지 않도록 제한했다.

`source-context.js`는 다음을 공통으로 대조한다.

- 실제 내용은 제목·소개·회차/판본/지문이 검증된 공식 보조 원문에서 확인한다. 보조 원문의 배우·진행자 경력과 캠페인, 사진 첨부 안내를 방송의 내용 근거로 사용하지 않는다. 원문 자체는 수정하지 않고 검색용 보류 범위만 같은 길이의 공백으로 가린다. 첨부 안내가 붙어 있다는 이유로 같은 문장의 방송 설명 전체를 지우지 않는다.
- 의미 확장과 시맨틱 태그의 실제 인용 위치를 대조한다. 동의 표현·생태 설명을 원래 검색어의 문자 일치만으로 재차 배제하지 않는다.
- 두 개 이상의 내용군이 있으면 제목/같은 문장 또는 길이450 UTF-16 이내인 인접 두 문장에서 연결 단서를 확인한다. 문서 전체의 흩어진 단어만 모은 결과를 제한한다. 단일어의 프로그램명 탐색과 과거 장소의 검증된 역사 지명은 기존 경로를 유지한다.
- ‘우리 고장’의 지역 의미와 기계 고장, 개인의 사회화와 국제 규범의 사회화를 문맥으로 구분한다.
- 서식 장소+생물, 주제+문제 상황, 낮과 밤의 변화, 주어 자체의 생성·형성, 필요성/기능, 수치 속성의 비교처럼 명시한 대상/관계는 별도로 대조한다. 흙 자체의 생성과 흙을 재료로 다른 물건을 만드는 동작은 구분한다. 이 관계들은 인접 문장 허용으로 우회하지 않는다.

`discovery-search.js`는 후보가 기본 조건을 통과한 뒤 이 문맥 검사를 적용한다. `request-search-plan.js`도 검증된 구조화 해석을 호출자가 제공했을 때 동일한 원문 문맥을 우회하지 않도록 적용한다. 유료 모델은 호출하지 않는다. `source-meaning-rules.js`에는 생물 관계를 먹이·공생·천적 등 생물학적 맥락과 대조하는 공통 의미 단위를 추가했다.

## 검증 기준

건수 증가를 정확도/성공률로 표시하지 않는다. 새200개/기존170개를 각각 고정 입력·동일 원천으로 실행하며 결과가 없어진 요청도 별도로 기록한다. 무관한 원래 결과를 제거한 경우와 정당한 후보가 빠진 경우를 분리한다. 중간 보완 실행은 최종 비교에서 제외하고 변경 지문이 고정된 `common-stable` 실행을 사용한다.

공통 fixture는 원래200문장 외의 환경오염·염전·도자기 고장·숲의 곤충·새 가상 인물/주제 문장도 사용한다. 미지 고유명·추가 내용·AND/OR·프로그램·형태·시간·제외·원문 불변, 제작자 경력/첨부 안내, 의미 근거 보존을 검사한다. 안개 자체의 생성과 안개를 이용한 무대 제작, 안전벨트의 기능과 디자인 전시, 새의 무게 비교와 날개 모양 비교처럼 새 대상·관계의 긍정/부정을 포함한다.

## 해석 한계

로컬 어휘·형태·인용·문맥 규칙이며 자연어 전체 의미를 이해한 모델 판정이 아니다. 모든 질문의 동사·다의어·생략·오타·복합 비교를 지원하지 않는다. 내용 단서가 있는 후보와 요청 관계/장면/학년/영상 길이가 확인된 자료는 구분한다. 시간·학년 조건을 임의 삭제하지 않고 기존 미확인 안내를 유지한다. 관계 설명을 확인하지 못하면 빈 결과로 남을 수 있다. 짧은·짧게 같은 정성적 요청은 요청 문구로 분리되며 실제 길이 충족을 뜻하지 않는다. 숫자로 명시한 분 조건은 기존 제약과 미확인 안내에 유지한다. 이 작업에서 소개문을 창작하거나 원문 품질 문제를 자동 승인하지 않았다.

## 중간 확인과 최종 실행

개발 중 실제 API에서 통계 비교 문장이 남는 문제와 기존 자연 다큐의 의미 근거가 지나치게 배제되는 문제를 발견했다. 주제+문제 상황의 관계 검사와 태그/의미 인용·인접 문장 보존을 보완했다. 질문 문법 분리 후 주제만 남아 흙 재료의 생활용품 같은 후보가 나오는 경우도 확인해 주어 자체의 생성·기능·수치 비교를 구분했다. 해당 중간 실행을 최종 성적으로 사용하지 않는다.

실제 API 표본에서 긴 민주주의 요청32건·지식채널e 인권 관련 편27건·도시 문제의 관련 후보1건·호흡 질문2건을 확인했다. 땅속 동물/낮밤 원리 요청의 무관 자료는 제외하고 과거 서울7건·갯벌 생태계5건은 유지했다. 이 건수는 정답률이 아니다.

회차 수집 당시의 `requested-programs-check.js`는 이미 사용자 요청으로 삭제한 NEWS76개를 요구하므로 현재 데이터에서0≠76으로 실패한다. 첫 DB 행수 단언이며 이번 검색 변경과 무관한 과거 수집 시점 검사다. 뉴스 복구나 해당 기대값 변경은 이번 작업에서 하지 않았다. 현재 변경 범위는 별도 검색 계약/실제 API/고정200·170으로 확인한다.

- 생성·기능·수치 비교는 원문의 제한된 서술 단서를 대조한다. 내용을 완전히 이해하거나 요구의 모든 관계를 증명하는 판정으로 표시하지 않는다.

최종 전후 검토에서 사막의 살아가는 모습 요청을 생물 서식 대상 조건으로 오인하는 경우를 추가 보완했다. 또한 생물 관계와 경제 먹이사슬, 물리적 계절 변화와 이야기의 짝짓기 계절, 감정의 에너지와 물리적 에너지를 구분하고 자원 추출의 설명 단서를 대조한다. 구체 생물 대상이 없는 모습/자료/영상 등의 명사는 서식 대상 조건으로 만들지 않는다.

최종 검증은 `common-request-evaluate.js`로 두 기존 실행기의 고정 입력/출력/지문을 보존하면서 카탈로그·로컬 의미 엔진을 공유한다. 집합별 원문만 사용하고, 두 집합의 요청 순서는 각 집합 안에서 유지된다. 개별 결과/오류와 실행 전후 지문은 각각 저장한다.

## 남은 검토 대상

- ‘고려청자는 어떻게 만들었을까’의 제작 절차처럼 능동형 동작/과정은 완전히 결합되지 않는다. 고려청자 역사·지역 이야기를 반환해도 제작 절차를 충족했다고 판정하지 않는다.
- 생물 분류·민주주의의 넓은 주제 일치는 성인 강의까지 포함할 수 있다. 초등학생 대상의 난이도·교육 적합성은 미확인이다.
- 호흡 질문의 건강/폐 관련 후보도 호흡 과정 자체의 설명 여부를 사람이 확인해야 한다.
- ‘5분’, ‘클립/애니메이션’ 요청의 실제 길이·자료 종류가 검증되지 않은 회차는 해당 조건을 충족한 정답으로 집계하지 않는다.
- 오타·생략·복합 요청과 현재 원문의 내용 부족은 여전히 빈 결과를 만든다. 빈 결과를 임의 동의어로 채우지 않았다.
- 공식 원문에 ‘1943년 광복 이후’처럼 사실 오류가 의심되는 문구가 남아 있다. 원문 보충/사실 검수는 별도 작업이며 이번 검색 규칙으로 승인하지 않았다.
