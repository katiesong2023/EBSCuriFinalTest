# R12-25 키워드 누락 점검·추출

2026-10-15 사용자 요청. 구현·전체 원문 인용·370개 검색 회귀·실제 API/화면 확인 완료, 사용자 결과 확인 대기.

## 전체 점검

대표22,161개와 별도 판본1,242개, 고유ID 총23,403개를 동일 원문으로 대조했다. 화면 내용 키워드 `contentKeywords`를 기준으로 집계하며, 사람 승인·교육과정 태그가 없는 수와 구분한다.

| 항목 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 키워드 있는 콘텐츠 | 8,806 | 15,591 |
| 키워드 없는 콘텐츠 | 14,597 | 7,812 |

기존 키워드가 없던 **6,787개에 11,522개 키워드를 추출**했다. 부정문인 ‘도시가 아닌 동네’/‘영국이 아닌 파리’의 기존 키워드2개는 보류했다. 따라서 순증은6,785개다. 기존 키워드가 하나라도 있던 자료를 무조건 확장하지 않으며 제작 안내/부정 규칙은 공통 적용한다.

전체 응답 키워드30,201개의 원문 인용 위치가 일치했다. 새로 채운 자료 중38개는 회차·판본·원문 지문이 검증된 공식 보조 원문을 사용했다. 전체 키워드 중 보조 원문 인용은324개다. 각 근거는 필드·UTF-16 시작/끝·인용·출처와 보조 원문 ID/지문을 보존한다.

## 추출 방법

- 기존 등록 개념·내용 어휘의 소개문 검증을 유지하고 키워드가 없는 자료에 소재/질환/생물/사회/교육·직업/예술/음식 어휘를 보충했다. 새 어휘는 원문 표현으로만 표시하며 등록 개념·교육과정 승인으로 자동 승격하지 않는다.
- 사전에 없어도 ‘○○에 대해 알아본다’, ‘○○를 관찰한다’, ‘○○의 제조 원리’처럼 본문이 주제로 명시한 명사구와 실제 조리명을 후보로 추출한다. 모든 후보는 같은 단어 경계·문맥 검사를 통과해야 한다. 임의 제목 단어·빈도만으로 태그를 만들지 않는다.
- 소개문에 없으면 회차/판본/출처/지문이 맞는 공식 보조 원문만 사용한다. 보조 원문을 소개문으로 복사하지 않는다.
- 은유·부정·인명 존칭·제작자 경력·사진 첨부 안내를 보류한다. 사회 문제와 대안의 대비(차별/불평등/폭력/전쟁/혐오/배제와 공존/평등/존중/평화/포용/화합)는 관련 주제로 보존한다. ‘자유로이’ 같은 파생 표현, ‘엔터테인먼트 언어로 풀어낸’ 같은 비유 표현을 내용 키워드로 삼지 않는다.
- 빈 소개/제목 복사는 억지로 채우지 않는다. 기존 검색/카드 경로와 파생 SQLite에 반영하고 카드 툴팁에서 소개문/공식 보조 원문을 구분한다.

마지막5,196개 모두가 내용이 없다는 뜻은 아니다. 한 글자 소재·복합어·영문·캐릭터/작품명·생략/감성 문구·짧은 설명 등도 남아 있다. 이번 추출은 형태/원문 문맥 규칙이며 모든 명사와 전체 의미를 이해하는 모델 검수가 아니다. 특히 원문 언급 확인을 관련성·사실성·영상 장면·학년 적합성의 확인으로 표시하지 않는다. 새 어휘 전체에 대한 사람 의미 검수는 미완료다.

## 저장·검증

- 원본23,403개 제목/소개/보조 원문의 변경 전후 지문 일치. 방송 DB·승인/개인 자료·자동 자산·임베딩 DB 변경0. 유료 호출0.
- 파생 `semantic-layer.sqlite`를 재생성하고 무결성 검사OK·키워드30,201행을 대조했다. 공식 보조 원문의 식별/지문 열을 추가했다. 개인 수업·승인·원본 방송은 수정하지 않았다.
- 누락 추출 계약8개, 기존 질문/구어체25개·은유15개·검색 근거8개 통과. 실제 API8개와1440/390px 화면2개에서 카드 키워드·가로 넘침0·브라우저 오류0 확인. 갯벌5·과거 서울7 유지.
- 오래된 `semantic-check.js`는 ‘백혈구…’ 요청의 잔여 검색어가 빈 배열이라고 가정하는 단언에서 실패한다. 새 키워드 함수를 빈 배열로 대체해도 같은 실패가 재현되어 키워드 추출과 별개인 현재 요청 해석 계약 불일치다. 해당 기대값을 임의 수정하지 않았다.

## 개발 중 검토

은유/부정 규칙을 확장한 중간 실행에서 ‘차별이 아닌 공존’의 관련 인권 콘텐츠가 빠졌다. 해로운 사회 문제와 대안을 대비하는 표현은 주제를 다루지 않는다는 부정과 구분하도록 공통 규칙을 보완했고, 독립 계약에 차별/전쟁과 공존/평화의 예를 추가했다. 해당 중간 `keywords-final` 실행을 최종 성적으로 사용하지 않는다. 최종 검색 비교는 `keywords-verified`로 기록한다.

## 최종200·170 검색 회귀

질문/구어체 개선 직후 `common-stable`과 이번 `keywords-verified`를 비교했다. 고정 입력/순서/원본·승인·자동 자산·임베딩4저장소 동일, 로컬E5 전체370개 사용, 실행 오류0·로컬 의미 엔진 실패0이다.

| 집합 | 결과 있는 문장 전→후 | 0건 전→후 | 상위5 후보 쌍 전→후 |
| --- | ---: | ---: | ---: |
| 새200 | 23→23 | 177→177 | 54→54 |
| 기존170 | 17→17 | 153→153 | 52→52 |

새200의 전체 건수/상위5ID는 모두 동일하다. 기존170은 전체 건수 동일, ‘마을 축제’·‘독도’2문장의 상위 순위가 보충 키워드에 따라 바뀌었다. 마을/축제의 실제 본문 키워드와 독도 회차/캠페인의 직접 키워드가 순위에 반영되는 것을 대조했다. 새로0건이 된 요청은0개다. 응답 자료/판본196개의 인용1,833개는 원문 범위와 일치했다. 결과 있음은 관련성 정답률이 아니다.

실행 중 `semantic-layer.sqlite`만 계획한 키워드 재생성으로 변경됐다. 이 파생SQLite는 교사 검색이 읽는 원천이 아니며 실제 경로는 `getSemanticIndex(catalog)`로 메모리 키워드를 계산한다. 따라서 원본/승인/임베딩4저장소와 서버JS 불변을 별도로 단언하고, 파생DB 변경은 비교 JSON에 그대로 남겼다. ‘모든 저장소 변경0’으로 표시하지 않는다. 파생 색인 자체는 별도 전체30,201행/무결성/인용 검사를 통과했다.
