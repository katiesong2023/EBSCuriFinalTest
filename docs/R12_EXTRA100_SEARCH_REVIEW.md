2026-10-14. **첨부100개를 현재 Curi 검색에 실행했다.98개는 빈 결과,2개에서 후보가 반환됐다. 반환 상위5 총7쌍을 모두 원문 검토했다.** AI 작성 교사 대리 사례이며 실제 교사 요청·독립 사람 판단·영상 검토는 아니다.

## 입력·실행·평가 범위

첨부 원본을 바이트 그대로 [원본](r12-extra100-input-original.json)에 보존하고, 기존 Q001 등의 ID 충돌을 막기 위해 [추가 개발 입력](r12-extra100-input.json)에 X100-Q001~Q100을 부여했다.100개는 내부 동일문장0·기존 개발70/이전152와 정확한 문장 중복0이다. 과정/교과17/17/17/17/16/16·10유형 분포와 출처는 [입력 검산](r12-extra100-validation.json)에 기록했다. 모두 AI_AUTHORED_TEACHER_PROXY·사람미검토·알려진정답없음이다. 기대 해석/빈결과 설명은 입력 작성자의 가설이며 정답이나 원인 증명으로 사용하지 않았다.

로컬3000의 교사 검색API에 원래 query만 넣었다. 입력에 있는 기대해석/학년·과목·수업 목표를 API 조건으로 주입하지 않았고 별도 성취기준을 추가하지 않았다. 실제 경로는 LOCAL_ONLY/NO_INTERPRETATION_SUPPLIED이며 유료API0이다. 최대3페이지의 상위20과 첫 응답,코드/저장소 지문을 [실행 원본](r12-extra100-search-results.json)에 보존했다.

## 반복 원인과 새로 확인한 문제

- 제외11개 모두 문맥 범위가 어긋났다. X100-Q006은 시장·마트 비교 대신 `거`,Q014/Q032는 `건`,Q066은 `장면`,Q080은 `내용`,Q081은 `설명`,Q097은 `위주`만 제외한다. Q031/Q048/Q049/Q096은 제외목록이 비어 있고 피해/전투/홍보/사냥 표현이 양의 검색어에 남았다. 실제 영상의 조건 위반은 후보0으로 판정 불가다.
- 선호8개가 분리되지 않았다. Q050의 가능하면 다큐가 필수장르,Q082의 외국 사례 선호가 필수해외범위로 바뀌었다. Q015/Q033/Q038/Q067/Q087/Q098의 선택적 요구와 요청 문법도 검색어에 남았다.
- Q020/Q054의 실험 전 설명·도입은 실험·시연 필수장르,Q055/Q070의 교실 토론 자료는 대담·인터뷰 필수장르로 오해했다.
- OR Q013/Q029/Q078/Q094의 하나이상/둘중하나를 대안그룹으로 표현하지 않았다. 대조용 Q051의 차별이나인권 OR는 표현되므로 모든 OR를 미지원으로 뭉뚱그리지 않는다. AND/비교/과정의 실제 충족은 해당 후보0으로 보류한다.
- 전자석을 일반 자석 별칭으로 축소하고,Q057 지구의 허파를 호흡기관으로 해석했다. Q049의1960~70년대는 고등학교19학년 경고가 되는 새로운 파싱 오류다. 단독 원인의 기여는 추가 분리 실행이 필요하다.
- Q017 우리지역/Q034 아까본거/Q100 저항에는 확인 질문이 없고,Q084의 실사필수+그림만 충돌도 표시하지 않는다. Q068의 특정 장면 시점 요청을 구조화하거나 시간정보 미확인으로 안내하지 않는다. Q099 가상행성 설정 영상은 존재할 수도 있어0건을 오류/정당한없음으로 단정하지 않는다.

표·글쓰기·관찰과제·가능하면·있어야해요 등이 양의 검색어로 남는 관찰은 기존70의 공통 실패와 이어진다. 다만 이 잔류만으로98빈 결과 전체의 원인을 확정하지 않는다.

## R12-02·03 실행 우선순위

1. **R12-03 P0: 조건·수업 목적 해석.** 제외 범위,선호/필수,교실 토론·실험과 영상형식,시대/학년을 분리한다.
2. **R12-03 P0: 정확한 개념·관계 발견.** 전자석/자석,비유와 실제개념,OR/AND를 보존하고 일상 표현/활동 문법을 분리해 기존원문을 찾는다. 후보를 늘리면서 원래 조건을 제거하지 않는다.
3. **R12-02 P0: 공통 원천 공백.** 사회 공공기관·교통통신/풍속·역사/제도,과학 상태변화/열·전자석/회로·암석/실험을 공식 경로 단위로 조사한다. 기존 최대200(사회100/과학100) 범위에서 경로당10회차를 먼저 대조하고 상세/공개대본/학습자료 및 신규 경로의 효과를 보고 확장한다.
4. **R12-03 P1: 근거와 남은 확인.** 제목 복제를 내용확인으로 보여주지 않고 모호함/충돌·자막 언어·길이/장면 시점 미확인을 안내한다.

[우선순위의 증거·기대 동작·검증 기준](r12-extra100-improvement-priorities.json)을 task에 연결했다. 이후 동일 개발 입력/버전으로 기존자료+기존검색,보강자료+기존검색,기존자료+개선검색,보강자료+개선검색을 비교한다. 이번은 테스트·진단이며 제품 검색/데이터/개인 기록은 수정하지 않았고 신규 원천자료 수집도 수행하지 않았다.

## 최종 평가의 독립성과 버전

기존 최종30의 내용 파일을 열거나 실행하지 않았다. 그러나 이전 분할명세의 최종 주제군(문화유산·소리·무역·천문·인구이동·암석)을 추가100에도 포함한다. 따라서 기존30을 그대로 쓸 때 주제단위 독립성을 주장할 수 없다. 원본은 보존하되 새 미노출 주제군의 평가를 준비하거나 같은주제 다른표현 일반화 평가임을 표시해야 한다. 실제 교사 요청24/개발12·새평가12 확보와 효용 확인은 여전히 미완료다.

100개 실행 중 코드/저장소 지문 변경0개. 보고서 작성 시점의 추가 변경6개는 [버전 대조](r12-extra100-version-check.json)에 기록했다. 기존70과 추가100은 각자의 실행 버전/입력으로 보존한다.

보고서 작성 중 다른 작업의 서버 코드6개 변경을 감지했다. 원천/색인/승인 저장 지문은 유지됐다. [대표8요청 재대조](r12-extra100-postcheck.json)에서 결과 수·첫 페이지 후보ID·요청 해석이 모두 동일했다.전체100을 변경 후 재실행한 결과라고 표시하지 않는다.
