# 검색 시나리오 ③ — 생물의 관계 살펴보기: 습지와 기생

작성일: 2026-10-16

수업 주제로 자료를 검색하고, 서로 다른 프로그램의 두 회차를 비교한 뒤 교육과정을 연결해 같은 수업 폴더에 담는 시나리오다. **〈습지 생명을 품다〉와 〈기생 1부 - 보이지 않는 손〉을 선택한다.**

## 1. 검색·저장 설정

| 항목 | 입력·선택 내용 |
| --- | --- |
| 검색어 | **생태계의 다양한 생물 관계를 보여주는 다큐** |
| 검색 방법 | 검색어 입력 → **자료 찾기** |
| 확인된 결과 | **8건** — 기생 보강 후 국소 검사 시점의 표시 건수 |
| 자료 선택 | 아래 두 회차를 각각 가져가기 |
| 수업 폴더명 | **생물의 먹이 관계** |
| 교과·과정 | **과학 · 초등 3~4학년군** |
| 연결 기준 | **[과학]4과14-02** |
| 기준 원문 | 생물 요소들의 먹고 먹히는 관계를 조사하여 먹이그물로 표현할 수 있다. |

건수는 이번 검색에서 원문 조건을 확인한 후보 범위이며, 전체 EBS 콘텐츠의 일치 총수를 뜻하지 않는다. 폴더명과 아래 수업 내용은 입력 제안이며, 개인 폴더 저장은 아직 수행하지 않았다.

## 2. 선택할 회차 2개

| 구분 | 첫 번째 자료 | 두 번째 자료 |
| --- | --- | --- |
| 프로그램 | **하나뿐인 지구** | **EBS 다큐프라임** |
| 회차명 | **습지 생명을 품다** | **기생 1부 - 보이지 않는 손** |
| 방송일 표기 | 2015-11-06 | 2013-07-22 |
| 선택 이유 | 습지에 사는 여러 생물과 먹고 먹히는 관계를 살펴볼 수 있다. | 숙주를 옮기는 기생충과 숙주·천적 사이의 관계를 살펴볼 수 있다. |
| 확인한 내용 근거 | 공식 보조 설명에 곤충들의 먹이 관계, 개구리의 포식자 회피, 수생식물의 역할이 제시되어 있다. | 공식 회차 소개에 연가시와 숙주 곤충, 기생충·개구리·새 사이의 관계가 제시되어 있다. |
| 교육과정 선택 | 해당 기준이 자동 후보에 없으므로 **전체 기준 보기에서 직접 선택** | **자료 관련 후보**에 해당 기준이 나타나는 것을 확인함. 없으면 전체 기준 보기에서 선택 |

방송 페이지:

- [하나뿐인 지구 — 습지 생명을 품다](https://docuprime.ebs.co.kr/docuprime/vodReplayView?siteCd=DP&courseId=BP0PAPF0000000022&stepId=01BP0PAPF0000000022&lectId=10402430)
- [EBS 다큐프라임 — 기생 1부 - 보이지 않는 손](https://docuprime.ebs.co.kr/docuprime/vodReplayView?siteCd=DP&courseId=BP0PAPB0000000005&stepId=60055952&lectId=10136540)

**기생 관계와 포식 관계는 구분해서 설명한다.** 기생을 다루는 영상 전체가 먹이그물 성취기준을 충족한다고 표현하지 않는다. 〈기생〉은 생물 사이의 관계를 비교하는 확장 자료로 사용하고, 실제 먹이 관계가 드러나는 부분을 보고 활동을 설계한다.

## 3. 화면에서 진행할 순서

1. 자료 검색 화면에서 위 검색어를 그대로 입력하고 **자료 찾기**를 누른다.
2. 결과가 나타난 뒤 프로그램명과 회차명을 확인한다. 검사 시점에는 8건이었으며, 촬영 전 현재 화면의 건수를 다시 확인한다.
3. 〈습지 생명을 품다〉의 내용 안내와 공식 보조 설명에서 생물 관계를 확인한다.
4. 이 자료의 **내 수업으로 가져가기**를 누른다.
5. **전체 기준 보기**에서 교과 **과학**, 과정 **초등 3~4학년군**을 선택하고 **4과14-02**를 찾는다. 공식 문장을 읽고 **[과학]4과14-02**를 선택한다.
6. **선택 완료**를 누르고 새 수업 폴더 이름에 **생물의 먹이 관계**를 입력한 뒤 **가져가기**를 누른다.
7. **자료 더 찾기**로 검색 결과에 돌아와 〈기생 1부 - 보이지 않는 손〉을 찾는다. 제목이 비슷한 〈생명의 전략, 기생〉과 구분한다.
8. 해당 회차의 공식 소개에서 숙주·기생충·천적의 관계를 확인하고 **내 수업으로 가져가기**를 누른다.
9. **자료 관련 후보**에서 **[과학]4과14-02**를 확인해 선택한다. 표시되지 않으면 **전체 기준 보기**에서 같은 기준을 직접 찾는다.
10. **선택 완료**를 누른 뒤, 새 폴더를 만들지 않고 앞서 만든 **생물의 먹이 관계** 폴더를 선택하여 **가져가기**를 누른다.
11. **내 수업으로 이동**하여 서로 다른 프로그램의 두 회차와 연결한 교육과정이 같은 폴더에 있는지 확인한다.

## 4. 수업 목표와 활용 내용 입력 예시

### 수업 목표

> 영상에 등장하는 생물을 찾아 먹고 먹히는 관계를 정리하고, 연결된 관계를 먹이그물로 표현한다. 기생 관계와 포식 관계가 어떻게 다른지도 비교한다.

앞 문장은 성취기준과 연결한 목표이고, 기생 관계 비교는 추가 탐구 목표다.

### 자료별 활용 메모

| 자료 | 입력할 메모 예시 |
| --- | --- |
| 습지 생명을 품다 | 습지의 생물들을 찾아 먹이 관계를 화살표로 정리한다. 생물과 비생물 환경의 관계도 함께 살펴본다. |
| 기생 1부 - 보이지 않는 손 | 기생충·숙주·천적을 구분한다. 개구리와 새의 먹이 관계를 살펴보고 기생 관계와 포식 관계의 차이를 비교한다. |

### 학생에게 제시할 질문

- 영상에는 어떤 생물들이 등장하나요?
- 누가 무엇을 먹나요? 화살표로 연결해 볼까요?
- 기생충과 숙주의 관계는 포식자와 먹이의 관계와 어떻게 다른가요?
- 한 생물의 변화가 다른 생물에게 어떤 영향을 줄 수 있을까요?

## 5. 시연 설명 문안

> 생물 사이의 관계를 다룬 자료를 검색합니다. 습지 생태계를 다룬 ‘하나뿐인 지구’와 숙주·기생충의 관계를 다룬 ‘다큐프라임’을 고릅니다. 각 자료의 원문을 확인하고, 수업에 연결할 교육과정을 선택합니다. 두 자료를 같은 수업 폴더에 담아 비교 활동을 준비합니다.

## 6. 실행 전 확인할 내용

- [ ] 두 회차가 현재 검색 결과에 표시되는지 확인한다.
- [ ] 교육과정 선택에서 **[과학]4과14-02**의 원문을 확인한다.
- [ ] 두 자료가 같은 **생물의 먹이 관계** 폴더에 담겼는지 확인한다.
- [ ] **방송 보기**로 각 회차를 열고 실제 재생·시청 조건을 확인한다.
- [ ] 실제 영상을 보고 사용할 구간을 정한다. 기생·포식 장면의 표현 수준을 확인한 뒤 학생에게 보여줄 부분을 선택한다.
- [ ] 구간 시작·종료 시각과 이름은 영상을 확인한 뒤 기록한다. 현재 확인하지 않은 타임코드는 사용하지 않는다.

검색 결과와 공식 텍스트 근거는 확인했지만, 이번 작업에서 실제 본편 재생·구간 시각·학년 적합성을 확인한 것은 아니다. 교육과정 연결은 교사의 개인 수업 연결이며 기준 전체 충족이나 사람 검수 승인을 뜻하지 않는다. **사용자 요청에 따라 370개 전체 테스트는 실행하지 않았다.**
