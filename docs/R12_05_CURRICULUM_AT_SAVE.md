# R12-05 교육과정 연결을 가져가기·폴더로 이동

**후속 화면 통합:** 내 자료와 수업 폴더의 최신 전체/폴더 보기는 [내 수업 자료 통합](R12_05_UNIFIED_LIBRARY.md)을 따른다.

**후속 변경:** 가져가기 버튼과 폴더 지정이 하나의 동선으로 통합됐다. 최신 사용법/검증은 [통합 가져가기](R12_05_UNIFIED_BRING.md)를 따른다. 아래는 교육과정 이동 당시 기록이다.

2026-10-14 사용자 요청을 적용했다. 검색은 주제/질문으로 자료를 탐색하고, 교육과정은 자료를 내 수업 자료로 가져갈 때 또는 수업 폴더에서 연결한다. 과거 CG-01~04의 교육과정 검색 선택·목표 적용 동선은 이번 사용자 요청으로 대체한다.

## 실제 동선

1. 자료 카드의 **내 수업 자료로 가져가기**를 누른다. 자료의 제목·소개문 표현을 이용한 관련 기준 후보를 먼저 볼 수 있고 **전체 기준 보기**·교과·과정·기준 문장/코드 찾기로 직접 선택할 수도 있다.
2. 체크박스로 교육과정을 여러 개 선택한 뒤 **선택한 기준과 가져가기**를 누른다. 기준을 선택하지 않아도 저장할 수 있다. 이미 담긴 자료는 **교육과정 연결 추가**로 기존 기준·메모·개인 확인 기록을 유지하면서 새 기준을 추가한다. 취소하면 저장하지 않는다.
3. **수업 폴더에 담기**에서도 교육과정을 여러 개 선택해 자료를 담을 수 있다. **만들고 담기**로 새 폴더를 만들 때 선택한 기준은 새 폴더에도 연결된다.
4. **내 수업 폴더**의 새 수업 이름 아래 **교육과정 연결 · 선택 사항**을 열어 여러 기준을 고르고 폴더를 만든다. 기존 폴더에서는 **연결한 교육과정**에서 추가·해제할 수 있다. 폴더 기준은 자료별 기존 연결에 자동 적용하지 않는다.

교육과정 연결은 선택 사항이다. 공식214기준을 탐색하며 한 자료의 기존 선택 이유 포함20개, 폴더 교육과정20개 제한을 표시한다. 여러 교과/과정도 함께 고를 수 있다. 관련 후보는 표현 기반 추천이며 기준 충족·영상 적합성의 확인 기록으로 저장하지 않는다.

## 검색과 기존 기록

교사 검색 화면에서 교육과정 선택·수업 목표 검색·기준 연계 상태 필터를 제거/비노출 처리했다. 이전 주소/저장 검색의 standard·state·curriculum·lessonGoal·usePurpose·goalRequirements 조건은 교사 화면에서 적용하지 않는다. 기존 서버의 기준 검색 API/관리자 기능은 보존한다. 자료의 개인 선택 이유에 남긴 기준과 목표는 삭제하지 않는다.

기존 개인 자료/폴더 저장 키를 그대로 사용한다. 자료 다중 연결은 기존 selectionContexts에 기준별 선택 이유로 추가하고, 폴더는 curriculumStandards에 기준 ID·공식 문장·교과·과정·학년군·판본을 저장한다. 기존 ID/기준/목표/메모/장면 확인 시점·구간 기록과 승인 경로는 보존한다. 폴더 교육과정은 폴더 목록 내보내기와 저장한 자료 찾기에도 포함한다.

## 검증

- 격리된390px 브라우저에서 검색의 기준 조건 비적용, 선택 취소, 다중 가져가기, 기존 기준/목표/장면 메모 보존, 재열기, 미선택 가져가기, 직접 폴더 만들고 담기, 폴더 생성/다중 변경·자료 연결 독립 보존의8개 동선 통과.
- 교육과정 조회503과 브라우저 저장 실패를 재현한2개 검증 통과. 미선택 저장·선택 유지·재시도가 가능하며 가져가기 버튼이 모바일 화면 안에 표시된다.
- 브라우저 오류0·가로 넘침0·관련 JS 구문 확인. 실제 사용자 브라우저에 쓰지 않고 별도 테스트 프로필을 사용했다.
- 원천/시맨틱/자산/검색/승인 관련5저장소 SHA 동일. 검색 서버 규칙·원문 수집·유료 API 변경0. 이번 기능은 개인 연결이며 실제 교사 선택 효용은 아직 미측정이다.
