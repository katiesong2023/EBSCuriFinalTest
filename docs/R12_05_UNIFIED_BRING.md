# R12-05 가져가기 버튼·폴더 지정 통합

**2026-10-15 최신 동선:** 교육과정을 여러 개 고른 뒤 “선택 완료”(미선택은 “선택 안 함”)를 눌러 폴더 선택으로 이동한다. 체크 즉시 이동하지 않는다. 상단의 관련 후보 보기/전체 기준 보기를 전환하며, 전체 기준 보기에서 교과·과정·기준 찾기 필터를 제공한다. [최신 반영·검증](../Tasks/task-r12-31-curriculum-multiselect.md). 아래는 통합 당시 기록이다.

**후속 화면 통합:** 내 자료와 수업 폴더의 최신 전체/폴더 보기는 [내 수업 자료 통합](R12_05_UNIFIED_LIBRARY.md)을 따른다.

2026-10-14 사용자 요청으로 자료 카드의 내 자료/수업 폴더 가져가기 버튼을 **가져가기** 하나로 합쳤다. 이전 두 저장 경로의 선택 화면을 대체한다.

## 사용 동선

1. 자료 카드의 **가져가기**를 누른다.
2. **가져갈 수업 폴더**에서 기존 폴더를 선택하거나 **새 수업 폴더 만들기**를 고르고 이름을 입력한다. 현재 폴더가 있으면 먼저 선택되어 있고, 폴더가 없으면 새 폴더 입력을 보여준다.
3. 필요하면 **교육과정 연결 · 선택 사항 · 다중 선택**을 펼쳐 여러 기준을 고른다. 선택 없이 가져갈 수도 있다.
4. 마지막 **가져가기**를 누르면 지정한 폴더에 저장된다. 취소하거나 폴더만 선택한 상태에서는 기록을 바꾸지 않는다. 성공하면 화면을 닫고 저장한 폴더 이름을 안내한다.

기존 폴더의 기준/메모/자료별 선택 이유를 보존하고 선택한 기준은 자료에 추가한다. 새 폴더는 이번 선택 기준을 폴더에도 연결한다. 폴더 기준과 자료 기준의 독립성은 유지한다. 같은 자료를 같은 폴더로 다시 가져가도 자료나 빈 선택 이유를 중복 생성하지 않는다.

새 자료는 지정한 폴더에 저장한다. 기존 ‘내 자료’ 모음은 그대로 유지하며 같은 자료를 별도 모음에 중복 저장하지 않는다. 기존 모음에서 수업 폴더로 가져오는 동선도 유지한다. 실제 영상/구간 저장과 서버 승인·검색은 바꾸지 않는다.

## 구현·검증

`teacher-folder-picker.js`가 단일 진입·기존/새 폴더 선택·명시적 저장을 담당한다. `discover.js`는 이전 내 자료 저장 대화상자/이벤트를 사용하지 않고 카드에는 가져가기 버튼 하나만 표시한다. `teacher-save-picker.js`는 최신 검색 화면에서 로드하지 않는다. 저장 시 폴더 목록 복사본에서 변경을 준비하고 성공 시에만 합쳐 실패한 새 폴더가 다른 저장에 끼어들지 않게 했다.

390px 격리 브라우저에서 단일 버튼, 취소/원본 보존, 기존 폴더와 다중 기준/메모 보존, 반복 가져가기 중복 방지, 새 폴더 이름·미선택 저장, 저장 실패 입력 유지/재시도, 폴더 재열기/기존 내 자료 모음 보존의7검증을 통과했다. 브라우저 오류/가로 넘침0·가져가기 버튼 화면 내 접근 확인·JS 구문 통과. 실제 교사 효용은 미측정이다.
