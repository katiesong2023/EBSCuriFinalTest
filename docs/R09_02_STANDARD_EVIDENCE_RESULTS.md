# R09-02 선택 기준 근거·독립 품질 비교 결과

2026-10-11 에이전트 기술 평가를 마쳤다. 개발 전에 고정한 실제 자료×성취기준 33관계에서 검사 미지원이 ‘관계 설명 부족’으로 표시된 경우는 8/10에서 0/9로 줄었다. 확인된 관련 자료 3관계 중 1관계는 여전히 후보에서 빠졌다. 실제 교사 응답은 0건이며 교사 평가·영상 시청·수업 효과 검증은 수행하지 않았다. 최종 평가 결과를 본 뒤 제품 규칙이나 표본을 조정하지 않았다. 사용자 결과 확인은 대기 중이다.

## 비교 조건

- 변경 전 제품 코드·공식 기준 214개·판본 포함 자료 23,360건·관계 이력을 압축 보존했다. 기존 개발 사례 513개와 같은 판본·정규화 원문이 겹치는 자료를 제외한 뒤 33관계를 고정했다. 결과 밖 자료도 별도 어휘 탐색으로 포함했다.
- 원문 판단은 독립 평가 담당 에이전트가 고정 소개문을 읽고 기록했다. 제품 담당은 평가 종료 전 ID·판단·개별 결과·집계를 읽지 않았으며, 원문 보강에는 SHA-256 제외 목록만 사용했다.
- 변경 전, R08-08 직후 같은 원문, 최종 코드의 같은 원문, 최종 코드의 보강 원문을 구분했다. 최종 두 실행은 정확히 같은 코드 스냅샷을 사용했다. 보강 입력에는 당시 고정 관계 이력을 주입하여 운영 자동 자산 재검사 효과를 섞지 않았다.
- 최종 평가 전후 운영 DB 해시는 같았다. 독립 표본 33관계의 원문은 모두 그대로였고 보조문서 연결도 없었다. 저장된 최종 코드·보강 입력으로 다시 실행한 요약과 개별 결과가 완전히 일치했다. [무결성 기록](r09-02-final-integrity.json), [준비·판독·재현 규칙](r09-02-independent-protocol.md)

## 남은 누락과 검증의 한계

중1 과학의 열전달 기준에서 소개문에 ‘초콜릿 열전도율 실험’이라는 소재가 있는 독립 표본은 전후 모두 후보에서 빠졌다. 실험 소재를 찾는 데 유용할 수 있지만 절차·결과·전도 원리·다른 전달 방식의 설명은 소개문에서 확인하지 못했다. 이 사례는 누락으로 남기며 이번 결과에 맞춰 검색 규칙을 조정하지 않았다. 다음 개발에 사용한다면 개발용으로 전환하고 새로운 독립 자료로 다시 비교해야 한다.

이 표본에는 상위에 노출된 사람·자동 확인 배지 사례, 자동 요구 충족 사례, 명시적 부정 문맥 사례가 없다. 따라서 연계 오류 0건은 배지 전파·요구별 인용·부정 대상 처리의 일반적 정확도나 개선 폭을 입증하지 않는다. 해당 경계는 별도 개발 회귀로 확인했다. [선택 기준 검사 7건](r08-07-standard-evidence-check.json), [관계·순위 검사 13건](r08-08-relation-ranking-check.json)은 합성·기존 개발 사례이며 독립 평가 점수에 합치지 않았다.

표본은 무작위 모집단 표본이 아니며 확인된 관련 자료도 3관계뿐이다. 전체 카탈로그의 정밀도·재현율·교육적 정확도, 교사의 선택 만족도, 실제 수업 효과는 미확인이다. 소개문 최소 기준 통과와 성취기준의 의미 충족도 별개다.

## 실행 비용 지시 보완

2026-10-11 전달된 사용량 재점검 기록은 재개 당시 부모 Sol Medium과 기존 자식3개의 Astra Ultra 실행을 구분했다. 부모 설정 변경이 기존 자식에 적용됐다고 가정한 재사용은 절감 지시를 충족하지 못했다. 후속 상태 조회에서 세 자식은 모두 완료였으며 실행 중인 자식은 없었다. 완료된 자식을 다시 호출하지 않고 새 위임·제품 변경·회귀 재실행 없이 정리를 마쳤다. 현재 상태 조회 도구는 모델·추론 설정을 제공하지 않으므로 이 후속 확인에서 실제 런타임 설정을 독립적으로 재확인하지는 못했다. 기존 평가·검사 산출물과 사용자 확인 대기 상태를 보존한다.
