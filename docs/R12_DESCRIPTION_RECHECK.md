같은 ID라도 제목이 다르거나 출처가 다른 응답은 보류한다. 제목의 자막 등 제공 방식 접두사와 HTML 줄바꿈만 대조에 허용한다. 별도 보충은 원래 제목·소개·주소 지문이 변경되면 자동 적용되지 않는다. 검색과 저장 자료의 재조회도 보충/발췌 정보를 유지한다. 기존 주소의 연결 확인 상태는 표준 주소의 소개 확인만으로 갱신하지 않았다.
