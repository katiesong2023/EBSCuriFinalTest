# R12-03 공통 요청 해석 개선과 개발170 전후 비교

2026-10-14. **제외·선호·수업 목적·세부 개념을 공통 규칙으로 개선하고 실제 Curi에 반영했다. 동일 개발170의 빈 결과는163→160,원문 주제 근거가 있는 후보는6→11로 변했다. 자료 선택 개선은 아직 제한적이다.** 영상 조건 준수나 실제 교사 효용을 확인한 결과는 아니다.

## 적용한 공통 원인 개선

- **제외 범위:** 조건을 장르·지역·개념 해석보다 먼저 분리한다. 단어 끝의 장면/내용/것만 떼던18요청에서 수식어와 대안을 포함한 제외 범위를 보존했다. 짧은 단일어·복합어·따옴표·프로그램/형식 제외는 기존 경로를 유지한다. 원문에 제외 구절이 확인되면 차단하고, 그렇지 않으면 실제 영상의 부재를 UNKNOWN으로 남긴다.
- **선호:** 가능하면/있으면좋겠고/나오면좋겠어요11요청을 별도 선호로 보존했다. 다큐 선호를 필수 장르로,외국 선호를 필수 지역으로 바꾸지 않는다. 뒤의 반드시/꼭이 쉼표로 연결된 필수 내용은 유지한다. 원문 형식 근거가 있는 장르 선호는 기존 관련순 가점을 사용하며,내용 선호의 범용 의미 충족·가점은 미구현이다.
- **수업 목적:** 교실 토론 시작/실험 전/도입/활동 문맥을 영상의 전달 형식과 분리했다. 확인한5요청의 대담·인터뷰/실험·시연 강제 조건을 제거했다. 직접 실험을 보여 달라는 형식 요청은 유지한다.
- **세부 개념:** 검색용 개념 묶음의 별칭을 모두 동의어로 취급하지 않는다. 전자석/자기장,중력/마찰력/부력,저출산/고령화 등 요청에 명시된 소재를 원문에서 다시 대조한다. 저출산/저출생 같은 명시 동의 표현은 보존한다. 신체 비유는 실제 기관으로 자동 대체하지 않고 확인 안내를 남긴다.
- **문법·표시:** 명확한 요청 동사/자료요/필요해요를 내용 검색어와 분리하고,일부 명시 OR를 미등록 선택지에서도 보존한다. 시대 숫자를 학교급/학년으로 읽던 경계를 수정했다. 기존 해석 영역에 선호 내용(필수 아님)과 교실 활용 목적을 표시하고 후보 원문에 제외 미확인을 연결했다.

질문ID/정답ID/상위 후보ID를 제품 규칙에 넣지 않았다. 구현은 문장 범위·긍정/제외·선호·교실 활용·개념 묶음 경계를 다룬다. 개발170과 다른 표현의 가상 원문19계약으로 필수 조건 보존·부정/선호·세부 개념·미지 고유명 회귀를 확인했다. 한국어 전반의 의미 해석이나 수업 적합성을 완료한 것은 아니다.

## 원문에서 확인한 개선과 잔여 실패

- 먹이관계: 수산자원 자료에 해조류 소멸→물고기 먹이/서식처 감소,밀리미터의세상에 플랑크톤→물고기의 직접 관계가 있다. 단문 미세플라스틱/플라스틱 피해 사례는 부분 관련이다. 대리석 무역의경제적 먹이사슬 비유가 여전히 끼어든다.
- 다문화: 공존과 권리/다문화 초등 교실/이주민2세대의 사회 현안을 다루는3원문 후보가 발견됐다. 희화화·고정관념 장면의 부재는 확인하지 않았다. 짧은 이주민 방송 단서는부분,더빙 강의 제목은원문 부족이다.
- 동물한살이: 실사 선호를 필수로 하지 않아 제목이 일치하는 클립을 찾았으나 소개문이 없다. 내용 확인은R12-02의원문 확보 대상이다.
- 지역브랜드: 기존 문법어 처리에서지역이 제거되면서 기업 브랜드/팬덤/패션/가구 오탐과 국가브랜드 부분 후보가 반환된다. 이번 선호 분리로 새로 드러난 오탐이며 효용 개선에 포함하지 않는다.

**다음 우선순위는 요청의 수식어·지역/대상·관계 보존과 경제적/신체적 비유의 문맥 대조다.** 전체 구절의 문자 일치만으로 의미적 제외를 해결하지 못한다. 160빈 결과 중 기존 원문을 놓치는 일상 표현/관계·비교와 공식 원문 공백을 구분한다. 공식 자료는R12-02의 경로당10·사회/과학각최대100이라는 공통 조사 단위로 이어간다. 원문 없음을 설명 생성으로 대체하지 않는다.

이번에는동일자료+기존검색/동일자료+개선검색의2조건을 비교했다. 원천 보강은 미실행이므로 보강자료+기존검색/보강자료+개선검색의2조건은R12-02후 남아 있다. 데이터 효과로 검색 개선을 설명하지 않는다.

## 새 최종 평가30

[최종30 v2](r12-03-proxy-final30-v2.json)·[주제군/지문 명세](r12-03-proxy-final30-v2-manifest.json)를 별도로 저장했다. 금융·은행,감염예방,저작권,측정/오차,사회조사/표본,형질유전의6새주제군을 전체 배정했고 과정×사회/과학각5개다. 개발170/기존152와 정확한 문장 및 확인한 주제 핵심어 중복이 없다. 의미 주제군 분리는 에이전트 검토이며 큰 교과 분야/개념까지 전혀 겹치지 않는다는 주장이나 독립 사람 판단은 아니다.

기존 최종30은 내용 미열람/미실행·원본 보존이며 주제중첩으로 주제단위 최종평가에서는v2로 교체한다. 새30도 검색하지 않았고 제품 규칙 개발에 쓰지 않았다. 생성 담당 에이전트는 내용을 보았으므로 완전한 블라인드/실제 교사 평가가 아니다. 변경 동결 후 평가할 때만 실행하고 그 결과로 수정하면 개발용으로 전환한다. 실제 교사24요청/독립 평가·수업 선택 효용은 별도로 미완료다.
