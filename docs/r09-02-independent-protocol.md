# R09-02 독립 비교 준비와 재현 규칙

2026-10-11 제품 변경 전에 공식 기준214개·판본 포함 자료23,360건과 제품 코드를 고정했다. 실제 자료×기준33관계를 여섯 과정·교과 구간에서 선택했다. 초등5~6 과학은 기존 개발 자료·같은 판본·근접 원문을 제외한 뒤 선정 규칙에 해당한 자료가3건이며, 나머지 구간은 각각6건이다. 표본 수를 맞추려고 개발 자료를 되넣거나 결과를 보고 교체하지 않는다.

## 개발과 평가의 분리

- 제품 개발·보강 담당은 `r09-02-preparation.json`과 `r09-02-exclusions.json`의 준비 상태·제외 해시만 사용한다. 제외 해시는 UTF-8 원본 ID의 SHA-256이며 같은 회차 판본·근접 원문도 포함한다.
- `r09-02-holdout.json.gz`, `r09-02-independent-labels.json.gz`, `r09-02-*-details.json.gz`의 ID·판단·개별 결과는 독립 평가 담당만 최종 평가 전 읽는다. 전체 검색 기준선도 구현 튜닝의 정답으로 사용하지 않는다.
- 기존 검증·보고 문서의 실자료 ID513개와 같은 판본 묶음, 정규화 원문의80자 겹침을 제외했다. 원문 겹침 검사는40자 간격이며 모든 의미적 유사성을 보장하지는 않는다.
- 순위의 상위 후보 외에 별도 어휘 탐색으로 결과 밖 자료를 선정했다. 이 단계는 관련 정답을 고르는 절차가 아니며, 관련 여부는 고정 이후 소개문을 읽어 별도로 기록했다. 같은 원문에서의 변형 요청은 추가 표본으로 세지 않는다.

## 판독과 지표

판단 주체는 에이전트다. 교사 응답·영상 시청·새 공식 페이지 대조는 수행하지 않았다. 공개 소개문이 제공하는 내용 또는 실험 소재가 선택 요구의 제한된 일부를 뒷받침할 때만 `PARTIAL_CONTENT`로 기록한다. 수업 주제만 선언한 `PURPOSE_ONLY`는 별도 집계하며 확인된 관련 자료의 분모에서 제외한다. 개념 언급, 다른 내용의 소개문, 원문 부족도 구분한다. 모든 직접 인용은 고정 원문의 정확한 위치와 대조한다.

상위 결과 관찰 범위는9개다. 잘못된 확인 노출은 독립 표본 중 실제 상위에 노출된 관계 수를 분모로 삼으며 전체 검색 정밀도라고 부르지 않는다. 확인된 관련 자료의 후보 미회수와 회수 후 상위9개 밖 배치를 따로 센다. 분모가0인 구간은 누락률을 계산하지 않는다. 최소 원문 부족과 해당 요구의 실질적 내용 미확인은 서로 다른 수치다. 자동 비교 미지원은 자료 부적합으로 계산하지 않으며 미지원이 관계 설명 부족으로 표시된 경우도 별도 표시 오류로 센다.

표본은 소량의 의도적 층화 표본이다. 전체 자료의 재현율·교육적 정확도·수업 효과를 추정하지 않는다. 실제 사람의 관계 승인과 교사의 선택적 사용 판단은 이 평가와 별개다. 현재 자동/사람 관계 이력은 검색 변경 효과를 분리하기 위해 고정한 읽기 사본을 사용하며, 운영 DB의 자동 투영 무효화나 승인 생성은 수행하지 않는다.

## 고정 파일과 재현

| 파일 | 역할 |
| --- | --- |
| `r09-02-capture.json` | 원본 DB·저장 JSON과 제품 코드의 해시, 코드·입력 스냅샷 해시 |
| `r09-02-frozen-code.json.gz` | 변경 전 제품 코드의 UTF-8 원본 |
| `r09-02-frozen-input.json.gz` | 원문·공식 기준·읽기 검증된 당시 관계 이력·카탈로그 |
| `r09-02-baseline-search.json.gz` | 전체214기준의 변경 전 후보·묶음·순위·상태 |
| `r09-02-holdout.json.gz` | 고정한33관계와 선정 경로 |
| `r09-02-label-lock.json` | 고정한 독립 원문 판단의 해시·판단 주체 |
| `r09-02-independent-labels.json.gz` | 요구 경계·판독 이유·정확한 인용 |

변경 전 재현은 아래처럼 새로운 실행명을 지정한다. 임시 디렉터리에 고정 제품 코드를 복원하고 고정 원문을 주입하며 전체214기준 후보·판본·순위가 처음 저장한 결과와 일치하는지 확인한다. 임시 디렉터리는 실행 후 삭제한다.

```sh
CURI_QUALITY_STAGE=user-baseline-replay node server/independent-quality-check.js baseline
```

`same-source`는 지정한 코드와 고정 원문을, `enriched`는 지정한 코드와 보강 후 원문을 비교한다. 코드 스냅샷을 생략하면 실행 당시 코드, 보강 입력 스냅샷을 생략하면 실행 당시 카탈로그를 사용한다. 최종 비교에서는 먼저 고정한 같은 코드로 두 조건을 평가했고 이후 저장된 코드·보강 입력을 재생하여 요약·개별 결과의 정확한 일치를 확인했다. 최종 결과를 재현할 때는 다음 두 명령을 사용한다.

```sh
CURI_QUALITY_STAGE=user-final-replay CURI_QUALITY_CODE_SNAPSHOT=docs/r09-02-final-same-source-code.json.gz node server/independent-quality-check.js same-source
CURI_QUALITY_STAGE=user-final-replay CURI_QUALITY_CODE_SNAPSHOT=docs/r09-02-final-same-source-code.json.gz CURI_QUALITY_INPUT_SNAPSHOT=docs/r09-02-final-enriched-input.json.gz node server/independent-quality-check.js enriched
```

각 실행은 별도 요약 JSON과 압축한 개별 결과를 남긴다. 같은 실행명으로 생성된 출력이 이미 있으면 덮어쓰기를 거절하므로 재실행에는 새 `CURI_QUALITY_STAGE` 값을 사용한다. `baseline`·`stage2`·`final`의 기존 파일을 지우거나 다시 생성하지 않는다. 보강 시 독립 표본의 해시 목록을 제외하므로 원문 보강의 일반적 성공률을 이 표본만으로 주장하지 않는다. 개발용 보강 시도·확보 원문·관계 증가의 전후 지표는 R08-09에서 별도로 기록한다.

현재 코드 평가도 실행 시작 시 모든 제품 코드를 임시 복제본으로 고정해 실행한다. 실행마다 `*-code.json.gz`를 남겨 새 모듈까지 재현할 수 있게 하며, 보강 후 평가에는 실제 입력의 `*-input.json.gz`도 보존한다. R08-08 직후 평가는 `CURI_QUALITY_STAGE=stage2`로 별도 기록했으므로 후속 원문 지원 기능을 포함한 최종 평가와 구분한다.

`independent-quality-capture.js`와 `independent-quality-freeze.js`는 이미 고정 파일이 있으면 덮어쓰기를 거절한다. 구현 후 새 기준선을 만들어 이전 수치를 대체하는 용도로 사용하지 않는다. 네트워크·유료 API·기존 DB 쓰기를 사용하지 않는다.

## 최종 결과와 미확인 범위 — 2026-10-11

[최종 보고서](R09_02_STANDARD_EVIDENCE_RESULTS.md)와 [단계별 비교](r09-02-comparison.json)에 네 지표·구간별 분모를 기록했다. 변경 전 노출 13관계와 최종 노출 12관계에서 잘못된 확인 노출은 각각 0건이었다. 미지원을 관계 설명 부족으로 표시한 경우는 미지원 노출 10관계 중 8건에서 9관계 중 0건으로 줄었다. 관련 자료 3관계의 후보 누락 1건·상위 노출 2건, 최소 원문 부족 16/33, 미지원 24/33은 그대로다. 원문에서 실질 요구 내용을 확인하지 못한 30관계는 개념만 확인·주제 선언·다른 설명·원문 부족을 포함하므로 원문 수집 부족으로 모두 계산하지 않는다.

보강 전후 독립 표본의 원문은 바뀌지 않았고 집계도 같았다. 다른 자료의 보강에 따라 초등 5~6 사회 2관계의 순위가 한 자리씩 밀렸지만 상위 9개 노출은 유지되었다. 최종 코드·입력 스냅샷을 사용한 전체 카탈로그 비교도 [별도 기록](r09-02-final-catalogue-comparison.json)에 남겼으며, 후보 수 증가는 관련 정확도 증가로 해석하지 않는다.

독립 표본에는 자동 요구 충족·확인 배지·명시적 부정의 노출 사례가 없었다. 그 경계는 개발용 기능 회귀로만 검증했으며 독립 일반화 성능은 미확인이다. 초등 5~6 과학의 표본은 3건·노출 0건이고 관련 자료의 전체 분모는 3건뿐이다. 실제 교사 응답 0건·영상 미시청·학교별 편성 및 콘텐츠 난이도 미확인의 한계를 유지한다.

최종 집계 공개 후 제품 규칙·판독·표본을 수정하지 않았다. 남은 누락을 다음 개발에 사용하려면 해당 자료를 개발용으로 전환하고 별도 독립 표본을 새로 고정해야 한다. 현재 운영 사람 승인 0건·자동 공개 1건은 [운영 기록](r08-09-operational-state.json)에서 확인하며, 고정 관계 이력의 평가 수치와 혼합하지 않는다. 사용자 결과 확인은 미완료다.
