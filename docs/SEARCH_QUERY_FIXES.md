# R04 검색 질의 회귀 보강 기록

## 목적과 상태

R03 자연어 탐색의 조건 해석 결함을 수정하기 위한 기준 문서다. 제품 코드와 에이전트 검증은 최신 `.2` 기준으로 통합 완료했지만 사용자 결과 확인 전이므로 이 문서는 완료 보고서가 아니다. 수집 완료 22,753건 스냅샷과 승인 저장소는 작업 대상으로 삼지 않으며, 회귀 비교는 고정 fixture 또는 메모리 카탈로그에서 수행한다. 유료 API는 사용하지 않는다.

독립 검토 자료는 `/private/tmp/curi-independent-review-01a0f279/REVIEW.md`와 `review.js`다. 그 검토는 가상 자료와 코드 복사본을 사용했고, 과거 실행 결과는 16건 중 13건 통과·3건 실패, 네트워크 호출 0회였다. 이 수치는 현재 구현의 완료 결과나 검색 성능 수치가 아니다.

## 결함 기준

| 질의 | 기대 동작 | 독립 검토에서 관측된 결함 | 수정 기준 |
| --- | --- | --- | --- |
| `설악산 또는 김제` | 설악산 또는 김제를 언급하는 후보 반환 | 미등록 개념 경로가 구형 terms로 돌아가 `또는`까지 필수어가 되어 0건 | 개념·원시 표현 모두에서 OR 범위를 보존하고 두 고유명사를 후보 조건으로 전달 |
| `해안 지형 제외하고 우주` | 해안 지형을 제외한 우주 후보 반환 | 제외 구의 마지막 토큰인 `지형`만 인식하거나 제외 전 문장으로 지리 개념을 선택해 0건/재유입 위험 | 부정 구를 먼저 전체 표현으로 분리한 뒤 긍정 주제와 지리 조건을 생성하고 제외 항목을 검색 결과에서 제거 |
| `김제 5분 이내` | 김제 후보 반환과 시간 조건 미지원 안내 | 파서가 제거한 시간 조건 대신 원래 terms를 사용해 `5분`·`이내`가 필수어로 남아 0건 | 미지원 조건은 경고·메타데이터로만 남기고 내용 검색어로 되돌리지 않음 |

## 담당 산출물과 경계

- 주 에이전트: `server/discovery-intent.js`, `server/discovery-search.js` 수정
- Luna query regression tests: `server/query-regression-check.js`, `docs/query-regression-before.json`, `docs/query-regression-after.json` 회귀 산출물
- 이 문서와 [R04 task](../Tasks/task-r04-query-regressions.md): 수정 기준·검증 상태·사람 확인 상태 기록

코드 수정 전후의 fixture는 동일한 자원 ID와 근거 필드를 사용해야 한다. 실제 수집 DB가 변경되는 동안에는 DB 해시 비교를 검색 회귀 통과 근거로 사용하지 않는다. 수집 무결성은 별도 작업으로 기록한다.

## 고정 fixture 전후 결과

`docs/query-regression-before.json`과 `docs/query-regression-after.json`은 같은 고정 fixture(`fixtureHash` 동일)를 사용한 전후 기록이다. 수정 전에는 21건 중 16건 통과·5건 실패였고, 수정 후에는 21건 통과·0건 실패였다. 수정 후 별도 `newCases` 6건도 모두 통과했다. 이 결과는 실제 검색 정확도나 실자료 적합성 평가가 아니다.

수정 후에는 네트워크 호출 0회였고, 승인 저장소 `server/data/curi-store.json`의 전후 SHA-256이 같아 승인 저장소 불변을 확인했다. 기존 semantic 검사 19건도 통과했다.

최종 통합 확인에서는 semantic 19건, R04 21+6건, 교사 기존 8건+추가 조사 2건, HTTP 11건, 기존 브라우저 14건·추가 브라우저 10건이 모두 통과했고 page error는 0건이었다. 추가 브라우저 외부 요청은 0건, 유료 API 호출은 0건이었다. 승인 저장소 SHA-256은 `f207ec...`, 방송 DB SHA-256은 `53451b156ed44afc05995b0ec5ffe74cffa6967268bf95bf221f595da4ccf106`이며 최종 테스트 기간 전후가 같았다. 추가 브라우저 범위에는 세 결함의 실제 HTTP/UI 동작, 사회·과학 문장, 목록 우선·설명 펼치기, 과학 자료 모음·재접속·메모 다운로드, context API, 미보유 빈 결과, 모바일, 서버 오류 시 해석 제거·재시도가 포함된다.

방송 DB는 작업 중 수집·출처 복구·호기심 딱지 MISMATCH 1건 반영으로 변경된 이력이 있으므로, 위 hash 불변은 최종 테스트 기간에만 적용한다. 교사 하네스는 임시 파일 의존을 제거하고 `server/data/quality-catalog-20260930.json.gz`를 기본 입력으로 사용했으며 원문 SHA-256은 `803bb0dd1cfd73d9a890edf4f679a75b4200425bada493643b095f7ccc0101ec`이다. quality 기술 검사 7건도 최신 통과했다. sourceaudit21 과거 `.1` 결과는 최신 독립 평가 수치로 사용하지 않는다.

수정 구현은 제외 구를 가장 긴 등록 개념·지리 별칭·따옴표 구로 먼저 분리하고, 모든 경로에 공통 `positiveQuery`를 적용했다. OR 분기 안에서는 개념·지리·일반어를 AND로 묶고 분기 사이를 OR로 결합하며, 구형 terms fallback을 제거했다. `reason`은 실제 일치 terms만 사용하고 `understanding.groups`로 논리 범위를 반환한다.

## 회귀 검증 매트릭스

아래 항목은 실제 실행 결과를 확인한 뒤에만 통과로 기록한다.

| 검증 축 | 최소 확인 내용 | 상태 |
| --- | --- | --- |
| 새 표현 | 수정 후 `newCases` 6건 모두 통과 | 확인 |
| 기존 정상 | 수정 전 21건 중 16통과·5실패 → 수정 후 21건 중 21통과·0실패 | 확인 |
| AND/OR | 알려진 개념·일반어 OR, 복수 개념 AND와 분기별 AND/전체 OR | 확인 |
| 근거 | quote가 원문 offset과 일치하고 후보의 근거 필드가 유지됨 | 확인 |
| 모음 통합 | 과학 자료 모음·재접속·메모 다운로드 및 검색 후보의 ID·제외 조건 유지 | 확인 |
| 경계 | 입력 길이·추론 후보 검색 제외·미지원 조건 안내 유지 | 확인 |

검증은 `server/query-regression-check.js`를 고정 fixture에 실행하고, 전후 JSON의 질의·기대·관측·경고를 비교하는 방식으로 남겼다. 새 표현·기존 정상·AND/OR·근거의 통과를 모음 통합 통과로 확대 해석하지 않는다.

## 완료 판단

구현 담당자의 회귀 실행과 수정 결과는 최신 `.2` 제품 코드 기준으로 통합됐다. 사람의 결과 확인 전에는 이 문서의 상태를 완료로 바꾸지 않으며, 과거 독립 검토의 13/16 결과나 sourceaudit21 `.1` 결과를 현재 독립 성능 수치로 재사용하지 않는다.

교사형 문장 문맥·프로그램 선호·관계 미확인 표시는 [R05 task](../Tasks/task-r05-teacher-language.md)에서 별도 관리한다. R05의 10개 사용자 예시와 precision fixture는 개발·회귀용이며 독립 최종 평가나 교육적 정답률로 해석하지 않는다.
